## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **调色正确性（硬性）** | 混色走「减色法查表 + 受控插值」，写死一张颜料混色表（红黄→橙、黄蓝→绿、红蓝→紫、任意色 + 白→浅、+ 黑→深），**不要直接用 RGB 平均**（RGB 平均下蓝 + 黄会得到灰，孩子会被教错）。混色函数纯函数化 + 单测覆盖全部两两组合。 |
| **可解性校验器（硬性）** | 写 `validateLevel()` 跑遍 **188 关全量**：断言 ①每关目标配色都能在给定调色板 + 调色次数上限内调出（做一次 BFS 搜索）②每个区域都有对应指令/编号③目标色两两之间可分辨（色差 ΔE 阈值）。**有一关不过就修数据。** |
| **线稿扩容** | 至少补到 12 幅线稿（新增 6 幅：小船 / 蝴蝶 / 城堡 / 火箭 / 大树 / 猫），全部手写内联 SVG，区域数 6–20 个不等，后段章节用区域多的。**原创造型，不许照搬任何 IP。** |
| **自由涂色沙盒（新增）** | 一个不计分的沙盒：任选线稿、任选颜色、无指令随便涂，支持撤销/重做与「清空」。作品缩略图存本地（key 走 `yiduo-yixing.` 前缀），最多存 12 张，满了提示替换。**沙盒不产星、不影响关卡进度。** |
| **撤销 / 重做** | 关卡内也给无限撤销（不扣星）；记录操作栈，`destroy` 时清空。 |
| **色盲友好** | 每个可选颜色除色块外**必须有中文色名文字**，指令里也用色名而非只用色块；限色章额外给每种颜色一个符号图例。 |
| **渐变章判定** | 「从最浅开始涂」的顺序判定用亮度值排序（写成纯函数 + 单测），相邻两级亮度差 ≥ 12% 保证肉眼可分。 |

## 七、视觉 · 建模 · 手感

- 点击区域填色有 120ms 的「颜料漫开」过渡，不是瞬间变色。
- 调色锅倒入两种颜色时看得见旋转搅拌，出色后锅口冒一颗小星。
- 完成整幅画：线稿边框发光 + 彩纸 + `api.play("win")`；涂错**不报错**，直接允许改。
- `prefers-reduced-motion`：关漫开与搅拌动画，直接换色。

## 八、手机 360px

- 画布区至少占屏高 55%；调色板横向可滑动，每个色块热区 ≥ 44px 且带色名。
- 小区域（如窗户）在 360px 下若小于 32px，提供双指放大到 2.5×。
- 指令文字一行放不下要换行不截断，字号 ≥ 14px。
