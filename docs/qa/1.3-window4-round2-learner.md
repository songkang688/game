## 二、盲区补充：三处密度短板写透 + 顶视留白基准

本窗没有棋牌 / 教育 / 养成三类，按派发口径把「补盲区」落在第 1 轮只给了一句话结论的
四个点上，把基准写成 C 档可以直接照着画的规格。学习来源仍是同题材头部作品的公开设计
结论（只记文字，未下载未截图未描摹）。

### 1. duo-vs-star：中景剪影带（背景层差 1）

平台对战题材基准是 2–3 层（天空＋中景剪影＋台面），远层铁律是「饱和度可高、颜色种类要少、
只留剪影」。本款九张场地全部缺第二层，平台像悬在一张纸前面。写透的规格：

- **几何**：剪影带一条，高度 ≈ `WORLD_H`×0.10–0.14（540 高下约 54–76px），
  基线贴 `WORLD_H`×0.76–0.80；上缘轮廓每屏 2–4 个起伏峰，单峰宽 ≥ `WORLD_W`×0.12，
  禁高频锯齿——360px 手机上整张世界要缩到约 1/3，密齿会糊成噪点。
- **颜色**：单色一次 path 画完，取 `stage.sky[1]` 加深 10–14%（`shade` 已有）；
  不描边、不加内部纹理。与天空底渐变的明度差 ≤12%（退居远景），
  与平台 / 角色层明度差 ≥25%（不抢前景）。
- **形状查表**（按 stageId）：云台广场＝圆顶云丘×3；摇摇岛＝远岛×2＋水平线；
  齿轮工坊＝厂房折线＋烟囱×2；弹簧糖乐园＝棒棒糖圆头×3；糖浆池＝糖山圆弧
  （糖浆水线以下不画，会被糖浆盖住）；风车高原＝矮丘＋远风车×1；冰湖＝冰脊折线；
  星梯＝远塔×2；终章＝城堡剪影。
- **动效**：0 通道，静态；soft 无差异；抖屏时跟世界层平移即可。
- **验收**：`art.test.ts` 断言九个 stageId 的剪影 path 序列非空且两两不同；
  360px 截图目检无锯齿噪点。

### 2. gold-hook：地表天空（装饰差 1 件）

矿工钩取题材基准是四层（天空地表 / 矿壁 / 矿物 / HUD）。本款矿下三层视差齐了，
地表天空 0 装饰，是全款唯一「越往上越素」的倒挂。写透的规格：

- **空间账**：地表带 y∈[0, ~110]（`PIVOT_Y`=52，双矿工站位 `PIVOT_X`±54），
  可用装饰区是矿工与绞盘之外的左右上角，右上还要躲 HUD。
- **内容**：两朵三瓣式慢云（`ellipse`×3，透明度 0.5，同 duo-rush `drawCloudPuff` 规格）
  ＋一件章节主题物，半径 ≈ `FIELD_W`×0.045 ≈ 21px，放 (0.82×`FIELD_W`, 48) 或左侧对称位。
- **冷暖分支**：`style.ts` 八套 pal 按 sky0 色相分三支——暖章＝太阳（圆＋径向光晕 2 停）；
  冷章＝月牙（双圆相减）；紫蓝夜章＝三粒小星（`drawIcon` 星形可复用）。
- **动效预算**：云 6px/s 慢漂、`calm` 定格；**主题物永远静态**——摆钩是全屏唯一的节拍器，
  天空不许出现第二个节拍和玩家的瞄准节奏打架。
- **对比红线**：装饰亮度不高于 sky0＋8%；全部收在地表带内，不进矿区。
- **验收**：`art.test.ts` 断言八套 pal 各产出非空天空装饰且冷暖分支序列可区分；
  `calm` 下两个 t 值云位相同。

### 3. monster-crisis：天空动效（动效通道差 1）

守家动作题材基准是 2–3 层，天空至少一条**低频**动效通道（云漂 / 星闪二选一），
但绝不与场内攻防抢戏。本款院内 `drawScenery` 六件装饰很精致，天上却是两朵定格云、
八章只换色相——「院内热闹、天上定格」的精致度断层。写透的规格：

- **云漂**：`drawSky` 签名加 `t`（秒）与 `motion`；两朵云 4–7px/s 相位漂移
  `(t*v+seed)%(w+80)-40`，两朵速度差 ≥1.5px/s（同速会像整张贴图在滚）；
  `!motion` 定格在 seed 初相，与现状等价。
- **主题物**：按 sky 明度分支——亮章＝小太阳（圆＋光晕，径向 2 停），
  暗章＝弯月＋4 粒定格星。院子圆盘占掉大半画面、天空只露边角，
  物件半径 ≈ 天空可见带高的 0.5，放 (0.86w, 0.1h) 附近，躲开顶部章节 chip。
- **亮度红线**：主题物与云的明度只比 sky 高一档（≤＋10%）——主场是院子与怪，
  天空是气氛不是内容。
- **验收**：`art.test.ts` 断言 `motion=true` 两个 t 值云 x 不同、`motion=false` 相同；
  亮暗分支序列不同。注意现有用例「天空是渐变加两朵定格白云」（`art.test.ts` 363）
  需同步改写成新契约，用例只增不减。

### 4. duo-arena：顶视「少而精」留白基准（本窗的参照系）

本窗唯一「密度差 0 且留白是设计」的款。把「怎么少而精」从一句话写成可检查的规则，
后续所有顶视 / 俯视款（含三款塔防的空地处理）横向对照都用它：

- **密度上限**：场内装饰 3–7 件/场（现状：云台 3 朵扁云、花田 7 粒微花，全部在带内）；
  装饰投影面积合计 ≤ 场地面积 8%。
- **位置纪律**：装饰全部 clip 在场地边界内（现状 `traceBoundary`＋`clip` 已做），
  避开中央约 60% 的活动带；不与目标物（金币 / 礼盒 / 迷糊泡）同色系。
- **对比纪律**：装饰透明度 ≤0.6（现状云 0.6、微花点到为止）；
  状态圈（呼吸 / 双环脉冲 / 星屑爆点）是唯一高对比动效——**留白的意义就是让状态圈独享注意力**。
- **动效预算**：场地装饰 0 动效通道，3 条动效全给角色与目标。
- **加料方向**：真想再加，只动边界（白绒边、花瓣圈——现状已有），不进场中央。

结论：duo-arena 是 9 款里「少而精」的正面参照系；它唯一的扣分项不在密度而在
事件飘字 emoji（见 R2-TOP2）。

## 三、横向一致性评审（9 款一起看）

先说像一家人的部分（有据可查）：光照口径九款统一左上 45°（A 档第 1 轮抽查背书：
duo-rush `drawCoinFrame`、duo-arena `drawKitCoin`、monster-crisis `bodyGrad(-0.32,-0.38)`、
sling-birds `bodyGrad(-0.35,-0.4)`、duo-vs-star `drawCharBody(-0.32,-0.38)`）；
描边 1.5–2px 口径一致；马卡龙软色板、圆润轮廓、腮红脸谱一脉相承。
家族感的裂缝集中在两类：**画布上残存的系统 emoji 字体**（谁用谁出戏）与
**款内精致度断层**（同一款里一半精致一半素）。最违和 5 款按违和度排序点名：

### 违和 1 · duo-rush —— 全窗唯一的「系统字体脸」HUD

- **违和在哪**：整条 HUD 是约 13 种 emoji 拼成的字符串一次 `fillText`
  （角色 emoji、❤️🤍、🪙、✋＋道具、🌿🌈、🤝）。九款同开时，其余八款的 HUD 图标
  都是手绘资产（gold-hook `iconCanvas` 手绘 HUD、garden-guard `drawPetalLabel` 花瓣币、
  duo-arena 星阶＋小花），只有它一行系统 emoji——跨设备字体形状不受控，
  和自家画布里精致的 2 头身跑者、8 帧旋转金币放在一起断层最大。
- **统一化建议**：即 R2-TOP1（第四节），资产全部现成：`drawMiniFace` / `drawHeart`
  补空心分支 / `drawCoinFrame` 静态帧 / `drawPowerIcon` 套 12px 圆底板，
  文字段与图标段分开画，保留 squeeze 挤压逻辑。

### 违和 2 · gold-hook —— 款内「越往上越素」的倒挂

- **违和在哪**：矿下三层视差＋矿脉＋微晶热热闹闹，抬头却是一片零装饰的纯渐变天；
  加上金块体表平涂（A 档 W4R1-05：全窗收集物家族里唯一无渐变成员），
  一款之内精致度两副面孔，和「九款金币 / 星星同一套渐变语言」的家族约定不齐。
- **统一化建议**：R2-TOP3（天空一件主题物＋两朵慢云，规格见第二节）
  ＋R2-TOP7（金块补 2 停渐变，与 `drawKitCoin` 全产品金币标准对齐）。
  两条同文件同批做，一次 PR 收掉。

### 违和 3 · monster-crisis —— 天上定格、院内精致的断层

- **违和在哪**：院内六件装饰＋环纹向心做得很足，天空却是两朵定格云八章不变；
  同窗 sling-birds 有九章远景、garden-guard 有十三章徽章，它的「章节感」弱一档。
  另有 A 档 W4R1-02（双英雄 16px 剪影 XOR 0%）严重项压着——家族里其余双人款
  （duo-arena 42%、gold-hook 30.6%）全部达标，它是唯一靠颜色记人的。
- **统一化建议**：R2-TOP4（云漂＋亮暗章主题物，规格见第二节）；
  W4R1-02 由 C 档按严重级先行（A 档已给最小改法：P2 换帽形＋围裙下摆差异化），
  我方无异议、不重复占位。

### 违和 4 · duo-vs-star —— 纵深最薄的一款

- **违和在哪**：九张场地都没有中景层，平台悬在「一张纸」前面；
  同为双人款的 duo-rush 四层视差、sling-birds 四层，对照下它的纵深垫底，
  首页九宫格一起看时最「平」。
