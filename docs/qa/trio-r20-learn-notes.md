### 2.3 结构性发现（配方级，进本文不占号）

1. **平板档媒体断点缺口**（U 系 546 处 @media 统计）：全库救济集中在 `max-width:420` 族与 `max-height:500` 档，**768×1024 / 1024×768 / 1180×820 几乎不命中任何档**，吃的是桌面默认布局。凡「默认布局总高 > 舞台高（1024×768 舞台 ≈662px）」的游戏平板横屏必切底（N-3/U-1 即例）。→ 修切底类伤时救济档一律用 **`max-height` 口径**（如 `(max-height:900px)`）而不是只写 500 档；监督主档不变（390×844 + 915×412），**1024×768 升级为修复必测第三档**（建议，监督表拍板）。
2. **l99 关内裁切链统一定性**（r18 只点了 `.l99-host`，本文补全）：`.game-stage--l99{overflow-y:hidden}` → `.l99-view{auto}` → `.l99-stage-wrap{flex:1;min-height:0}` → **`.l99-stage{overflow:hidden}`**。单关内容超高时 `.l99-view` 的 scrollHeight 不涨（被 stage 裁掉），表现为「**既裁切又滚不动**」（N-95/N-99/N-111/U-1 同一病理）。修法只有两条正路：钳内容显示高，或游戏内部自建滚动容器 + CTA 钉底（fixed 参照 N-75）。
3. **c337 绿档数字**收进干净清单：pinyin-train 390 地图全绿（CTA 43~87、tab 44、格 61–64、`.l99-view` 滚 730/793）；word-garden 915 关内选项 288~336 IN；landlord 模式芯片 66~110 IN；match-stars 1024 地图三芯片绿；sprout-defense/ocean-munch 全 canvas 款画布 IN（内部热区无头量不到，留人工抽验）。
4. **U 系「不要再犯」清单**（11 条）与「关卡排布规则」（6 条）质量很高，已在 `docs/ux-iteration-playbook.md`（在途），**合入后直接引用**，本文不抄——若该分支最终不合，下轮学习员把两节搬进 trio 笔记。
