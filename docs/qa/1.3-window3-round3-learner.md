## 二、风格基线文档编写说明（正文见 `docs/qa/1.3-window3-style-baseline.md`）

- **路径**：`docs/qa/1.3-window3-style-baseline.md`（按窗口命名,不占用全局 `docs/qa/1.3-style-baseline.md`,避免与其他窗口撞文件）。
- **结构**：七大类 —— ① 粉彩色板 token 表（外壳近白粉紫家族 7 款 + 玩法主色 11 组）;② 描边宽度档位（标准/等比/厚底/下限保护四档）;③ 左上 45° 光照约定（渐变亮心/高光件/SVG 平涂/对角提亮/投影落右下五手法,参数区间量化）;④ 动效三段式（7 款模板逐款给毫秒）与 reduced 退化三铁律;⑤ 金币三件套规格（标杆件 `drawCoinFrame` 全参数 + LOD 金色恒定 + 同族件 + 拾取反馈）;⑥ 双人剪影差异化手法（6 款逐款 + 「身份位放头顶那一笔」总结）;⑦ 2.5D 纵深三种做法（地面透视/多层视差/落影缩放,附密度与留白附则、om high 档禁令、three.js 禁令）。
- **可溯源性**：全文 60 余条规范条目,每条注明「文件 + 函数/常量名」（如 `gomoku/art.ts` `paintStone`、`rainbow-run/view3d.ts` `PARALLAX_LAYERS`）;编写过程即逐款只读走查,所有引用的类名/函数名/参数值均在终态代码上二次核实（含 `.hh-wrap`/`.hp-wrap` 类名、`drawPad` 完美圈段等易错引用）。
- **要点摘录**（详见正文）：
  1. 外壳近白粉紫渐变七款同族,棋类姊妹款按钮强调粉 `#C84483→#AD3A72` 逐字共用;
  2. 「按颜色做判断」的信息必须配形状第二通道（四色卡角标/六星六形/四列符号）;
  3. 小于 40px 图元不指定渐变底,平涂 + 左上 gloss 即可（第 2 轮对账修订口径固化）;
  4. reduced 三铁律:功能提示只静态不消失、装饰动效冻结层还在、时序压 1 帧状态机不变;
  5. 金币 LOD 退化态也只许用金五阶 token（机器钉子锁死的「金色恒定契约」）;
  6. 双人身份信息优先挂「头顶那一笔」,同体型双人必须加脚圈色环兜底,形色双通道齐备;
  7. 密度上限=「玩家目光该在哪」,加密度只许材质精度/事件仪式/剪影饰层三选一。
