## 三、这一轮的取证口径（不认自述，全部自己重跑）

- **真机** = `npm run build` 产物 → `vite preview` → **Chrome headless（`--headless=new`）+ Node 22 自带 `WebSocket` 直连 CDP**，
  **零新增依赖**；一次性探针落在 `/tmp/w5r3/`，**跑完即删，0 字节进提交**。
- **进关方式**：种 `yiduo-yixing.l99.<id>` 星级存档让第 N 关成为 `furthest`，再点地图上的「继续 第N关 ▶」，
  走的是**玩家自己那条路**，不是内部 API。
- **「点不着」只认一条**：`document.elementFromPoint(元素中心点)` 拿回来的是**它自己或它的后代**。
  去掉 `hit.contains(el)`（那会把「点到的其实是壳层祖先」放成假绿）；**禁止 `el.click()`** 判热区可达性。
- **裁切线按 padding box 算**，并沿**整条祖先裁切链**求交集：
  `rect.left+borderLeft … +clientWidth` / `rect.top+borderTop … +clientHeight`
  （`.game-stage` 有 `border:4px`，按 `rect.bottom` 会少算 4px）。
  同时判「有没有可滚祖先能把它救回来」——救得回来的记 soft，救不回来的才算硬裁。
- **教育正确性**：另写一套判据**独立复算**，**绝不调用被测代码算答案**。
  钟面只读 SVG 两条指针的**几何角度**，形状只读 `<polygon points>` / `<rect w,h>` 的**几何**，
  一律不读 `data-kind` / `aria-label`（那是读答案，不是算答案）。判据算不出就**弃权**，据实登记。
- **`destroy` 泄漏**：进出 10 次，读 `window`/`document` 残留监听、残留 rAF、残留 timer、未关闭 AudioContext。
