## 现状审美评测（第三节自查结论）

1. **鱼是 emoji（核心问题）**：`drawSwimmers` 就是 `g.fillText(s.fish.emoji, px, py)`
   加 0.55 透明度——鱼群是一排半透明字符；游动只有匀速平移 + 正弦上下漂 3px，
   speed 为负时 emoji 也不转向、没有摆尾、深水鱼和浅水鱼画法完全一样（无饱和度
   衰减、无轮廓虚化）。拉扯中的 `hooked.emoji`、挂钩「🪝」、岸上的「🧒」「🪣」全是
   emoji 平涂。
2. **`drawWater` / `drawShore` 自查**：水体是天空两停渐变 + 五条 `LAYERS[i].color`
   纯色横条 + 天色 tint，只有一条白色正弦细线当水面；无波光带、无光柱（仅夜晚
   一条月光柱）、无岸水交界浪花、无气泡。岸是两块纯色矩形 + 一条直线当鱼竿。
3. **`drawLine` 自查（确认为准直线）**：单段 `quadraticCurveTo`，空中与水下同色不分段、
   无入水折射断点；浮标是「🎈」且画在钩深处而非水面，上钩「点头」只是整只气球
   跟着 `hookDepth()+1.2m` 往下画，提示弱、无涟漪。
4. **`drawAim` / `drawBand` / `drawRuler` 自查（功能件，保住）**：观感确是 debug 风——
   纯白虚线 + 纯白刻度 + 直接 `fillText` 的文本，无木质 / 卡片质感；蓄力量只有 DOM
   进度条，画布上的鱼竿不弯。
5. **收获瞬间自查**：`landFish()` 之后 `phase="show"` 只换按钮文案与 tip 文本 +
   `.fss-show` 白色浮层一行字；画布上没有任何演出——无鱼跃出水、无水花、无星屑、
   稀有鱼与普通鱼毫无区别；展示行也不是木牌样式。

## 改造方案（对应规格四 / 四·补一 / 四·补二 / 四·补三）

- **新增 `src/art/kit/fishArt.ts` + 单测**（kit 里没有鱼类能力，按「谁先用到谁新增」落
  自己的文件；已有 `fruit.ts` / `caterpillar.ts` / `juice.ts` / `sparkle.ts` / `jigsaw.ts` /
  `icons.ts` 只 import 不修改）：7 种参数化矢量鱼 spec（纺锤宽高比 0.9–1.6 / 叉尾·圆尾·
  扇尾 / 条纹·圆点·无纹·金鳞四选一），五道工序：纺锤身三停渐变（背深腹浅）→ 尾鳍 +
  背鳍 → 花纹层（< 15px 省略）→ 圆眼 + 高光 + 微笑嘴 → 摆尾 ±14°（相位 =
  `x × 0.05 + speed × 2`）+ 朝向 `scaleX(±1)`；`depthFade` 深水饱和度 −30%、alpha 0.7。
- **新增 `src/games/fishing-star/visual.ts`**：`fsh*` 配色 token 九枚（与四·补一逐字一致）、
  动效时序常量（波光 5200/6800ms、气泡 ≤6 颗 4s、涟漪 600ms 窗口内加密 2 倍、浮标
  点头 3px/160ms、鱼跃 240ms、水花 5 瓣 320ms、稀有金光 260ms）、图层序常量（①天空
  →⑪HUD）、钓线两段分割（入水点折射错位 2px）、钓竿弯曲量映射（与力度逐点一致）、
  涟漪 / 水花 / 鱼跃 / 星屑的 FX 池（`destroy` 一把清）、reduced 全套映射。
- **`index.ts` 只动绘制**：`render` 重排成规格图层序；鱼群自绘替换 emoji（游动坐标
  演算三行原样保留，深水先画浅水后画）→ 水体三层（波光网 / 光柱 / 深蓝渐变 + 浪花
  白边 + 气泡）→ 钓线两段 + 自绘红白浮标 + 入水涟漪（上钩窗口加密、浮标点头 160ms）
  → 收获仪式（鱼跃弧线 240ms + 水花皇冠 + 星屑 + 稀有金光,reduced 瞬移）→ 岸上
  场景（Q 版草帽小人拉杆后仰 8° + 草丛 + 小桶露鱼尾 + 远山云两朵）→ 木尺刻度 /
  木牌展示卡 / HUD 卡片化 → `destroy` 清 FX。
