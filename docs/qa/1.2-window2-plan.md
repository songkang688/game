## 四、每格交付口径

1. `meta.ts` 纯数据、不 import 玩法；`index.ts` 顶部 `export { meta } from "./meta"`，导出 `mount(api): { destroy }`。
2. `meta.modes` / `meta.platform` 照实现填（平台字段按第 1 步文档形状写在自己的 `meta.ts` 里，不改窗口 1 的平台文件）。
3. 闯关走 `level99.ts` 的 `mountLevelGame`，章节和恒等 188，`assertTotal(chapters, 188)`。
4. 无尽记 `save.recordEndlessBest`；存档 key 只增不改。
5. 音效只用 `api.play("tap"|"win"|"oops"|"coin"|"pop"|"meow"|"jump")`。
6. 双人键位：朵朵 `WASD+F+G`，星星 `方向键+L+K`，`Esc` 暂停，手机有触屏等价。
7. `destroy` 拆掉全部监听 / timer / rAF / AudioContext。
8. 新游戏每款 ≥ 15 个单测，升级每款新增 ≥ 8 个单测；用例总数只增不减。
9. 禁止 three.js、CDN 字体、外链音源、统计 SDK、Socket；离线可玩。
10. 商标黑名单 0 命中（含代码注释）；无血无死亡；失败只鼓励；360px 文字不溢出。
