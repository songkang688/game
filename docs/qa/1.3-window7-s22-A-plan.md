## 现状审美评测（第三节自查结论）

1. **牌面是便签（核心问题）**：`cardFaceHTML`（index.ts 310–327 行）只有左上角标
   （数字 + 花色字符）+ 右下同一个花色字符放大；大小王直接一个 🃏 emoji + 竖排
   「大 / 小王」（315–317 行）。没有边框装饰、没有中心图案、没有牌面身份。
2. **手牌扇形底子好但无层次**：`fanLayout`（fan.ts 47–67 行）两端下沉微转是好底子
   （保住坐标算法一个数不动）；但 `.ld-card` 只有一层泛投影（172 行），牌与牌之间
   没有右侧层叠阴影；选中态只是 `lift = cardW*0.42` 位移 + 换描边色（716/739 行），
   没有「可出牌」抬升与底光；轮到自己时手牌区没有任何呼吸提示。
3. **出牌轨迹半成品**：1.2 已有 `anim.ts` 飞牌状态机（180–240ms 弧线 + 旋转，
   `tableShown` 落桌才显示，比任务书预期好，全部保住）；但落桌无软影一闪、
   炸弹 / 王炸只有一行 say 文字 + 音效（966 行），无桌面震动与星屑环；
   上一手是 `innerHTML` 直接替换，无渐隐让位；叫分「当前 X 分」是死胶囊无翻牌感。
4. **身份标识弱**：`renderFoes`（606 行）/ `renderMeHead`（743 行）是文本 + emoji
   头像（团团🐰 / 圆圆🐼）；地主身份只有一颗 11px 文字胶囊 `.ld-role-l`
   （151–153 行），头像上没有任何徽章，扫一眼分不清谁是地主。
5. **桌面无氛围**：`.ld-wrap` 是粉白渐变（141 行），完全没有牌桌感；按钮是圆角
   矩形；`ldc-hintline` 是淡紫方块无气泡感；`renderKeys` 纯文本行；遮挡幕
   `.ld-cover` 防偷看逻辑好（689–704 行「不渲染手牌」，保住）但视觉是一块白幕。

## 改造方案（对应规格四 / 四·补一 / 四·补二 / 四·补三）

- **新增 `src/art/kit/cardArt.ts` + 单测**（按「谁先用到谁新增」落自己的文件，
  不改别人的 kit 文件）：四枚自绘花色 SVG（桃 / 方暖 `#E85D75`，黑桃 / 梅花冷
  `#4A5A8F`，每枚左上小高光）；朵朵（花冠 Q 版半身）与星星（星冠 Q 版半身）
  原创王牌立绘 SVG；四角星星屑 SVG（DOM 游戏用不了 canvas 版 `sparkle.ts`，
  星花剪影口径与它对齐）。
- **新增 `src/games/landlord-cards/visual.ts`**：`--ld-` 配色 token 与动效时长
  自定义属性（单一来源，测试逐字核对）、z-index 图层序（毛毡→对手→出牌区→手牌→
  飞牌→星屑→按钮提示→遮挡幕）、牌面七道工序 HTML 生成（窄牌 < 48px 省略中心浮雕）、
  可出牌集合（只读 `playableGroups`）、身份徽章 SVG、炸弹震动 / 呼吸微光的
  reduced 映射、星屑环 HTML。
- **`index.ts` 只动渲染**：毛毡桌面 + 木沿 + 中央淡纹圆环 → 牌面七道工序替换便签牌 →
  手牌层叠阴影 / 可出牌抬升 6px + 底光 / 轮到自己呼吸微光 → 落桌软影一闪 +
  炸弹震动 + 星屑环 + 上一手渐隐 + 叫分翻牌小卡 → 地主皇冠 / 农民草帽徽章 →
  遮挡幕幕布化（布褶 + 「请交给 XX」缎带 + 星星，防偷看逻辑零改动）→
  按钮胶囊化 / 提示气泡 / 键位卡片 → reduced 全接线 → 计时全走 `later()`，
  destroy 原有清理链路覆盖。
- **新增 `visual22a.test.ts` ≥ 12 个视觉用例**；既有玩法测试文件零改动。
