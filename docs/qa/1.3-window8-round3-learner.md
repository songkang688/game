## 二、风格基线固化（正文单独成文件）

- **文档路径：`docs/qa/1.3-window8-style-baseline.md`，条目 39 条**（B-01~B-33、B-34a/b/c、B-35~B-39），八节：粉彩色板 token 表（5 条）/ 描边宽度档位（5 条）/ 左上 45° 光照约定（4 条）/ 动效三段式与 reduced 退化规则（9 条）/ 金币三件套规格（5 条）/ 双人剪影差异化手法（5 条）/ 2.5D 纵深三种做法（3 条）/ 附则工程纪律（5 条）。
- **编写说明**：每条注明溯源「文件 + 函数/常量」，全部出自本窗 12 款与本窗新建的 kit 件；口径与视觉宪法对齐（宪法定底线，基线给库内实证样板），冲突时以宪法为准。文档尾注维护规则：溯源失效（函数被删/改名）当轮要么修文档要么修代码，不许悬空。
- **要点摘录**（编号见基线正文）：
  - 色板：全库 7 token（`palette.ts PASTEL`）+ 题材色下沉六张样板表；装饰透明度上限 .12（B-01/03/05）。
  - 描边：主轮廓 2px / 次级 1.5px / 细节 0.8–1.4px 三档；描边色 = 主色 shade(−45) 推导；DOM 格子描边走 box-shadow inset 不占几何（B-06~B-10）。
  - 光照：渐变一律 135° 左上受光；高光斑左上 −24°；按钮顶光带 22% 钮高；花瓣「瓣根深→瓣尖亮」（B-11~B-14）。
  - 动效三段式：常驻微动 ≤2 处 / 交互反馈（60ms 回弹、节拍收缩环）/ 答对仪式 900ms 一次性；reduced 四规则——装饰全停、功能提示静态化不消失、粒子计数归零、位置判定照常（B-15~B-23）。
  - 金币三件套：≥2 停渐变 + 高光 + 描边/落影，三样缺一即打回；硬质（gem）/ 发光（glowStar）/ 软质（paintBlob）/ 同页多铺（stickers 双色分面防重复 id）四张样板（B-24~B-28）。
  - 双人剪影：三通道叠加 + 16px 灰度 ≥15% 量化线 + 镜像头饰两笔 + 无角色款「每色绑一形」（B-29~B-33）。
  - 2.5D 三做法：地面透视（perspective+rotateX / 0.85 等比收窄）、多层视差（2–3 层）、落影缩放（shadowW 姿态表 + TEAM_SCALES 深度缩放 + 2px 底部暗边）（B-34a/b/c）。
