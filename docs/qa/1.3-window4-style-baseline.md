## 二、描边宽度档位

**口径:1.5–2px 起步、随半径缩放、永不小于 1px**;描边色取本体色加深(不是黑)。

| 档位 | 溯源 | 规则 |
| --- | --- | --- |
| 角色 / 怪物本体 | `garden-guard/art.ts` `drawMonsterSprite`(611):`lineWidth = max(1.5, r * 0.09)`;`monster-crisis/art.ts` `drawHero`(194):固定 2.6px(`HERO_R` 恒定,不必缩放) | 半径会变的按 9% 缩放、下限 1.5px;半径恒定的可取 2–2.6px 定值;描边色一律 `shade(bodyColor, …)` 深同族色,不用黑 |
| 小图标 / HUD 件 | `duo-rush/art.ts` `drawHeart`(83,空心分支 99):`lineWidth = max(1.2, r * 0.2)`;`sprout-defense/index.ts` 星弹(2007):`max(1, cell * 0.02)` | 小件下限放宽到 1–1.2px,但必须有 max 兜底,禁纯比例(小屏会消失) |
| 装饰性内环 / 压印 | `duo-arena/art.ts` `drawKitCoin`(366):内环 `max(1, r * 0.13)` | 内部结构线可以更粗(13%),半透明(`hexAlpha` 0.85)不抢轮廓 |

## 三、左上 45° 光照约定

**全窗统一:光从左上来,渐变亮斑圆心取 (−0.32~−0.35r, −0.38~−0.45r),体积感靠径向 /
线性渐变,平涂退休**(第 2 轮 A 档抽查背书,九款口径一致)。

| 款 | 溯源 | 参数 |
| --- | --- | --- |
| monster-crisis | `art.ts` `bodyGrad`(46–48) | `createRadialGradient(x−0.35r, y−0.45r, 0.12r → 1.15r)`,亮档 `shade(color, 1.18)` |
| duo-arena | `art.ts` `drawKitCoin`(354–357) | 币面 `createRadialGradient(x−0.35r, y−0.42r)` 三停:coinLight → coinMid → coinDeep |
| garden-guard | `art.ts` `drawMonsterSprite`(606–608) | `createRadialGradient(mx−0.35r, my−0.4r, 0.15r → 1.25r)` |
| sling-birds | `art.ts` `drawBirdArt`(150–152) | `createRadialGradient(−0.35r, −0.4r, 0.2r → 1.15r)`,亮 +26 / 暗 −14 |
| duo-vs-star | `art.ts` `drawCharBody`(502 起) | 同族参数 (−0.32r, −0.38r) |
| gold-hook | `art.ts` `drawOre`(533–536) | 矿物用**线性**渐变模拟同一光向:`(x−0.8r, y−0.9r) → (x+0.7r, y+0.9r)`,lit → fill 两停 |

推论规则:落影永远在右下 / 正下(与光向相反);高光弧 / 亮斑一律画左上,
谁把高光画到右下谁破功。

## 四、动效三段式与 reduced 退化规则

### 三段式(演出有铺垫、有高潮、有收尾,不瞬变)

| 例证 | 溯源 | 三段 |
| --- | --- | --- |
| duo-arena 出手圈 | `index.ts` grabPhase 与出手圈绘制(1189–1201) | 前摇=淡橙细圈(`rgba(255,210,150,.7)`)→ 生效=深橙加粗 + 外圈波纹(`rgba(255,150,60,.95)`)→ 后摇=灰紫淡出;攻略照此措辞 |
| sling-birds 命中链 | `index.ts` 倒塌结算(775–776)、方块受击(1375–1377) | 变形(stress 歪一下抖一抖)→ 倒塌 → 结算,段间留 0.8s 不瞬变;r3 又在 0.8s 窗口里塞进逐只腾弧的胜利小仪式(`art.ts` `winLeapPhase`,966),同一节拍器不另开时钟 |
| gold-hook 金块扫光 | `art.ts` 扫光段(665–667) | 2 秒一趟的斜向扫光只给金块家族(`GOLD_KINDS`,476),是「周期动效当识别通道」的样板 |

### reduced / calm 退化规则(三轮验收的强制口径,新动效一律带分支)

**总则:功能位移保留,装饰动画停在有代表性的一帧;不许直接删画面。**

- **周期漂移 → 定格初相**:`gold-hook/art.ts` `drawSkyDecor`(887 起)云 6px/s 慢漂,
  `calm` 定格;`monster-crisis/art.ts` `drawSky`(797 起)签名带 `t`/`motion`,
  `!motion` 云停在 seed 初相。
- **循环动画 → 静态代表帧**:`sprout-defense/art.ts` `drawBugBody`(875 起)`calm` 时
  翅膀停在张角 0.8(不是收拢——静态剪影仍要认得出会飞);`sling-birds/index.ts`
  `drawBeans`(1448–1450)胜负小舞 `!reduceMotion` 才跳。
- **姿态倾斜 → 归零、位移照旧**:`duo-rush/index.ts` 换道侧倾(1010–1011)
  `laneTiltDeg(..., calm)` reduced 下归零,换道位移不受影响。
- **周期扫光 → 静态高光**:`gold-hook/art.ts` 扫光相位(666–667)`calm ? 0.55 : (t…)`,
  停成一道固定斜高光,金块识别通道不丢。

## 五、金币三件套规格(金物家族通用)

**三件套 = ①左上受光的金渐变体 ②深金描边 / 内环 ③独立高光层。**
全窗基准件是 `duo-arena/art.ts` `drawKitCoin`(346 起,注释自称「全产品金币标准」):
侧面厚度 + 金渐变币面(coinLight → coinMid → coinDeep)+ 深金内环 + 五角星压印 + 左上高光弧。

| 成员 | 溯源 | 与基准的对应 |
| --- | --- | --- |
| duo-rush 8 帧旋转金币 | `art.ts` `drawCoinFrame`(163 起) | 三件套 + 旋转帧;HUD 用静态正面帧(`coinFrameSpec(0)`) |
| gold-hook 金块 | `art.ts` `drawOre`(533 起) | 渐变(lit→fill)+ 描边落影 + 扫光当独立高光;石头系刻意压暗保持金石明度比 ≥1.25(r2 W4R2-07,`ORE_SKIN` 有钉住测试) |
| duo-vs-star 金星 | `art.ts` `drawGoldStar`(96 起) | r2 补齐独立白高光第三层(9dbd0f8) |
| sprout-defense 星弹 | `index.ts` 子弹段(1994–2007) | 径向金渐变 + `#c9861b` 描边,与 `art.ts` `drawClearStar`(405)三色同族 |
| candy-swing 金星 | `art.ts` `drawGoldStar`(196 起) | STAR_CORE 渐变 + STAR_RIM 描边 |

红线:金物家族禁平涂(三轮清零的就是平涂成员);「亮出来的东西」(金 / 星 / 钻)
必须比同屏非收集物亮一档,色弱下靠明度差仍可分。

## 六、双人剪影差异化手法

**法则:色 + 形双通道,缺一不可;形状差必须长在轮廓外才进 16px 剪影**
(画在身体内部的徽章 / 花纹在 16px 下全部糊掉——三轮验收反复验证)。

| 款 | 溯源 | 双通道做法 |
| --- | --- | --- |
| duo-rush | `art.ts` `drawRunnerSprite`(469 起) | P1 花苞裙摆 / P2 星呆毛披风;r2 呆毛放大一档(星呆毛 headR×0.32→0.5,花苞轨道 0.16→0.24,d22912c)才在 16px 网格下站稳——**轮廓外配饰要按最小显示尺寸反推比例** |
| monster-crisis | `art.ts` `HERO_SKINS`(143)+ `drawHero`(163 起) | 三层差:帽形(P1 扁贝雷歪戴 / P2 尖顶帽 + 帽尖星揪揪,帽形直接进剪影)+ 帽徽(flower / star,色弱通道)+ 围裙下摆(圆摆 / 锯齿摆,重叠区灰度纹理);r2 修复 W4R1-02 的成果,art.test 有 P2 帽尖 < −1.4R 的几何钉 |

| duo-arena | `art.ts` 角色体(`duoBack` 花瓣体 vs 切面星体) | 非蛋形轮廓本身就是通道:五瓣花剪影 vs 多面星剪影,16px 稳 |

## 七、2.5D 纵深的三种做法

### 1. 地面透视(针孔投影)

- 溯源:`duo-rush/view25d.ts` `project()` / `depthScale()`(102–119,`CAM_DEPTH = 34`)
  + `index.ts` `drawRoad`(857 起,车道虚线近长远短)。
- 规则:`scale = CAM_DEPTH / (CAM_DEPTH + z)`;CAM_DEPTH 按「障碍要在最后 2–3 秒稳稳变大」
  反推,不是拍脑袋;地平线 / 落地线比例(`HORIZON_RATIO` 0.32 / `GROUND_RATIO` 0.97)一起进常量。

### 2. 多层视差(镜头动 / 世界动时的层速差)

- 溯源:`gold-hook/art.ts` `drawParallax`(751,矿下三层:远洞穴钟乳石 / 中矿层微晶 / 近岩台,
  随绳长微移);`sling-birds/art.ts` `drawMidground`(1009,中景剪影随 `midShift` 微移);
  duo-rush 四层背景(天体云 0.03 / 远山 0.06 / 近山 0.16 / 近景剪影 0.26 视差系数,`index.ts` 810 起)。
- 规则:越远的层速度系数越小、颜色种类越少、越接近纯剪影;**镜头不动的款不硬造视差**——
  静态单色远景带即可(`duo-vs-star/art.ts` `drawMidgroundBand`,1052:sky[1] 加深 12%、
  一次 path、0 动效,r2 补层的做法)。

### 3. 落影缩放(高度写进影子)

- 溯源:`duo-rush/index.ts` 跑者影子(1014–1017):`base × 0.42 × (1 − jumpArc × 0.4)`,
  跳得越高影子越小;`garden-guard/art.ts` `drawMonsterSprite`(562–571):飞怪身体抬升
  `lift = 0.85r + sin` 而影子留在地面且缩小(0.9r → 0.55r)、变淡(0.14 → 0.1);
  `sprout-defense/art.ts` `drawBugBody`(899–902):影子固定画在 `groundY`,飞虫身体悬空
  自然拉开「身影分离」。
- 规则:影子永远贴地、椭圆、半透明深灰(`rgba(58,58,74,…)` 族);悬空高度只改影子的
  「大小 + 透明度」,不改影子位置——这是最便宜的高度语言。
