### R2B-1 · `dark-chess` 双人同屏：一人一个光标，两套键各管各的

**先红**：新开 `src/games/dark-chess/duo.test.ts`，照双人同屏那两个座位摆一盘残局，轮到星星时按朵朵的键：

```
AssertionError: 朵朵的 D 把星星的光标拨走了: expected 1 to be 0
AssertionError: 朵朵的 F 替星星把这一手下掉了: expected 1 to be 0
```

—— 和测试员写的「按 D / S 光标跟着动、按 F 直接替星星落子」逐字对得上。

**修法**（`src/games/dark-chess/view.ts`，照窗口 2 第 1 轮包 A 在 `junqi-camp` 上的 `PA-JQ-1` / `PA-JQ-2` 那一笔）：

- `cursor` 一个变量拆成 `cursors: Record<Side, number>`：**朵朵从左上角（0）起、星星从右下角（31）起**，谁也拨不走谁的。
  屏幕上只画一个光标 —— `activeSeat()` 说了算：轮到谁画谁的，电脑回合里画留在原地的那位真人的。
- `onKey` 从「一串 if 里混着两套键」改成两张明确的键表：
  `DUO_MOVE`（`w/a/s/d`）→ 永远走 `"duo"` 这个座位，`STAR_MOVE`（四个方向键）→ 走 `starSeat`；
  `f` / `g` 归朵朵，`l` / `k` 归 `starSeat`。
- `starSeat` 是这一份的关键：**双人局里它是 `"star"`，单人局里它就是 `"duo"`** ——
  所以单人时方向键与 `L` / `K` 仍旧是朵朵的别名，老键位一条都不丢。
- `clickCell(i, side)` 加一道闸：`side !== state.turn` 直接返回，连光标都不挪。
  点棋格走的是 `activeSeat()`，所以鼠标 / 触摸这一路的行为一个字节没变。
- `cancel(side)` 抽出来：不是当前该走的那一方，取消键碰不着别人选中的子。
  顺手把「取消选择」按钮接到 `board.cancel()` 上（以前它只 `refresh()`，其实并不真的取消），
  双人同屏时按钮上写的是轮到那一位的键（`取消选择 (G)` / `取消选择 (K)`）。

**回归**（8 条，`dark-chess/duo.test.ts`）：

### R2B-2 · `hop-pads` 幽灵对战：两边用同一把尺，高手不再和大师同分

**先红**：新开 `src/games/hop-pads/versus.test.ts`，让「一路踩圆心、站满 16 座就冻结」的满分玩家去对同一条台序上的幽灵：

```
AssertionError: 第 1 局幽灵比玩家多站了几座: expected 18 to be 16
AssertionError: 第 1 局 hell 幽灵反超了踩满圆心的玩家: expected 230 to be >= 270
AssertionError: 第 1 局 hell 没比 expert 高: expected 270 to be > 270
```

三条红分别对应测试员记的三件事：座数对不齐、满分玩家必输、高手与大师同分。

**修法一：口径对齐 —— 幽灵也按「站满 16 座」收**（`src/games/hop-pads/ai.ts` 的 `playGhost`）

`for (let i = 0; i < hops; i++)` 改成 `while (run.hops < hops)`。
`hops` 这个参数从「起跳多少次」变成「**站满多少座**」，和玩家那边 `run.hops >= goal` 冻结是同一句话；
弹簧台白送的那一跳现在两边都算进座数里，谁也不多占。选这一种而不是「玩家也按起跳次数收」，
是因为屏幕上顶栏写的一直是 `⭕ N / 16 座`，改玩家那一侧等于把 HUD 上的话改掉。
`MATCH_HOPS` 的注释里把这件事写死，免得以后再有人把两个「16」理解成两回事。

**修法二：高手与大师拉开 —— 加一层确定性的「故意打偏」**（`TIER_SLIP_EVERY` / `slipPower`）

`TIER_NOISE`（±25% / ±12% / ±5% / ±1.5%）是规格第十节写死的四个数，**一个没动**；
问题在于噪声是**按理想力度按比例**加的：完美圈的容差折算成力度约 0.06，
高手那 ±5% 在常见力度上最多偏出 0.025 —— 整个落在完美圈里，所以高手与大师跳跳都完美、逐局同分。

所以另加一层和噪声正交的东西：**每隔几跳故意往台沿方向偏一点**
（`TIER_SLIP_EVERY = 新手 3 / 普通 5 / 高手 9 / 大师 0`，大师一次都不偏，「跳跳完美」这句话仍旧成立）。
偏多少不是拍脑袋定的常数 —— 台子有大有小、移动台还在滑、力度一改飞行时长跟着改，
所以 `slipPower()` 直接量「这个力度落下去离台心多远」，再**二分**到「完美圈边 → 台沿」那段路的 45% 处；
解出来的落点要是没能同时满足「出了完美圈」和「没出台面」，就当没偏过，原样打准
（余量不足 6 个世界单位的小台子也直接跳过这一层）。所以这一层**只掉分、不掉人**。

改前 / 改后，对战前八局（满分玩家 = 一路踩圆心站满 16 座；`分数/站住的座数`，`F` = 掉下去）：
