## 一、题材密度基准表与剪影经验（学习结论）

**口径**：密度记「背景层数 / 一屏装饰物件数 / 动效通道数」三个数。基准取的是成熟小游戏平台同题材头部作品的**中位水平**，不是最满的那一档——本库是粉彩萌系，密度目标是「基准的八成 + 留白」，不是照搬「满」。剪影经验只记「缩到 16px 后靠哪一笔认出」的结论文字。

| 题材（对应本窗款） | 密度基准（背景层 / 装饰数 / 动效通道） | 剪影经验（16px 靠什么认出） |
| --- | --- | --- |
| 2048 数字合成（merge-2048） | 2 层（渐变底 + 极淡纹理）/ 3–5 件（框饰、角标）/ 4 通道（合并弹跳、出块缩放、飘分、里程碑） | 头部作品全靠**色阶单调递增 + 数字粗字重**；聪明的做法是加一条「非颜色的段位通道」（角标 / 皇冠），16px 下数字糊掉时角标还在 |
| 扫雷（mine-garden） | 2 层（底色 + 格纹）/ 3–4 件（HUD 表情、边框饰）/ 3 通道（翻格波纹、插旗弹跳、胜利礼花） | 旗的**三角旗面**是第一剪影，杆可以糊、旗面必须是实心三角；数字靠「色相 + 底下的辅助记号」双通道才稳 |
| 数独（sudoku-petal） | 1–2 层（纸面 / 木框）/ 2–3 件（角落静饰）/ 2–3 通道（错误抖动、行列完成波、通关礼花） | 数独没有「角色」，剪影经验在**冲突标记**上：只变红不够，头部作品都配一个形状（叉 / 抖动），色弱也认得出 |
| 格子迷宫吃豆（dot-maze） | 2 层（深底 + 星点/网格微光）/ 满屏豆即装饰 / 4 通道（豆闪、能量脉动、变身闪帧、得分飘字） | 主角剪影 = **缺一角的圆（嘴楔）**；只要嘴楔在，加呆毛、加眼睛都不破坏辨识。幽灵剪影 = **圆顶 + 裙边齿**，齿数改 3 或加耳朵就能既认得出「幽灵」又不像官方四鬼 |
| 落体合成大果（fruit-stack） | 3 层（天空渐变 + 云/远景 + 容器）/ 4–6 件（云、警戒线标、进度树）/ 5 通道（爆汁粒子、扩散环、飘字、震屏、下一颗预览动画） | 果子全是圆，头部作品靠**梗 + 叶打破圆轮廓** + 表情统一；16px 下「圆 + 顶部一点绿」就是果，纹理（条纹/籽点）是 32px 以上才起作用的第二通道 |
| 8 球台球（pool-stars） | 3–4 层（木框 + 库垫 + 台呢渐变 + 定位钉）/ 6–8 件（六袋口、钻石钉）/ 3 通道（瞄准线、进袋星光、力度条脉动） | 花色球剪影 = **白底色带**；纯色球 = 满色 + 白圈号码。本库用「花印 vs 星印」替号码，极小尺寸要有**退化形**（圆点 vs 菱形点），这是行业里最稳的做法 |
| 军棋（junqi-camp） | 3 层（板底 + 铁路/公路网 + 地形件）/ 8–12 件（行营、大本营、山）/ 3 通道（走子滑动、对撞翻子、胜利升旗） | 棋子是「色块 + 字」，不认字的孩子靠**军衔记号可数**（星/杠/点的个数）认大小；双方剪影要靠**面板形状或角标**分，光换底色 16px 下必糊 |
| 国际象棋（chess-garden） | 2–3 层（棋盘格 + 外框饰 + 角饰）/ 4–6 件（篱笆、花盆）/ 2–3 通道（选中高亮、吃子飘物、将杀演出） | 棋子高矮阶梯（王最高兵最矮）是第一剪影；每种棋子**头部那一笔**（冠十字 / 花瓣放射 / 垛口三齿 / 马头折线 / 尖树 / 圆帽）承担 16px 辨识，身体可以糊 |
| 翻子暗棋（dark-chess） | 2 层（桌面/板底 + 格阵）/ 2–4 件（记牌面板、边框）/ 3 通道（翻子动画、吃子退场、提示环） | 牌背剪影 = **中央印章 + 双线框**；翻开面靠**阵营环粗描边**先于汉字被认出，汉字是 24px 以上的通道，16px 下环色 + 点数才是主通道 |

**横向剪影经验（给 C 档的三句话）**：

1. 16px 下最先消失的是纹理和渐变，最后消失的是**外轮廓的缺口与突起**——所以差异化要做在轮廓上（呆毛、嘴楔、旗角、冠齿），不要做在填色里。
2. 双人 / 双方剪影必须「形状 + 颜色」双通道，颜色通道的灰度差要 ≥40/255 才扛得住 16px 灰度化（本窗 junqi-camp 实测只有 ≈2–3.6，是全窗最大短板）。
3. 粉彩萌系的密度上限：背景加层只加**低饱和、低对比**的静态层（淡纹理、角落静饰），动效通道宁可少一条也不要让两条动效同屏抢眼。

## 三、给 C 档的优先级建议清单（严重度 × 修复成本排序，前 10 条到绘制规格级）

> 排序口径：先按 A 档定级（阻断 > 严重 > 一般 > 建议），同级内**成本低的在前**（一行 CSS 的先修，改造型的靠后）。#1–#3 与 A 档立案重合，规格里补的是「怎么画」；#4 起是本报告新增的密度/剪影向建议。

1. **junqi-camp · 双方形状通道 + 灰度差**（严重 / 成本中）——`view.ts:112–115` + `art.ts`。绘制规格：① 棋面左上角加 7×7px 的侧别角标——朵朵方一朵**五瓣小花**（实心 `#A9531F`，可直接调用花形 path），星星方一颗**五角星**（实心 `#25508F`，`starPts` 现成）；角标压在军衔条外、不遮汉字。② 双方面板底渐变拉开灰度：朵朵保持 `#FFE7D5→#FBD3B6`，星星压暗到 `#C4D8F4→#9FBCE4`（灰度差从 ≈2 拉到 ≥40）。③ `crestSVG` 顺手把旗面形状分家：朵朵燕尾旗（尾部剪一个三角缺口），星星平角旗——三处都是字符串级改动。
2. **mine-garden · 小地图 hidden 失效**（阻断·1.3 新增 / 成本极低）——`index.ts:385/653/659`。规格：CSS 补 `.mn-mini[hidden]{display:none}`（或改 `style.display` 切换）；`drawMini` 的 300px 基准改 `Math.min(容器 clientWidth−4, 300)`；修完 320px 视口逐格复测 canvas 右缘 ≤ 容器右缘。
3. **dark-chess · 360px 8 列挤爆**（阻断·存量 / 成本低）——`view.ts:34,37`。规格：`.dc-cell{min-height:0;min-width:0;}` 让 1fr 真正收缩；触控红线用**整格按钮**保住（按钮 `aspect-ratio:1/1` 占满格，360px 下格宽 ≈41px 仍 ≥40 可点；320px 下 ≈36px，则 gap 从 4px 收到 2px 再保 37px+，并在报告登记实测值）；格内 SVG `width:100%` 自然缩，不另调 viewBox。
4. **chess-garden · 棋子主体补渐变层**（一般 / 成本低）——`art.ts` 六个 `*Inner()`。规格：不动现有 path，在 body path 之后各叠一条**提亮 path**：同一条 body 路径 `transform="translate(16 18) scale(.92) translate(-16 -18)"`、`fill="rgba(255,255,255,.14)"`（黑方 .10）、再用 `clip` 或直接把 path 的下半 y 截到 20 以上不画（简单做法：提亮 path 用上半段子路径重描）。禁 defs/id（styles.css 契约与 sudoku-petal 同口径）。
5. **dark-chess · defs 固定 id 撞车**（一般 / 成本低）——`art.ts:35,73`。规格：`dcWood`/`dcIvory` 改为「id 加格位后缀」（`dcWood${seedIdx}`、`dcIvory-${color}-${kind}`）或改双层实心叠色（底 `#5f3a1c` + 上 `#8a5a30` 高度 55% 圆角矩形）。两案选一，改完 32 格逐字节仍需满足「牌背除木纹相位外一致」的既有契约。
6. **dot-maze · 幽灵剪影差异化**（建议·商标向 / 成本低）——`art.ts:404 drawGhostFigure`。规格：裙边循环 `k<4` 改 `k<3`、`tooth = r/1.5`（三尖裙边）；头顶补一根小呆毛：`moveTo(x+r*.06, y-r*1.0)` → `quadraticCurveTo(x-r*.16, y-r*1.32, x+r*.2, y-r*1.38)`，`strokeStyle` 取身体色 `darken 20%`、`lineWidth max(1.5, r*.12)`。fright/eyes 两态同步改齿数，三态互异契约（A 档已锁）跑一遍。
7. **HUD 小字统一提级**（一般·A 档 5-4 / 成本低量大）——9 款 `index/view` 内联 CSS。规格：状态类 chips（`dmz-chip` `fs-chip` `ps-chip` `jq-chip` `dc-chip` `cg-tool` `cg-seat`）与正文类 tip/note 全部 `font-size:14px`；纯装饰星标（`l99-star`）豁免但登记。每款改完跑 A 档的 360px 契约用例。
