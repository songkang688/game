### 2. 剪影经验(每题材 1–2 条)

- **极简即识别度**:头部弹射作品的主角只用 3 个几何元素(椭圆身 + 三角喙 + 圆点眼)
  就能在 16px 认出;每加一笔都要问「缩小后这笔还在吗」。
- **配饰剪影是塔防的命**:泳道塔防头部作品的每种敌人靠**一件头顶配饰**(桶 / 杆 / 气球)
  在重叠中被认出——配饰要长在轮廓外,不要画在身体里面。
- **双人游戏靠「色 + 形」双通道**:红蓝双色编码是同屏双人游戏的通行做法,
  但色弱下必须再有形状差(呆毛 / 披风 / 星形 vs 花形),缺一不可。
- **60-30-10 配色律**:主色 60%、辅色 30%、点缀 10%;点缀色只给眼睛 / 配饰 / 特效,
  灰度化后仍要能认出角色(= 我们的 16px 剪影测试)。
- **远层剪影化**:离玩家越远的层,颜色种类越少、越接近纯剪影;近景层要「清晰轮廓 +
  高对比」,让孩子一眼分清「能碰的是什么」。

## 三、给 C 档的优先级建议清单(按严重度 × 修复成本排序)

### TOP1 · duo-rush:画布 HUD 手绘化(严重度高 / 成本中)

- **位置**:`src/games/duo-rush/index.ts` `hudText()`(1124–1141)+ `drawHud()`(1143–1165)+ `activeIcons()`(1104–1112)。
- **改法**:把「拼字符串一次 fillText」改成「文字段 + 图标段分开画」:
  - 名字前的 `r.emoji` → `art.ts` 已有的 `drawMiniFace(ctx, x, y, r, who)`(619 行,现成);
  - ❤️🤍 → 实心 / 空心心形各画一枚:`drawHeart`(83 行)已有,空心版补一个 `stroke` 分支(描边 1.5px、无填充);

  - ✋ + 道具 emoji → `drawPowerIcon`(819 行,四种图标全都画好了)套一个 12px 圆底板;
  - 🌿 / 🌈 支路标与 🤝 让分 → 纯文字「左路 · 稳」「让分 +N%」即可,不必配图;
  - 挤压逻辑(1150–1153 的 squeeze)保留:先算「图标数 × 槽宽 + 文字宽」再决定缩放。
- **测试**:`art.test.ts` 追加「HUD 渲染路径不含 emoji 字符」断言(对 `hudText` 产物正则 `/\p{Extended_Pictographic}/u`)。
