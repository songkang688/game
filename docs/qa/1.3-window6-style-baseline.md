附注(纪律与边界):

1. kit 冻结纪律下的增补路径:老 kit 文件(`badge.ts` / `moleSvg.ts` / `hamsterSvg.ts` 等)只增不改,特征强化一律走**新增叠加 kit 文件**(先例:`moleAccents.ts` → `hamsterAccents.ts`),叠加层注入角色 figure 组内跟随姿态;「改底色」类需求叠加不了,交统筹解冻决策(W6R1-11 遗留的纪律原因)。
