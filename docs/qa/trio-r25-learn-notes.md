与 adventure-king 那种「基础规则无高度、后面补 `.ak-back{min-height:44}`」不同，这四款 **全文搜不到** `min-height:44` 打在返回钮上（padding 只有 6–7px）：

### N-136 🔧 A · 返回钮 min-height 静态巡检

N-104、N-134、N-135 都是同一漏网。加测试：`src/games/**` 里匹配 `.\w+-back{...}` 且该块含 `cursor:pointer` / `button` 语义时，必须出现 `min-height:` ≥44，或紧随的组合选择器补上。豁免：牌背装饰（`.mj-back` 麻将牌面、`.hh-back` 花色接龙牌图）、canvas 绘制（走 N-126/129）。

### N-137 🔧 A · kit 正文字号地板 14 ≠ 军规 16

`uiTouch.ts` 的 `MIN_BODY_FONT_PX = 14`，`bodyFontUpliftCss` 只抬到 14。三人组正文是 **16**（N-105 / N-130）。与 N-132（触区高度 40→44）并列、不要并号。

修法：仅改该常数 14→16 及 kit 测试。若禁止动 kit：降级，N-130 逐款抬 `*-msg`。
