### 0.5 本轮另查的三个专项

1. **难度曲线**：五款各取一串关号，量参考解步数 / 预算 / 目标值，看有没有「跳崖」与「只是数值加大」。
2. **竞态**：连续进出同一款 20 次、暂停 / 恢复 20 次、快速连点、中途退出。
3. **无尽能否持续**：声明了 `endless` 的款逐个确认能一直玩下去、难度单调上升、有明确结算。

### 0.6 分级口径

- **阻断**＝这一款玩不下去 / 崩 / 数据错乱 / 让 `npm test` 或 `npm run build` 变红；
- **严重**＝一整条铁则不成立（窄屏热区整片不达标、暂停封不住、双人输入互相抢占、模式声明了玩不了）；
- **一般**＝单点不一致、少接的键、拆不干净的样式、文案口径。
