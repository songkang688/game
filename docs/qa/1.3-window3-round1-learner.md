## 一、题材密度基准表与 16px 剪影经验（学习结论，只记文字）

> 学习方法：按 9 个题材回忆并梳理成熟小游戏平台（4399 及同类）头部作品的**画面构成规律**，只记「层数 / 件数 / 通道数」与剪影经验的**结论文字**。全程未下载、未截图入库、未描摹任何具体造型。
> 口径：背景层=一屏里能分出的纵深层（含地面）；装饰物件=非玩法必需的点缀件；动效通道=同时可能在跑的独立动效类别（粒子算 1 通道 / 类）。

### 1.1 密度基准表（每题材一组数字）

| 题材 | 背景层数基准 | 装饰物件基准 | 动效通道基准 | 备注 |
| --- | --- | --- | --- | --- |
| 色彩手牌（UNO 类） | 2（桌布渐变 + 氛围光/纹理） | 4–6（对手席、牌堆厚度、桌沿高光、徽章） | 3（出牌飞行、发牌、状态字浮动） | 头部作品靠「桌面质感 + 卡面精度」撑画面，桌外留白多 |
| 跳台（Doodle 类） | 3–4（天空渐变、远山/云、中景浮物） | 5+（台面花纹、侧壁、云朵、小岛） | 3（落点粒子、蓄力表现、坠落缓冲） | 越往上主题渐变换色是常见密度手法 |
| 音游点按（钢琴块类） | 3（底渐变、动感光束/波纹、主题饰层） | 3–4（泳道分色、判定线光、连击字） | 4（判定爆点、火花、连击弹跳、长按反馈） | 密度集中在判定线附近，上半屏刻意留空 |

### 1.2 16px 剪影经验（每题材 1–2 条）

| 题材 | 剪影经验 |
| --- | --- |
| 色彩手牌 | 卡牌缩小后靠「角标符号 + 色条」双通道认牌；功能牌靠图标轮廓（箭头/禁止圈）而非文字。 |
| 跳台 | 主角 16px 时只剩「头顶那一笔」——呆毛 / 花苞 / 小帽是身份位；台子靠顶面花纹分种类。 |
| 音游点按 | 泳道靠「列首形状符号」而非纯色分列；长按块靠中心环与点按块拉开轮廓差。 |
| 五子棋 | 黑白子天然灰度安全；「最后一手」标记必须是形状（点/圈），不能只靠闪烁。 |
| 消星星 | 六色棋子必须「六形」，缩小后先认轮廓再认色；特殊棋子靠腰带/纹样而非光效认。 |
| 彩虹跑酷 | 跑者靠「披风 + 发带」两笔动的东西活起来；金币远处退化成金点也必须保住金色恒定。 |
| 吞鱼 | 鱼的敌我靠「附加物」（光环 / 头饰）而非体色；玩家鱼头顶一笔金冠在 16px 仍是最强识别。 |
| 象棋 | 红黑靠「字形 + 墨色明度」双通道；棋子精度在侧壁月牙与阴刻，缩小后仍显厚度。 |
| 格斗 | 双人同屏必须「头饰区」拉开（帽/发型/背件），再加脚圈色环兜底；面部表情缩小即失效，不做识别位。 |

## 三、给 C 档的优先级建议清单（按「严重度 × 修复成本」排序，前 10 条绘制规格级）

> 排序口径：先「一般」级且低成本（P-01~P-04），再中成本代差修复（P-06 / P-04 头像、P-07），最后低严重度的密度补层。所有建议**只加层次、不塞满**，粉彩留白是设计。

1. **ocean-munch 主页标题避让图鉴徽章（P-01，严重度·一般 × 成本·低）**
   位置：`src/games/ocean-munch/index.ts` `drawHome()`（标题 `fillText(w/2, 28)` 与 `dexFace {x: w-120, w: 112}`）。
   规格：标题改左对齐 `textAlign="left"`、锚点 `x=16`；或保持居中但先量 `measureText`，当标题右缘 > `w-130` 时按比例缩字号（下限 18px）。徽章不动。360 视口（画布 w≈336）下复测标题右缘 ≤ 206。
2. **rainbow-run 战役主页标题避让收藏册按钮（P-02，一般 × 低）**
   位置：`src/games/rainbow-run/index.ts` 战役主页标题 `fillText` 与 `face {x: w-46, w: 38}`。
   规格：标题最大可用宽 `w-100`；超宽时缩字号（下限 18px）或标题左移锚点至 `x=(w-100)/2+8`。复测 360 视口标题右缘 ≤290（按钮左缘）。
3. **fight-king 菜单两处字号提门槛（P-03，一般 × 低）**
   位置：`src/games/fight-king/index.ts` 内嵌 CSS `.fk-sub{font-size:13px}`、`.fk-mode-d{font-size:12.5px}`。
   规格：均改 `14px`；改完在 360px 视口核模式卡不出现换行撑破圆角卡（若溢出，行高收到 1.35 或卡内边距减 2px）。
4. **xiangqi「棋灵象」画制头像替换 🐘（P-04，一般 × 中）**
   位置：`src/games/xiangqi/index.ts` `avatarHTML()` L112。
   规格：30px 圆片内画 SVG 小象头——底 `PIECE_FACE #FFF7E6` 圆面 + `PIECE_WALL` 3px 月牙侧壁（与棋子 sprite 同规格），象头用 `BLACK_INK #2F3A2F` 2px 描边勾「圆头 + 大耳 + 卷鼻」三笔，耳内填 `RED_INK` 10% 淡红。禁止任何写实象、禁止近似任何棋院会徽。
5. **hue-hand 对手席三头像画制化（P-06，建议 × 中）**
   位置：`src/games/hue-hand/index.ts` L100-102 `BOT_FACES`（🐰🐼🦊）。
   规格：三只动物头像各出 34px SVG——同卡面规格：对角 linearGradient 底（左上 `lighten +15%`）+ 1.5px 深色描边 + 左上 gloss 小椭圆；兔=长耳+粉耳窝、熊猫=黑耳黑眼斑、狐=尖耳+白面颊，全部 2–3 色平涂、圆角轮廓。禁止近似任何知名 IP 动物造型。
6. **rainbow-run 画布 HUD 四枚 emoji 换绘制图标（P-07 前半，建议 × 中）**
   位置：`src/games/rainbow-run/index.ts` HUD 段（💗🤍🍬⭐ 4 行）。
   规格：心=两圆一角路径填 `#ff6a7a`、空心心同路径 1.5px 描边不填；糖=椭圆糖身 `#ffb84d` + 两侧三角糖纸结；星直接复用 `art.ts` `starPath` 填 `COIN_GOLD_MID`。统一 1.5px 深 20% 描边、尺寸对齐原 emoji 字号盒。战役地图 5 行（🔒🏁⏱ 等）可留到下一轮。
7. **ocean-munch 画布主页/地图 emoji 分批画制化（P-07 后半，建议 × 中）**
   位置：`src/games/ocean-munch/index.ts` 14 行（主页/地图/对手名牌小图标）。
   规格：本轮先换出现频率最高的 3 枚（心/星/皇冠——皇冠直接复用 `art.ts` `drawCrown` 缩放），规格同上条；其余登记留后续轮次，避免一轮改面过大。
