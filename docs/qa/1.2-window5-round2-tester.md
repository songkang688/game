**本轮换样本的原则（第 2 轮的核心要求）**

1. **不许只玩第 1 关。** 每款换一批关卡：战役取**中段与末段**（40 / 90 / 140 / 170 附近），外加 100 / 188 若能开。第 1 轮已经把 1 / 100 / 188 走过一遍，本轮的新样本落在 40 / 90 / 140 / 170。
2. 有无尽 / 双人 / 沙盒的**都要再玩到结算**（换打法，不重复第 1 轮的路径）。
3. **难度曲线**：量化每关通关耗时与失败次数，判断有没有跳崖、后期是不是纯数值重复。
4. **竞态**：快速连点、快速进出 10 次、暂停恢复、切后台。查崩溃与 `destroy`。
5. **教育正确性**：`clock-house` / `word-garden` **换一批题**再核；`color-fun` 混色结论再核。
6. **视口**：360px 与 390×844 两档都走。热区判定一律 `document.elementFromPoint(中心点)`，不用程序化 `click()`。

**严重度口径**：阻断 = 白屏 / 点不着 / 教错 / 泄题 / 必现崩溃；其余按严重 / 一般 / 建议记。
