## 二、三轮节奏

每轮固定三段，段段落地：

1. **测试员**：只写报告 + 补 `*.test.ts`，不改玩法代码。
2. **学习优化员**：列 ≥ 8 条可落地改进，真正改代码落地 ≥ 3 条，每条带测试。
3. **监督修复员**：修掉本轮阻断 / 严重；商标黑名单 0 命中；`destroy` 拆干净监听 / timer / rAF / AudioContext；`npm test && npm run build` 全绿。

### 第 1 轮

五款均走：首页进入 → 赢一次 + 输一次 → 战役第 1 / 100 / 188 关 → 有对战 / 无尽 / 双人的每种模式玩到结算 → 360px 宽不溢出。

### 第 2 轮（换样本）

换关卡与模式（不只玩第 1 关）：难度曲线单调性、竞态（狂点 / 同 tick 输入 / 重入）、无尽能否持续、存档往返。学习优化员再落地一批。

### 第 3 轮（收官）

五款一款不漏再过一遍；遗留问题给最终结论（已修 / 标明原因交主管）；明确写出档 C 五款**能否发布**。
