## 三、商标终审结论

对照两轮清单（r1 第四节九行表 + r2 第五节新增蘑菇/雪宝两条），对 9 款**终态**逐点复扫，

drawMidgroundBand 十张剪影 / 双英雄帽形 / HUD token）：

- **结论：商标风险清零。** 文案层 `copy.test.ts` `BRAND_WORDS`（≥30 词）全库看守常绿，
  本轮新增文案 0 命中；造型层九行表逐行过毕，无一命中红线组合。
- 新资产逐项：BOSS 四配饰（肩甲/速度羽/云座/虚线环）均为通用几何、与 PvZ 的头戴
  路障/铁桶构图无交集；gold-hook 与 monster-crisis 天空物均为通用太阳/月牙/星；
  duo-vs-star 终章城堡为单色通用剪影（中央主楼+两侧塔+城齿，`art.ts` 1184–1188），
  与任何标志性城堡构图无涉；duo-rush HUD token 全部自有资产；P2 尖顶画家帽为通用画家帽。
- **维护注记 2 条（非残留，防将来越线）**：① garden-guard 蘑菇徽章（`drawThemeBadge`
  forest 分支 1410–1435）终态确认：渐变伞盖、白点恰 2 粒、无脸——红线「红伞白点+正面脸」
  三要素永远不许凑齐，后续加表情彩蛋时这枚必须跳过；② 雪人徽章（snow 分支 1484–1509）
  终态是两球身+点点眼+侧向小三角橙鼻：橙鼻属民间雪人通用符号，距雪宝四件套
  （三球身+树枝手+龅牙+胡萝卜鼻）还差三件，判定安全；维护红线是**树枝手与龅牙
