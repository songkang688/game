### 2. 根因 —— 不在关卡表，也不在她那几个数值，是**两个必杀挂反了键**

先排掉"数值不够"这条路。把她的单项数值逐个抬上去再上尺（后段八关合计 /64）：

| 试法 | 合计 |
| --- | --- |
| 基线 | 2/64 |
| 元气 100 → 115 | 4/64 |
| 威力 ×1.15 | 6/64 |
| 收招 ×0.85 | 5/64 |
| 格挡槽 60 → 72 | 3/64 |
| 起手 ×0.85 | 8/64 |
| 起手 ×0.9 + 收招 ×0.9 + 元气 106 | 10/64 |

**把三项一起抬 10% 都只从 2 涨到 10**，而且第 160 / 165 / 176 / 180 关照旧 0 —— 说明卡点不是"她不够硬"。

再看**逐招命中统计**（无增益、两边都是 lv4 的手，30 回合，朵朵 0 号位对星星）：

```
朵朵 命中 118 次 / 1185 伤害   s1:37 jH:30 5H:15 5L:12 s2:8 …   s3 一次都没出过
星星 命中 334 次 / 3120 伤害   s1:214 5H:35 s2:28 s3:21 …
平均净距离 81.8，30 回合朵朵赢 0
```

两件事一眼就看出来：

1. 双方绝大多数交火发生在**净距离 80 左右**，这一距离上 AI 反复按的是「前 + 轻」（= `s1`）与「前 + 重」（= `s2`）；
2. **朵朵的 `s3` 追风踢一次都没被打出来** —— 它挂在「后 + 重」上，而 AI 在中距离从不按「后 + 重」。

把八位的 `s1` 有效射程（判定框 `x + w`，带突进的再加 `advance`）和底账（两两互打，无增益双 lv4，共 210 局）摆一起：

| 角色 | `s1` 有效射程 | 底账 |
| --- | --- | --- |
| 🌸 朵朵 | 98 | **33/210** |
| 🐤 啾啾 | 80 | 61/210 |
| 🌱 绿绿豆 | 96 | 77/210 |
| ⚡ 闪闪 | 88 + 突进 44 = 132 | 110/210 |
| ☁️ 云云 | 150 | 120/210 |

| 🍡 糯糯 | 106 + 突进 46 = 152 | 135/210 |
| 🐼 墩墩 | 114 + 突进 40 = 154 | 137/210 |

**朵朵的问题不是没有中距离的手段，是那只手被挂在了没人按的键上。** 她的两个必杀是这样挂的：

| 键 | 朵朵（改前） | 这个键在中距离被按的频率 | 结果 |
| --- | --- | --- | --- |
| 前 + 重 | **樱吹雪**（对空招，够 64，收招 26 帧） | 很高 | 每按一次都在原地打空一记大收招的招，还要被抓 |

也就是**往后按才往前冲、往前按却是对空** —— 这一条不光尺子上难看，孩子手上更别扭。
八位小伙伴里另外五位（星星 / 糯糯 / 闪闪 / 绿绿豆 / 啾啾）的对空招本来就挂在「后 + 重」，
朵朵是两个例外之一（另一个是云云）。

### 3. 修法 —— **只换槽位，招式数值一个都没改**

## 三、R2B-11 · 对手跨章撞车 —— **复量不成立，按闭合收**（补 3 条守住）

测试员记的是「八章首关摆开看：星星 / 绿绿豆 / 云云 / 朵朵 / **闪闪 / 闪闪 / 闪闪 / 闪闪** ——
`(idx*3 + ci*5 + 1) % 8` 在后四章连着落在同一位身上」。

**本轮直接把 188 关的对手序列全量导出来数了一遍，这条不成立：**

| 章 | 首关对手 | 守擂者 | 章内出场人数 |
| --- | --- | --- | --- |
| 1 樱花道场 | ⭐ 星星 | 🌸 朵朵 | 8/8 |
| 2 星光广场 | 🌱 绿绿豆 | ⭐ 星星 | 8/8 |
| 3 糯米集市 | ☁️ 云云 | 🍡 糯糯 | 8/8 |
| 4 云端回廊 | 🌸 朵朵 | ☁️ 云云 | 8/8 |
| 5 竹林擂台 | ⚡ 闪闪 | 🐼 墩墩 | 8/8 |
| 6 闪电高台 | 🍡 糯糯 | ⚡ 闪闪 | 8/8 |
| 7 豆田操场 | 🐤 啾啾 | 🌱 绿绿豆 | 8/8 |
| 8 云顶王座 | 🐼 墩墩 | 🐤 啾啾 | 8/8 |

`idx = 0` 时 `foeIdOf` 就是 `(ci*5 + 1) % 8`，八章分别是 `1 6 3 0 5 2 7 4` ——
**八个互不相同的余数**，所以八章首关必定是八位不同的小伙伴，后四章是 闪闪 / 糯糯 / 啾啾 / 墩墩，不是四个闪闪。

另外三件也一并数了：**每一章八位全部上过场**（每人 2 ~ 4 次）；
**章节交界那两关从不撞同一位**（第 24→25 关 朵朵→绿绿豆，第 48→49 关 星星→云云，……）；
**全塔连着遇到同一位对手最多 2 关**（仓库里本来就有一条"不连着三关"的守卫）。

结论：**R2B-11 闭合**（原记录是数错了，不是代码问题）。为了不让它以后真的坏掉，
往 `levels.test.ts` **补 3 条**：八章首关八位各不相同 / 每章八位全部上场 / 章节交界不撞。
