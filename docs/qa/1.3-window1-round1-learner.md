## 一、题材密度基准表与剪影经验（学习结论）

**学习方法与红线**：调研对象为 4399 及同类平台的同题材头部作品与公开的休闲游戏美术方法论
（背景分层规范、小尺寸剪影规范、棋盘类界面分层实践）。全程只记文字结论，
无下载、无截图入库、无造型描摹。通用结论有三条，先立在前面：

- **80/20 密度律**：一屏约八成面积保持「平/静」，高密度细节集中在两成的口袋区（边缘、角落、地平线）。
  加的是层次感，不是塞满；背景饱和度与对比度必须比可交互主体低一阶（眯眼测试：模糊后主战区仍应最醒目）。
- **休闲档视差规范**：2–3 层视差是休闲游戏的甜点区（远景 0.2–0.4 倍、中景 0.5–0.7 倍镜头速度），
  五层以上属于过度工程且伤低端机。
- **16px 剪影三律**：① 一个主导形状（不靠内部细节）；② 亮度对比 ≥ 4.5:1，色相差在 16px 下失效；
  ③ 渐变在 16px 下糊成脏色，剪影特征要落在**轮廓**上（帽 / 耳 / 尾 / 翼），涂黑仍可辨才算数。

| 吞噬 io | 圆形主体本身无剪影可言，头部作品全靠「头顶附加物 + 表情」两条附加通道保辨识；警戒圈用颜色 + 运动双通道（转动光点比纯色环可读一倍）。 |

| 麻将 | 牌面在 16px 只需「类别可辨」（饼=圆、条=长、字=方块字），数字辨识交给放大与选中态，不必硬塞细节。 |
| 掷骰地产 | 棋子立牌「头形差异 > 颜色差异」；20px 视窗的地格图标线宽 ≥ 1.5px、留白 ≥ 2px，否则缩到实机就是脏点。 |
| 卡牌对战 | 花色角标要「红黑 × 形状」双通道；头像认人靠帽饰轮廓，脸部趋同没关系。 |
| 围棋 | 黑白明度两极天然达标；唯一坑是白子融进浅色盘底，需一圈暖描边或投影兜底。 |
| 飞行棋 | 同形棋子必须加部件差异（尾翼 / 头饰），纯换色在 16px 灰度下全军覆没；骰子点数用传统 pip 布局最快读。 |

## 三、给 C 档的优先级排序建议清单（严重度 × 修复成本）

排序口径：严重度看「一眼可见的风格断层 > 层次缺失 > 锦上添花」；成本看改动文件数与是否引入新动效。
前三条展开到绘制规格，后续条目以第二节表格的建议动作为准。

### P1 · star-estate 地格图标矢量化（对应 G-6；严重度高 × 成本中）

- **位置**：`src/games/star-estate/art.ts`（新增函数）+ `index.ts`（地格渲染处替换插入）。
- **规格**：
  1. 新增 `tileIconSVG(kind: string): string`，viewBox `0 0 20 20`，`aria-hidden="true" focusable="false"`；
  2. 图标款数 = `levels.ts` 地格 emoji 的去重种类（约 12–16 款：毛线团、郁金香、遮阳伞等），
     每款构图 ≤ 8 个图元、线宽 1.6、双色阶（主色 + `shade(主色, 0.25)`）、留白 ≥ 2px；
  3. 色板只用 `KIT_PALETTE` 与 `shade/tint` 派生色，与 `houseSVG/coinSVG` 同族；
  4. `index.ts` 地格按钮内 emoji 节点替换为 SVG 节点，原 emoji 字符转入 `aria-label`（无障碍语义不降）；
  5. 契约测试：每款 SVG 含 `viewBox="0 0 20 20"`、不含 emoji 码位、款间字符串互异（≥ 12 例）。
- **为什么第一**：这是本窗唯一「主棋盘上的风格断层」，24 格 × 每屏常驻；且 emoji 字形随系统漂移，
  是九款里仅存的不受控视觉面。

### P2 · orb-arena 中景具象贴片层（严重度中 × 成本低）

- **位置**：`src/games/orb-arena/art.ts drawArenaBackground`（圆斑层与网格层之间插一段）。
- **规格**：
  1. 确定性哈希布点（可直接搬 `snake-royale/art.ts hash2` 的写法，注明出处），格边 176 世界 px，
     约 40% 格出件，其余留白（80/20 律）；

  3. 视差 0.3（与圆斑层同系数，避免三速打架）；离屏 sprite 缓存（参照本款 `makePelletSprites` 既有套路）；
  4. `soft` 分支无差别（贴片本身静态，零动效通道新增）；
  5. 契约测试：贴片函数存在、同格同相位输出确定、绘制调用计数 > 0（≥ 4 例）。

### P3 · flight-chess 盘面四象限装饰（严重度中 × 成本低）

  4. reduced-motion 无涉（全静态）；
  5. 契约测试：装饰节点数 ≤ 6、不与格子选择器重叠、带 `aria-hidden`（≥ 3 例）。
