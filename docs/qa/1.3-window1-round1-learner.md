## 0. 学习计划（开工承诺）

1. **向外学习**：按九款题材分组（大乱斗 io / 贪吃蛇 io / 方块消除 / 格斗 / 麻将连连 / 掷骰地产 /
   卡牌对战 / 围棋 / 飞行棋），逐题材调研 4399 及同类平台头部作品的**画面密度**
   （背景层数 / 装饰物件数 / 动效通道数）与**角色剪影**（16px 缩略仍可辨认靠什么），
   每题材落一组数字基准 + 1–2 条剪影经验，只记文字结论。
2. **对照评估**：读本窗 12 格（kit / motion / runner + 九款）的绘制源码，逐格给出
   密度差距（数字化）/ 剪影达标 / 观感短板 TOP1（点名文件与函数）/ 建议动作（绘制规格级）。
3. **对账**：与测试员报告「一般 6 条（G-1–G-6）/ 建议 1 条（G-7）」逐条对齐，不重复、不遗漏、
   不把 1.2 遗留误写成 1.3 回归。
4. **商标风险提醒**：按题材列「易踩线对象 → 规避要点」，专供 C 档动笔前自查。
5. **文案优化**（唯一动代码范围）：把 1.3 新视觉亮点讲进九款 guide / blurb / 纯文案字符串，
   面向约小学六年级、中文粉彩萌系；每处改动在第五节登记并补 / 更新快照测试。
6. **收尾**：`npx vitest run` 与 `npx tsc --noEmit` 全绿，fetch → rebase → 普通 push。
