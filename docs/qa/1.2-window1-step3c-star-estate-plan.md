## 三、文件拆分

| 文件 | 职责 |
| --- | --- |
| `meta.ts` | 纯数据 meta，不 import 玩法 |
| `board.ts` | 40 格棋盘、8 色组、租金表（纯数据 + 查表函数） |
| `rent.ts` | `moveBy` / `passedGo` / `rentOf` / `ownsColorSet` / `netWorth` |

| `cards.ts` | 机会 / 命运各 ≥ 16 张原创卡，抽完洗回 |
| `auction.ts` | 无底价拍卖，轮流出价 |
| `ai.ts` | 菜鸟 / 普通 / 高手 / 地狱四档 + 无头对局模拟器 |
| `levels.ts` | 8 章 188 关残局配置 + 参考解法 |
| `guide.ts` | 攻略书 |
| `index.ts` | DOM 棋盘、走子动画、抽屉地契、四种模式 |
