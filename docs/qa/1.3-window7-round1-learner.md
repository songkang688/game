## 一、九题材密度基准表与剪影经验（学习结论）

密度记法：**背景层数 / 一屏装饰物件数 / 动效通道数**。「动效通道」指互相独立的动效来源（粒子池、常驻循环、状态脉冲各算一条）。

| 题材（对应款） | 头部作品密度基准 | 剪影经验（16px 缩略后靠什么认） |
| --- | --- | --- |
| 接水果（fruit-catch） | 背景 2–3 层（天空渐变 + 远树/山 + 近景草地）；装饰 6–12 件（日/月、云 2–3 朵、枝叶、草丛）；动效 3–5 通道（接住爆星、飘分、容器挤压回弹、连击提示） | 篮子靠「上宽下窄梯形 + 双提耳」一笔；水果必须「形 + 色」双通道：香蕉弯月、葡萄串团、草莓倒水滴——纯换色不换形 16px 必混 |
| 切水果（fruit-slice） | 背景刻意薄：1–2 层（深色砧板/舞台渐变，低噪声给前景让路）；装饰少但有一条「果渍留底」残留通道（汁印在底板停留数秒渐隐）；动效 4–6 通道（刀光丝带、汁滴、切半旋飞、果渍、连击字、特殊果光环） | 识别核心是「切开瞬间的双半块 + 切面对比色」；16px 下瓜靠深浅条纹、桃靠心形顶凹、柠靠橄榄两尖；炸弹靠圆 + 引信的剪影级差异 |
| 贪吃蛇/毛毛虫（snake-snack） | 背景 2 层（双色棋盘 + 边框/栅栏）；装饰 4–8 件/关（草丛、石、门）；动效 3–5 通道（移动插值、吞咽鼓包、眨眼/张嘴、食物待机浮动） | 头必须比身宽 1.2–1.4 倍 + 大眼白黑瞳；虫类靠圆节交替双色；**双蛇同屏时色相差不够，必须有一件剪影级附件（触角/蝴蝶结/睫毛）** |
| 连连看（lianliankan） | 背景 1–3 层（桌面纹理即可，密度主体在牌面）；牌面：图标底色 4–6 组 + 牌侧沿立体感；动效 3–4 通道（选中脉冲、连线光带、消除星尘、提示柔光） | 图标要「一形一色」，同套图标**形状差异 > 颜色差异**；面具/牌背统一纹样，扫一眼就知道「这是同一套牌」 |
| 拼图（puzzle-tiles） | 背景 1–2 层（画室/画架）；密度靠「成品图内容 + 齿边光影 + 完成装裱」撑——**牌面内容本身是一幅画**是题材底线；动效 3–4 通道（拾起抬升、吸附回弹、接缝白光、完成彩带） | 拼块靠齿边凹凸剪影（凸头/凹口 16px 可辨）；块面内容靠大色块构图，不靠细节 |
| 翻翻乐（memory-cards） | 背景 1 层渐变即可；密度全在卡背（中心徽章 + 环形纹 + 金描边）与配对反馈；动效 4–5 通道（3D 翻转、配对相碰、星屑、波浪翻回、辅助柔光） | 卡背徽章 16px 可辨 =「这是一张还扣着的记忆卡」；图案靠粗轮廓 + 双色填充；双人款轮次要走 HUD 徽章而非场上角色 |
| 斗地主（landlord-cards） | 背景 2 层（毛毡渐变 + 木沿），氛围件 2–4（灯光光晕/桌角饰/座位垫）；动效 4–5 通道（出牌飞行、炸弹震屏 + 星屑、轮次呼吸、倍数翻牌）。行业经验明确：**打牌区要简洁化、冷色、弱化非功能元素**，密度克制本身是对的 | 三人桌身份靠「帽形/徽章形状」而不是颜色；头像圆框 + 立绘剪影一笔（长耳、圆耳）16px 可辨；大小王靠金/银边框 + 立绘 |
| 钓鱼（fishing-star） | 背景 3–5 层（天空 + 远山/岸 + 水面波光 + 深水渐变 + 光柱）；水下密度通道：气泡 ≤ 若干颗、鱼群分层游动、**深度变色（越深越偏蓝绿、去饱和）**；动效 5–6 通道（波光平移、气泡、涟漪、鱼摆尾、水花、稀有金光） | 鱼靠「纺锤身 + 尾鳍角度 + 花纹带」三笔；稀有度靠金鳞光效而不是加细节；浮标红白双色是功能剪影 |
| 跑酷/清扫（poop-hero） | 视差 3–5 层是行业标准：**远 0.1–0.3 / 中 0.5–0.7 / 近景前景 0.8–0.9 / 玩法层 1.0**；装饰每屏 8–15 件；动效 4–6 通道（腿摆、残影、尾流、收集闪光、尘土） | 主角 16px 时颜色几乎失效，靠「披风飘动方向 + 头部轮廓一笔（帽/呆毛/发卡）」；**双人款两角色必须有几何差异 + ≥25 灰阶的亮度差，色相互换不算通道** |

三条横向结论（给 C 档定调）：

1. **密度是分层不是堆料**：头部作品的「满」来自层与层的速度差 / 明度差，单层内物件其实不多。本库粉彩萌系的留白是设计资产，补密度只补「缺的层」和「缺的通道」，不加填充物。
2. **剪影四通道**：形状（几何差异）> 附件（帽/发卡/蝴蝶结）> 亮度（≥25 灰阶）> 色相。16px 验收时色相通道视为 0。
3. **残留通道最便宜**：果渍留底、扫过发亮带、踩亮花砖这类「玩过的痕迹」是密度性价比最高的一条通道——本库多款已有（poop-hero 干净带、snake 花砖），fruit-slice 缺。

## 三、给 C 档的优先级建议清单（严重度 × 修复成本排序，前 10 条绘制规格级）

排序口径：A 档严重项优先，同级里成本低的先做（快赢）；点名文件均已核对到行。

1. **poop-hero 香香星 ✨ → kit 星（严重 4，成本最低）**
   `index.ts:1500`。`traceStar` 已在同文件 import。规格：五角星 `r = 9*scale`，径向渐变 3 停 `#FFF6C4(0) → #FFC94D(0.55) → #E8A62E(1)`（渐变心偏左上 `-0.3r,-0.3r`），描边 1.5px `#C7861F`，外圈微光 `rgba(255,214,120,.35)` 半径 `1.4r`；待机浮动沿用现有 bob 相位，reduced 不加光圈。
2. **poop-hero 双人 16px 剪影（严重 9，成本低）**
   `visual.ts:58-85` + `index.ts:829`。双通道一起上：① 亮度：星星 `capeOut0 #7FA9F0 → #A8C6F5`、`capeOut1 = shade(新色,-18)`（Rec.601 灰度约 165→196，Δ≥25）；② 几何：朵朵头部轮廓并入两撮呆毛（各高 `headR*0.55`、根宽 `headR*0.28`，发色填充 + 同色 2px 描边），**画进头部 path 本体**，不走 `showDetail`（5px 门槛）分支，16px 时仍在。改完把两人灰度差与呆毛存在性钉进用例。
3. **poop-hero 分类桶图标 3 枚自绘（严重 5，成本低）**
