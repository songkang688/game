### 0.2 本轮的取材口径

第 3 轮测试员包 A 记的是 **阻断 0 / 严重 0 / 一般 1**（`R3-PA-1`，明令不修），
第 1 / 2 轮登记的 17 条一般项已全部有终态。也就是说：**本轮没有「照着缺陷单修」的活可干**，
学习优化员该做的是从五款自己走一遍，找**测试员的七条铁则量不到、但孩子真会碰到**的粗糙处。

本轮的取材角度定三条：

1. **五款之间的口径要一致**。同一套动作（暂停、取消、归位）在五款里得是同一个脾气。
   哪一款少一道闸、少一个入口，就是那一款的粗糙处。
2. **触屏与键盘两条通路都要走得通**。测试员量的是「热区够不够 44px」，
   量不到的是「这条路在手机上到底有没有入口」。
3. **读屏能不能听懂**。`aria-label` 写了什么、光标在哪、按钮为什么点不动，
   这些不进热区表，但直接决定看不清屏幕的孩子能不能玩。

按这三条把五款过了一遍，挑出来的都是「加一道闸 / 补一个钮 / 补一个属性」的改法，
**小而稳，不碰关卡表、不碰难度、不碰物理判定**。

## 一、落地明细（**列 14 条 / 落地 10 条**，7 个 commit）

计划里写的 9 条全部落地，`L3A-10` 也一并做了，合计 **10 条**。
每条一个独立 commit，自带测试；改动全部落在这 5 个游戏目录里，

### L3A-1 · dot-maze：暂停期间除 `Esc` 外一律不接

`2530c00`

暂停原本只挡住了游戏推进，**没挡住输入**：遮住的这段时间里按下的转向会攒进
`nextDir` 缓冲，一恢复就集体生效——孩子按暂停是为了想清楚下一步，结果一恢复
先替他走了三个他早忘了的拐弯。三条通路全补上闸：

- 键盘 `onKey`：`Escape` 先处理，其余（含 `G` / `K` 取消键）在 `paused` 时直接 return；
- 虚拟方向键 `.dmz-key[data-dir]` 的 click；
- 触屏滑动 `onTouchEnd`。

### L3A-2 / L3A-3 / L3A-10 · dot-maze：触屏的暂停入口与读屏

`b856192`、`a618064`

- **L3A-2**：方向键盘是 3×3 的九宫格，左上角原本是个 `visibility:hidden` 的占位格。
  把它换成 `⏸` 暂停钮（复用 `.dmz-key`，热区跟方向键同尺寸 ≥ 44px），
  和 `Esc` 是同一个开关：文字在 `⏸` / `▶` 之间翻，`aria-label` 在「暂停」/「继续」之间翻，
  `aria-pressed` 跟着走。在这之前，**手机上根本没有暂停入口**。
- **L3A-3**：剩下的那个占位 `<button>` 补 `aria-hidden="true"` + `tabindex="-1"`，
  读屏不再念出一个没有名字的空按钮，Tab 也不会停在上面。
- **L3A-10**：无尽 / 抢豆 / 追逃三种玩法的一行说明与攻略里都补上暂停口径。

> `a618064` 是 L3A-10 的收尾：攻略那一句本来单开了一条通用心得，
> 顶破了平台 `src/games/copy.test.ts` 卡的「每本攻略 3–6 条通用心得」上限。
> 改成并进相邻那条按键说明里（内容一句没少），并在本包自己补了一道同口径的自查，
> 以后改文案先在本款红，不用等平台那条大扫描。

### L3A-4 · pool-stars：暂停钮与暂停遮罩，电脑那一杆也一起停住

`1a0eb5f`

原本暂停只换一行提示文字，而且只有 `Esc` 一个入口。三件事一起补：

- 工具行加 `⏸ 暂停` 钮（`.ps-btn`，与既有钮同热区），带 `aria-pressed`；
- 样式表里 `.ps-veil` / `.ps-veil-t` / `.ps-veil-s` 一整套遮罩早就写好了却没人用，
  这次接上：遮罩里带一个「▶ 继续」钮，`destroy` 时一起 `clearVeil()`；
- **顺手抓到一个真 bug**：`maybeAi()` 排下去的定时器不看 `paused`，
  所以遮罩盖着的时候电脑照样会把球打出去。现在 `setPaused(true)` 会
  `clearTimeout(aiTimer)`，`maybeAi` 的进出两处都加了 `paused` 判断，
  恢复时再 `maybeAi()` 重新排。

`Esc` 与钮走的是同一个 `setPaused`，「蓄到一半按暂停这一杆作废」的既有行为原样保留。

### L3A-5 / L3A-6 · fruit-stack：暂停闸补到指针通路；人机提示补 `G`

`0977b57`

- **L3A-5**：暂停闸原本只挡键盘，**盆上拖动瞄准、`◀` `▶` 挪落点、投果、落点归位
  在程序上照样接**，全靠遮罩挡在手指前面——遮罩挡得住手指，挡不住程序（也挡不住
  遮罩边缘漏过去的那一下）。给 `BowlOptions` 加 `isPaused?: () => boolean`，
  `canDrop()` / `moveAim()` / `centerAim()` / `aimTo()` 与 canvas 的 `pointerdown`
  五处各加一句。为此把 `paused` / `finished` 两个状态的声明提到 `createBowl` 之前。
- **L3A-6**：人机对战那一行提示漏了朵朵的归位键 `G`（双人那一行一直写着），补齐。

### L3A-7 / L3A-8 · junqi-camp：暂停时确认 / 取消置灰；工具钮补读屏说明

`c9d04c5`

- **L3A-7**：暂停时「确认 / 取消」点了没反应，可按钮长得跟能点一样，
  孩子会以为是卡了。样式表里 `.jq-btn.jq-off{opacity:.45}` 早写好了却没人用，
  这次接上：`render()` 里按 `opts.isPaused?.()` 给两个钮挂 `jq-off` 与
  `aria-disabled`，`togglePause()` 里补一句 `board?.refresh()` 让棋盘跟着翻面，
  暂停钮自己也补上 `aria-pressed`。**只改外观不改行为**——暂停照旧不落子，
  已经选好的落点也不丢，恢复之后原来那一步照样走得出去（有用例盯着）。
- **L3A-8**：工具条上 `➖` `➕` `🏠` 三个钮只有符号，读屏念「减号」「加号」听不出
  是干什么的，补上「把棋盘缩小一点」「把棋盘放大一点」「把画面移回自己这半边」。

### L3A-9 · chess-garden：64 格的读屏说明

`f3f9817`

格子的 `aria-label` 原本只有「格名 + 棋子」。可**光标、选中、可走点、将军这四样
界面上全是用颜色画的**，看不见颜色的孩子拿到的就只是一张 64 格的静态清单：
不知道光标停在哪、不知道刚才那一下选中没有、更不知道哪几格现在能落。现在读成

```
e1 白王，光标在这儿
e2 白兵，已选中，光标在这儿
e4 空格，可以走到这儿
e1 黑车，可以吃这一颗
h1 白王，正被将军
```

另外给光标那一格挂 `aria-current="true"`（其余 `false`），
读屏在 64 个同名按钮里才定得到位置。可走点跟着「💡 提示」开关走：
提示关掉就不报，跟画面保持一致；`showHints` 关着时「已选中」照常报。

三条口径：

1. **既有断言只翻面、不删除、不放宽**——本轮 `.test.ts` 的 diff 里
   删除的 `it(` 与 `expect(` 都是 **0** 行。
2. **每条新用例都做过变异验证**：把对应改动改坏（或退回改前的写法）必须红。
   例如把 `L3A-9` 的「可以吃这一颗」并回「可以走到这儿」，
   `能吃的那一格和能走的那一格分开报` 立刻失败。
3. **躲开空过**：fruit-stack 的暂停用例最早写成「暂停期间点一下，当场断言 HUD 没变」，
   可暂停期间 `refreshHud` 本来就不跑，这么写永远绿。改成
   「暂停期间动一下 → 恢复 → 推帧 → 再跟暂停前比」才真的量到那道闸。
   dot-maze 的 `corridorRun` 也补了 `dom.frames.length = 0`，
   否则上一条用例遗留的 rAF 回调会串到下一条里。
