## 四、新抽验（N-138 起）

### N-138 🔧 A · level99 壳层可点无 min-height:44

`level99.ts` 里这些 **button** 都没有 `min-height`（padding 7–8px，915 上很容易 <44）：

| 选择器 | 用途 |
| --- | --- |
| `.l99-back` | 关内「回地图」 |
| `.l99-tool` / `.l99-tool-skip` | 跳到当前关 / 攻略 / 跳过 |
| `.l99-continue` | 「开始冒险 ▶」（N-100 管卷顶，不管热区） |
| `.l99-tab` | 章节页签（N-117 管折行） |
| `.l99-ov-btn` | 胜负 overlay CTA（padding 大，仍应钉 44） |

修法：统一补 `min-height:44px`。矮档 `.l99-tool-skip` 的 `padding:6px 10px` **不许**把高度压回去。`.l99-node` 已有全局 44，勿动格子。
