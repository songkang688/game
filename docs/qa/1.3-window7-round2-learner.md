## 二、盲区题材密度基准补充：棋牌桌面 × 钓鱼 × 跑酷——「怎么少而精」

第 1 轮基准表偏重「往上补密度」;本轮反向补盲区:本窗四款棋牌桌面（landlord / memory / lianliankan / puzzle）密度天然低,低得对不对?对照钓鱼/跑酷把「少而精」写透。学习方式同 R1:只记文字结论,未下载、未截图、未描摹。

1. **棋牌类的密度上限由「信息检索」决定,不由「氛围」决定。** 成熟棋牌桌面的通行做法:牌区周边 60% 以上面积保持低对比、低饱和（毛毡绿 / 深蓝 / 木纹）,所有装饰元素的对比度压在牌面对比度之下——玩家每秒都在做「找牌→比大小」的视觉检索,任何高对比装饰、高频动效都直接拖慢检索。数值基准:桌面氛围件 ≤4、常驻动效通道 ≤2（轮次呼吸 + 一条提示）,爆发动效（炸弹）允许短时打满但 ≤400ms 自灭。**landlord 现状（毛毡 2 层 + 木沿四角 + 呼吸 + 震屏 160ms）正落在基准带内,「简洁冷色」是功能不是偷懒。**
2. **「少」省下来的预算要全部花在「最小信息单位」上。** 棋牌类的精致感不摊在背景,全部集中在牌面（landlord 七道工序）、卡背（memory 双环 + 金线 + 徽章）、图标（lianliankan 16 枚一形一色）、切片（puzzle 场景画）。**单位精致 × 阵列重复 = 满而不乱**——与跑酷「靠层数堆氛围」是完全相反的密度公式。本窗四款全部踩中这个公式,R1 修复(P5/P6)补的恰好都是「最小单位」而不是背景,方向正确。
3. **对照钓鱼 / 跑酷:多层数的正当性来自「玩家在世界里移动」。** fishing-star 4 层背景 + 深度变色是「深度 = 鱼的价值」的玩法信息;poop-hero 三档视差是速度感的来源。棋牌玩家视点不动,背景超过 2 层只会制造无意义负担——所以「fishing 4 层达标、landlord 2 层同样达标」并不矛盾,层数基准必须按「视点是否移动」分档。
4. **「少而精」一句话判据:每个像素要么携带玩法信息,要么携带主题氛围,两者都不带的删掉。** 落成验收问题:棋牌款问「这件装饰会不会跟牌面抢对比度」;移动款问「这一层有没有独立的视差速度 / 明度档」。
5. **残留通道在棋牌类同样成立,但形态从「空间痕迹」变成「事件痕迹」。** 跑酷的干净带、贪吃蛇的花砖是空间残留;棋牌对应物是 lianliankan 流星光带（沿判定折线）、memory 星星印章（收纳态）——事件驱动、自灭、不占常驻通道预算,是棋牌类少数可加动效的位置。fruit-slice 若补果渍留底,也应按「事件残留、自灭、≤6 个硬顶」的同款口径。

结论:本窗棋牌四款的「素」是题材正解,**不需要**向跑酷/钓鱼的密度看齐;唯一在舒适线以下的是 memory-cards 的桌面四角（见第三节),补法也必须遵守第 1 条的对比度上限。
