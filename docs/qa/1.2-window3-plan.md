## 二、实现约定（每一款都照做）

1. 1.2 的新深度统一落在游戏目录内**新建的纯逻辑模块**里（命名按玩法领域，不叫 `depth12`），
   老的 `logic.ts` / `physics.ts` / `levels.ts` / `sim.ts` 只做加法，既有导出与既有断言一律不动、不调弱。
2. 每款新模块配一份 `*.test.ts`，用例数按各自规格文件的下限（18 或 20）走，只增不减。
3. `meta.ts` 只补 `modes`（规格要求补 `endless` 的才补）与 `blurb` 对齐；
   `platform` 字段属于第 1 步 B 档（窗口 1）的 `src/engine/types.ts`，**本窗口不自造类型**，
   实测结论以 `meta.ts` 注释写下，等平台字段合进来后一行即可落位。
4. 公共文件一律不碰：`src/ui/**`、`src/engine/**`、`src/games/level99.ts`、`src/games/quiz99.ts`、
   `src/styles.css`（本窗口新玩法不需要新增全局样式，游戏内样式走各自 `index.ts` 的内联/局部类名）。
5. 每款做完跑 `npm test` + `npm run build`，全绿才继续下一款。
