### 4.2 reduced（`prefers-reduced-motion`）退化三铁律

1. **功能提示不消失，只静态**：毒藻光环 reduced 恒 0.62（`ocean-munch/art.ts` `toxinAuraPulse`）、水母灯恒 0.6（`jellyGlowPulse`）；将军警示改静态描边 + 徽章（`xiangqi/art.ts` `checkGlowAlpha`）；P1/P2 头顶标记停摆但仍在（`fight-king/art.ts` `drawSideMarker` bob=0）。
2. **装饰动效冻结或归零，层还在**：视差平移恒 0（`fight-king/art.ts` `parallaxOffset`）；残影整关（`afterimageAlpha` 恒 0）；飘带/浮动归零（`rainbow-run/art.ts` `flutterPhase`/`pickupFloat`）；光柱停摆（`ocean-munch/art.ts` `shaftSway` 恒 0）；饰层相位冻结（`tap-tiles/index.ts` `drawDriftSymbols`）；镜头沉降恒 0（`hop-pads/index.ts` `Camera.shake` 注释约定）。
3. **时序压 1 帧，状态机不变**：`match-stars/anim.ts` `CALM_TIMINGS` 把每段压到 16ms（下落每格 2ms）但段一个不删、事件序列照走；超必杀切入 72 帧 → 24 帧（`fight-king/art.ts` `SUPER_CUT_REDUCED_FRAMES`）；河豚鼓起不过冲直接到位（`ocean-munch/art.ts` `pufferInflateScale`）。

## 五、金币三件套规格（收集物通用）

宪法要求收集物必有「边缘厚度 + 高光 + 内圈细节」，本窗标杆实现：

1. **标杆件**：`rainbow-run/art.ts` `drawCoinFrame` —— 厚度=2px 深金侧棱（错位椭圆 `COIN_GOLD_EDGE`）；高光=左上径向渐变 + 每 1.2s 一道斜扫光（`coinSweepPhase`/`drawCoinSweep`，只占周期前 22%）；内圈细节=0.68r 亮环凹槽 + 0.42r 五角星压印（侧帧镜像、背面调暗一档）。8 帧绕 Y 轴旋转（`COIN_FRAME_COUNT`=8、`COIN_SPIN_FPS`=10）预渲染离屏（`makeCoinSprite`），播放只 `drawImage`。
2. **LOD 金色恒定**：投影缩到 `COIN_DOT_SCALE`=0.16 以下退化为双层金点（`coinLOD` → `drawCoinDot`），退化态也只许用金五阶 token（机器钉子锁死）。
3. **同族件**：收集星「厚边 + 亮金星面 + 内圈小星 + 高光点」（`ocean-munch/art.ts` `drawCollectStar`）；HUD 星「光晕 + 星体 + 内芯」（`rainbow-run/art.ts` `drawStarPickup`）；完美反馈「台面完美圈 + 星屑 + 皇冠」（`hop-pads/index.ts` `drawPad` 完美圈段、`hop-pads/art.ts` `spawnPerfectBurst`/`drawCrown`）。
4. **拾取反馈**：星屑粒子 + 计数飞字（`rainbow-run/index.ts` 星屑注释「画成小星星而不是圆点」）；reduced 退化为淡出（宪法第四节）。粒子池上限见 `hop-pads/art.ts` `PERFECT_STARS`=4/`DUST_PUFFS`=2/`ONCE_SHARDS`=3 的小池写法。

## 六、双人剪影差异化手法

原则（宪法第三节）：A/B 在**剪影 + 主色 + 配饰**三层都不同；本窗落法是「身份位放头顶那一笔 + 形色双通道 + 兜底环」：

| 款 | 手法 | 出处 | 验收量化 |
| --- | --- | --- | --- |
| hop-pads | P1 花苞呆毛 vs P2 星呆毛（剪影）+ 配饰色 `HERO_TRIM`（粉 `#F58FB4` / 黄 `#FFD76A`，测试直接断言两值不同） | `hop-pads/art.ts` `HERO_TRIM` + `drawHeroSprite` | r1 实测 16px 头顶灰度差 38.2 |
| ocean-munch | 附加物差异不动体色：P1 金冠（三尖）vs P2 银星发带（星 + 发带弧），形状颜色双不同 | `ocean-munch/art.ts` `drawCrown` / `drawStarBand` + 色 token `CROWN_GOLD`/`STAR_SILVER` | r1 实测 top 灰度差 79.6 |
| fight-king | 三层保险：八套行头查表（headgear 剪影位）→ 头顶标记（P1 五瓣小花 / P2 小星，形状通道）→ 脚下光环（粉 `#e0679f` / 蓝 `#4a7fd6`，颜色通道）；影子贴身加深防重叠误读 | `fight-king/art.ts` `HERO_LOOKS`/`drawHeadgear`/`drawSideMarker`/`drawFootRing`/`RING_COLORS`/`shadowAlpha` | r1 实测 8 位 28 对全过（top 23.7–138.2）；镜像同角色靠标记 + 环仍可分 |
| rainbow-run | 发带五段配色成组换装：P1 彩虹系 vs P2 蓝系（`HEADBAND_P1/P2`），幽灵替身另用半透明 + 蓝描边名牌 | `rainbow-run/art.ts` `HEADBAND_P1/HEADBAND_P2`/`drawHeadband`、`ghost.ts` | 单人款双人预留，幽灵与本体可辨 |
| gomoku / xiangqi | 棋类天然双通道：黑白明度差 / 红黑「字形 + 墨色」 | `gomoku/art.ts` `paintStone`；`xiangqi/art.ts` `paintPieceBody` | 灰度中间调差 176/255；红帅黑将 gray 41.4 + 字形 |

手法总结：16px 缩放后面部失效、体色靠不住，**身份信息优先挂「头顶那一笔」**（呆毛/冠/发带/头标）；同体型双人必须再加脚圈色环类兜底；一切差异化都要「形状 + 颜色」两通道齐备，色弱可分。

## 七、2.5D 纵深的三种做法

### 7.1 地面透视（纵深改变玩法判断的款）

- `rainbow-run/view3d.ts`：整套相机纯函数——地平线 `HORIZON_RATIO` 0.3、相机纵深 `CAM_DEPTH_RATIO` 1.35、车道横距 `LANE_SPREAD` 0.26；`makeCamera/depthOf/scaleAtDepth/screenYAtDepth/projectTrack` 完成世界 → 屏幕投影；`groundGridDepths` 出地面网格滚动；远景雾 `fogAlpha`（`FOG_START_SCALE` 0.55 起雾）。**禁止再造第二套透视数学**（宪法第五节）。
- `hop-pads/index.ts` `project()`：轻量斜俯视——纵深压扁 `DEPTH_SQUASH` 0.52、地平线 `horizonFor()`（矮画布 0.68 / 常规 0.74）、落地镜头沉降 `Camera.shake`（reduced 恒 0）；配套深度雾 `hop-pads/art.ts` `fogAlpha`（`FOG_NEAR` 140 / `FOG_FAR` 560 / `FOG_MAX` 0.35，严格单调、永不糊死）。

### 7.2 多层视差（纵深只做观感的款）

- `rainbow-run/view3d.ts` `PARALLAX_LAYERS`：远山 0.05 / 云带 0.13 / 近树 0.29 三层 + `parallaxShift` 平铺循环；低端机从最远层开始砍（`QUALITY_TIERS`，45fps 降档 / 55fps 升档，`nextQualityTier`）。
- `fight-king/art.ts` `PARALLAX`：sky 0.08 / far 0.22 / near 0.52 / petal 1.15 四层（飘物只进中远景，近景不放会动的装饰——第 2 轮 §2.3 结论）；`parallaxOffset` reduced 恒 0。
- `ocean-munch/index.ts`：远景剪影 + 鱼影视差 0.3、前景水草大剪影视差 1.3（35% 半透明只贴屏角不挡触控）；分档开关 `ocean-munch/art.ts` `qualityFor`/`layerToggles`——**砍装饰层不砍主层**。

### 7.3 落影缩放（一切离地实体）

- `rainbow-run/art.ts` `drawContactShadow`：接地椭圆（ry=rx×0.28），跳起随投影缩放。
- `fight-king/art.ts` `shadowShrink`（`max(0.45, 1-y/220)`）+ `shadowAlpha`（平时 0.15、贴身 `SHADOW_NEAR_GAP` 70 内加深到 0.3）：影子既表高度又表两人距离。
- `xiangqi/art.ts` `paintPieceShadow`：抬子时影子变淡摊开（lift 参数）——静态棋类同样用落影表「离地」。
- `gomoku/art.ts` `paintStone` 投影：右下偏移常驻，与光照约定（第三节）共用一套方向。

### 7.4 密度与留白附则（第 2 轮 §2 结论固化）

**密度上限不是「能放多少」，而是「玩家目光该在哪」。** 先定目光锚点（盘心 / 路面中央 / 双方角色 / 玩家鱼），锚点区只放玩法元素并给最高精度；离锚点越远，密度与饱和度按档递减。加密度只许三选一：材质精度（棋牌，`gomoku/art.ts` `paintBoardFrame` 桌面→柔影→深木框→金线→铜角五层）、事件仪式（全部）、剪影饰层（跑酷/吞鱼，`match-stars/view.ts` `CSS` 三主题静态剪影、`tap-tiles/index.ts` `drawDriftSymbols` alpha 0.07 上飘层）。ocean-munch 的留白同时是性能预算：**任何人不得给它的 high 档加常驻粒子/饰层**（r2/r3 两轮禁令,4× 节流实测 48.3→53.9fps）。真 3D（three.js 等）一律禁止（宪法第五节）。
