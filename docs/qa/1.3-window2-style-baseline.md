# 1.3 窗口 2 · 风格基线（棋牌 / 数字盘面 9 款专用）

> 编写：窗口 2 第 3 轮终验学习优化员（B 档），模型 `claude-fable-5-thinking-xhigh`。
> 适用范围：**只覆盖本窗 9 款**——`merge-2048` `mine-garden` `sudoku-petal` `dot-maze` `fruit-stack` `pool-stars` `junqi-camp` `chess-garden` `dark-chess`。
> 本文件是本窗专用基线，不覆盖他窗可能使用的全库 `1.3-style-baseline.md`；他窗的 2.5D 地面透视 / 多层视差**不是**本窗规范，本窗题材为信息盘面，一律精 2D。
> 每条规范注明出处（文件 + 函数名 / 规则名），全部经第 3 轮读码复核，机器契约在 `round1/2/3-*.test.ts` 与 `window2-r*-learner-copy.test.ts` 中在跑。

## 一、粉彩色板 token（B1–B7）

- **B1 · 主角双色永远同源**：朵朵玫红 `#a8306a` / 星星深蓝 `#28568f`。出处：`fruit-stack/index.ts` `drawRim()`（盆沿内衬，:508）与同文件座位名字色（:268）、`pool-stars` 座位条同源。新增双人视觉一律引用这对 token，不得另起新色。
- **B2 · 星星侧冷蓝带**：星星方主色收在 `#25508F–#2f66b8` 冷蓝带内（`junqi-camp/view.ts` `.jq-star .jq-face` 字色 `#25508F`；`dark-chess/art.ts` `FACTION.blue.ring:#2f66b8`）。唯一登记例外：`junqi-camp` 朵朵侧用军营暖橙 `#E0813C`（阵营既有配色，盘上有形状角标兜底，r2 会签维持）。
- **B3 · 盘面底色只用低饱和马卡龙**：数字块色表见 `merge-2048/art.ts` `tileFaceCSS()` 注释「基调仍是 tileColors 的马卡龙色表」；junqi 双方面板 `#FFE7D5→#FBD3B6`（朵朵）/ `#C4D8F4→#93B2DE`（星星，`junqi-camp/view.ts` :125，底停灰度差 Δ42.8 有契约钉死）。
- **B4 · 角色淡彩每通道 ≥120**：`dot-maze/ghosts.ts` `GHOST_COLORS`（`#FF9AB0` `#FFC48A` `#9FD8F5` `#C7B3F2`），四色每 RGB 通道均 ≥120，远离任何官方饱和四色；契约在 `dot-maze/round1-visual-scan.test.ts`。任何一轮都不许把它们改回饱和色。
- **B5 · 壳卡渐变族**：盘外壳卡一律「浅粉彩双停 180° 渐变 + 16px 圆角 + 10px 上下内衬」——`pool-stars/view.ts` `.ps-wrap`（`#EFF7F0→#E7F1EA`，侧衬 6px）、`fruit-stack/index.ts` `.fs-wrap`（`#FFF4F8→#FBF0FF`，侧衬 0）、`src/styles.css` cg- 追加段 `.cg-wrap`（`#f2f7ea→#eaf3e4`，≤420px 侧衬归零）、`dot-maze/index.ts`（`#FFFBEA→#F4F0FF`）、`dark-chess/view.ts`（`#FDF3E4→#F7EDF6`）、`junqi-camp/view.ts`（`#F4F8EC→#EAF1F7`）。侧衬数值按各款盘面几何实测收敛，改壳卡先跑对应 `round2-fix.test.ts` 几何契约。
- **B6 · 深色大面积仅两处题材豁免**：pool-stars 台呢深绿与 dot-maze 深夜迷宫底。豁免条件是外层仍包家族壳卡（见 B5），登记于 r2 learner 第三节，不得新增第三处深盘面。
- **B7 · HUD 白底圆丸**：状态 chips 一律 `background:#fff;border-radius:999px` + 2px 级投影（`dot-maze/index.ts` `.dmz-chip`、`fruit-stack/index.ts` `.fs-chip` 等 8/9 款）。按钮圆角存在「999px 圆丸派」与「12–16px 圆角矩派」双方言，r2 会签维持不强并，新款自选一派内部一致即可。

## 二、描边宽度档位（B8–B10）

- **B8 · SVG 棋子描边 1.2px 档**：`chess-garden/art.ts` `duoTone()` 的 `stroke-width="1.2"`（本色描边整形层）为棋子类内联 SVG 的统一档位；军衔条金星描边同档（`junqi-camp/art.ts` `rankBadgeSVG()`）。
- **B9 · canvas 线宽三档**：细节线 1.2–1.4 / 结构线 1.8–2.2 / 依尺寸自适应线 `max(1.5, r*0.12)`。出处：`dot-maze/art.ts` 各绘制函数（:126 `1.2`、:344 `1.8`、:296 `2.2`）与 `drawGhostFigure()` 呆毛描边（:448 `Math.max(1.5, r*0.12)`）。缩小到 16px 时 1.2 档允许糊、自适应档必须存活。
- **B10 · 强调框 3px 档**：选中 / 目标高亮用 `inset 0 0 0 3px` 级内描边（`merge-2048/index.ts` :173 `.mg-goal` 的 `#E08FA6` 内框；`fruit-stack` 盆沿 3px 座位色内衬同档）。不再出现 >3px 的装饰描边。

## 三、左上光照约定（B11–B13）

- **B11 · 光源统一左上 45°**：9 款全部成立（A 档 r1 全查、r3 终验维持）。SVG 范式：`chess-garden/art.ts` `duoTone()`——同一路径三层「本色描边整形 → 半透明暗纱 `rgba(56,34,16,.14)` → 向顶部左上内缩 92% 的本色亮层」，顶亮、底与右缘留一圈暗。
- **B12 · canvas 高光点落左上象限**：`pool-stars/art.ts` 球体高光斑圆心 `(-r*0.38, -r*0.42)`（:139），径向渐变白 `.95→0`；`fruit-stack/art.ts` `paintFruit()` 果面三停径向同口径。
- **B13 · CSS 面高光走 135° 对角**：`merge-2048/art.ts` `tileFaceCSS()`——`linear-gradient(135deg, lighten14% 0%, 本色 55%, darken6% 100%)`，左上提亮右下压暗；配外层深色厚度边成「宝石面」。平涂新增面一律套这三选一范式（B11/B12/B13），不引 defs/id（内联多份会撞 id，见 `dark-chess/art.ts` `pieceFaceSVG()` 的 uid 拼接教训）。

## 四、动效三段式与 reduced 退化（B14–B17）

- **B14 · 弹出三段式**：`0% 缩起 → 45–65% 过冲 1.12–1.18 → 100% 落回 1`。出处：`merge-2048/index.ts` `@keyframes mgpop`（1→1.18→1）、`sudoku-petal/index.ts` `@keyframes sppop`（.72→1.12→1）、`spbloom`（.2→1.12→1）。新动效不超过 1.2 过冲、总时长 ≤420ms。
- **B15 · 翻面一律压扁、不透视**：单段式 `mine-garden/index.ts` `@keyframes mnflip`（rotateX 70°→0、110ms）与 `junqi-camp/view.ts` `@keyframes jq-flip`（rotateY 88°→0）；两段式 `dark-chess/view.ts` `@keyframes dcFlipIn`（前半旋到 90° JS 中点换面，后半 -90°→0）。**全部不设 `perspective`**，rotateX/rotateY 在无透视下渲染为纯压扁，这是「压扁翻面」的实现口径；数字键翻面同款（`sudoku-petal` `spdigitflip` 直接 `scaleX(1→0→1)`）。
- **B16 · reduced 双保险**：每款自带 `@media (prefers-reduced-motion:reduce)` 块（9/9，A 档 r3 实测功能提示 9/9 可见）——装饰动效 `animation:none` 后必须留静态可读终态（`merge-2048/index.ts` :247 `.mg-goal::after{animation:none;opacity:.3}`），纯 fx 节点直接 `display:none`（`sudoku-petal/index.ts` :446 `.sp-budfx,.sp-petalfx,.sp-linefx`）；JS 侧另有 matchMedia 早退（`junqi-camp/view.ts` :183）。新动效两层都要接。
- **B17 · 同屏强动效 ≤1 条**：棋牌/数字盘面的信息层自带图案密度，背景静层 ≤2、盘外静饰 ≤3 件、同屏强动效 ≤1 条是本窗上限（r2 learner 第二节 2.1，9 款读码复测全部在上限内）。要减负时先减动效通道，**盘内信息记号（军衔条 / 战力点 / 种子点 / 星级角标）永远不减**。

## 五、道具体积规格（B18–B21）

- **B18 · 可交互体最小 14px**：pool-stars 球径 ≥14px 三档契约（`pool-stars/round1-fix.test.ts`）；HUD 正文字号 ≥14px 已由 r3 全目录契约钉成总闸（各款 `round3-final-verify.test.ts` 字号闸）。登记豁免仅：`.cg-coord` 10.5px 加粗 / `.cg-piece-tag` 12px（40px 格内辅助标注，A 档 r1 核准）与 `l99-star` 12px（共用件装饰字符）。
- **B19 · 「数量可数」记号 11px 见方即可用**：`junqi-camp/view.ts` `.jq-mark` 11×11px 角标、`dark-chess/art.ts` `pieceFaceSVG()` 战力点 `r=1.9`（:70）实测活到 16px 灰度化。比放大记号更要紧的是记号四周留 ≥1.5px 静空，并先盘点该格四角的状态占位（选中框 / 落点点 / 光标框），空角才是落点（jq-mark 落左下即因右下被落点绿点占用）。
- **B20 · 圆形道具用 2–3 停径向 + halo**：`dot-maze/art.ts` `dotSprite()` / `powerSprite()`（豆 / 能量豆），`fruit-stack/art.ts` `paintFruit()`（hi→主色→edge 三停，11 级 hi 色互异有契约）。
- **B21 · 体积感来源限「两笔以内的层叠明暗」**：`chess-garden/art.ts` `duoTone()`（三层但两停明暗）、`dark-chess/art.ts` `backSVG()` 三停层叠实心（零 defs）、`pieceFaceSVG()` 底部椭圆错位半格的厚度阴影。禁止用透视 / 立体投影造体积（见第七节）。

## 六、双人可区分手法（B22–B24）

- **B22 · 「形状 + 颜色」双通道缺一不可**：颜色通道 16px 灰度差 ≥20（junqi 底停实测 Δ42.8，契约钉 ≥40：`junqi-camp/round2-fix.test.ts`）；形状通道必须独立成立——`junqi-camp/art.ts` `sideMarkSVG()`（朵朵圆瓣花 ≥5 圆 / 星星尖角星 polygon 零 circle，去色互异 12 兵种×双方全量契约）、`pool-stars/art.ts` 花印 vs 星印（极小尺寸退化形：圆点 vs 菱形点，契约在跑）、`dark-chess` 金钩 vs 银钩 + 环色。
- **B23 · 同款道具的座位差异做在「沿 / 边」上**：`fruit-stack/index.ts` `drawRim()` 盆口两侧 3px 座位色内衬（B1 token），纯视觉描边、碰撞盒不变。双人道具本体不换形，避免玩法不对称的错觉。
- **B24 · 旗帜 / 徽记类双方形状分家**：`junqi-camp/art.ts` `crestSVG` / `hqSVG` / `hoistSVG` 三处旗形互异（三角尖旗+花徽 vs 燕尾旗+星徽），抽象几何旗，禁写实军徽（见商标终审）。

## 七、精 2D 可读性（B25–B28）

- **B25 · 俯视正投影是盘面信息的唯一无损投影**：棋盘每格承载等量信息，透视 / 等距会让远格记号先被挤掉（360px 视口格宽仅 27–44px）。9 款盘面全部正对相机：canvas 盘面（dot-maze / fruit-stack / pool-stars / mine-garden 小地图）与 DOM 网格（其余）均零透视。
- **B26 · 翻面 / 起伏一律压扁实现**：见 B14/B15——`mnflip` `jq-flip` `dcFlipIn` `spdigitflip` 四款翻面全部无 `perspective`，等效 scaleX/scaleY 压扁。棋子高度感只许来自 B21 层叠明暗，不许让棋子「立起来」遮挡邻格落点提示。
- **B27 · 零透视关键字机器闸**：`perspective` / `rotate3d` / `matrix3d` / `translateZ` / `three.js` 在 9 款全目录非测试源码零出现，契约为每款 `round3-final-verify.test.ts` 第①道闸（B 档 r2 建议、A 档 r3 落地）。任何统一化 / 修复建议若引入上述关键字，一票否决。
- **B28 · 文字通道优先**：以汉字 / 数字为第一信息层的 5 款（merge-2048 / sudoku-petal / junqi-camp / dark-chess / mine-garden 数字）字形永不倾斜；窄屏取舍时「收辅助记号、留文字」（`dark-chess/view.ts` :114 `≤400px` 收起战力点 `g.dcd` 只留汉字，文案已同步教学）。
