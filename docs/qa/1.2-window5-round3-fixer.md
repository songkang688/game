## F5 · 一个刻意的重复，写在这里免得以后被当成疏漏

本窗口现在有 **5 份**「量舞台下沿 → 自己钳 → 自己滚」的近似实现：

| 文件 | 这一份多做了什么 |
| --- | --- |
| `poop-hero/runtime.ts` `wrapRoomPx` | 画布收到底仍装不下时，壳层自己挂滚动条 |
| `shape-kingdom/dockTight.ts` | 按量收薄常驻控件摞；钳完把图形整张送进眼里 |
| `word-garden/fit.ts` `fitQuizHost` | 钳位 + 把选项排送进眼里 + 松开 `min-height`；答题屏 / 组字工坊 / 描红台三条入口共用 |
| `kitty-care/runtime.ts` `fitIntoStage` / `showPlayRow` | 先逐档收猫、收不下才滚；滚了就把动手层送进眼里（要减掉粘住那一行的高） |
| `red-blue-tug/fit.ts` | **不挂滚动条**，改成四档收紧（扣场地 → 减空隙 → 收字号 → 扣按钮） |

**这是故意的，不是复制粘贴的疏忽。** 抽成公共件得放 `src/games/` 根或 `src/ui/**`，
那是跨窗口共用目录，本窗口无权改。每份文件的头注释里都写明了这一点。
真要合并，得等平台侧（窗口 1）把 `.game-stage` 的定高硬裁一起收掉——
到那天这五份大半可以直接删掉，而不是搬家。
