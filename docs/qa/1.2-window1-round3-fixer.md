## 一、W1-R3-01 · 只掷骰也能通关 —— 修了两遍才算修住

### 第一版：把「手里攥住 N 处产业」加进过关条件

测试员给的方向是「净资产达标 **且** 手里至少有 N 处产业」，我先照这个做了：

- `LevelGoal` 加一个门槛字段，`goalReached()` 先看地够不够再看钱；
- 门槛取「开局赠地 ＋ 本章要求新买的处数」，`BUYS_BY_CHAPTER = [2,2,2,2,2,1,2,2]`
  （第 6 章「抵押周转」开局只有 320 星币，买第二块会把自己压破产，所以只要 1 处）；
- 门槛一加，188 关里有十来关的参考解法**在回合预算内买不够**，逐关搜了新的骰序补进
  `SEED_FIX`（同一关的 seed 只往后挪几格，关卡形状不变）；
- 顺带修掉第 8 章「对手一两个回合就把自己付破产」：`CH8_RIVAL_CASH` 从 150 抬到 320，
  残局才有得算。

到这一步单测全绿：188 关逐关回放全部达标，「只掷骰」的懒人假人在 4 个样本关上全部**不过关**。

### 浏览器复验推翻了第一版

单测绿不等于产品对。真浏览器上照「只点掷骰、一块地都不买」打第 170 关，
结算浮层弹出来的是：

```
★★★ 第 170 关过关！ 16 回合达成目标，净资产 4479 星币
```

**还是过关了。** 原因是第 8 章的目标是「让对手收摊」，而对手收摊时
**他名下的地会整批转到债主（也就是孩子）名下** —— 手里的地一下子就够了。
「手里攥住 N 处」这道门在第 8 章等于白送。

### 第二版（树上留的这一版）：只数「自己掏钱拿下的地」

给每个座位加一个 `deedsBought` 计数，**只有真的付了钱才记一笔**：

| 拿到地的方式 | 记不记 |
| --- | --- |
| 停在空地上买下来（`buyTile`） | ✅ 记 |
| 拍卖拍到（`runAuction` 落槌） | ✅ 记 |
| 接盘别人甩卖的地（`tryRaise` 的救急交易） | ✅ 记 |
| 开局赠地（`preset`） | ❌ 不记 |
| 对手收摊整批转过来（`declareBankrupt`） | ❌ 不记 |

过关条件随之改成「钱到线 / 对手收摊 **且** `deedsBought ≥ goal.minBuys`」，
UI 文案从「手里攥住 N 处产业」改成「自己买下 N 处产业」，
没过关时的那句话也跟着说清楚差在哪：

> 就差一点点！这一局自己还差买 2 处产业，下一把路过空地就把它买下来，肯定能行！

**关卡可解性重新逐关验过**：口径从「手里有几块」换成「自己买了几块」之后，
第 61 / 62 关的参考解法差一处，各自又补了一格 seed（`SEED_FIX` 里 `60: 4` / `61: 3`），
188 关重新全绿。

### 证据

| 判据 | 结果 |
| --- | --- |
| 188 关参考解法逐关回放 | 全部在回合预算内达标 |
| 「只掷骰」的懒人假人（`passiveRun`，样本 12 / 31 / 60 / 109 关） | 一块地都没买，**全部不过关**；其中有关卡是「钱够了但地没买」 |
| 白拿的地不顶数 | 单测：把一批地整批判给朵朵、对手标成收摊，`goalReached` 仍为 `false`；自己买够才 `true` |
| 第 8 章对手起手钱 | 165 ～ 188 关全部 ≥ 320，参考解法至少要打 2 个回合 |
| 真浏览器（第 170 关，只点掷骰 / 不买 / 不跟） | `就差一点点！这一局自己还差买 2 处产业…` |
| 真浏览器（第 1 关，正常经营） | `第 1 关过关！`（第 1 把） |

## 二、W1-R3-02 · 别人快破产时，游戏拿孩子的钱替他把地买了（本轮新抓 · 严重）

### 怎么撞见的

第二版修完之后，浏览器上那句失败文案第一次跑出来写的是
**「还差买 1 处产业」** —— 可门槛是 2，而这个假人**一次「买下」都没点过**。
也就是说有一处产业是它**没花心思、也没被问过**就到手的。

顺着这一处查下去，落在 `economy.ts` 的救急交易上：

```ts
rescue: (debtorId, pos) => {
  for (const id of alivePlayers(state)) {
    if (id === debtorId) continue;
    const offer = ctx.policyOf(id).rescueOffer(state, id, pos);   // ← 人类座位也被问了
    …
```

同一个文件里，**买地** (`wantBuy`) 和 **拍卖** (`bidLimit`) 都明明白白地把人类座位挡在外面
（`ctx.humans?.has(id)` → 不出价，注释还写着「绝不背着他掏钱」），
**唯独救急接盘这一条漏了**。于是别人快破产时，孩子的 AI 策略会替他掏几百星币把地接下来：
钱是他的，地也记在他名下，而他自己既没看见弹窗、也没按过任何键。

### 为什么定严重

1. **背着孩子花钱**，和这一款自己写下的口径直接相反；
2. 它**正好把第一节那道门送掉一半** —— 战役要求「自己买下 N 处」，
   而游戏会自动替他买。W1-R3-01 如果只修到第二版就收工，这条会让门槛在有对手破产的关卡上失效。

### 修法

救急接盘的循环里补一句 `if (ctx.humans?.has(id)) continue;` —— 和买地、拍卖同一个口径。
**AI 之间照样能互相接盘**（这条路没有被堵死，只是不许伸手到孩子兜里）。

### 证据

| 判据 | 结果 |
| --- | --- |
| 单测「人类座位不参与接盘」 | 债主是人类座位时，地不落在他名下、现金一分不动、`deedsBought` 仍是 0 |
| 单测「AI 座位照样会接盘」 | 同一局面换成 AI 座位，地成交、`deedsBought` ＋1 |
| 真浏览器（第 170 关，只点掷骰） | 失败文案从「还差买 **1** 处」变成「还差买 **2** 处」—— 那处白送的地没有了 |

## 三、走查工装这一轮踩的坑（不是产品缺陷，但必须记下来）

收官轮有一半时间花在「假人为什么打不出结果」上。三处坑都改在脚本里，
产品一个字没动，但下一位接手的人值得先看这一节：

1. **「⏭️ 跳过 第 N 关」被 `/结束回合|过/` 命中。** 假人本来想点「结束回合」，
   实际把这一关整个跳掉了 —— 于是永远等不到结算浮层，报出来是「超时没结算」。
   正则收紧成 `/结束回合/`。
2. **进了小黑屋，掷骰那颗会改名叫「🎲 掷同点」。** 只认「掷骰」的假人会在小黑屋里
   坐到超时。名单补上 `掷同点` 与 `用出门卡`。
3. **`block-drop` 的通关剧本，贪心算不出来。** 每一手只挑眼前分数最高的落点，
   第 1 关 22 个块下完**消行 0**。改成定宽束搜索（宽 60，出块顺序是定死的，
   先整串取出来再搜），第 1 / 12 / 60 / 140 关都能在预算内算出通关剧本，
   浏览器上第 1 把就过。
   > 剧本落在 `.qa-tmp/block-drop-plan.json`，这个目录**不进 git**。
   > 换机器重跑走查前要先跑一遍算剧本的探针，否则 `block-drop` 的赢局会报
   > 「按键剧本没算出来」。
4. **`snake-royale` 第 160 关的真负证据会偶发超时。** 这一关本身是 **119 秒**的局，
   而输局预算只有 90 秒：一根手指不动的蛇有时几十秒就被别人吃掉（拿得到证据），
   有时能一直滑到时间用完（拿不到）。同一天两次跑分别是「就差一点点」和「超时没结算」，
   **不是产品时好时坏，是尺子比局还短**。这一款的输局预算放宽到 180 秒之后稳定复现。

前三处都会把工装问题伪装成产品缺陷，第四处会把产品的正常行为伪装成偶发故障 ——
收官轮如果按第一版读数交卷，报告会同时冤枉产品和放过 W1-R3-02。

另外，第 3 轮测试员报告第三节里「canvas 款分不出来、记成不可判」的那套双人判据，
本轮把工装也一并补强了：DOM 指纹从「文字」换成**结构指纹**（标签 ＋ `class` ＋
`aria-label` ＋ 内联 `style`，故意不取文字，免得秒表每秒变一次把判据糊掉）、
进双人后会去点各款自己的「开始」钮、回合制的款每套键位最多重试三轮
（只有轮到的那一位才认键）。补强之后 **11 款 41 项全部判得出来、全部通过**，
不再有「不可判」。
