### 0.3 每款必做（一款不漏）

1. 首页 / 深链定位；
2. 真赢一次 + 真输一次，都玩到结算；
3. 战役第 **1 / 76 / 188** 关都真打到结算；
4. 有几种模式就每种玩到结算；
5. 360px 宽下量热区（≥ 44px）—— **第 2 轮修复员刚补的那批按钮必须重新量一遍**
   （`gomoku` `.gmk-btns/.gmk-seg/.gmk-mode/.gmk-over-btn`、`xiangqi` `.xq-btns/.xq-mode/.xq-over-btn`
   含 `@media (max-width:380px)` 那一档、`rainbow-run` 与 `ocean-munch` 的 `touchArea` 10 处）；
6. `destroy`：进 → 玩 → 退出 → 再进，数监听 / 定时器 / 子节点 / rAF；
7. 商标黑名单逐条扫，必须 **0** 命中。

外加：难度曲线、竞态、无尽可持续性、红线词（无血无死亡 / 无广告内购抽卡 / 无联网上报）。

### 0.6 走查手法

- 走查脚本一律临时件，放在 `src/__r3packc__/`（vitest 的 `include` 是 `src/**/*.test.ts`，
  放这儿才跑得起来，且**不在 `src/games/**` 下**），取证完成后整目录删除。
- 与 1.1 的对比用 `git show origin/game-1.1:<path>` 取原文当参照，不改工作区。
- 对局与动画一律冻时钟（假 `performance.now` / 假 `rAF` / mulberry32 定 seed），保证可复现。
