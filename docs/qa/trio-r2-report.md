## 二、缺陷清单

### 缺陷 1(S3,已修复):结算浮层/弹窗没有防狂点冷静期,胜利瞬间被孩子的连点误触

- **复现**:红蓝拔河第 1 关狂点拉绳到获胜 → l99 结算浮层弹出的瞬间,孩子的手指还在原地连点 →
  点击落在「🔁 再玩一次」上,结算画面根本没看到就重开了。自动化实测:结算按钮与狂点热区重叠,
  连续狂点时连着误触 3 次「再玩一次」,本来 ~60 次点击能赢的关卡点了 160 次才「看到」结算。
- **影响面**:所有狂点/连点型玩法(红蓝拔河、红蓝点点、地鼠嘭嘭、气球砰砰、红蓝赛跑…)的
  l99 结算浮层,以及 34 款共用的平台结算弹窗(`showResultDialog` 的「再玩一次/回首页」)。
  对 6–7 岁孩子是高频真实场景:赢了却「莫名其妙又开始了」,还会误触「回首页」丢上下文。
- **修复**:
  - `src/ui/dialogs.ts`:新增 `CLICK_GUARD_MS = 400` 与纯函数 `isGuardedClick`;
    `showDialog` 的按钮在弹出后 400ms 内的点击一律忽略(冷静期)。
  - `src/games/level99.ts`:`showOverlay` 的结算按钮加同一冷静期。
  - 单测:`src/ui/dialogs.test.ts` 新增 3 例(冷静期内忽略/期满生效/自定义时长)。
- **验证**:修复后重跑同场景,拔河狂点 60 次获胜,结算浮层稳稳停住不再被误触;
  正常节奏(≥400ms)点「下一关/再玩一次/回地图」不受影响(算数小农场全链路复验);
  34 款全量冒烟 + 22 款 l99 深关冒烟重跑全绿。
