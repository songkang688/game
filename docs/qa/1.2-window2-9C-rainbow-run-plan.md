## 二、现状审查结论

| 问题 | 结论 |
| --- | --- |
| 相机参数能否单测 | 能。`HORIZON_RATIO 0.3`、`CAM_DEPTH_RATIO 1.35`、玩家线 `0.78h`、`MAX_SCALE 2.4`、`MIN_SCALE 0.05`、`FOG_START_SCALE 0.55`、`SPAWN_TRACK_Y -680` 全是导出常量,`view3d.test.ts` 已经在测 |
| 画质降级指标 | 指数平滑帧率(权重 0.08)+ 迟滞阈值 `FPS_DOWNGRADE 45` / `FPS_UPGRADE 55`,三档砍视差层数、粒子倍率、网格间距 |
| 土狼 / 缓冲 | `COYOTE_TIME 0.09`、`INPUT_BUFFER 0.12`,都有单测 |
| 换道插值 | **不达标**:`smoothing(dt, 10)` 走完 90% 要 230ms,规格要 80–120ms。本步补 `LANE_GLIDE` 常量 |
| 30fps vs 60fps | 换道与镜头跟随用 `smoothing()` 已是帧率无关;但跳跃是 `actionTimer` 计时 + `sin` 曲线,没有速度/重力积分,也没有位移差断言 |
| 必过窗口覆盖 | 8 个模板全覆盖,`endless.test.ts` 已有随机 2000 段断言(空车道构造法) |
| 存档 key | 战役 `yiduo-yixing.rainbow-run.campaign.v2`;无尽 `yiduo-yixing.rainbow-run.endless-record.v2`。**都没走** `l99` 与 `save.recordEndlessBest` |
| 收藏册加成 | **没作用到跑酷**,只有一个开面板的 🎁 按钮,`collectionEffects()` 一次都没调 |
| HUD 叠字 | 战役 ↔ 无尽是互斥分支,不会叠;但无尽追赶条 12px 小于 13px 下限 |
| 窄屏溢出 | 「世界选择」卡片的章节名与简介没有量宽,360px 会横向溢出 |

## 三、本步要做的事

1. **日夜与天气光照** — 新增 `daynight.ts`:按距离循环晨 / 昼 / 黄昏 / 夜的纯函数,
   返回雾色、网格亮度、远景色温、雨天反光强度。全部是纯 Canvas 渐变,不加贴图。
2. **幽灵竞速** — 新增 `ghost.ts`:换道 / 跳 / 滑 + 时间戳的精简快照,
   上限 3 分钟与 1200 条事件,压成一行字符串,往返有单测;下一趟半透明幽灵同场。
3. **路段语法升级** — `endless.ts` 加四种模板:三连节拍段、低梁抢道、彩纸箱链、分岔合流。
   校验器同步升级成「可通过车道」口径(空道、或跳 / 滑能过的道),
   新增 `fairWindows()` 落实「任意连续 3 行不得三条车道全是既不可跳又不可滑」。
4. **手感常量 + dt 积分** — 新增 `motion.ts`:换道 80–120ms、速度 / 重力 / 跳跃初速全按 dt 积分,
   30fps 与 60fps 同一段路位移差 < 2% 写成断言;换道侧倾在 reduced-motion 下取消。
5. **平台接线** — 新增 `campaign.ts`:`openCampaignLevel(n)` 直开第 N 关(越界 clamp)、
   `?level=` 与 `api.initialLevel`、Skip 走 `getLevelExtras().requestSkip`、
   无尽成绩走 `save.recordEndlessBest`(老 key 读一次迁移)、收藏册加成封顶。
6. **战役 188 关**:关卡表一个数都不改,只改渲染与手感。
7. **同屏双人不做**:双人跑酷归 `duo-rush`(第 11 步 A 的地盘),这里一个字都不碰。
