## 二、盲区题材密度基准补充（棋牌 / 教育 / 养成）

第 1 轮的基准表按题材给了「背景层数 / 装饰物件数 / 动效通道数」三个数；本轮按任务书把第 1 轮覆盖不足的三类补透，核心结论是**「怎么少而精」**。方法同第 1 轮：回看成熟平台（4399 及同类）头部作品的通用做法，只记文字结论，无任何素材落盘。

### 2.1 棋牌桌面

**本窗无棋牌**（本窗 12 款无一属棋牌桌面题材；chess-garden / gomoku / dark-chess 等归别窗）。基准学习不越窗做，仅留一条通用观察供全局参考：头部棋牌款的密度几乎全部让位给「盘面可读性」，桌面陈设常年只有 2 层（桌布纹理 + 盘框），动效通道 ≤3 且全部服务于落子确认与胜负仪式。

### 2.2 教育四款（本窗：clock-house / math-farm / pinyin-train / word-garden）

头部教育小游戏的密度基准显著低于娱乐题材，且「低」得非常讲究，拆成四条可执行结论：

1. **答题区是净土**：装饰物件永远不进答题区的包围盒。头部作品的舞台陈设（农场、车站、教室）一律停在题卡边界之外，题卡内部只有「题目本体 + 选项」两种元素。本窗现状对表：四款全部达标——math-farm 的谷仓风车停在题卡外、word-garden 米字格内只有笔迹与引导点、clock-house 摆锤暖窗在小屋段不进钟面、pinyin-train 站台喇叭不进车票行。**这条要在 C 档后续轮次里守住**：任何「加氛围」的建议（含我自己的 TOP9 一类）都不适用于教育款答题区。
2. **内容性密度 ≠ 装饰性密度**：教育款唯一允许「加密度」的方向是把**教学内容本体**实物化——数一数的计数物、认字的配图、钟面的刻度。这类元素每多一个都在帮孩子建立「数量↔实物」「字↔物」的映射，不算分心。C 档第 1 轮的 stickers 贴纸化（W8R1-01/02）正是这条的教科书式落地：密度涨了（题卡里多了最多 14 枚贴纸），但涨的全是内容，A 档实测教学数据零改动、答题不受扰。结论：**教育款的密度预算优先全给内容性密度，装饰性密度上限压在其他题材的一半以下**（背景 2–3 层、常驻微动 ≤2 处，第 1 轮基准表数字维持）。
3. **仪式动效只在「答对瞬间」放**：头部教育款的动效预算集中在答对反馈的 600–900ms 里（彩纸、点亮、小动物欢呼），常态画面几乎静止——这与娱乐题材「常态就热闹」相反。本窗四款的动效通道（3 条上下）符合此基准；clock-house 答对的小鸟弹跳 + 星屑正是标准做法，但**星屑用裸 ✨ emoji（W8R2-03）和小鸟遮住连对徽章（W8R2-02）说明仪式层的工艺与位置还欠打磨**——仪式动效因为出现频次最高（每答对一次放一次），工艺瑕疵会被放大，值得优先修。
4. **留白就是给注意力让路**：word-garden 的宣纸底 + 一条花园横条、pinyin-train 的单排候选车票，看似比基准「少一层」，实际正是头部教育款的做法——第 1 轮我把这两处记为「风格取舍可接受（-1）」，本轮升级结论为**「主动正确」**：教育款对表密度基准时，差 1 层以内不但不算缺陷，反而不应该去补。

### 2.3 照护养成（本窗：kitty-care）

头部养成款「少而精」的三条结论：

1. **密度堆在主角身上，不堆在房间里**：主角立绘占屏 25–40%、表情/耳朵/尾巴的状态通道 3–4 条，而房间陈设普遍只有 2 层且低饱和——玩家的眼睛 90% 时间在主角身上，陈设只提供「在家」的氛围。kitty-care 现状（猫三态立绘 + 房间三段）达标。
2. **道具必须成套自绘、风格同炉**：养成款的道具（食物/玩具/配饰）是玩家高频交互对象，头部作品全部成套自绘且与主角同一工序——第 1 轮我把 kitty-care 道具 emoji 记为密度 -2 的主因，C 档 12 种道具贴纸化后，本轮把这一格改判 **0（达标）**：气泡与托盘同套图卡、贴纸与看病 toolIconSvg 同工序，正是「同炉」标准。
3. **反馈物件宁少勿滥**：飘心、音符这类情绪反馈一次 3–5 枚就是头部款的克制线，多了会淹掉主角表情这个真正的情绪通道。kitty-care 现状（heartBubbleSpecs 定量生成）在线内。

## 三、横向一致性评审——最违和 5 款与统一化建议

评审口径：本窗 12 款升级后放在一起看（入口页卡片 + 玩局首屏），从**色板偏离 / 描边粗细 / 光照方向 / 动效节奏 / 工艺代际**五个维度找「不像一家人」的款。证据全部来自只读代码检视与 A 档两轮实测数据。总体结论先行：经过第 1 轮修复，12 款的 kit 一致性（2px 系描边、左上 45° 受光、粉彩色板、贴纸工序）已经成型，违和主要剩在**「emoji 残留」与「新旧工艺两代同堂」**两个族群。按违和程度排序点名 5 款：

### 3.1 red-blue-tap（最违和 · 工艺代际断层在核心交互物上）

- **违和在哪**：闯关模式的核心操作对象「点点」是裸 emoji 直出（`index.ts:31-46` SKINS 十章 mine/trap 皮肤 🔵🔴⭐🌑⚡🌩️💙❤️👑💣💠🟥🟪🟦🟫🌟 + 道具 ❄️🧲，`:527` 直排 textContent）——同款游戏的**对战场**已经是 jellyBtn 果冻按钮 + 信号形状双通道的库内工艺，一款游戏里两代工艺同屏；放到 12 款里看，其余 11 款的核心交互物全部矢量/贴纸化，只有它还是系统 emoji 渲染（不同 OS 字形还不一致）。场地素底（TOP9 未消化）加重了「半成品感」。
- **统一化建议（绘制规格级）**：对应 W8R2-01（A 档已定严重级）。emoji → 贴纸映射走 `stickers.ts` 扩容（该件是 C 档独占可自扩）或本款独占件：17 个符号按贴纸工序（双色分面 + 2px 深描边 + 左上高光 + 软投影）重画，圆/方/菱形系直接几何拼装，⭐🌟 沿 glowStar 的十点星外轮廓（不加脸），👑 画三尖圆头王冠（尖顶圆球化，避开任何具体游戏王冠造型），💣 画成圆滚滚软弹 + 火花改星点（分级红线：无伤害暗示）；`.rbt-dot` 内 emoji 收 sr-only，62px 热区与判定（读 skin 字符）零改动。氛围底按 TOP9 规格同 commit 带上。

### 3.2 find-diff（盘面主体整块停在 1.1 工艺）

- **违和在哪**：侦探书桌、双木画框、徽章沙漏全是 1.3 矢量工艺，但**盘面本体**——玩家盯着看的那 18–30 格——仍是 92 种 emoji 直排（W8R1-04 挂账中）。边框越精致、盘面越显旧，是 12 款里「画框与画不配套」的唯一一款。挂账合理（题目数据 SHA-256 钉死、需数据版本化专项），但横向看它仍是违和第二名。
