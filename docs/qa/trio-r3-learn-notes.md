## 二、本轮改动（全部在 `sling-birds/` 本目录，不动玩法入口约定与存档 key）

### 1. 竖屏画布自适应（R2 遗留主项）

- `physics.ts` 新增纯函数 `canvasBufferHeight(boxW, boxH)` 与 `padSplit(bufferH)`：
  宽度固定映射 `WORLD_W`，竖屏时缓冲高度按舞台宽高比延展（上限 2.6 倍防无限拉伸），
  延展量拆成上方天空（72%，高弧线不再飞出画面）+ 下方泥土装饰（28%）。
- `index.ts`：游戏区改 flex 填满舞台；画布绝对定位脱离布局流（自身尺寸不反过来影响舞台
  测量，避免布局反馈环）；`resize` + `ResizeObserver`（有则用）双通道重测；
  指针坐标映射同步换算天空偏移，**拉弓手感与实弹完全不变**（物理世界坐标系未动）。
- 渲染：天空渐变铺到画布顶 + 延展区飘慢云；泥土延展区点缀确定性小石子；
  关卡横幅从世界坐标改钉画布顶部（否则天空延展后会掉到屏幕中间）。
- 412×915 实测：画布 347×568（此前约 347×218），占舞台 70%，其余为教练卡/按钮/徽章，
  舞台不再有成片留白；横屏 915×412 无溢出、缓冲退回原始 340 不裁玩法区。

### 2. 教练卡 + 技能口诀朗读（走现有 `speech.ts`，不动 engine audio）

- 画布下方新增「教练卡」：当前小鸟头像色点 + 名字·技能（15px 加粗）+ 口诀（15px，
  原 14px 低对比小字），转瞬即逝的飞行/胜负消息也落在这里。
- 自动朗读规则：**每关第一只小鸟、以及换到不同种类的小鸟时**念技能口诀；
  同一关反复重试、同种小鸟连发不重复念（防唠叨）；🔈「再听一遍」按钮 46×46，
  无中文语音包时按钮隐藏、全程静默（沿用 speech.ts 降级行为）。
- 防叠音：回选关、点重来、destroy 时 `stopSpeaking()`；胜负那次平台弹窗自带朗读（R1），
  `speak` 本身会顶掉未念完的口诀，不叠音。
