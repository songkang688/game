## 0. 扫描计划（开工承诺）

1. **全量跑与盘点**：`npm ci` → `npx vitest run`（全仓）→ `npx tsc --noEmit` → `npx vite build` / `vite preview` 冒烟；记录用例总数对照「只增不减」；清点 kit/motion/runner 与九款文件清单，对照 `docs/qa/1.3-window1-plan.md` 十二格提交 SHA。
2. **六大专项**（收缩到本窗 12 格，逐条给证据）：
   - ① 火柴人 / 草稿圆：grep `fillText(` emoji 直出 + 「纯圆 + 两点眼」画法；
   - ② 金币体积：收集物绘制函数须 ≥2 停渐变 + 高光 + 描边/落影之一；
   - ③ 多角色可区分：hero-cards 14 头像、flight-chess 四色、combo-clash 双人等，16px 灰度两通道可分辨；
   - ④ 纵深 / 体积：kit 三阶光影、棋牌/消除类精 2D 体积；禁 three.js；
   - ⑤ 360px 布局：360×640 + 320px 极限，溢出/遮挡/字号<14px/触区<40px；
   - ⑥ 商标扫描：`rg -i "<黑名单>" src/ README.md --glob '!.cursor/skills/**'`。
3. **横向一致性**：kit 光照约定（左上 45°、高光偏移、描边 1.5–2px）九款遵守情况；`prefers-reduced-motion` 降级；`destroy` 泄漏（进→退 ×5）；粒子节流。
4. **产出**：本报告六大专项逐节 + 问题清单（位置/现状/期望/严重度/责任文件）+ 12 格 × 六专项结果矩阵；可新增机器化扫描 `*.test.ts` 用例。
