### A1 · 复审手法：为什么不认 `el.click()`

一台 `google-chrome --headless=new`，Node 22 自带的全局 `WebSocket` 直连 CDP，**零新增依赖**。
点击一律走 `Input.dispatchMouseEvent`、滑动一律走 `Input.dispatchTouchEvent`，全程真实屏幕坐标。

判「点得着」这件事，本轮用的尺子比前两轮又紧了一格，**两条同时成立才算数**：

1. 键心必须落在「**所有裁切祖先 ∩ 视口**」围出来的那块真看得见的矩形里；
2. 在键心上问 `document.elementFromPoint`，拿回来的得是**它自己或它的后代**。

第 2 条里**去掉了 `hit.contains(el)`**（前几轮的写法带这一项）。这一项会放过一整类假绿：
舞台裁在 `y=554`、视口有 568，中间那 14px 的带子里 `elementFromPoint` 拿回来的是壳层大盒子，
而它**正好是这颗键的祖先**——按 `hit.contains(el)` 算就成了「点得着」，
可那一处画的根本不是这颗键，手指真按下去点到的是壳。
本轮就是靠去掉这一项才把 `color-fun` 调色台那几颗从「绿」里揪出来的（见 A2 · L-02）。

「滚一下够不够得着」分两步，**程序滚只算粗筛，不作数**：

- 粗筛：写 `scrollTop` / `scrollIntoView` 看理论上能不能进视区；
- **定案：真手指**。在滚动容器上派完整 `touchStart → touchMove ×14 → touchEnd`，
  落指点必须①在舞台看得见的那一段里、②在这层容器自己的矩形里、
  ③那一处不是 `touch-action:none`（涂色画布就是，按下去是画画不是滚）、
  ④不在写了 `overscroll-behavior:contain` 的小盒子里（那一下滚不出去，传不给外层）。
  滑到之后**再真按一次**，用文档级捕获监听确认游戏真收到了 `click`。

一次性量尺与探针全在 `/tmp/w5r2a/` 下，**0 字节进提交**（收尾前已 `rm`，`git status` 干净）。

### B1 · 复审手法：为什么不认 `el.click()`，以及这一轮又踩到的两把假尺子

一台 `google-chrome --headless=new`，Node 22 自带的全局 `WebSocket` 直连 CDP，**零新增依赖**。
被测的是 `npm run build` 的产物经 `vite preview` 起的那一份，不是 dev server。
点击一律 `Input.dispatchMouseEvent`、手势一律 `Input.dispatchTouchEvent`，全程真实屏幕坐标；
视口用 `Emulation.setDeviceMetricsOverride` + `setTouchEmulationEnabled`（`mobile:true`，5 触点）。

判「点得着」两条同时成立才算数：键心落在「所有裁切祖先 ∩ 视口」围出来的那块真看得见的矩形里，
并且在键心上问 `document.elementFromPoint` 拿回来的是**它自己或它的后代**。

**这一轮自己的探针先后被抓出三处会造假的地方，都改完才敢采信数字**——写在这里是因为
前两轮的「已落地」有一大半就栽在同类问题上，不把尺子先校准，复测出来的绿和它们的绿一样不值钱：

1. **探针装早了就等于没装。** 头一版在 `about:blank` 上注入 `window.__w5`，
   再 `location.hash` 跳进游戏——一路 `Cannot read properties of undefined (reading 'all')`。
   改成「进关、等到 `.game-stage` 出现之后再注入」。
   顺带把 PWA 的 `autoUpdate` 拆了（`dist` 一换 `sw.js` 页面会自己重载，探针跟着没），
   并在 `eval` 里兜一层：一旦报 `__w5` 不存在就补装再重来。
2. **存档得在应用启动之前就位。** 灌完 `localStorage` 直接跳 hash，读到的还是空档——
   `Save` 是页面加载那一刻建的。改成「灌 → 整页重载 → 再跳 hash」。
   `.fss-gbuy`（升级键）一开始量出来「禁用、点不响」，根因就在这儿，不是缺陷。
3. **滑动方向不能按「目标在起手点上边还是下边」猜。** 矮屏上挡住格子的是**常驻的 dock**：
   格子明明在起手点上方，却要把内容往上推才能从 dock 底下露出来。
   按老写法在 `scrollTop=0` 上会当场死锁，报成「划了 6 趟还够不着」——
   七巧板在 360×640 / 320×640 上一度被我自己判成「摆不满」，**那是探针的账，不是游戏的账**。
   改成扫：一个方向推到 `scrollTop` 不再变就掉头，两头都扫遍才算真够不着。
   另外点击监听里 `e.target.className` 对 SVG 是 `SVGAnimatedString`，`.slice` 会抛，一并修了。

#### `W5R2-FB-03`（严重）`red-blue-tap`：关卡在跑时模式条连藏都没藏

`d76eea0`。`b4324a7` 给 `poop-hero` / `red-blue-tug` / `find-diff` / `kitty-care`
四款补过「关卡在跑时侧模式入口点响了也不许开」（档C 的 `W5R2-C-06`）。
本款不在那四款里，我独立量了一遍——**这一款比那四款还差一档**：
那四款至少 `bar.hidden = true` 把手指挡住了，本款**连藏都没藏**。

⚔️ 双人对战      elementFromPoint 命中，disabled=false

孩子在关卡里手一滑点到 `⚔️`，对战屏盖上来，而底下那一关的秒表、小电脑的 AI、
点的生灭全都没停；等他退回去，那一关可能已经输了。

修法照抄 `b4324a7`，外加本款自己踩到的**第三条**：

1. `playLevel` 包一层：关卡一开 `bar.hidden = true` 且 `inLevel = true`，一销毁先落 `inLevel` 再销毁；
2. `openSide` 加闸 `if (side || inLevel) return`——`hidden` 挡的是手指，挡不住焦点残留与壳层补发的 click；
3. **补 `.rte-bar[hidden]{display:none}`**。这一条是打完前两步**复量时才露出来的**：
   `bar.hidden` 已经是 `true`，可这一条**还是 60px 高、两颗入口照旧命中**——
   `.rte-bar{display:flex}` 的优先级高过 UA 样式表里的 `[hidden]{display:none}`，属性写了等于没写。

四个状态真机复量全对：地图 60px/两颗 `ok:true` → 对战开着 0px/`ok:false` →
退出对战 60px/`ok:true` → 关内 0px/`ok:false` → 退回地图 60px/`ok:true` 且选关地图在。

#### `W5R2-FB-04`（阻断）`red-blue-tap`：场地宁可掉出屏幕也要撑住 216，点整片按不着

`5c9f54c`。竖屏三档连采 14 轮 × 逐颗 `elementFromPoint`，67 颗点 **0 漏**；横过来拿：

```

844×390   243…459(216)    378         10/10
740×360   243…459(216)    348         11/11

```

这一款**故意不给滚动条**（连点游戏，能滚就会「想点却滚走了」，`fitArena()` 的注释里写着），
所以够不着就是真的够不着。两处根因都补：

① `arenaHeightPx()` 守着 `ARENA_MIN_PX = 216`（「低于它三行点摆不开」）。
这条策略在竖屏上是对的，横屏上却变成**宁可让它掉出屏幕也要 216**。
摆得小一点还能玩，摆到屏幕外面就没得玩了——新增 `arenaBoxPx()`：
要得到 216 就照旧（**竖屏一个字没变**），要不到就退到「装得下就行」，
底线是**装得下一整颗点**（`ARENA_FLOOR_PX = 72 + 4×2 = 80`）。

② `placeDot()` 把 `top` 写成 `6% + random × 72%`，这对数字是按「场地 300px 上下」定的。
场地一收到 105px，78% 就是 82px，再加 72px 的点整颗探出场外（真机量到最大 **+24px**），
而 `.rbt-arena{overflow:hidden}` 把它裁掉半颗——**看得见一半、按下去却在场外**。
改成 `dotBandPct()` 按真实像素倒推百分比，整颗点（含热区）必须留在场内。

顺带 `fitArena()` 收场地时把后面那一行 `.rbt-msg` 让出来（`belowPx()`），
不然「加油」「答对啦」整行掉在裁切线以下。

`click`、以及任何拿得到元素引用的代码，都能让 `openMode()` / `openSide()` 照常跑完。而这两个函数里
