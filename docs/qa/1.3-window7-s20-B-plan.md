# 1.3 第 20 步 · B 档 · `fruit-slice` 视觉升级计划（工人 w7-s20-B-fruit-slice）

> 只改视觉，不动玩法：抛物线 / 判定半径 `f.r` / 连切 / 加倍 / 冰冻 / 炸弹效果逻辑 / 出果编排 / 存档 key 一律不碰。

## 现状审美评测（第三节自查结论）

1. **剪影（致命伤，主管点名）**：`drawFruit` 果身底子确实是全库水果最好的——径向渐变 + 深色描边 + 左上高光 + 呆萌表情齐全；但除蕉蕉走 `drawBanana` 月牙外，桃桃 / 瓜瓜 / 橙橙 / 莓莓 / 柠柠**共用同一个 `ctx.arc(0, 0, f.r, 0, Math.PI * 2)` 正圆**（原 1785 行），差异全靠圆内表面纹理（瓜纹三道 / 桃缝一道 / 皮孔七粒 / 高光籽点六粒 / 点阵八粒）。抛起时全是彩色圆球，灰度下完全不可辨。
2. **切面（比预期好，但没到「果肉感」）**：`drawHalf` 已有半圆果皮 + 压扁椭圆切面 + 品种细节（瓜籽 6 / 橙柠共用放射 8 线 / 桃核 + 10 纹 / 莓籽 8 点）。缺：瓜瓜白皮环、橙橙中轴白膜与瓣间细线、莓莓 12 条白芯细纹、柠柠瓣格 + 汁泡、切开瞬间的亮 1 帧；柠柠与橙橙切面完全同构，分不出。
3. **刀光**：`drawTrail` 只有两层（粉晕 + 白芯），无丝带层次感；切中无白闪星花、无果汁液滴，「切中了」的反馈全靠水花五点。
4. **菜单 / 地图 / 面板一族**：白卡 + 圆角 + 彩描边的底子好；但菜单是平涂米色背景无氛围，面板是素白矩形无标题装饰，与局内新舞台风格需要统一（圆角卡片 + 标题缎带）。
5. **特殊物**：炸弹是黑球 + 引信,偏写实武器（要整改成皱眉乌云娃娃）；冰果雪花均匀、缺棱面与寒气；双倍果金光尚可但无脉动节奏；花朵与果王观感达标保留。
