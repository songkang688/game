## 二、缺陷清单

### 缺陷 1(S3,已修复):弹弹小鸟竖屏时游戏画面只占舞台上部约 43%,下方 450px 空白

- **复现**:412×915 进弹弹小鸟任意关卡。实测:关卡视图容器高 352px / 舞台高 809px(占比 0.43),
  顶部对齐,下方空白 453px;选关地图页同样顶部对齐(占比 0.59)。
  即 R2 报告「三、无缺陷的观察项」第 1 条,量化确认后按本轮授权顺手修复。
- **影响面**:竖屏手机(该产品主力形态)玩弹弓时画面挤在最上面,视觉重心失衡,孩子容易误触顶栏。
- **修复**(`src/games/sling-birds/index.ts`,仅样式,不动物理/关卡表/存档):
  - `.slb-wrap` 撑满舞台高度(`height:100%` + flex column + `overflow-y:auto`);
  - `.slb-map` / `.slb-play` 用 `margin-top/bottom:auto` 垂直居中——内容超高时 auto margin
    自动归零并转为纵向滚动,**不裁顶部**(比 `justify-content:center` 安全)。
- **验证**:修复后 412×915 关卡视图上下留白对称(241/241px),容器占满舞台(0.99);
  320×640(上下 111/111px)与 900×1200(299/299px)同样居中,选关地图 17+ 格与角色介绍全部可达,
  横向溢出 0、零错误;34 款冒烟 + 弹弓深关冒烟重跑全绿。

## 三、无缺陷的观察项(留给后续,不动手)
