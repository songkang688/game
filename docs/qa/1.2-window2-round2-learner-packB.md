### 每条都要带测试（用例只增不减）

- **P2B-1**：四款各断言一次 `TIER_LABELS` / `TIER_NAMES` 的四个字；再断言四款的 `Tier` id 仍旧是 `rookie/normal/(pro|expert)/hell`（存档口径没被顺手改掉）；顺带扫一遍这四款的可见文案里不再出现「菜鸟」「地狱」。
- **P2B-2**：拿第 1 局那张真谱逐档跑 `aiRun`，断言四档分数**严格递减**（`hell > expert > normal > rookie`）；断言最高档仍是零 miss 零良好的满分（守住 B-2 的平局前提）；再断言中间两档的失手是确定性的（同 seed 两次跑一模一样）。
- **P2B-3**：断言同一次连胜里第 n 局的牌堆稳定、不同 `salt` 的牌堆不同；断言前若干局、若干 `salt` 下玩家开局都有牌可接；断言 `salt = 0`（第一次玩）仍旧是原来那一副，老玩家的第一局手感不变。
- **P2B-4**：`createStage` 按住到 `MAX_HOLD` 之后读 `data-full` / `full()`，断言从 `0` 翻到 `1`、收力之后翻回 `0`、`ready` 时恒为 `0`；断言满力提示不改变任何一跳的判定（同样的 `holdMs` 站住的座数、分数一字不差）。
- **P2B-5**：直接喂一个 `quiet` 快到线的局面进 `createTable`，断言顶栏出现倒数字样且数字随手数递减；断言 `quiet` 归零之后提示消失；断言真判和时结算文案没变（老用例不受影响）。
- **P2B-6**：CSS 常量断言 —— 这两个类的字号 ≥ 12px，且整份 CSS 里不再有 `font-size:11px`。

`git fetch` → rebase `origin/game-1.2-window2` → `npm test` 与 `npm run build` 全绿 → 普通 push（禁止 force）。
