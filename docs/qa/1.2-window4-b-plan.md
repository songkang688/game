## 三、三轮节奏

每轮固定三段,顺序不可调:

1. **测试员** —— 按剧本真跑,记录阻断/严重/一般/建议四档问题,只增用例不删用例。
2. **学习优化员** —— 列 ≥8 条改进建议,其中 ≥3 条落地成代码 + 覆盖测试。
3. **监督修复员** —— 修本轮阻断/严重;复核商标 0、`destroy` 无泄漏、存档 key 只增不改。

每轮收尾:`npm test && npm run build` 全绿才进下一轮,然后 push。

### 第 1 轮剧本

- 五款都要从首页进入(`loadGames()` → `meta.modes` → `mount`)。
- 玩到真实胜负:赢一次 + 输一次。
- 战役第 1 / 100 / 188 关。
- 对战 / 无尽 / 双人的每种模式玩到结算。
- 360px 窄屏走一遍。
- 学习优化员列 ≥8 条、落地 ≥3 条(有测试)。
- 修复员清阻断 / 严重、商标 0、`destroy` 无泄漏。

### 第 2 轮剧本

- 换一批关卡 / 模式样本(不再只玩第 1 关)。
- 查难度曲线是否单调、是否有竞态、无尽能否长时间持续。
- 再落地一批改进,清零本轮新问题。

### 第 3 轮剧本

- 五款一款不漏再过一遍。
- 每条遗留必须有最终结论(已修 / 明确交给主管)。
- 结论:档B 五款能否发布。
