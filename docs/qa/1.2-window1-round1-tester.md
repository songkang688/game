### 每款的走查链路

1. 首页能不能看见卡片、点进去（走 `import.meta.glob` 自动发现，不许手工注册）。
2. 真实胜负：**赢一次、输一次**都要真跑出来。
3. 退出再进：`destroy` 之后监听 / timer / rAF / AudioContext 不留残。
4. 战役：第 **1 / 100 / 188** 关各进一次，看关号、章节、难度是不是对得上。
5. 有对战 / 无尽 / 双人同屏的，每种模式各玩到**结算**。
6. **360px** 宽走一遍：文字不溢出、`documentElement.scrollWidth - clientWidth <= 1`。
7. 双人键位：朵朵 `WASD + F + G`，星星 `方向键 + L + K`。

### 取证手段

- 单元测试全量：`npm test`，记录文件数 / 用例数。
- 类型 + 构建：`npm run build`。
- 真浏览器：`puppeteer-core` + 本机 `google-chrome`，视口 `360×640`，跑 `scripts/smoke-1.2-window1-r1-tester.mjs`（本轮新写的测试员专用脚本，只读不改玩法）与仓库已有的 `scripts/smoke-1.2-step*.mjs`。
- 假时钟：root 门的 1 小时过期用改写 `Date.now` / 直接写入过期 `expiresAt` 的方式验证，**不真等 1 小时**。

### 严重度口径

| 级别 | 定义 |
| --- | --- |
| 阻断 | 进不去 / 玩不到结算 / 白屏报错 / 数据写坏 / 安全红线（密码落盘等） |
| 严重 | 模式缺失或走不到结算、360px 溢出、`destroy` 泄漏、关号对不上、键位失灵 |
| 一般 | 手感、文案、边角视觉、可优化项 |
