### W1-01 · 阻断 · 5 款战役里按一次 Esc 之后游戏再也回不来

**受影响**：`orb-arena` `snake-royale` `block-drop` `combo-clash` `merge-2048`（战役与模式页都一样）。

**复现步骤**

1. 首页点「圆圆大作战」→ 进第 1 关，等画面动起来。
2. 按一次 `Esc`。游戏自己停住，同时壳层的「先歇一会儿」暂停面板弹了出来（两层暂停叠在一起）。
3. 按第二次 `Esc`（或者点面板上的「继续玩」按钮）。面板收掉了，但**游戏没有恢复**。
4. 之后怎么按方向键、点画面都没反应，只能退出这一关重来。

**取证**（真浏览器，DOM 结构 + canvas 像素双重指纹判断「画面还在不在动」）

| 款 | 开局在动 | 按 1 次 Esc 后 | 按 2 次 Esc 后 | 改点「继续玩」按钮 |
| --- | --- | --- | --- | --- |
| `orb-arena` | ✅ | ❌ 停 | ❌ **仍停** | ❌ 仍停 |
| `snake-royale` | ✅ | ❌ 停 | ❌ **仍停** | ❌ 仍停 |
| `block-drop` | ✅ | ❌ 停 | ❌ **仍停** | ❌ 仍停 |
| `combo-clash` | ✅ | ❌ 停 | ❌ **仍停** | ❌ 仍停 |
| `merge-2048` | （回合制，静止） | 盘面不动 | **盘面仍不动**：暂停前后盘面指纹完全一致，方向键全部无效 |

`merge-2048` 另有一条肉眼可见的痕迹：`.mg-msg` 一直停在「⏸️ 暂停中,再按一次 Esc 继续。」，永远不会变成「继续!」。

对照组（同样按两次 Esc 就能接着玩）：`weiqi-garden` `sudoku-petal` `mahjong-bloom` `star-estate` `flight-chess` —— 这几款没事。

**根因**（三件事凑在一起）

1. 这 5 款的 `Escape` 处理里没有 `e.preventDefault()`；
2. `src/ui/gameShell.ts` 的 `onGlobalKeyDown` 是延后一拍再看 `e.defaultPrevented` 才决定要不要弹壳层暂停面板，于是面板被弹了出来：

```383:391:src/ui/gameShell.ts
  function onGlobalKeyDown(e: KeyboardEvent): void {
    if (disposed || !isDismissKey(e.key)) return;
    if (dialog || pauseDialog) return;
    window.setTimeout(() => {
      if (disposed || dialog || pauseDialog || e.defaultPrevented) return;
      openPause();
    }, 0);
  }
```

3. 面板一开，`src/ui/dialogs.ts` 就在 `document` 上挂了一个**捕获阶段**的 `Escape` 处理器，它 `stopPropagation()` 之后自己把弹窗关掉 —— 第二次 `Esc` 根本传不到游戏那个 `window` 监听：

```217:225:src/ui/dialogs.ts
  function onKeyDown(e: KeyboardEvent): void {
    if (closed) return;
    if (isDismissKey(e.key)) {
      if (!escapable) return;
      e.preventDefault();
      e.stopPropagation();
      dismiss();
      return;
    }
```

而壳层关面板时调的 `tellGame("resume")` 对这 5 款也是空转 —— 它们的 `mount()` 只返回 `{ destroy }`，没有 `resume` 方法。于是游戏内部那个 `paused = true` 再也没人翻回来。

**建议给修复员的方向**（任选其一，别两头都改）：这 5 款的 `Escape` 分支补 `e.preventDefault()`（和 `mahjong-bloom` / `star-estate` / `flight-chess` / `sudoku-petal` 现在的做法对齐）；或者让它们的 `mount()` 一并导出 `pause` / `resume`，交给壳层面板统一管。
