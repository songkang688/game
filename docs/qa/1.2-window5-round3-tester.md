### C3 · 教育正确性：`pinyin-train` 换一批题、声调独立复算（188 关全量）

C0 要求「换一批题**核声调**，另写判据独立复算，不调 `logic.ts` 算答案」。

**独立到什么程度**：调号表**一个字都没抄**被测代码的 `TONE_MARKS` / `TONE_ROWS`，
而是拿 Unicode 组合附加符号现场拼出来再 NFC 归一——
一声 `U+0304`（macron）、二声 `U+0301`（acute）、三声 `U+030C`（caron）、四声 `U+0300`（grave），
`"u\u0308" + "\u0304"` → NFC → `ǖ`。落位规则也自己按《汉语拼音正词法基本规则》重写：
**有 a 找 a，没 a 找 o、e，都没有就戴在最后一个 i / u / ü 上**（这一句同时覆盖课本单讲的「iu 标 u、ui 标 i」）。
被测代码这边**只 import 出题函数与题库数据**（`buildQuestions` / `DUOYIN_CARDS` / `TONE_DRILL_CARDS`），
**不 import 它算答案的任何工具**（`applyTone` / `stripTone` / `toneOf` / `markTone` / `toneTargetIndex` 一个都没碰）。

先自证我这套判据本身是对的（跑在被测代码之外）：
`myMark("liu",2)=liú` / `myMark("shui",3)=shuǐ` / `myMark("hao",3)=hǎo` / `myMark("gou",3)=gǒu` / `myMark("xue",2)=xué` / `myMark("lüe",4)=lüè`，六条全中。
