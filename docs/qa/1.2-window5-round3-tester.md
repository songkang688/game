**判据（照抄第 2 轮监督修复员那把尺子，一分不放松）**

- 「点不着」只认一条：`document.elementFromPoint(元素中心点)` 拿回来的是**它自己或它的后代**。
  拿不回来就叫点不着。**去掉 `hit.contains(el)`**——那一项会把「点到的其实是壳层祖先」放成假绿。
- **禁止 `el.click()`** 判热区可达性。被 `overflow:hidden` 裁掉的元素 `el.click()` 照样绿，那是假绿。
- 「滚一下够不够得着」不认 `el.scrollIntoView()`；程序写 `scrollTop` 只算粗筛，
  **定案一律真手指**（`Input.dispatchTouchEvent` 完整 `touchStart → touchMove ×N → touchEnd`），
  滑到之后**再真按一次**，用文档级捕获监听确认游戏真收到 `click`。
- 真机 = `npm run build` 产物 → `vite preview` → **Chrome headless（`--headless=new`）+ Node 22 自带 `WebSocket` 直连 CDP**，
  **零新增依赖**；一次性探针落在 `/tmp/w5r3a/`，**跑完即删，0 字节进提交**。
- 教育正确性**另写一套判据独立复算**，绝不调用被测代码算答案。
