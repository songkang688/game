## 每款要做的事（对着规格 Markdown）

### 17C `alien-seek`
- 44px 点击容错 + 多目标取最近（纯函数）；点空 3 次给温和提示，不扣星。
- 摆放校验：可见面积、UI 遮挡、中心距阈值，随机 1000 次布局全过。
- 缩放 0.8–2.5× 与拖动，命中判定走世界坐标。
- 每关 2 次「望远镜」提示（只缩范围，不高亮目标本体），用掉不给三星。
- 目标清单改缩略图；双人抢答与无尽保留。新增用例 ≥ 18。

### 18C `box-hamster`
- 无限撤销（带内存上限）+ 重来；撤销不扣星但参与三星判定。
- 死锁检测（角落 / 贴墙 / 2×2 团块），温和提示。
- 用 `solver.ts` 给 188 关标难度（**不改关卡数据**），曲线单调。
- 每关 1 次「下一步提示」（solver 解的第一步），用掉不给三星。
- 无尽仓库：`generate.ts` 生成 + solver 验证 + 超时保护。新增用例 ≥ 20。

### 19C `bubble-aim`
- 瞄准线：第一段墙面反射预览（长度有限）、拖动角度微调放大。
- 掉落物理：失联泡泡群真的往下掉（有中间位置），计入连锁分。
- 发射器：当前 + 下一颗、可换弹，颜色只从墙上还有的颜色里出。
- 特殊泡：炸弹 / 彩虹 / 石头。无尽下推行。新增用例 ≥ 18。

### 20C `snake-snack`
- 转向输入队列（缓存 2 个、同 tick 反向丢弃）+ 反向保护。
- 速度曲线数据化 + 稳定速度辅助档。
- 机关：传送门、可推石头、限时星星、绕圈开门。
- 两种无尽档（经典加速 / 休闲不加速）；失败温柔化（打结歇会儿）。
- 保持格子蛇，**不许**靠向 IO 长蛇。新增用例 ≥ 18。

### 21C `memory-cards`
- 先把发牌、翻牌状态机、配对判定、计分抽成 `logic.ts` 纯函数（数值不改）。
- 翻牌 90° 换面的时序语义、狂点保护 + 末次点击缓存。
- 6 套主题（动物 / 水果 / 交通 / 乐器 / 天气 / 朵朵一家），每套 ≥ 12 图案，全原创绘制。
- 进阶机制：会移动的牌、三连牌、单面干扰牌；记忆辅助档；无尽记忆挑战。新增用例 ≥ 18。

## 纪律

- 前 99 关（及各款闯关关卡数据）生成参数不改，只做加法。
- 每款做完 `npm test && npm run build` 必须全绿再做下一款，用例总数只增不减。
- 存档 key 只增不改；音效只走 `api.play`；`destroy` 清干净监听 / timer / rAF。
- 文案与注释无商标、无血无死亡、失败只鼓励；360px 宽不溢出。
- 只推 `game-1.2-window4`，禁止 force push，不改 `main`，不用 `gh` 开 PR。
