## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **回合类型（≥ 4 种）** | ① 反应：亮灯后先点者得分，抢点扣分；② 顺序：按 1→2→3 顺序点；③ 颜色指令：只点指定颜色（含「不要点红色」的反向指令）；④ 计数：限时点满 N 个但**超过就作废**（教克制）。 |
| **公平性** | 两侧的目标序列必须镜像（写断言）；抢点判定用同一时钟源。 |
| **防乱拍** | 同一按钮在 60ms 内的重复输入只算一次（写常量 + 用例）；用手掌拍多个点也不给分。 |
| **AI 对手（单人时）** | 四档反应时间：600 / 420 / 300 / 220ms + 失误率，**不许 0ms 完美反应**。 |
| **无尽「点到手软」** | 回合类型随机、节奏加快；失误 3 次结束；成绩 `save.recordEndlessBest("red-blue-tap", rounds)`。 |
