## 二、极高质量改进方案（可执行绘制规格）

### 1. 棋子 → 花园居民棋子（核心资产）

- 每类棋子一个内联 SVG（viewBox 32×36，替换 `GLYPH` 字符，`PIECE_CN` 中文小标保留）：
  - 兵=小蘑菇（圆帽+白点）；马=小木马头（鬃毛三束）；象=尖顶小树（三层树冠）；车=石塔（垛口三齿）；后=盛开花冠（5 瓣大花+宝石芯）；王=戴十字小冠的大花（庄严感靠高度与金冠）——**剪影差异必须在 20px 下可辨**；
  - 白方：象牙白填充 + 暖灰描边 + 左上高光；黑方：深可可填充 + 更深描边 + 高光弱化；底部统一椭圆底座 + 投影（立体感）；
  - 32×36 内笔画 ≤ 18 条，保证 DOM 内联性能。
- 升变仪式：兵走到底线时 0.4s「破土开花」动画（蘑菇帽裂开 → 花冠展开成后/所选子），`reduced` 直接换。

### 2. 棋盘 → 花园石板

- 浅格=暖石板色 `#F2E8D5` + 极淡石纹对角线 1 根；深格=草地绿 `#A8C88E` + 2–3 根小草叶（伪元素背景，格索引哈希）；
- 外框：8px 木篱笆边框 + 四角小花盆装饰（SVG，不占格）；
- 坐标标注（a–h/1–8）加到边框内侧小字（可读性 + 记谱教学）。

### 3. 状态高亮升级（保留 6 态语义）

- 可走点 `cg-sq--hint`：中心小绿芽点；可吃 `cg-sq--cap`：目标格四角红色小三角（形状与颜色双通道）；
- 将军 `cg-sq--check`：王格红光呼吸（`reduced` 静态红框）+ 王棋子头顶冒「!」气泡；
- 上一手 `cg-sq--last`：淡金底；选中：金框；光标：虚线框——三者形状互不相同。

### 4. 吃子与结算

- 吃子：被吃棋子 0.3s 缩小 + 化作 3 片花瓣飘出（对象池，`reduced` 直接消失）；
- 将杀结算：胜方王/后棋子放大居中 + 花环绕圈 + 记谱回放按钮；和棋：双王并立 + 白鸽（SVG 简笔）。

### 5. 座位条与记谱

- 座位 chip 加棋子头像（王的 SVG 缩小）；记谱面板每行加走子方小色点；最后一手高亮行。
