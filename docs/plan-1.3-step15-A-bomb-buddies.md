## 三、现状审美评测（先开代码再动笔）

打开 `src/games/bomb-buddies/index.ts`，全部画面出自单个 `render`（约 753 行起）与 `emojiAt` 辅助。已核实的问题：

1. 双人角色就是两个 emoji：`P_EMOJI = ["🌸","⭐"]`（102 行）——号称「炸弹人」的主角连一个自绘的身体都没有，走路无步态、埋弹无弯腰、被困无表情；
2. 地形三件套是 `roundRect` 平涂：硬墙 `palette.wall` 一色到底（770–773 行），软砖 / 地板同理，没有顶亮边、砖缝、破碎中间态；
3. 门画的是 `emojiAt("🚪", ...)`（792 行）、全部道具是 `ITEM_INFO[kind].emoji`（813 行）、胜利花瓣也是 emoji 池 `FLOWER_EMOJI`（330 行）——一屏下来自绘元素几乎为零；
4. 炸弹泡泡与爆炸波的绘制混在 `render` 内联段里，逐行读完后把「泡泡有没有高光、爆炸波是不是纯色矩形」的结论记进开工 commit；
5. `dangerTiming` 的危险格提示画法（预期是平涂变色）也要自查并在回复里说明。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **双人角色自绘** | 替换 🌸⭐：朵朵 = 圆头 + 花瓣发卡 + 粉背带裤；星星 = 圆头 + 星形呆毛 + 蓝背带裤。剪影靠「发卡 vs 呆毛 + 裙 vs 裤」区分，不只靠颜色。三态各 2 帧：走路（左右脚交替 8px 摆动）、埋弹（下蹲 0.85 倍压扁）、被困变泡泡（既有逻辑，只加表情）。判定格位置不动，角色画在格中心。 |
| **炸弹泡泡** | 圆球三停径向渐变（左上高光 → 主体 → 底部暗）+ 顶部月牙反光；引信改成小星火沿弧线上蹿（0.4s 循环）；临爆前 1s 用**体积脉动 ±6%**替代纯变色（reduced 时只变色）。 |
| **爆炸波** | 十字波改成「花瓣涟漪」：中心白闪 2 帧 → 沿四臂推进的圆瓣串（每格一瓣、150ms 渐隐）+ 末端星屑 3 颗。危险格预警保持既有时序，画法升级为地板泛红呼吸 + 边缘虚线。 |
| **地形质感** | 硬墙加 2.5D 顶亮边 / 右暗边 + 铆钉四点；软砖画 2×2 砖缝 + 被炸时两阶段裂纹（裂纹是纯视觉，不改一次炸碎的逻辑）；地板棋盘双色差 4% 明度 + 四角圆润；门自绘（拱形木门 + 星星门牌），道具自绘统一图标（火力 = 星火、脚力 = 小靴、泡泡数 = 泡泡串），彻底替换 emoji。 |
| **关卡主题** | 读取既有 `palette`（章节配色）做三套主题墙纹：花园（砖 + 藤蔓角饰）、冰原（砖 + 霜花角饰）、星空（砖 + 星子角饰），只换装饰层不换布局数据。 |
| **布局与 HUD** | 双人头像徽章 + 剩余泡泡数 / 火力一行卡片化；倒计时加圆环进度化。 |

- 渐变 / 描边 / 落影统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：脉动、星火、涟漪推进全停，保留静态危险变色（保命信息不减）。

### 四·补一：配色板与图层序（落成常量块再引用）

| token | 色值 | 用途 |
| --- | --- | --- |
| `bbFloorA` / `bbFloorB` | `#FDF3F7` / `#F8ECF2` | 地板棋盘双色（明度差 4%） |
| `bbWall` | `#D9C4E8` | 硬墙顶面 |
| `bbWallSide` | `shade(bbWall,-22)` | 硬墙右 / 下侧面 |
| `bbBrick` | `#F3C9A8` | 软砖主色 |
| `bbBubble` | `#BFE4FF` | 炸弹泡泡主体 |
| `bbDanger` | `rgba(244,110,110,.32)` | 危险格泛红呼吸峰值 |
| `bbPink` / `bbBlue` | `#F4859F` / `#7FB2F0` | 朵朵 / 星星服装主色 |
| `bbShadow` | `rgba(93,64,90,.16)` | 全图统一落影 |

图层序（`render` 内固定从底到顶）：① 地板棋盘 → ② 危险格泛红层 → ③ 软砖 / 硬墙 / 门（2.5D 块）→ ④ 道具 → ⑤ 炸弹泡泡 → ⑥ 角色 → ⑦ 爆炸涟漪与粒子 → ⑧ HUD。危险层永远压在砖下、角色上层不遮提示。

### 四·补二：角色工序单（`chibi.ts` 参数化圆头小人，两人共用一份函数）

1. 椭圆落影（0.7 格宽、0.18 格高，`bbShadow`）；
2. 身体：背带裤梯形（朵朵粉裙摆 / 星星蓝直筒——裙裤差是灰度剪影保险）；
3. 圆头（0.55 格径）三停径向渐变 + 1.5px 描边；
4. 发饰：朵朵五瓣花发卡（头顶偏左）/ 星星星形呆毛（头顶正中）——发饰是第二道剪影保险；
5. 表情三态：常态眨眼（3s 随机）/ 埋弹鼓腮 / 被困泡泡里「哇」嘴型；
6. 步态：走路两帧脚交替 8px 摆动，蹲 0.85 倍压扁 120ms；
7. 朝向：左右移动时整体 `scaleX(±1)` 镜像，上下移动不镜像。

### 四·补三：动效时序表（毫秒写死成常量并被测试引用）

| 动效 | 触发 | 时长 | 缓动 | reduced 行为 |
| --- | --- | --- | --- | --- |
| 引信星火上蹿 | 炸弹存在 | 400ms 循环 | linear | 静态星火点 |
| 临爆体积脉动 | 爆前 1s | ±6%、250ms 周期 | sin | 退化为纯变色 |
| 爆炸中心白闪 | 起爆 | 2 帧 | step | 保留（功能反馈） |
| 花瓣涟漪推进 | 起爆 | 每格 150ms 渐隐 | easeOutQuad | 一次性静态显示 |
| 危险格泛红呼吸 | `dangerTiming` 既有时序 | 跟随原时序 | sin | 静态红色（时序不变） |
| 走路步态 | 移动 | 2 帧交替 | step | 保留（幅度减半） |
