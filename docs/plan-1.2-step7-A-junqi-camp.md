## 四、这不是什么

- 不是 `xiangqi`（中国象棋），不是本步 C 档的 `dark-chess`（4×8 翻翻暗棋）。
- 本款是**二人军棋（陆战棋）电子暗棋**：有铁路 / 公路 / 行营 / 大本营，电子裁判自动判子。

## 五、完整规则（二人军棋，电子暗棋）

### 棋子（每方 25 枚）
司令 1、军长 1、师长 2、旅长 2、团长 2、营长 2、连长 3、排长 3、工兵 3、炸弹 2、地雷 3、军旗 1。

### 布局限制
- 军旗必须放在两个大本营之一。
- 地雷只能放在**最后两行**。
- 炸弹不能放在**第一行**。
- **行营内开局不能放子**（按常见规则；若你选择允许，请写进常量并在 guide 说明，并保持测试一致）。

### 移动
- **公路**：一次走一格。
- **铁路**：直线上无阻挡可走任意格；**只有工兵能在铁路上转弯**（用 BFS 求可达集合）。
- **行营**：行营里的棋子不能被吃，必须自己走出来。
- **大本营**：进去的棋子不能再动；地雷与军旗本身不能移动。

### 对撞（电子裁判）
- 大小：司令 > 军长 > 师长 > 旅长 > 团长 > 营长 > 连长 > 排长 > 工兵。
- 同级对撞：两子同尽。
- **炸弹**：与任何棋子相遇同尽（含地雷与军旗）。**若炸弹是撞上军旗导致同尽，本款判扛旗成功**（写进常量并单测）。
- **地雷**：工兵吃地雷成功；其他棋子碰地雷 → **地雷胜，进攻方回营**；炸弹与地雷同尽。
- 司令阵亡 → 立即亮出该方军旗所在位置。

### 胜负
- 扛走对方军旗即胜；或对方无子可动；或对方可动棋子全部退场。
- 70 步内双方无吃子判和。

## 九、前端建模与视觉（含 360px）

- DOM 或 Canvas 棋盘：**铁路画粗线、公路画细线、行营画圆、大本营画方**，一眼能看懂。
- 暗棋时对方棋子显示为粉彩背面；对撞时**两子翻开 → 停顿 → 较小的一方淡出回营**，禁止瞬删。
- 可走点高亮（铁路可达要一次性显示整条线）。
- `prefers-reduced-motion`：缩短翻牌动画。
- 360px：棋盘可缩放 + 双指拖动，棋子文字 ≥ 12px 且清晰；确认 / 取消钮 ≥ 44px。
