## 四、这不是什么

- 不是 `find-diff`（找不同），不是 `memory-cards`（翻牌记忆）。
- 本款是**经典扫雷**：数字提示、洪水展开、插旗、双键和弦、首点安全、无猜生成。

## 五、完整规则

- 网格，每格：空 / 数字 1–8 / 刺种。数字 = 周围 8 格的刺种数。
- **首次点击必安全**：第一次翻开的格子**及其 8 个邻格**都不含刺种（生成时把刺种重排走）。必须单测。
- 翻到 0：洪水填充展开整片连通空区及边界数字。
- 翻到刺种：本局失败（先播动画再结算）。闯关前两章可开「第一次失误有保护」。
- 插旗数不必等于刺种数；**胜利条件是所有非刺种格都被翻开**，不要求旗全对。
- **双键和弦**：某数字格周围旗数 = 该数字时点它，一次翻开周围未开格；旗插错就会真的踩到刺种（必须单测）。
- 计时从第一次翻开开始；三星看时限与是否用过保护。
- 难度：初级 9×9 / 10、中级 16×16 / 40、高级 16×30 / 99；闯关可自定义尺寸与密度。
- **无猜生成**：第 3 章起，生成后用约束求解器验证「全程可用逻辑推出」，不行就换 seed 重生成。测试对 ≥ 50 个 seed 断言可逻辑解。

## 九、前端建模与视觉（含 360px）

- DOM 网格；翻开有 80–150ms 翻转动画，数字用粉彩八色。
- 踩到刺种：**该格开出一朵花**，其余刺种温柔揭开，**禁止连环爆炸式表现**。
- 旗子是小三角旗，插旗弹一下。
- `prefers-reduced-motion`：动画缩到最短。
- 360px：格子 ≥ 28px，高级图允许滚动 + 迷你地图；HUD（剩余旗数 / 计时）字号 ≥ 13px；长按插旗要有视觉进度环。
