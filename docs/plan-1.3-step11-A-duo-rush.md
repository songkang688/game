## 二、极高质量改进方案（可执行绘制规格）

### 1. 跑者 → 朵朵/星星双主角（核心资产）

- 保留全部运动参数（jumpArc/slideSquash/laneTilt/bumpShake 一行不动），重画身体：
  - P1 朵朵：粉色 2 头身、头顶花苞呆毛、小裙摆（奔跑摆动 1 帧）；P2 星星：金黄 2 头身、星形呆毛、小披风；奔跑双腿交替（沿用 bounce 相位 979 行）+ 双臂摆动；
  - 表情按状态查表：奔跑专注 / 跳跃张嘴笑 / 下滑眯眼 / 被撞 ×眼 + 星星绕头 3 颗（替代 😵）/ 无敌闪烁保留；
  - 幽灵回放（👻 → 半透明本体轮廓 + 头顶小幽灵火苗）；尾焰（💨 → 3 根速度线 + 2 粒星屑）；皇冠（👑 → 绘制的金冠，领先者标识保留 1037 行的温柔口径注释）；加油爱心（💖 → 绘制的心形上飘）；
  - 自定义头像模式（980–986 行 drawImage 裁剪）保留，头像外加角色色描边环。

### 2. 金币 → 旋转星币（与 rainbow-run 共用规格）

- 8 帧绕 Y 旋转 sprite（金渐变 + 内环 + 五角星压印 + 侧棱帧），近处大远处小走现有 `laneWidthAt` 缩放；吃到时 +N 飘字 + 3 星屑；
- **必须与 rainbow-run 的金币走同一份共享 kit 资产**（若 kit 未建立则本地实现但函数签名一致，注明待上移）。

### 3. 障碍与道具

- pit：内壁渐变 + 边缘碎石 2 粒；rock：改水晶簇/圆石双主题随 Theme；hurdle/gate：木纹与金属杆质感（双色+高光线）；全部保留现有轮廓与判定尺寸；
- 道具糖泡：emoji 改绘制图标（速度云=小云+速度线、护盾=盾形、彩纸=纸屑束、爱心=心形），泡壁加高光弧；
- 加速带：绿椭圆升级为发光跑道箭头（三箭头流动，`reducedMotion` 静止）。

### 4. 场景纵深强化（吃现有系统红利）

- `drawHills` 双层保留，按 Theme 加第三层近景剪影（树/糖果柱/冰锥/星塔四主题查表）+ 路边每隔一段一个路牌/小旗（用 `project` 放置，纯装饰）；
- 天空加太阳/月亮 + 2 朵慢云（视差 0.03）；
- 雾带 `drawFog` 保留；远处实体的 fog 淡出（830 行）保留。

### 5. 双人对抗演出

- 分屏对比条：顶部双方进度并排（小头像在进度条上跑）；
- 一方淘汰：该侧画面 0.3s 灰化 + 温柔文案（沿用现有口径，不出现羞辱语）；
- 终点：冲线彩带 + 双人名次卡（胜者跳跃庆祝帧）。
