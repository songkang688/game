## 一、`shoot-range`「星星射击场」（category: `casual`）

固定视角靶场。鼠标 / 触屏瞄准，键盘微调准星，靶子全部是非人形卡通对象。

### 目标类型
| 类型 | 说明 |
| --- | --- |
| 靶子 `bull` | 站着不动的同心圆靶，越靠圆心分越高 |
| 气球 `balloon` | 慢慢往上飘，打中「啵」一声变成小彩纸 |
| 飞碟 `ufo` | 左右横飘，偶尔小幅上下摆 |
| 机器人 `robot` | 铁皮小机器人，走来走去，打中就摊手坐下 |
| 编号靶 `number` | 带号码，必须按 1→2→3 的顺序打 |
| 好人靶 `friend` | 举着小旗子的笑脸靶，打中要扣分 |

### 玩法系统
- 弹道：出膛速度 + 轻微下坠，瞄哪打哪靠 `aimToVelocity` 反解仰角（纯函数）。
- 命中：线段扫掠 vs 圆（`segmentCircleHit`），遮挡物用线段 vs 矩形（`segmentRectHit`）。
- 弹匣与换弹节奏：打空要换弹，换弹期间不能开火。
- 连击加成：连续命中越多倍率越高，打空 / 打好人靶断连击。
- 限时挑战：后期章节给倒计时。
- 命中率评级：`S / A / B / C` 四档，星级由「命中率 + 目标全清」共同决定。

## 二、`sky-squad`「飞机小队」（category: `action`）

纵版清版射击。全部是原创卡通小飞机，被击中只是**冒烟迫降**滑出画面。

### 系统
- 三种主武器：`star` 星星弹（正面扇形）、`wave` 波纹弹（宽而慢）、`beam` 光束（窄而穿透）。
- 僚机：最多 2 架，跟随主机同步开火。
- 护盾：吃到护盾道具后挡一次子弹。
- 炸弹：清空全屏敌弹并让在场小飞机冒烟迫降。
- 弹幕可读性：敌弹是**低速大弹**，敌弹暖色（橙 / 粉），我方子弹冷色（蓝 / 青），
  Boss 预警弹先亮一下再飞。

### 弹幕生成器与「可躲避性」
`buildPattern(spec, tick)` 是纯函数，Boss 每个阶段一份 `PatternSpec`。
`findDodgePath(...)` 用「时间 × 横向格子」的可达集合 DP，
在玩家最大移动速度约束下找一条**全程不被击中**的路径；
`sky-squad` 的测试对 **8 个 Boss × 每个 3 个阶段**逐个断言这条路存在。

## 三、分级红线自审清单
- 无血、无伤口、无死亡描写；击中只有「冒烟迫降 / 气球爆彩纸 / 机器人摊手坐下」。
- 武器一律卡通化（星星弹、波纹弹、光束），不写实、不出现真实枪械名词。
- 靶子全是非人形或卡通对象；「好人靶」是笑脸旗子靶，打中只扣分并提示「那是好人靶呀」。
- 无任何商业商标或官方角色名（含注释）。
- 文案约小学六年级水平，中文粉彩萌系。
- `prefers-reduced-motion` 下关闭抖动与闪烁。
