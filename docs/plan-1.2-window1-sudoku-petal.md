# 数独花田 · 工作计划与唯一解生成策略

窗口 1 · 1.2 第 5 步 C 档。独占 `src/games/sudoku-petal/**` 与 `scripts/smoke-1.2-step5-c.mjs`，
不碰别人的游戏目录、不碰 `src/ui/home.ts`、不碰平台文件。

## 一、这款是什么

标准数独：行、列、宫内 1–9（小盘是 1–4 / 1–6）不重复，**每题唯一解**。
难度按「解这题最少要用到哪一档技巧」分级，不是只数一数空了几格。
铅笔笔记、冲突高亮、方法级提示（**绝不填答案**）、四种变体盘（4×4 / 6×6 / 对角花 / 异形宫）。

不是 `math-farm`（四则运算），不是 `shape-kingdom`（图形认知）。

## 三、唯一解生成策略（这一节是本档的核心）

### 3.1 位运算内核

盘面是一维 `number[]`（0 表示空）。把「行 / 列 / 宫 / 对角线」统一抽象成**约束组**
`groups: number[][]`，每个格子记一张 `cellGroups[idx]`。这样标准盘、对角花、异形宫、
4×4、6×6 共用同一份求解器，不用为每种变体各写一遍。

每组维护一个 `used` 位掩码（第 d 位 = 数字 d 已被占）。于是：

- `isValidPlacement(board, idx, digit)`：`(usedMask(idx) >> digit) & 1` 为 0 就合法，O(组数)。
- `countSolutions(board, limit = 2)`：MRV（最少候选优先）+ 位掩码回溯，**数到 limit 就立刻停**。
  数到 2 说明多解，不必把整棵搜索树跑完。

### 3.2 生成流程

1. **完整解**：空盘 + 随机数字顺序回溯，`mulberry32(seed)` 保证同一 seed 每次一样。
2. **挖洞**：把全部格子按随机顺序过一遍，每次尝试挖掉一个：
   - 挖完 `countSolutions(board, 2) === 1` 才留住，否则原样填回去；
   - 再要求「只用允许的技巧档就能推完」（`solveByTechniques`），否则也填回去。
     这一条保证提示按钮永远给得出方法，玩家不需要靠猜。
3. **技巧记账**：从低到高逐档试，找出**最低能推完这题的技巧档**，写进 `techniques`。
   章节难度就按这个字段挑题，而不是按空格数。

### 3.3 188 题为什么固化成常量

挖洞时每挖一格要跑一次解计数，一题 9×9 要跑几十次；188 题现场生成在 CI 上是几十秒量级，
放进单测会顶破超时。所以：

- 题库由生成器**一次性产出**并固化进 `puzzles.ts`（每题记 `kind` / `puzzle` / `solution` /
  异形宫的 `regions` / 最低技巧档 / seed）。
- 单测对**全部 188 题**断言 `countSolutions(题, 2) === 1`（位运算求解器，整批毫秒级）。
- 单测再对**抽样若干题**断言「用记录的 seed 重跑 `generate()` 能一字不差地复现题面」，
  证明题库确实是这套生成器产出的，不是手抄的魔法常量。
- 单测还对全部 188 题断言「四档技巧能纯逻辑推完，不需要猜」。

## 五、四种模式

- **闯关 188**：走 `level99.ts` 的 `mountLevelGame`，一关一题，错 3 次本关失败。
- **对战**：和本机假人同题竞速，四档难度。
- **无尽**：连着解题，错 3 题结束，`save.recordEndlessBest` 记最高连解。
- **双人同屏**：左右分盘同一题，朵朵 `WASD`+`F`+`G`，星星 方向键 +`L`+`K`。

## 六、交互与视觉红线

- 键位：点格 + 数字钮 1–9；`F` 填入，`G` 切铅笔；`WASD` / 方向键移光标；数字键直接填；`Esc` 暂停。
- 360px：盘面不溢出，每格 ≥ 34px，字号 ≥ 16px，数字钮 ≥ 44px 且不遮盘面。
- 完成时九宫依次开花，每宫错开 100ms；`prefers-reduced-motion` 下缩短。
- 冲突只高亮，不立刻判负。铅笔笔记不计入完成判定。
- 音效只用 `api.play("tap"|"win"|"oops"|"coin"|"pop"|"meow"|"jump")`。
- `destroy` 清干净监听 / 定时器 / rAF。
- 角色只有朵朵与星星；失败只鼓励；零商标（注释也不许）；离线，零新依赖。

## 七、测试（≥ 25 个用例）

`isValidPlacement` 行 / 列 / 宫三种冲突 · `countSolutions` 唯一解与多解 · 挖洞不破坏唯一性 ·
188 题全唯一解 · 188 题全可纯逻辑推完 · 抽样题面可由 seed 复现 · 4×4 与 6×6 宫映射 ·
对角线约束 · 异形宫映射合法（九宫各九格、连通、行列不重叠）· 四档技巧各自的检出 ·
笔记不计入完成 · 错 3 次失败开关 · 提示只返回方法（正文里一个阿拉伯数字都没有、结构里没有答案字段）·
`assertTotal(CHAPTERS, 188)` · 评星 · 假人四档强弱单调 · 挂载与 `destroy` 无泄漏。
