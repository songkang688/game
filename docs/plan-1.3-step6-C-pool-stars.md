## 二、极高质量改进方案（可执行绘制规格）

### 1. 球 → 朵星双阵营球（核心资产）

- 预渲染每种球一张 sprite（`kind` × 尺寸缓存）：
  1. 主体径向渐变（高光点左上 30%：亮 +25% → 边缘 −15%）；
  2. 顶部白色高光斑（半径 0.22r，模糊边）；
  3. 底部台呢反光暗弧；
  4. **阵营花纹**：「朵」阵营球画 5 瓣小花压印（白色 60% 透明），「星」阵营球画五角星压印；母球纯白 + 一颗极淡蓝点；黑球画金色大五角星（替换现有黄圆，566–571 行）；
- 滚动感：球移动时花纹压印按速度累计旋转角（视觉旋转，不影响物理）；速度 > 阈值时拖 2 帧残影（`reduced` 关）。

### 2. 球桌 → 绒布与木框

- 台呢：删掉冗余双 fillRect，改为径向渐变绒布（中心 `#7BBF8E` → 角落 `#5DA574`）+ 置球点/开球线标记（白色细点线）+ 长边中点小菱形定位钉 6 颗；
- 库边：三层——外框深木渐变 10px + 内侧库垫绿色深条 4px + 1px 高光线；
- 袋口：内阴影渐变（外浅内黑）+ 半圆金属护口弧（金色 2px）；指定袋高亮（513–520 行）改为袋口金光脉动（`reduced` 静态金圈）。

### 3. 击球表现

- 瞄准阶段画球杆：母球后方沿 `angle` 反向画杆（木色渐变 + 深色握把），蓄力时杆后拉距离 ∝ `power`；
- 击球瞬间：杆快速前推 2 帧 + 母球出发点小白闪；
- 旋转（`spin`）设置可视化：母球放大示意图上标记击点（HUD 小图，上旋/下旋点位）。

### 4. 进袋与犯规反馈

- 进袋：沿用 `sinking` 缩小，叠加向袋心的位移吸入 + 袋口一圈星光迸出（黑球进袋金星 ×6）；
- 犯规（母球落袋等）：屏幕边缘红光 0.3s + 提示条震动 1 次（`reduced` 只变色）；
- 自由球放置预览（576–584 行）保留，加禁放区红色淡罩提示。

### 5. HUD 与结算

- 力度条改为球杆造型进度条；双方剩余球用球 sprite 缩略排显示（不再只有文字）；
- 结算：胜方阵营球大图 + 本局进球回放列表（文字+球图标）。

## 三、2D / 2.5D / 3D 决策

**保持 2D 俯视**（台球俯视是竞技可读性最优解）。立体感 = 球体渐变 sprite + 袋口内阴影 + 库边三层；不做 3D 桌沿透视、禁止 three.js。sprite 预渲染是性能硬要求（16 球 × 60fps）。
