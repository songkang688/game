## 三、现状审查（回复里逐条回答）

1. 网格移动是否有「贴边转向补正」（差半格也能拐弯）？没有的话孩子会一直卡墙角。
2. 放泡 → 膨胀 → 破裂的时间线各是多少毫秒？连锁引爆有没有做？
3. 道具有哪几种（威力 + / 数量 + / 速度 + / 踢泡 / 穿泡）？掉落概率可复现吗？
4. 五种模式**是不是都能真的玩到结算**（尤其 `coop` 与 188 关后段）？
5. AI 会不会自己把自己困死？有没有「逃生路径判断」？
6. 双人同屏两套键位 + 触屏是否互不抢占？

## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **移动补正** | 转向时若前方半格内可通行则自动对齐（补正阈值抽成常量 + 单测）。这条能直接消掉一半挫败感。 |
| **泡泡时间线** | 放置 → 0.4s 膨胀 → 2.0s 破裂 → 波及 3 帧内连锁。全部常量化；连锁顺序要可复现（同一局面同一结果）。 |
| **道具体系** | 至少 6 种，含「踢泡」「穿泡」「泡泡护盾」；掉落用 seeded 随机，测试可复现。 |
| **AI 三档 + 自保** | 每档都必须有「放泡后能走到安全格」的检查（BFS 逃生判定），高档还会封路与预判。固定 seed 胜率断言。 |
| **救援机制（coop）** | 被困在泡泡里 5 秒内可被队友拍破救出，救人有星星奖励——把合作模式做出真正的合作理由。 |
| **无尽「泡泡塔」** | 一层一张小地图，敌人渐强，撑到第几层记录 `save.recordEndlessBest("bomb-buddies", n)`。 |

## 六、2.5D / 3D 决策

## 七、视觉 · 建模 · 手感

- 泡泡膨胀有呼吸感，破裂是「啵」的一圈彩虹波（不是火焰）。
- 被困住的角色在泡泡里晃动，头顶有倒计时圈。
- 砖块被波及是「变成小花散开」。
- `prefers-reduced-motion`：关屏震与闪烁。

## 八、手机 360px

- 摇杆 + 放泡钮（+ 踢泡钮）不重叠，热区 ≥ 44px；双人上下 / 左右分区明确。
- 地图在窄屏要整屏可见（不许滚动找角色），格子最小 24px。
