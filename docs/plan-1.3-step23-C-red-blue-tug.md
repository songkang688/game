## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **拔河现场（核心）** | 在计量条上方画完整拔河剧场：红蓝两队各 3 只 Q 版小人（SVG，后仰拉绳姿态，前位领队咬牙鼓腮表情），中间麻绳悬垂曲线（两段贝塞尔 + 绳纹短斜线）+ 中点红丝带标；**丝带位置直接映射既有拉力值**（`renderMeter` 的数据源），拉力偏移时全队身体后仰角度加大（±4–10° 分三档映射）、绳子绷直程度同步。 |
| **计量条升级** | 原进度条改成「地面刻度带」：中央河沟（蓝渐变 + 波纹）+ 两侧地面刻度线，红丝带过线就是把对方拉过河——胜负语义从抽象条变成看得懂的画面（阈值逻辑不动）。 |
| **节拍可视化** | `renderBeats` 升级为绳上节拍圈：拍点沿绳中点冒出圆环收缩（命中窗口 = 环最小时刻，读既有节拍数据只做映射）；命中时全队猛拉一帧 + 尘土两粒，miss 时绳子轻晃（不批评）。 |
| **胜负仪式** | 胜方全队后倒叠罗汉笑 + 抛帽 + 彩纸；败方坐地吐舌头笑（都是可爱收场）；连胜数用小奖杯堆叠可视化（读 `streak`）。 |
| **场景氛围** | 背景草地 + 远山两层 + 加油小旗串；观众小花两朵摇摆（reduced 静止）。 |
| **布局与 HUD** | `paintHead` 卡片化（局数 / 连胜 / 纪录三卡）；键位提示做成键帽图形（朵朵 F / 星星 L 的既有约定照抄不改）。 |

- 色板走 `src/art/kit/palette.ts`；小人可复用 A 档 `runnerSvg.ts`（若已落）改拉绳姿态参数，或自建 `tugTeam.ts`。
- `prefers-reduced-motion`：后仰过渡、节拍环、尘土、摇摆全停，保留丝带位置与静态队形（拉力信息不减）。

### 4.2 拉绳小人工序单（tugTeam.ts）

1. viewBox `0 0 48 56`；身体：圆角胶囊躯干（队色渐变 `tugRed→tugRedDark` 135°）+ 圆头（肤色 `#ffe3c8`，2px 队色深色描边）；
2. 后仰姿态：整体绕脚跟点 `transform-origin: 24px 52px` 旋转，站位角基准 −6°（向己方倾）；
3. 手臂两条圆端粗线（`stroke-width:5`）伸向绳子方向，手部小圆握在绳带上；
4. 表情两档：普通（豆点眼 + 抿嘴）与领队（咬牙 `path` 短齿线 + 鼓腮圆），红队领队加头带、蓝队领队加帽子——剪影差异保证红蓝一眼分清；
5. 脚下椭圆阴影 `rgba(0,0,0,.12)`，后仰角加大时阴影沿反方向偏 2px；
6. 三只小人同队错位排布（间距 26px、依次缩放 1 / 0.92 / 0.86 造前后纵深），领队在最靠绳位。

### 4.3 动效时序表

| 触发 | 动画 | 时长/缓动 | reduced 行为 |
| --- | --- | --- | --- |
| 拉力值变化 | 丝带平移 + 全队后仰角插值 | 220ms / ease-out | 直接跳到目标位 |
| 拍点出现 | 绳上圆环由 r=26 收缩到 r=8 | 与既有节拍窗口对齐 / linear | 换静态高亮点 |
| 节拍命中 | 全队猛拉一帧（后仰 +6° 回弹）+ 尘土 2 粒 | 160ms / ease-in-out | 全停 |
| 节拍 miss | 绳子中段轻晃 ±2px | 200ms / ease-out | 停 |
| 胜负判定 | 胜方叠罗汉 + 抛帽 + 彩纸 24 粒；败方坐地吐舌 | 900ms 一次性 | 只留静态胜负队形 |
| 待机 | 小旗串摆动 ±3°、观众小花摇摆 | 2.4s / ease-in-out 循环 | 停 |

## 九、测试（只增不减，新增 ≥ 12 个视觉用例）

1. 丝带位置 = 拉力值线性映射（0 / 0.5 / 1 三点断言，数据源不变）；

6. 领队与普通队员的表情/头饰节点差异断言（红头带、蓝帽子各存在）；
7. 同队三人缩放比 1 / 0.92 / 0.86 断言（纵深错位）；
8. 河沟刻度带渐变与过线判定阈值展示位一致（阈值常量原值断言）；
9. 胜负仪式走不同分支且 `recordEndlessBest` 调用参数原样（回归断言）；
10. 连胜奖杯堆叠数量 = `streak` 值（0 / 3 / 7 三点）；
11. 顶栏三卡渲染齐全且 360px 下单行放下；
12. reduced 下节拍环 / 尘土 / 摇摆 / 彩纸为 0，丝带位置仍随拉力更新；
