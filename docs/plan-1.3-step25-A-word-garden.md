## 三、现状审美评测（先开代码再动笔）

打开 `src/games/word-garden/tracing.ts` 与 `buildChar.ts`，渲染入口是 `drawGrid` / `render`（tracing）与 `render`（buildChar）。已核实与预期的问题：

1. `drawGrid` 的米字格预期是细线裸格（自查确认）：没有纸质感、红线格的传统书写氛围没有立起来；
2. 描红笔迹预期是等宽线条（自查 `render` 的 stroke 段确认）——毛笔 / 铅笔的粗细变化没有，写字像划线；
3. 「花园」题材自查：字写成后有没有花的反馈？预期没有或只有文本——识字与花园两个意象没连起来；
4. `buildChar` 部件拼字的部件块预期是纯色块 + 文本；
5. 当前笔画的引导提示（起点 / 方向）画法自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **书写纸质感** | 米字格升级：宣纸底色（暖白渐变 + 极淡纤维噪点两三处）+ 红色格线（外框粗 2px、米字虚线 1px）+ 格角圆润；当前书写格加柔光聚焦，其余格降饱和。 |
| **毛笔笔迹（核心）** | 描红笔迹改成有笔锋的变宽线：按书写速度映射粗细（慢粗快细，范围 0.6–1.4 倍基准宽）+ 起笔顿点 / 收笔出锋（线帽用圆头 + 尾端宽度渐收）；**判定轨迹与容差一律不动**，笔锋只是渲染层。已写完笔画墨色沉稳、当前笔画亮色。 |
| **笔顺引导** | 当前笔画起点画呼吸圆点 + 方向小箭头沿笔画路径预演一遍（600ms 渐隐，reduced 静止箭头）；写错方向时轨迹变灰抖一下（不批评）。 |
| **写字开花（核心）** | 每写成一个字：格子上方开出一朵自绘五瓣花（花瓣展开 5 帧 + 花心渐变，450ms，reduced 一帧）；花落进底部花园横条（本局写过的字各对应一朵花，悬停 / 点按显示该字）——「识字小花园」的名字落到画面上。花园随进度从空地 → 发芽 → 花丛三层繁茂。 |
| **部件拼字精修** | `buildChar` 部件块升级为木质字卡（木纹 + 描边 + 抬起阴影），拼对时两部件磁吸合体 + 金边一闪；拼错轻弹回（不批评）。 |
| **布局与 HUD** | 顶部字卡（目标字 + 拼音 + 朗读喇叭）卡片化；进度 = 花园里花的数量；橡皮 / 重写按钮做成文具图标。 |

- 色板走 `src/art/kit/palette.ts`；花朵可**新增** `src/art/kit/flower.ts`（五瓣花参数化 + 展开帧）并配套单测。
- `prefers-reduced-motion`：预演、展开帧、磁吸动画全停，保留静态引导与花朵结果。
