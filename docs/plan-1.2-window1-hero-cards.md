# 窗口 1 · 第 4 步 A 档 · `hero-cards`「英杰令」工作计划

对照规格：`docs/plan-1.2-step4-A-hero-cards.md`。
本档只碰 `src/games/hero-cards/**`，同步骤的 `weiqi-garden`（B）、`flight-chess`（C）一个字都不动。

## 一、模块切分

| 文件 | 职责 | 关键导出 |
| --- | --- | --- |
| `meta.ts` | 纯数据卡片，不 import 玩法 | `meta` |
| `cards.ts` | 牌堆结构：基本牌 / 锦囊 / 装备，洗牌、摸牌、弃牌、回收 | `createDeck` `draw` `discardTo` `recycle` `isRed` |
| `distance.ts` | 座位环、距离、坐骑修正、攻击范围、合法目标 | `distance` `attackRange` `inSlashRange` `legalTargets` |
| `heroes.ts` | 14 名原创英杰与技能。技能一律纯函数 `apply(state, event, self) → Effect[]` | `HEROES` `trigger` `queryNumber` |
| `engine.ts` | 局面、回合流程、判定、身份胜负、奖惩、结算。交互用生成器 yield 请求 | `createGame` `playCard` `runAiTurn` `winnerOf` `onEliminated` `judge` |
| `ai.ts` | 四档 AI 与身份推理 | `AI_TIERS` `roleHeuristic` `decideTurn` `decideRespond` `simulateMatch` |
| `levels.ts` | 8 章 188 关残局，构造式生成 + 求解器 | `CHAPTERS` `levelConfig` `solveLevel` |
| `guide.ts` | 攻略（只讲方法） | `default` |
| `index.ts` | DOM 牌桌 + 战役 / 对战 / 无尽三种模式 | `meta` `mount` |

交互为什么用生成器：出「击」要等对方决定挡不挡，出锦囊要挨个问无懈，
回调式写法在「无懈反制无懈」这种递归里会炸开。生成器 `yield` 一个请求、
`next(reply)` 拿回答，界面按钮和单测脚本用同一套驱动器，规则只写一遍。

## 三、牌堆（原创名，结构对齐经典身份牌）

- 基本：花瓣击 ×30、星星盾 ×15、蜜桃愈 ×8
- 锦囊：顺手摘花 ×5、拆花篮 ×6、对花令 ×3、落英缤纷 ×3、流星阵雨 ×3、
  贪玩令 ×3（延时）、春风无懈 ×4、春风借力 ×2
- 装备：银铃短笛（范围 1）、玉兰折扇（2）×2、长虹彩带（3）×2、纸鸢长弓（4）、
  连珠花轮（1，出击不限次）、星纱披风 ×3（防具，判定红当挡）、
  疾风小马 ×3（+1）、踏云软靴 ×3（-1）
- 花色四门：🌺花 / 🍒果 为红，🍃叶 / 🪨石 为黑。判定翻牌堆顶，抽空把弃牌堆洗回。

## 四、身份与胜负

5 人：1 主公（开局亮明，元气上限 +1）、1 忠臣、2 反贼、1 内奸。

- 主公 / 忠臣：反贼与内奸全部退场。
- 反贼：主公退场时不是「只剩内奸一人」的局面。
- 内奸：主公退场时全场只剩自己。
- 奖惩：让反贼退场 → 摸 3 张；主公误让忠臣退场 → 弃光手牌与装备。

## 五、188 关残局（8 章）

24 / 24 / 24 / 24 / 22 / 22 / 24 / 24 = 188，`assertTotal(CHAPTERS, 188)`。
每关构造式生成：先定「玩家用哪几步赢」，再按这条线发牌，
`solveLevel(i)` 用同一套规则引擎把这条线真的走一遍，测试断言 `solvable === true`。

## 六、模式

对战身份场（1 人 + 4 AI）、闯关 188、无尽连胜。
**不做双人同屏**：身份场靠隐藏身份撑着，两个人挤一块屏会互相看光手牌与身份，
所以 `meta.modes` 不填 `twoPlayer`，攻略里也写明这个理由。完整国战 8 人版不做，
用「双势力合作」小关（同势力不能互相出击牌）代替。

## 七、测试下限

新增 ≥ 35 个用例（硬性下限 15）。必覆盖：坐骑距离、武器只改击不改锦囊、
退场后距离重算、主公误伤忠臣的弃牌罚、让反贼退场摸 3 张、内奸四种胜负边界、
无懈反制无懈、延时锦囊判定、牌堆抽空洗回、14 名英杰各一条、188 关可解、
`assertTotal`、`destroy` 干净、360px 不溢出。
