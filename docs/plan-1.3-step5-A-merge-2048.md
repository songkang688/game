## 二、极高质量改进方案（可执行绘制规格）

### 1. 数字块 → 星星宝石块（核心资产）

- 每块三层（保持 DOM 块结构与 `place()` 签名）：
  1. 底层：保留 `tileColors` 色表为基调，但改为对角线性渐变（左上 +10% 亮）+ 底部 2px 深色厚度边（伪 3D）；
  2. **角标星星**：块右上角一颗小星星徽章，星级随数值升档——2/4 无星、8/16 铜星、32/64 银星、128/256 金星、512/1024 双金星、2048+ 彩虹星（SVG 五角星 + 高光点，尺寸 ≈ cell×0.22）；
  3. 数字排版保留 `tileFontPx` 逻辑与白圈 `tileRingPx`（色弱双通道是 1.2 的好设计，必须保留）。
- 2048 块（达标块）常态微光呼吸（box-shadow 金光 2s 循环，`soft` 关）。

### 2. 棋盘 → 星空收纳盒

- `.mg-board` 加 8px 木盒边框（双色渐变描边）+ 四角圆钉；`.mg-hole` 改内凹感（inset 阴影 + 顶部 1px 暗线）；
- `.mg-wrap` 背景渐变升级为「黄昏星空」：上层淡紫下层暖黄 + 3–4 颗 CSS 伪元素装饰星（静态）。

### 3. 障碍格 → 画出来的花坛

- `🌺` emoji 改为内联 SVG 花朵（5 瓣粉花 + 黄芯 + 两片叶），`.mg-block` 底色改花坛土壤纹（横细线 2 道）；
- 尺寸随 cell 缩放，`aria-label` 保留「这格被花占着」类描述。

### 4. 合并爽感分级（核心体验）

- 合并动画在现有 `mg-pop` 之上叠加（不改 `MERGE_MS`）：
  - 小合并（≤64）：接缝处迸 3 颗小星屑（DOM 粒子，0.3s 淡出）；
  - 中合并（128–512）：6 颗星屑 + 一圈扩散光环；
  - 大合并（≥1024）：8 颗星屑 + 屏幕轻震 1 次（translate 2px，`soft` 关）+ 金色闪光；
  - 星屑粒子用共享 kit 星星，对象池 ≤ 24。
- 加分飘字：合并处 `+N` 上浮 0.5s（金色描边数字，`soft` 时不飘只更新分数）。

### 5. 结算与里程碑

- 首次合成 256/512/1024/2048：中央弹「星级升格」卡 0.8s（大星星 + 数值，点击可跳过）；
- 结算面板：最大块的星星宝石大图 + 分数 + 步数，加奖杯。

## 三、2D / 2.5D / 3D 决策

**保持 2D**（数字类棋盘规范）。立体感 = 渐变 + 厚度边 + 内凹洞三件套；滑动性能优先（DOM transform 已是最优解，别换 Canvas）。禁止 three.js。
