## 二、极高质量改进方案（可执行绘制规格）

### 1. 圆圆 → 有脸的果冻球（核心资产）

- **结构（由内向外）**：径向渐变主体（中心 `owner.color` 提亮 18%，边缘压暗 12%）→ 2px 深色 rim 描边（owner 色 HSL 亮度 −25）→ 左上 28% 半径椭圆高光（白 60% 透明）→ 底部 20% 内阴影弧。
- **脸**：半径 > 10px 时画双眼（白底黑瞳，瞳孔朝移动方向偏移 `0.2r`）、两团 `#FFB6C1` 腮红；半径 > 22px 加嘴（微笑弧线）。吞吃瞬间 0.25s 换成「张嘴」帧（下半圆缺口），被吞方 0.2s「惊讶」帧（O 形嘴）。
- **玩家/AI 区分**：人类圆圆戴一颗五角星头饰（P1 金、P2 银，双人同屏时必须一眼分清 A/B）；AI 只有脸不戴饰品。名字牌改成圆角白底 75% 透明胶囊，替换现在裸 `fillText`。
- **分身动画**：分裂瞬间两球间画 3 帧拉丝（贝塞尔果冻拉伸），替代目前的瞬移感。

### 2. 彩豆 → 星光糖（消灭纯色圆）

- 三种造型循环：五角星糖（旋转 ±15° 摆动）、圆糖带十字高光、花瓣糖（4 瓣）。
- 每颗 = 主体渐变 + 1px 白描边 + 中心小高光点；用 `p.x*7+p.y*11` 之类的确定性哈希选型与相位，**不引入新的随机源**（不动 logic）。
- 预渲染到 offscreen canvas（3 种 × 2 尺寸），主循环 `drawImage`，避免上千个 `arc` 的开销回归。

### 3. 刺球 → 危险仙人掌球

- 内芯径向渐变（`#8FD48F` → `#5CA85C`）+ 外圈尖刺分离绘制（刺根粗尖细，逐根三角形），刺尖描 1px 深绿。
- 加一张「凶脸」：倒八字眉 + 咧嘴，让 6 岁玩家一眼知道「碰不得」。
- 呼吸动画：半径 ±3% 正弦（`soft` 模式下停用，沿用现有 `soft` 开关）。

### 4. 缩圈 → 风暴光环

- 描边改双层：内圈 6px 青色 40% 透明光带 + 外圈 2px 实线；圈外区域盖一层 `#7FB8C4` 12% 透明罩（用 `evenodd` 填充环外）。
- 缩圈进行时边缘加 8 个绕行光点。

### 5. 背景 → 糖果竞技场

- 平涂改三层：底层线性渐变（上 `#FBF7FF` 下 `#EFE6FF`）→ 中层保留网格但降到 6% 透明 → 顶层 6–8 个超大淡紫圆斑（视差系数 0.3，跟随相机慢移）。
- 竞技场边界（世界边缘）画粗糖果条纹墙，替代现在的「走到头突然没了」。

### 6. 关卡主题差异（不改数值）

- 按 `levels.ts` 现有分段每 ~47 关换一个调色主题：糖果紫 → 海洋青 → 黄昏橙 → 星夜蓝，只换背景渐变与网格色常量，写成 `THEME[palIndex]` 查表。

### 7. 结算与特效

- 吞吃 ≥ 自身 1/3 质量的目标时：爆出 6–10 颗星星粒子（350ms，缓出）。
- 结算面板加名次奖杯图（前三名金银铜，Canvas 画，不用 emoji 凑数）、本局质量曲线小图。
- 排行榜 `boardEl` 改成带头像小圆（直接复用果冻球绘制函数 16px 版）。

## 三、2D / 2.5D / 3D 决策

**保持 2D 俯视**（io 类玩法本质是俯视大地图，转 3D 收益低、性能风险高）。但要求「伪体积」：所有球体必须径向渐变 + rim + 高光三件套，禁止再出现单次 `fill` 的平涂圆。禁止引入 three.js。
