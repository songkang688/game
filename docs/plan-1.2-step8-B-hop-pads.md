## 四、这不是什么

- 不是 `rainbow-run`（三车道 2.5D 跑酷），不是 `puff-bros`（跳跃平台）。
- 本款是**单点蓄力跳跃**：一次一跳，落点判定分「完美 / 边缘 / 落空」，靠手感与节奏冲连击。

## 五、完整规则

### 蓄力与飞行
- 角色站在当前台面中心。前方生成下一座台（距离、左右偏移、大小、类型）。
- 蓄力时间 `t` 映射到力度：`power = clamp(t / MAX_HOLD, 0, 1)`；**映射必须单调且可学**（线性或 `t²`，把常量写清，训练关显示辅助圆）。
- 飞行是抛物线：`landPoint(p0, power, yaw)` 为纯函数；高度与水平距离都随力度增加。
- 摄像机在落地后平滑跟到新台。

### 落点判定
- **完美**：落点到台心距离 < `PERFECT_R` → 连击 +1，得分 = 基础分 × 连击倍数，台面绽放小花。
- **边缘**：落在台面内但不在完美圈 → 站住，连击清零。
- **落空 / 擦边掉下** → 本局结束；**必须有下落动画再结算，禁止瞬死**。

### 台面类型
稳台、左右移动台、逐渐缩小台、弹簧台（落上后自动多跳一次）、一次台（跳走后消失）。

### 生成器
`nextPad(seed, i, difficulty)` 必须保证**每座台都在可达范围内**：所需力度落在 `[0.2, 0.9]` 区间（测试抽样断言）。

胜负：掉下即结束。闯关目标是分数或连续座数；无尽记最高分 `save.recordEndlessBest`；对战用同一 seed 的台序比分。

## 九、前端建模与视觉（含 360px）

- Canvas 伪 2.5D：台面画成椭圆 + 侧壁（等距透视即可，**不要 three.js**）。
- 蓄力时角色压扁 + 蓄力条增长；起跳有拉伸；落地有小尘土与轻微镜头下沉。
- 掉下：角色往屏幕下方掉出去再结算，配一句鼓励文案。
- `prefers-reduced-motion`：去掉镜头晃动与压扁形变，保留蓄力条。
- 360px：台面居中，蓄力条在底部且 ≥ 12px 高；分数与连击字号 ≥ 16px；整块屏幕都是蓄力热区。
