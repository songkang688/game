## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **钩索手感** | 下钩加速度、抓住后的回收速度 `v = v0 / (1 + w * mass)`、空钩快速回收，三条都抽成常量 + 单测。抓到时钩子有 60–90ms 顿感。 |
| **矿洞纵深（伪 2.5D）** | 背景分 3 层（近岩壁 / 中矿层 / 远洞穴），随钩子下潜视差移动；**只做视差与明暗，不做真透视**（钩子角度必须精确可读）。 |
| **道具重做** | 炸药：抓到不值钱的大石头时可炸掉换重抓；力量水：本关回收加速；幸运石：提高稀有矿刷新。三者都写成纯函数，价格随章节递增。 |
| **新矿物** | 补 2 种：会滑走的「泥泥矿」（抓住后有几率脱手，可用炸药固定）、需要连抓两次的「双层晶」。 |
| **无尽矿井** | 层深越大越暗（照明圈缩小），每 5 层给一次「补给点」选择（三选一）。成绩 `save.recordEndlessBest("gold-hook", depth)`。 |
