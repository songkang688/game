## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **无限撤销 + 重来** | 用状态栈实现无限撤销（内存上限保护，超过就丢最早的），撤销**不扣星**但记录「使用了撤销」用于三星判定（三星要求：不超过最短解 +N 步且不用提示）。 |
| **死锁提示** | 检测到当前局面已无解时，给温和提示「这个箱子推到墙角就出不来啦，按撤销试试」——**必须用 solver 或死锁规则判断，不能瞎猜**。 |
| **难度分档** | 用 `solver.ts` 算出每关最短解步数，把 188 关按步数重新标注难度星标（**不改关卡本身**），并保证曲线单调不跳崖。 |
| **提示系统** | 每关 1 次「下一步提示」（走 solver 的解的第一步），用掉不给三星。 |
| **无尽「仓鼠仓库」** | `generate.ts` 随机生成 + solver 验证有解，难度随进度上升；成绩 `save.recordEndlessBest("box-hamster", solved)`。**生成必须有超时保护**（解不出来就换一张，不许卡住 UI）。 |

## 七、视觉 · 建模 · 手感

- 推箱有 120–160ms 格间插值 + 轻微「吱呀」音（用 `api.play("tap")`）；到位的箱子变色 + 小星星。
- 仓鼠转向有朝向动画，不许瞬转。
- 撤销时动作反向播放（快 2 倍）。
- `prefers-reduced-motion`：位移时长压到 1 帧，仍走同一状态机。
