# 1.1 第 6 步 · 角色 C —— 朵星双人冲刺 2.5D 双人 + 无尽竞速

开工记录。独占目录：`src/games/duo-rush/` 下**除 `meta.ts` 之外**的全部文件。
不碰 `rainbow-run`（A 档）、不碰 `src/engine/collection.ts` / `src/ui/collection.ts`（B 档）、不碰 `src/ui/home.ts`。

## 基线

- 分支从 `origin/game-1.1` 拉出。
- 现状：`duo-rush` 已有同种子公平赛道（`logic.ts` 的 `createTrackGen` / `trackIsFair`）与
  「无尽对战比谁远」「抢金币赛」两个赛制，`logic.test.ts` 共 16 个用例。
- 这 16 个老用例一条都不删、不改，只往上加。

## 要做的事

1. **2.5D 伪三维分屏**
   - 三条车道向远处收敛的透视投影：`z` 越远 `scale` 越小，地面网格线跟着距离滚动，
     远端做雾化淡出。纯 Canvas 2D，不引 three.js 或任何新依赖。
   - 宽屏（≥ 720 CSS px）左右分屏，窄屏自动切上下分屏；投影与分屏都抽成纯函数放
     `view25d.ts`，单测直接算坐标。
2. **键位**
   - 朵朵 `W`（跳）`A`（左道）`S`（下滑）`D`（右道）；星星 `↑ ← ↓ →` 同构。
   - 两张键表零交集，写成单测断言，保证两人同屏各按各的互不抢键。
   - `Esc` 暂停（两人共用），暂停面板挡住画面、松开继续。
   - 手机：以画布中线切左右两半，各自识别四方向滑动。
3. **无尽竞速模式（新）**
   - 两人同时无限跑，**先撞满 3 次者输**，不再等两人都撞完。
   - 另加**幽灵对战**：和自己上一次的最好成绩赛跑，幽灵按存档里的最远距离匀速推进。
   - 老的「无尽对战比谁远」「抢金币赛」照旧保留，`endlessWinner` 不动。
4. **障碍对称性**
   - 两人赛道逐个实体（种类 / 车道 / 位置）完全一致，写成单测断言，
     而且要断言「模拟一整局之后两条赛道仍然一致」，不只是生成时一致。
5. **人机对战三档**
   - 简单档：反应慢、会失误（有一定概率不躲）。
   - 中档：反应中等、基本不失误。
   - 高档：几乎不失误，但有固定反应延迟（不是无延迟外挂）。
   - AI 用确定性随机数，同 seed 同行为，单测里可复现。
6. **攻略**：`guide.ts` 补上新赛制与新键位的条目，继续过 `src/games/copy.test.ts` 的文案巡检。
7. **收藏册入口**：`src/ui/collection.ts` 由 B 档新建。用 `import.meta.glob` 探测，
   模块在仓库里才显示按钮，不在就当没有——绝不自己建 collection 文件。
