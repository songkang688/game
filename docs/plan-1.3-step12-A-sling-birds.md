## 二、极高质量改进方案（可执行绘制规格）

### 1. 小鸟从可爱到精美（保留现有骨架）

- **体型差异化**（判定半径 `bird.r` 不动，只改绘制轮廓）：直冲=标准圆；分裂=略瘦高椭圆（ry=1.1r）；横杆(slam)=矮胖椭圆（rx=1.15r）；钻头=前尖水滴形（贝塞尔拉尖嘴侧）；卷卷=圆+两侧蓬毛 3 撮；
- 飞行演出：速度 > 阈值时身后 2–3 根速度线 + 每 0.15s 脱落 1 片小羽毛粒子（椭圆+旋转下飘）；技能触发瞬间加白色闪圈 1 帧；
- 表情状态：拉弓时鼓腮闭眼蓄力、飞行瞪眼、落地后眨眼捂头（`restT` 期间）；
- 排队小鸟（`drawQueue` 1793–1819 行）加「排队小动作」：第一只原地小跳（`reduceMotion` 静止）。

### 2. 豆豆（目标）家族化

- 三种体型（不动判定 r，只改画法与装饰）：普通豆保持现状；大豆加胡子两撇+眉毛（长辈感）；戴叶盔豆头顶叶子改成 3 片叠盔；
- 被击中演出：0.2s「惊讶脸（圆嘴+飞汗滴 2 粒）」再爆成 4 粒绿星屑+1 片叶子飘落（`reduceMotion` 直接淡出）；
- 待机偶发眨眼（每 3–5s 随机一只，全员共用相位错开）。

### 3. 方块破坏演出（材质碎片）

- 残血分级：血量 > 50% 无裂纹；≤50% 画 1 条折线裂纹；≤25% 画 3 条放射裂纹（裂纹颜色取材质 edge 色加深）；
- `drawParticles` 升级为**材质碎片查表**：木=旋转长条（2:1 圆角矩形）、石=不规则四边形、冰/玻璃=三角闪片（半透明+白描边）、岩壳=褐色圆石粒、晶核=菱形亮片、TNT=橙黄火花+烟圈；每种 ≤6 粒，`reduceMotion` 减半；
- TNT 爆炸加一圈白色冲击波环（0.25s 扩散淡出）。

### 4. 场景纵深与弹弓

- 每章节加中景剪影层（一次 path 画完，视差随镜头拉伸 `releaseStretch` 微移）：草原=圆树 3 棵+栅栏、雪原=雪杉+雪人剪影、星空=云堡+浮岛剪影；
- 地面加横向草丛带（三角草簇每 60px 一组）；弹弓底座加 2 簇草+1 块小石头；
- 皮筋改双线（亮边+暗边错 1px）体现厚度，拉满时中段加张力白高光。

### 5. 结算与横幅

- 关卡横幅加章节 emoji 对应的**绘制角标**（草原=小花、雪原=雪花、星空=星星，画在圆角条两端）；
- 胜利结算：剩余小鸟逐只从左飞入排成一排，每只落地时 +分数飘字，最后星级逐颗点亮（每颗 0.3s，伴随星屑）；失败则豆豆们开心跳舞 1s（幸灾乐祸要可爱不要嘲讽）；`reduceMotion` 全部静态展示。
