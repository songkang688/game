## 二、极高质量改进方案（可执行绘制规格）

### 1. 角色 → 朵朵/星星跳跳员（核心资产）

- 保留椭圆身体与 squash/stretch 参数（202–203 行公式不动），叠加：
  1. 脸：大眼（白底黑瞳 + 高光）+ 腮红；蓄力时眼睛眯成一条线（用力）、飞行中眼睛圆睁、落台后 0.2s 笑脸、落水/坠落时 >< 眼；
  2. 双人区分（形状+颜色双通道）：P1 朵朵=头顶花苞呆毛 + 粉裙边（身体下缘波浪）；P2 星星=头顶星星呆毛 + 黄披风飘带（飞行中拖 2 帧）；
  3. 起跳/落地各 2 帧小手（起跳上举、落地平展）；
- 落地反馈：普通落地 2 粒尘土；**完美落点**（落进白圈）：一圈金色扩散环 + 4 颗星星粒子 + 台顶短暂发光；连续完美 combo ≥ 3 时角色头顶冒小皇冠（`reduced` 只发光）。

### 2. 台子 → 主题化台面

- steady 基础台保留双面色制式，按 `pad.kind` 换造型（顶面纹理 + 侧壁色，`KIND_ICONS` 字符移除改绘制）：
  - 移动台：顶面画双向箭头浮雕 + 侧壁条纹；
  - 易碎台：顶面裂纹 2 道（踩上后裂纹扩展到 4 道再碎裂成 3 块下坠）；
  - 弹簧台：侧壁画弹簧圈线，起跳时压缩回弹 2 帧；
  - 其余种类一律「顶面图案 + 侧壁色」双通道区分；
- 台子入场：新台从远处淡入 + 从下往上浮 4px（`reduced` 直接出现）。

### 3. 场景 → 天空跳台世界（强化 2.5D）

- 背景三层（按相机 z 轻微视差）：
  1. 天空线性渐变（顶 `#BFE3FF` → 地平线 `#FFF3D9`）；
  2. 远景：3–4 朵大云（`drawCloud` 复用放大版，视差 0.2）+ 远山剪影一条；
  3. 中景：漂浮小岛剪影 2 块（视差 0.5）；
- 深度雾：远处台子按 z 距离叠加淡天空色罩（`globalAlpha` 按距离 0→0.35），拉开纵深——这是 2.5D 廉价而有效的关键一笔；
- 无尽模式每 20 跳渐变换时段：白天 → 黄昏 → 星夜（查表插值天空色）。

### 4. 云朵救援与蓄力条

- 救援云加睡眼 + 接住时弹性下沉 2 帧；
- 蓄力条改为角色脚下的弧形力度环（跟随角色，颜色从绿到红），旧条保留为无障碍备份（`reduced` 或窄屏用旧条）。

### 5. 结算

- 结算面板：跳数 + 完美率进度环 + 最远台数；双人模式两角色并排（胜者跳起庆祝帧）。
