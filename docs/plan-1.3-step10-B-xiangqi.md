## 二、极高质量改进方案（可执行绘制规格）

### 1. 棋子 → 有厚度的木刻棋子（核心）

- 在现有渐变面（248–254 行）之下加**侧壁**：底部 3px 月牙形侧面（面色加深 20%），投影相应下移——一颗真正立在盘上的棋子；
- 字改「刻字感」：楷体字保留（266 行字体栈不动），加 0.5px 同色深描边 + 1px 右下浅色错位（阴刻效果）；
- 双圈线保留（258–264 行），外圈加极淡高光弧（左上 90°）；
- 红黑双方字色微调：红方 `#C23B2E`、黑方 `#2F3A2F`（更沉的墨色）；
- 预渲染 14 种棋子 sprite（2 方 × 7 种，尺寸变化重建），满盘 32 子改 `drawImage`。

### 2. 走子 / 吃子 / 将军演出（本步主要增量）

- **走子**：棋子沿直线滑动 160ms（easeOut）+ 落定 1.08→1 回弹 + 轻微落子波纹（`reduce` 直接落定）——配合现有 lift 浮起形成「拿起—移动—放下」三段；
- **吃子**：攻方滑入时被吃方 0.25s 缩小旋出 + 3 片花瓣（与全仓库「花瓣退场」口径统一）；被吃大子（车马炮）额外一圈金环；
- **将军**：将/帅棋子红光呼吸 2 次 + 头顶「将军!」毛笔字横幅 0.8s（`reduce` 静态红框 + 文字）；
- **将杀结算**：胜方将/帅跳起两下 + 印章式「胜」字盖下（0.4s 缩放盖印 + 微尘 2 粒）。

### 3. 棋盘装饰

- 外框：现有 3px 框（218 行）升级为双层木框（外 8px 深木 + 内 1px 金线）+ 四角如意云头小饰（SVG 路径 ≤ 8 笔）；
- 河界：「楚 河 / 汉 界」保留，底下加两道极淡水波曲线（5% 透明，静态）；
- 兵位/炮位加传统位点标记（十字小角标，线宽 1）；
- 最后一手标记：橙方框改为落点圆形罗盘印记（细圈 + 四短线，与圆棋子同族）。

### 4. HUD 与结算

- 座位条：红黑双方各配将/帅小棋子图标 + 名字 + 吃子槽（被吃的子按序排成小图标，双方各一排——形势一眼可读）；
- 记谱（`notation.ts` 现有数据）加最新一手高亮；
- 残局模式（endgames）：过关时目标印章「妙手!」+ 星级。

## 三、2D / 2.5D / 3D 决策

**严格保持 2D 俯视**（规范点名棋类 2D）。立体感全部来自棋子侧壁 + 投影 + 刻字，view.ts 242 行注释「保持 2D，不做立体透视」的口径延续。禁止 three.js。
