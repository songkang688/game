## 四、这不是什么

- 不是 `fruit-catch`（接水果）、不是 `fruit-slice`（切水果）——**这两个目录一个字都不许改**。
- 也不是 `merge-2048` 的网格合成：本款是**连续坐标下的圆形物理堆叠 + 同级相碰合成**，靠重力、弹性与摩擦决定落点。

## 五、完整规则

### 物理（自写，固定步长）
- 容器是矩形（左右墙 + 地面），重力向下。
- 每个果子是一个圆：位置、速度、半径、质量（∝ 半径²）、弹性 `RESTITUTION`、阻尼 `DAMPING`、摩擦。
- **固定 dt 子步进**（例如 1/120s，每帧跑 2–4 个子步），先积分再解重叠：圆-圆按法向冲量分离，圆-墙按反射 + 能量损耗。
- 必须收敛：连续 100 次子步后系统总动能不允许增长（写成测试，防止「能量爆炸」）。
- 静止判定：速度低于阈值持续 `SETTLE_MS` 视为 settled。

### 合成链（11 级，原创名）
籽 → 莓 → 柑 → 桃 → 梨 → 苹 → 橙 → 柚 → 瓜 → 玉瓜 → 团圆瓜。
- **同级两果相碰 → 合成下一级**，新果出现在两者中点，半径与质量按表。
- 可以连锁：合成后立刻可能再触发同级相碰，逐级播放。
- 得分按合成级别递增；一次连锁额外加成。
- 最高级两颗相碰：合成为一颗最高级并加大分（或按常量选择消失加分，写清并单测）。

### 投放与失败
- 顶部有一个可左右移动的投放点，落下前显示瞄准竖线与影子。
- 预览「下一个」1–2 个。
- **失败判定**：任何**已静止**的果子圆心越过警戒线即失败；刚落下的果子有短暂宽限期不判定。警戒线在快要触发时先闪烁警告。

胜负：闯关目标是「合成出指定级别」或「达到分数」；无尽是失败前的最高分；对战是两个容器比谁先合成目标 / 比分数。

## 九、前端建模与视觉（含 360px）

- Canvas 渲染：果子是纯色圆 + 高光 + 小叶子，全部原创造型（不要照抄任何商业游戏的果子画风）。
- **合成禁止瞬变**：两果先「吸合 + 缩小」再「弹出新果 + 放大回弹」，总时长约 200ms；连锁一节一节播。
- 落下有影子与瞄准线；越线警告先闪。
- `prefers-reduced-motion`：缩短吸合动画，保留顺序。
- 360px：容器占满宽，警戒线清晰可见；预览与分数在顶部一行；字号 ≥ 13px。
