## 三、现状审美评测（先开代码再动笔）

打开 `src/games/find-diff/index.ts`，渲染入口是 `paintAll` / `paintCell`（约 174 行起）。已核实的问题：

1. 场景是 **emoji 拼贴**：`paintCell` 把 `view.emoji` 用 `<span class="fdf-glyph">` 缩放 / 翻转 / 位移拼出画面（183–186 行）——整个「图」是 emoji 网格，找不同找的是字符差异；但注意：**emoji 与其变换参数是题目数据**，本步不能推翻这套机制，只能给它更好的舞台；
2. 双图的呈现方式自查（上下 or 左右分屏）：预期两块裸网格无相框，「对比两幅画」的语义弱；
3. 找到差异的反馈自查：预期是简单圈或变色，缺放大镜 / 侦探的仪式感；
4. 点错的反馈自查（有没有惩罚性闪红——有就要改柔）；
5. 计时与提示按钮样式自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **双画框舞台（核心）** | 两幅图各装进木质画框（框纹 + 内衬白边 + 顶部小挂牌「左图 / 右图」）+ 画框之间放中缝装饰（小别针 / 麻绳连接）；背景做成侦探书桌语义（桌面木纹 + 角落放大镜与笔记本装饰小图）。**格子与 glyph 的坐标、变换参数一律不动。** |
| **找到的仪式感** | 命中差异点：放大镜聚焦动画（圆形放大镜框从旁滑到差异点上，镜片内轻微放大效果用 scale 变换的装饰层模拟，260ms）→ 双图同位置各画一个圆圈标记（虚线旋转一圈收紧）+ 星屑 3 颗；已找到的差异点保留淡金圈常显。reduced：直接显示圈。 |
| **点错反馈** | 点错处冒出小问号气泡 + 轻微涟漪（灰色、不闪红、不扣血式惩罚观感——若既有扣时逻辑保留，只是画面不吓人）。 |
| **进度可视化** | 差异总数用「侦探徽章」排显示（找到一个点亮一枚）；全部找到时两画框中缝贴上「完全一致!」缎带 + 彩纸。 |
| **glyph 层微质感** | 在不动 emoji 数据的前提下给场景加统一滤镜层次：每格底加极淡圆形软影（让 glyph 像贴纸贴在画上）、画面整体加 2% 暖色滤镜统一色调——emoji 拼贴的「杂」感立刻收敛。 |
| **布局与 HUD** | 计时改沙漏图形（上下两仓 + 流沙线，读剩余时间映射，reduced 静止刻度）；提示按钮做成放大镜图标。 |

- 色板走 `src/art/kit/palette.ts`；星屑走 `sparkle.ts` 等价。
- `prefers-reduced-motion`：放大镜滑动、虚线收圈、流沙全停，保留静态圈与徽章。
