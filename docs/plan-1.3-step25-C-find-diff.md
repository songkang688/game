## 三、现状审美评测（先开代码再动笔）

打开 `src/games/find-diff/index.ts`，渲染入口是 `paintAll` / `paintCell`（约 174 行起）。已核实的问题：

1. 场景是 **emoji 拼贴**：`paintCell` 把 `view.emoji` 用 `<span class="fdf-glyph">` 缩放 / 翻转 / 位移拼出画面（183–186 行）——整个「图」是 emoji 网格，找不同找的是字符差异；但注意：**emoji 与其变换参数是题目数据**，本步不能推翻这套机制，只能给它更好的舞台；
2. 双图的呈现方式自查（上下 or 左右分屏）：预期两块裸网格无相框，「对比两幅画」的语义弱；
3. 找到差异的反馈自查：预期是简单圈或变色，缺放大镜 / 侦探的仪式感；
4. 点错的反馈自查（有没有惩罚性闪红——有就要改柔）；
5. 计时与提示按钮样式自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **双画框舞台（核心）** | 两幅图各装进木质画框（框纹 + 内衬白边 + 顶部小挂牌「左图 / 右图」）+ 画框之间放中缝装饰（小别针 / 麻绳连接）；背景做成侦探书桌语义（桌面木纹 + 角落放大镜与笔记本装饰小图）。**格子与 glyph 的坐标、变换参数一律不动。** |
| **找到的仪式感** | 命中差异点：放大镜聚焦动画（圆形放大镜框从旁滑到差异点上，镜片内轻微放大效果用 scale 变换的装饰层模拟，260ms）→ 双图同位置各画一个圆圈标记（虚线旋转一圈收紧）+ 星屑 3 颗；已找到的差异点保留淡金圈常显。reduced：直接显示圈。 |
| **点错反馈** | 点错处冒出小问号气泡 + 轻微涟漪（灰色、不闪红、不扣血式惩罚观感——若既有扣时逻辑保留，只是画面不吓人）。 |
| **进度可视化** | 差异总数用「侦探徽章」排显示（找到一个点亮一枚）；全部找到时两画框中缝贴上「完全一致!」缎带 + 彩纸。 |
| **glyph 层微质感** | 在不动 emoji 数据的前提下给场景加统一滤镜层次：每格底加极淡圆形软影（让 glyph 像贴纸贴在画上）、画面整体加 2% 暖色滤镜统一色调——emoji 拼贴的「杂」感立刻收敛。 |
| **布局与 HUD** | 计时改沙漏图形（上下两仓 + 流沙线，读剩余时间映射，reduced 静止刻度）；提示按钮做成放大镜图标。 |

- 色板走 `src/art/kit/palette.ts`；星屑走 `sparkle.ts` 等价。
- `prefers-reduced-motion`：放大镜滑动、虚线收圈、流沙全停，保留静态圈与徽章。

### 4.1 配色板与图层序

| token | 色值 | 用途 |
| --- | --- | --- |
| `frameWood` / `frameWoodDark` | `#c98d54` / `#96622f` | 画框木纹 / 框角描边 |
| `matteWhite` | `#fffdf7` | 画框内衬白边 |
| `deskWood` | `#a06b3a` | 侦探书桌背景木纹 |
| `foundGold` | `#f4b942` | 已找到差异的常显金圈 |
| `hitRing` | `#ff8c42` | 命中瞬间虚线收圈 |
| `missGray` | `rgba(140,140,150,.6)` | 点错问号气泡与涟漪 |
| `badgeBrass` | `#d1a054` | 侦探徽章底色（点亮加金描边） |
| `sandAmber` | `#f4d03f` | 沙漏流沙色 |

图层序（DOM 从底到顶）：书桌背景（木纹 + 角落装饰小图）→ 双画框（框 → 内衬 → 挂牌）→ emoji 网格层（**坐标与变换零改动**）→ 每格底部软影层 → 标记层（金圈常显 + 命中收圈）→ 放大镜动画层 → 问号气泡层 → HUD（沙漏 + 徽章排 + 提示按钮）→ 彩纸层。标记层及以上全部 `pointer-events:none`。

### 4.2 画框与放大镜工序单

1. 画框：外框 8px 木纹（两色相间斜纹线）+ 45° 斜接角线 + 内衬 4px `matteWhite`；顶部小挂牌（圆角牌 + 两个钉点 + 「左图 / 右图」）；
2. 中缝装饰：两框之间画麻绳一段 + 小别针两个（左右各别住一角）；窄屏上下排布时改为顶部麻绳横挂；
3. 放大镜：圆镜框（`frameWoodDark` 描边 3px）+ 斜柄圆头 + 镜片高光弧两条；命中时从画框外滑到差异点（贝塞尔路径）；
4. 命中圈：虚线圆从 r=28 收紧到命中判定半径大小，转一圈后定格为 `foundGold` 实线圈 + 星屑 3 颗；
5. 沙漏：上下两三角仓 + 中间细腰，流沙用一条渐窄竖线 + 底仓堆积弧，读剩余时间等比映射（计时逻辑不动）；
6. 徽章：圆形铜牌 + 五角星浮雕线，未点亮灰度 60%，点亮时金描边 + 一次性闪光。

### 4.3 动效时序表

| 触发 | 动画 | 时长/缓动 | reduced 行为 |
| --- | --- | --- | --- |
| 命中差异 | 放大镜滑入聚焦 + 虚线收圈定格 | 260ms + 300ms / ease-out | 直接显示金圈 |
| 命中同时 | 星屑 3 颗 + 徽章点亮闪光 | 400ms 一次性 | 徽章直接点亮 |
| 点错 | 问号气泡浮起 + 涟漪一圈 | 350ms / ease-out | 只显气泡一帧 |
| 全部找到 | 中缝贴「完全一致!」缎带 + 彩纸 16 粒 | 800ms 一次性 | 静态缎带 |
| 计时 | 流沙线流动 + 底仓渐积 | 随剩余时间连续 | 静止刻度条 |
| 提示使用 | 放大镜图标按钮按下 + 目标区柔光 | 200ms / ease-out | 只柔光 |
