## 三、现状审美评测（先开代码再动笔）

打开 `src/games/shoot-range/index.ts`，绘制入口是 `drawField` / `drawTarget` / `drawCrosshair` / `drawLauncher` 四个函数。已核实的问题：

1. `drawTarget`（约 988 行起）的 `bull` 靶就是 4 圈同心圆平涂色环（`#FFFFFF/#FFC9DC/#FFFFFF/#F4859F`）加一颗中心点——没有靶框、没有支架、没有受光面，是典型的「草稿圆」；
2. 远排靶的纵深表达只有 `targetDepthMul(t) > 1` 时垫一圈 45% 白雾加半径缩小（992–998 行），没有地平线、没有靶架落影，「远」的感觉基本靠猜；
3. 即将离场的靶只做 `globalAlpha` 正弦闪烁（999–1001 行），闪烁是功能性提示，但没有任何离场动画（缩小、飘走、鞠躬谢幕都没有）；
4. 其余靶种（分裂靶 / 护盾靶 / 彩虹靶 / 花朵靶）逐个打开 `drawTarget` 的 switch 分支自查：预期同样是纯色几何拼贴，把每种的问题记进你的开工 commit；
5. `drawField` 的场地、`drawLauncher` 的发射台、`drawCrosshair` 的双人准星你要逐行读完再动手，回复里逐条说明每个函数现在画了什么、缺什么。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **场景纵深** | 嘉年华靶场剧场化三层：远景条纹帐篷天幕（两色 `linearGradient` 条纹 + 顶部彩旗串）、中景靶架横梁（木色 `#C89B6C` 加 3px 顶亮边）、近景木质柜台压底。远排靶站在中景横梁上，近排靶站在近景柜台后，取代白雾圈。 |
| **靶子体积** | 每个靶子加：木框圆环（外圈 8% 半径宽、双色木纹）、背后支架斜杆（2px、深 20%）、脚下椭圆落影（`softShadow`，rx=0.8r）。色环从平涂改三停径向渐变（左上高光 → 主体 → 边缘暗 18%）。 |
| **靶种剪影** | 分裂靶画成「大星星怀里抱两颗小星星」；护盾靶加半透明蓝盾罩 + 盾裂纹两阶段；彩虹靶用 `conic-gradient` 等效的扇形七彩环 + 缓慢自转；花朵靶画成五瓣粉花 + 叶子，一眼看出「这个不能打」。 |
| **准星与手感可视化** | 朵朵准星粉色四爪 + 外圈呼吸（1.2s 周期 ±6%），星星准星蓝色三角爪；连发散布增大时准星爪张开的角度同步张开（读已有散布常量，只做映射不改数值）。 |
| **命中特效** | 命中爆星星彩纸升级为「星屑 + 丝带」双粒子（`sparkle.ts`）：星屑 8–12 颗 300ms 抛物线，丝带 3 条 420ms 螺旋飘落；花朵靶被误击时改成花瓣飘落 + 皱眉小云，不批评。 |
| **HUD 布局** | 分数 / 连击 / 剩余弹药一行卡片化：圆角 12px、底色 `rgba(255,255,255,.72)`、1.5px 描边；连击倍率数字加金色光环双通道（已有逻辑，只精修画法）。 |

- 全部渐变 / 描边 / 落影走 `src/art/kit/` 的公共函数；光源统一左上 45°，高光偏移 (-0.35r, -0.4r)。
- `prefers-reduced-motion`：呼吸、自转、粒子全部关掉，保留静态高光与落影。

## 五、共享美术套件 src/art/kit/

- 先看 `src/art/kit/` 是否已有别人落的文件；**已有的只 import 不修改**。
- 套件约定接口（谁先用到谁新增，一个文件只归一个人）：
  - `palette.ts`：粉彩主色 token 与 `shade(hex, ±n)`；

  - `sparkle.ts`：星屑 / 彩纸 / 丝带粒子（数量、寿命、重力参数化）。
- 你需要而 kit 没有的能力：**新增** `src/art/kit/<你的模块>.ts` 并配套单测，不改别人的文件。
