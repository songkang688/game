## 二、极高质量改进方案（可执行绘制规格）

### 1. 音符 → 星光琴键（核心资产）

- 单点音符改三层（尺寸/位置公式不动，594–608 行的 x/w/headY 保留）：
  1. 主体：纵向渐变（列色亮档 → 列色）+ 圆角保留；
  2. 顶面高光条（上缘 30% 白色 22% 透明）+ 底部 2px 深色厚边（琴键立体感）；
  3. 中心一颗小星形压印（白 35% 透明，「音符=星星」呼应产品）；
- 长条音符：头部同上，条身改半透明渐变管（列色 45% 透明 + 两侧 1px 亮边），流动亮块保留并改为星光流（2 颗小星随流）；holding 时条身外发光 1px；
- 预渲染 4 色 × 2 种 sprite，`drawImage` 拼装（60fps 大量音符的性能要求）。

### 2. 命中反馈 → 打击感三件套

- **判定等级可视化**（读 `judge.ts` 现有判定结果，不改窗口）：完美=金色六芒星爆点 + 「完美」小字上飘；好=白色四芒星；错过=保留现有轨道变暗（温柔口径不变，绝不闪红）；
- 判定线命中处：一圈扩散圆环（0.25s，列色）替代/叠加现有底部亮块；
- 粒子从 `fillText` 字符改为绘制的小星星/小音符路径（预渲染 2 张贴图），上飘物理保留（629–635 行速度公式不动）；
- **连击数上画布**：连击 ≥ 5 时判定线上方显示大号连击数字（描边圆体，每 +1 弹跳 1 帧；`reduced` 静态）。

### 3. 轨道与舞台氛围

- 轨道底色改极淡纵向渐变（顶暗底亮，向判定线汇聚的视觉引导）；分隔线加微光；
- 判定线升级：主线 + 两端小星星端点 + 命中时整线 0.1s 增亮；
- 背景：画布最底层加「舞台灯」——2–3 道极淡斜向光束（10% 透明，随曲目进度缓慢摆动 ±5°，`reduced` 静止）；连击 ≥ 20 时光束变暖色；
- 每关按 `levels.ts` 现有分段换主题色调（紫夜/暖橙/青蓝查表）。

### 4. 预备与结算

- 「预备…」改为 3-2-1 节拍圆点倒数（与 `t<0` 时间轴对齐，纯视觉）；
- 结算：判定统计条（完美/好/错过三色横条）+ 最大连击徽章 + 星级；双人模式两列对比。

## 三、2D / 2.5D / 3D 决策

**保持 2D**（音游判定精度优先，透视会破坏下落速度的线性可读）。立体感 = 音符厚边 + 舞台光束；禁止 3D 倾斜轨道、禁止 three.js。sprite 预渲染为性能硬要求。
