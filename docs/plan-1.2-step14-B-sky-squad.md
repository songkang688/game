## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **弹幕语法** | 把弹幕写成可声明的模式表：`{ pattern: "fan" \| "ring" \| "aimed" \| "spiral", count, speed, delay, arc }`，用纯函数展开成子弹列表。至少 6 种基础图案，boss 用组合。 |
| **判定盒可视化** | 玩家中心一个明显小圆点（判定核心），默认显示；被弹幕擦过（未命中但很近）给「好险！」小反馈。 |
| **火力成长** | 关内拾取升级（散射 / 追踪 / 穿透 / 僚机），有上限；被击中掉一级而不是直接结束（更适合孩子）。 |
| **boss 时间线** | 每章一个 boss，行为分 3 阶段，阶段切换有明确预告动作；boss 不许有「无解弹幕」——写一个「每一帧都存在可行走位」的模拟断言。 |
| **无尽「云海远征」** | 段落拼接 + 难度曲线，成绩 `save.recordEndlessBest("sky-squad", n)`；每段生成可复现。 |

## 五、模式矩阵

四种模式全保留（玩不了就修好或从 `modes` 删）；闯关 **前 99 关数据不改**；`coop` 要有真正的配合价值（例如两人火力合并出更强波）。

## 六、2.5D / 3D 决策

**保持 2D 纵版**。允许云层视差与地面滚动，**不做真 3D**（弹幕必须精确可读）。

## 七、视觉 · 建模 · 手感

- 子弹颜色按阵营固定（敌方暖色、我方冷色），**不能只靠颜色**：形状也要不同。
- 被击中：飞机打转 + 短无敌闪烁，掉一级火力，**不是坠毁**。
- 对象池：子弹与粒子全部复用，写「1000 次生成回收后池不膨胀」的用例。
- `prefers-reduced-motion`：关屏震与闪烁频率降到安全范围（避免光敏问题）。

## 八、手机 360px

- 触屏拖动飞行时，飞机要在手指上方 40px（不然手指盖住判定点）；这条要有开关但默认开。
- 火力等级 / 生命 / 分数一行显示，字号 ≥ 14px。

## 九、平台接线

- `openCampaignLevel(n)` / `initialLevel` / `?level=` 直开第 N 关；Skip 走 `requestSkip`。
- 无尽成绩 `save.recordEndlessBest`；`meta.platform` 按实测填；`blurb` 与事实对齐。

## 十、独占文件与冲突

只许改 `src/games/sky-squad/**`。不要碰 `shoot-range` / `tank-battle`。CSS 类名 `sks-` 前缀；`destroy` 清 rAF、定时器与监听。
