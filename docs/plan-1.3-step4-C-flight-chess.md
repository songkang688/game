## 二、极高质量改进方案（可执行绘制规格）

### 1. 棋子 → 真正的小飞机（核心资产）

- 每色一架 SVG Q 版小飞机（22×22 视图）：圆润机身（座舱盖白色高光）+ 双翼 + 尾翼 + 头部螺旋桨两叶；主色用 `COLOR_INFO[c].ink`、机腹用 `soft` 色；
- 朝向：沿外环行进方向旋转机头（8 方向查表即可，按当前格→下一格向量取角度）；
- 基地待命：飞机停机姿态（缩小 0.85 + 停机轮）；到终点（`GOAL`）：飞机换「着陆收翼」姿态 + 花环；
- emoji 保留进 `aria-label` 与座位卡文案（`describePos` 不变）。

### 2. 棋盘 → 机场乐园

- 外环格子按四色分段上色（每段用该色 `soft` 底 + `ink` 描边箭头指示行进方向，每 3 格画一枚小箭头）；
- 四角改「机库」：色块圆角区 + 机库门弧线 + 停机坪 4 个圆位；
- 终点区：中心画四色风车跑道汇聚 + 中央大星星塔台；
- 快速通道（`fc-cell-air`，108 行）：白圈升级为「云朵航线」——格内画小云朵 + 虚线弧线飞往对角；
- 底板 `#F4FAFF` 改草地渐变（`#EAF7E3 → #D8EFD0`）+ 四条淡跑道纹。

### 3. 骰子 → 立体骰

- `diceBox` 从 emoji 文字改为 SVG 三面体骰（顶面点数 + 两侧暗面），转骰沿用现有 `spinFrames` 帧序列逻辑（575–590 行**不改节奏**），每帧换点数面 + 微旋转；掷出 6 时金边闪一次（对应再掷一次规则）；
- `reduced`（现有变量）时保持现状快速出结果。

### 4. 走子 / 起飞 / 击落动画

- 逐格跳：每格 140ms 小跳（上抛 4px + 螺旋桨转速加快），替代整段直线滑（`prefers-reduced-motion` 退回直线滑）；
- 起飞（基地→起点）：飞机沿弧线爬升 + 两条尾迹白线 0.4s；
- 跳格/飞行通道：飞机拉高 + 影子分离（影子留在地面缩小），落地影子合并——低成本的 2.5D 高度感；
- **击落**：被撞飞机播放 0.5s「打转+降落伞回基地」（旋转 720° 缩小，基地处伞花绽放），攻击方机身闪金边；
- 迭子：两机错位 45° 叠停 + 底部「×2」小徽章。

### 5. 座位卡与 HUD

- 座位卡加小飞机头像（同款 SVG 缩小）+ 到家进度改 4 个小机位点亮图；
- `fc-pick` 选机按钮加对应飞机缩略图。

### 6. 结算

- 第 4 架落地：终点塔台放烟花（12 粒星星粒子 ×3 波，`soft` 关）+ 名次面板（飞机头像排名）。

## 三、2D / 2.5D / 3D 决策

**2D 俯视为主 + 影子分离的轻 2.5D 高度表现**（跳格/飞行通道时飞机与影子分离）。不做透视棋盘、禁止 three.js。DOM+SVG 沿用（保留按钮语义）。
