## 三、现状审美评测（先开代码再动笔）

打开 `src/games/puzzle-tiles/index.ts`，渲染入口是 `render` / `renderFill` / `renderRotate` / `renderSlide` / `renderPreview` / `renderTop`。已核实的问题：

1. 三种玩法的拼块预期都是方格 DOM 换色 / 换图案（逐个自查确认）：**没有拼图的凹凸齿边**——「拼图乐园」的拼块是方砖，拼图感先天缺失；
2. 拾起 / 放置没有物理感：预期无抬升阴影、无吸附动画（自查拖拽段确认），放对与放错的反馈差异要评；
3. `renderPreview` 目标预览图的呈现方式（预期是缩略平铺）缺「画框里的成品」仪式感；
4. 完成一关的庆祝画法自查；
5. `renderTop` 顶栏样式与三种玩法的切换视觉统一性自查，把全部结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **拼图齿边（核心）** | 拼块加经典凹凸齿：用 SVG `clip-path`（或 mask）给每块生成上下左右「凸耳 / 凹口」组合（按块在网格中的位置参数化，边缘块平边）；齿形半径 = 块宽 18%；块面加纸质渐变 + 1px 内亮边。**块的逻辑坐标与判定不动，纯裁剪层。** |
| **拾起与吸附** | 拾起：抬升 4px + 放大 1.04 + 影子扩大（80ms）；接近正确位时半透明虚影提示（读既有校验只做映射）；放对：吸附回弹（scale 1.04 → 0.98 → 1，150ms）+ 接缝白光一闪；放错：轻微摇头 ±3°（不批评，reduced 瞬回）。 |
| **旋转玩法专属** | `renderRotate` 的块加旋转把手视觉（角上小圆点）+ 旋转过渡 120ms 缓动；转对时四角星闪。 |
| **滑块玩法专属** | `renderSlide` 的空格画成凹槽（内阴影）；滑动加 90ms 位移过渡与轻微惯性拉伸（scaleX 1.03）；可滑的块加微光边提示（读既有可滑判断）。 |
| **画框与完成** | `renderPreview` 升级为木质画框小样（框纹 + 玻璃反光斜线）；完成时：全图接缝渐隐 → 成品点亮 → 画框装裱动画（框从四边合拢 300ms）+ 彩纸；画廊语义（第几幅作品）在结算里露出。 |
| **布局与 HUD** | 顶栏（玩法切换 / 步数 / 计时）卡片化；玩法切换用三枚图标签（齿块 / 旋转箭头 / 滑槽）。 |

- 色板走 `src/art/kit/palette.ts`；齿形生成器可**新增** `src/art/kit/jigsaw.ts`（输入行列与位置输出 clip-path 字符串）并配套单测。
- `prefers-reduced-motion`：抬升、回弹、摇头、装裱动画全停，保留静态齿边与层次。

### 四·补一：配色板与 DOM 层级（CSS 自定义属性统一管理）

| token | 色值 | 用途 |
| --- | --- | --- |
| `--pt-easel` | `#EFE4D4` | 画室背景底 |
| `--pt-frame` | `#C89B6C` | 木质画框（框纹 `shade(-20)`） |
| `--pt-piece-edge` | `rgba(255,255,255,.5)` | 拼块 1px 内亮边 |
| `--pt-ghost` | `rgba(244,133,159,.3)` | 接近正确位的半透明虚影 |
| `--pt-slot` | `inset 0 2px 4px rgba(0,0,0,.12)` | 滑块玩法凹槽内阴影 |
| `--pt-glow` | `rgba(255,214,120,.5)` | 可滑块微光边 |
| `--pt-seam` | `#FFFFFF` | 放对接缝白光 |

DOM 层级（z-index 从低到高）：① 画室底 → ② 底板网格 / 凹槽 → ③ 已放定拼块 → ④ 虚影提示 → ⑤ 拾起中的拼块（最高 + 影子）→ ⑥ 星闪 / 彩纸 → ⑦ 顶栏 → ⑧ 完成装裱浮层。

### 四·补二：齿形生成规格（`jigsaw.ts`）

1. 输入 `(rows, cols, r, c, size)`，输出该块的 `clip-path: path(...)` 字符串；
2. 每条内边的凸 / 凹由确定性哈希决定（同一关卡两次生成一致），相邻块自动互补；
3. 齿形半径 = 块宽 18%（块 < 40px 时降到 14%）；边缘块对外边为平边；
4. 齿颈宽 = 齿半径 55%，用三段贝塞尔画出「蘑菇头」标准齿；
5. 纸质渐变叠加：`linear-gradient(135°, 白 4%, 透明 60%)`，接缝处 1px 内亮边。

### 四·补三：动效时序表（CSS 动画时长写成自定义属性）

| 动效 | 触发 | 时长 | 缓动 | reduced 行为 |
| --- | --- | --- | --- | --- |
| 拾起抬升 | 拖起 | 4px + 1.04、80ms | ease-out | 只加描边 |
| 吸附回弹 | 放对 | 1.04→0.98→1、150ms | ease-out-back | 瞬间落定 |
| 接缝白光 | 放对 | 1 帧 | step | 保留（功能反馈） |
| 放错摇头 | 放错 | ±3°、240ms | ease-in-out | 瞬回 |
| 旋转过渡 | 旋转玩法 | 120ms | ease-out | 瞬转 |
| 滑动位移 | 滑块玩法 | 90ms + scaleX 1.03 | ease-out | 位移保留、拉伸关 |
| 装裱合拢 | 完成 | 300ms 四边合拢 | ease-in-out | 直接展示成品 |
