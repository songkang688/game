## 二、极高质量改进方案（可执行绘制规格）

### 1. 蛇 → 真正的糖果蟒

- **身体**：保留逐节 `arc` 骨架（性能与碰撞不变），每节叠三层——底层节色径向渐变（中心 +15% 亮、边 −10%）、中层沿蛇行进方向的背脊高光带（宽 0.5r 的浅色圆，偏移到行进法线上方）、`skins.ts` 花纹升级为「条纹/波点/渐变尾」三族（新增 skin 只加数据不改逻辑）。
- **节间填缝**：相邻节之间补画一个中点圆（半径取两节均值 × 0.9），消除高速转弯时的「断珠」感。
- **头**：椭圆头（沿 `r.angle` 拉伸 1.25 倍）替代正圆；眼睛保留现有双瞳逻辑但加眼白高光点；加两颗小圆鼻孔；boost 时眼睛眯成弧线 + 嘴角上扬；死亡帧 X 眼（0.4s，配合现有 `fade`）。
- **双人 A/B 区分**：P1 头戴红色蝴蝶结、P2 戴蓝色棒球帽（形状 + 颜色双通道，色弱可辨）；名字牌改白底胶囊。

### 2. 星光豆 → 会发光的星星

- 五角星主体（金黄渐变 `#FFE066 → #F5A623`）+ 外圈 2 倍半径的柔光晕（径向渐变到透明，`soft` 模式关闭光晕只留星形）+ 相位闪烁（用 `f.x*13+f.y*7` 哈希取相位，缓慢 alpha 0.75↔1）。
- 预渲染 2 种尺寸 offscreen sprite，主循环 `drawImage`；数百颗豆不许逐帧 `beginPath` 画星。

### 3. 掉落光点 → 糖果宝石

- 六边形宝石切面画法：顶面亮色 + 左右两侧面各降 12%/24% 亮度，中心十字高光；按 `o.value` 分三档尺寸+三种色（粉/青/金）。
- 落地后 0.5s 内从 1.4 倍缩到 1 倍（弹性缓动），提示「刚掉的」。

### 4. 围栏与缩圈 → 名副其实的发光

- 围栏：三层描边（8px 20% 透明外光 + 4px 主线 + 1px 内亮线），沿圆周每 30° 一颗小灯珠，靠近围栏 80px 内的蛇头触发红色警示脉动（仅视觉）。
- 缩圈：圈外盖 10% 青灰罩 + 圈线双层光带，同 orb-arena 规格，可与其共用 kit 函数。

### 5. 加速尾焰 → 拖尾粒子

- boost 时每帧在尾节后方生成 2 颗寿命 0.3s 的星屑粒子（缩小 + 淡出），上限 40 颗对象池；`soft` 模式沿用现有关闭分支。

### 6. 背景 → 糖果原野

- 三层：底层线性渐变（`#F4FBEF → #E6F5DC`）；中层网格降到 8% 透明；顶层稀疏装饰贴片（小花、三叶草、糖果石子，确定性哈希撒点，视差 0.85 跟随相机），让「原野」二字成立。
- 按关卡段换色：白天原野 → 黄昏 → 迷雾夜（fog 关卡自动用夜色调，配合现有 `cfg.fog`）。

### 7. 迷雾雷达 → 罗盘小地图

- 方块改圆形罗盘：外圈金属渐变环 + 内部深色底 + 扫描线旋转（`soft` 关）；自己的点保留 `#E0508C` 加白描边。

### 8. 结算

- 结算加名次奖杯 + 本局长度曲线；「拦截」模式显示拦截数徽章（盾形绘制）。

## 三、2D / 2.5D / 3D 决策
