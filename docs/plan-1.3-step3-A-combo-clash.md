## 二、极高质量改进方案（可执行绘制规格）

### 1. 格斗家 → 二头身 Q 版斗士（核心资产）

- **头身比 1:1（二头身）**：大头（半径 ≈ `halfWidth×1.1`）+ 短身；保持现有碰撞尺寸（视觉可以略溢出判定框，判定不变）。
- **分层绘制**（替换 `drawFighter` 内单矩形）：后臂 → 身体（渐变+描边，沿用 `ch.color/ch.ink`）→ 前臂 → 头（脸+发型/头饰按角色区分）→ 表情。
- **姿态帧**（按 `f.phase` / `f.stance` / `currentMove(f)` 切换，纯查表不改帧数逻辑）：
  - idle：身体上下 2px 呼吸浮动，双拳收于胸前；
  - walk：双腿交替摆（2 帧）；
  - 轻拳：前臂直线伸出（startup 收拳 → active 拳到 `mv.box` 中心 → recovery 收回）；
  - 重脚：抬腿踢出，身体后倾 8°；
  - crouch：屈膝压头，不再是压扁矩形；
  - hitstun：身体后仰 + 眼睛变 ><；knockdown：躺倒 + 头顶转圈星（画的星形，不是 ✦ 字符）；
  - 投技：抓住对方时双方画拉近拖拽 3 帧。
- **角色差异**：`frames.ts` 每个角色加 `look` 外观字段（发型/头饰/服装色二色），如 🌸 花花＝花瓣头饰粉裙、⭐ 星星＝星形头饰黄披风；头顶 emoji 移除，改为绘制的头饰（emoji 只留 HUD）。
- **双人 A/B**：P1 脚下红色光环、P2 蓝色光环 + HUD 侧名牌同色，形状（圆环 vs 方环）双通道区分。

### 2. 出招与受击特效

- 判定框白矩形改为「攻击弧光」：沿出招方向画月牙形渐变刀光（轻招小弧、重招大弧 + 残影 2 帧）；debug 显示判定框改为 `?debug` 才开。
- 命中：放射状 hit spark（6–8 根短线 + 中心闪白圆，0.15s）+ 命中停顿沿用引擎现有 hitstop（不改数值）；
- 破防（guardbreak）：盾碎片粒子（蓝色三角 6 片散开）；
- 连招计数 ≥ 3 时屏幕角落弹出连击数字（大号圆体数字 + 弹跳缓动）。

### 3. 背景 → 主题舞台

- 保留双层视差结构，把白半圆升级为主题剪影：
  - 舞台 1「樱花道场」：远层樱树剪影 + 花瓣飘落 ≤ 12 粒；
  - 舞台 2「星空擂台」：远层星山 + 流星偶发；
  - 舞台 3「糖果广场」：棒棒糖路灯剪影；
  - 按 `levels.ts` 现有分段查表选舞台（只换绘制，不动关卡数据）。
- 地面：平涂改为擂台木板条纹 + 中线标记 + 边缘绳索（顶部两根水平线+立柱）。

### 4. HUD 强化

- 血条端头加角色小头像（Canvas 画 24px 头，复用角色头部函数）；
- 回合胜利星（现 ♥ 文字改为画的星星徽章）；
- 「能量满」时 meter 条流光动画（CSS gradient animation，`prefers-reduced-motion` 关）。

### 5. 结算

- KO 瞬间：0.3s 缩放震屏（`soft` 关）+ 胜者做胜利姿势帧（举手）+ 彩带粒子 20 片；
- 结算面板显示本局最大连击、使用招式统计。

## 三、2D / 2.5D / 3D 决策

**2D 横版 + 强化视差**。格斗判定是严格 1D 距离（`distance.ts`），透视会破坏距离可读性；用三层视差（远景/中景/擂台）+ 地面影子做深度感即可。禁止 three.js。
