## 三、现状审美评测（先开代码再动笔）

打开 `src/games/music-stars/index.ts`、`ui.ts`、`advanced.ts`、`sandboxUi.ts`，渲染入口是 `renderDots`（两处）/ `renderScore` / `paintScore` / `renderIntervalChoices` / `renderClips`。已核实与预期的问题：

1. `renderDots` 的音符点预期是纯色 DOM 圆点（自查确认）——「音乐星星」的音符不是星星，也没有发光、没有节奏脉动；
2. 键盘 / 打击垫预期是纯色块按钮（自查确认）：按下无按键下沉、无发声光效——音乐游戏的「按下去有回响」的感觉没有；
3. `renderScore` / `paintScore` 乐谱区预期是简单线格：五线谱有没有画、谱号有没有、音符在谱上的位置可视化程度自查；
4. `renderIntervalChoices` 音程选项预期是文本按钮；
5. `renderClips` 沙盒录音片段列表预期是裸列表，把全部结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **音符星星化（核心）** | 音符点升级为发光五角星：星形 SVG + 径向光晕（音高越高星越亮、色相沿音阶渐变——do 红到 si 紫的彩虹音阶助记，**音高数据不动**只做映射）；当前拍的星星脉动放大 1.15（随节拍，读既有节拍时钟，reduced 常亮）。 |
| **星空五线谱** | 乐谱区改夜空舞台：深蓝渐变底 + 五线谱线画成星轨细线（微微发光）+ 谱号用星座连线风格描绘；音符星星落在正确线间位置（**位置由既有音高数据决定**）。 |
| **键盘果冻化** | 键 / 打击垫改果冻质感（渐变 + 高光 + 2px 描边）；按下：下沉 3px + 键顶发光 + 从键上升起一颗小音符星（400ms 渐隐，reduced 只发光）；每个键的颜色与音阶彩虹一致（颜色 + 位置双通道）。 |
| **节奏可视化** | 击中节拍：星星炸成音波环两圈（同心圆扩散 240ms）；连击时背景星空渐亮 + 流星一条（reduced 关）；miss 时星星轻轻眨眼（不批评）。 |
| **音程选项与录音片段** | `renderIntervalChoices` 选项做成琴键小卡（含音程名 + 上下两星示意距离）；`renderClips` 片段做成音符胶带条（波形微缩示意 + 播放按钮圆钮）。 |
| **布局与结算** | 分数 / 连击卡片化；结算时整片星空点亮 + 星座连线把本局击中的音符连成一笔画（纯装饰）。 |

- 色板走 `src/art/kit/palette.ts`；星形与光晕可复用 `star.ts`（若 prince-princess 档已落）或自建。
- `prefers-reduced-motion`：脉动、音波环、流星、星座连线动画全停，保留静态发光与彩虹映射。

### 4.1 配色板与图层序

| token | 色值 | 用途 |
| --- | --- | --- |
| `nightTop` / `nightBottom` | `#1d2b53` / `#3a4a7d` | 夜空舞台纵向渐变 |
| `staffGlow` | `rgba(180,200,255,.55)` | 五线谱星轨线（1px + 微光晕） |
| `noteDo` → `noteSi` | `#ff6b6b / #ff9f43 / #ffd93d / #7bc86c / #2ec4b6 / #5b9bff / #9b6dd6` | 彩虹音阶七色（do→si 色相单调） |
| `starGlowInner` | `rgba(255,255,255,.9)` | 星心高亮 |
| `keyJelly` | 各音色 +`rgba(255,255,255,.35)` 顶光 | 果冻键渐变 |
| `waveRing` | `rgba(255,255,255,.5)` | 命中音波环 |
| `meteorTail` | `rgba(255,246,214,.7)` | 连击流星尾迹 |

图层序（DOM/SVG 从底到顶）：夜空渐变 + 背景细星 → 五线谱星轨 + 谱号星座线 → 音符星星层（谱面位置由音高数据决定）→ 音波环 / 流星层 → 键盘 / 打击垫（**热区零改动**）→ 键上升起的小音符星层 → 分数连击卡片 → 结算星座连线层。特效层 `pointer-events:none`。

### 4.2 发光星与果冻键工序单

1. 五角星（glowStar.ts）：`star(size, color)` 十点多边形（外 r、内 r=0.42×外 r），圆角尖（`stroke-linejoin:round`）；
2. 光晕：星底垫径向渐变圆（直径 2.2× 星宽，中心色 = 音色 45% 透明度 → 边缘 0）；星心叠 `starGlowInner` 小圆；
3. 音高映射：do→si 依 `noteDo…noteSi` 七色，同音名不同八度用亮度 ±12% 区分（**音高数据只读**）；
4. 果冻键：圆角矩形（音色渐变，顶部 35% 叠白色顶光弧）+ 2px 深色描边 + 底部 2px 暗边；按下整键 `translateY(3px)` + 顶光收窄；
5. 音波环：命中点两个同心圆 1 → 1.8 倍扩散、透明度 0.5 → 0 交错 80ms；
6. 音程选项卡：迷你琴键底 + 上下两颗小星按音程距离摆位（距离示意由题目数据映射，乐理不动）。

### 4.3 动效时序表

| 触发 | 动画 | 时长/缓动 | reduced 行为 |
| --- | --- | --- | --- |
| 当前拍 | 星星脉动放大 1.15（随既有节拍时钟） | 与节拍同步 / ease-in-out | 常亮加描边 |
| 按键按下 | 下沉 3px + 键顶发光 + 小音符星升起渐隐 | 400ms / ease-out | 只发光 |
| 命中节拍 | 音波环两圈扩散 | 240ms / ease-out | 无环，星星定格高亮 |
| 连击 | 背景星空渐亮 + 流星一条 | 800ms 一次性 | 关 |
| miss | 星星眨眼（缩 0.9 回弹） | 260ms / ease-out | 静止 |
| 结算 | 星座连线逐段点亮把命中音符连成一笔画 | 1.2s / ease-in-out | 一次性全亮 |
