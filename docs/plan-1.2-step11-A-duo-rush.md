## 四、1.2 要加的深度

## 六、2.5D / 3D 决策

**继续 2.5D，不做真 3D。** 分屏 × 透视已经是性能上限，真 3D 会让低端安卓掉帧。掉帧时按已有画质档位减视差层与粒子。

## 七、视觉 · 建模 · 手感

- 两块分屏之间要有清晰分隔（粉彩描边），谁是朵朵谁是星星一眼可辨（角色色 + 名字贴顶）。
- 换道 80–120ms 横向插值 + 轻侧倾；撞击是「转圈打晃」不是受伤。
- 领先 / 落后要有明确反馈：领先者头顶小皇冠，落后者不许出现羞辱式文案。
- `prefers-reduced-motion`：关侧倾与抖动，保留位移。

## 八、手机 360px

- 上下分屏时每块至少 45% 高度，HUD 压成一行；触屏控件左右各半屏，热区 ≥ 44px 且不重叠。
- 两人同屏时任何一侧的弹窗都不许盖住另一侧画面。

## 九、平台接线

- 没有战役，就把 `initialLevel` / `?level=N` 映射到「赛道难度档 + 人机档」，映射表写注释与测试。
- `meta.platform` 按实测填（双人键盘偏桌面，触屏双人也能玩 → 多半是 `"both"`）；`blurb` 与事实对齐。
- 无尽成绩统一 `save.recordEndlessBest`；旧 key 若存在读一次迁移，不许清零纪录。
