## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **差异生成校验器（硬性）** | 写一个 `validateScene()` 纯函数并在测试里跑遍 **188 关全量**：每关断言 ①差异点数量 = 声明数量 ②每个差异点在可视区内 ③任意两个差异点的格距 ≥ 1 ④答案唯一（不存在「未被标记但实际也不同」的格）⑤镜像/旋转关的坐标换算可逆。**有一关不过就是 bug，必须修数据不是改断言。** |
| **点击容差与命中** | 命中判定按格中心半径取 `max(格宽 * 0.55, 22px)`；相邻两个差异点同时命中时取距离更近的那个。写单测。 |
| **温和惩罚** | 点错不扣分不扣时，改成「短暂冷却 0.6 秒 + 涟漪提示」，连点乱扫（1 秒内 ≥ 5 次错点）冷却翻倍到 1.2 秒。**不许出现「点错就失败」。** |
| **放大镜 / 双指缩放** | 大棋盘章节支持双指缩放（1×–2.5×）与拖动平移，两图**联动缩放**（上图放大下图同步放大，不然没法比）。桌面端提供滑块或滚轮。 |
| **提示经济** | 提示先「圈出一个大致区域（3×3 格）」，再点一次才精确指出；每关提示次数有限（章节越后越少），用完不阻塞过关。 |
| **差异类型补齐** | 换 emoji / 挪位置 / 变大小 / 变朝向（左右翻）/ 加减一个 / 变底色。后段章节混合多种类型，写单测断言每章的类型分布。 |
| **进度可视** | 已找到的差异点在两图上都打圈并计数「3/5」；未找到的绝不提前显形。 |

## 七、视觉 · 建模 · 手感

- 两图之间有清晰分隔线；找到的差异点画彩色圆圈 + 一次 `api.play("win")` 轻音。
- 找齐全部：两图之间放彩纸；**不做倒计时红屏、不做刺耳音效**。
- 双胞胎替换（`LOOKALIKE`）在小屏上必须仍可辨，字号 ≥ 22px。
- `prefers-reduced-motion`：关涟漪与彩纸，圆圈直接出现。

- 计数与提示按钮一行放得下，字号 ≥ 14px。
