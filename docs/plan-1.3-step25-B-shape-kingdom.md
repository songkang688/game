## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **宝石形状块（核心）** | 四色平涂升级为宝石质感：每块加同色系三停渐变（左上受光）+ 中央切面高光三角 + 1.5px 深色描边 + 底部 2px 暗边（2.5D 厚度）；**形状轮廓与比例一个点不动**（教育语义），只加表面质感。 |
| **城堡地基语义** | 目标区 `shk-cell-target` 升级为「城堡地基」：虚线轮廓 + 石纹底 + 四角小旗；拼放进度越高，目标区外圈的城堡剪影（塔楼 + 城墙，SVG 背景层）逐段点亮——「形状拼好 = 王国建成」的叙事成立。 |
| **拾起与吸附** | 从 `paintRack` 拾起：抬升 4px + 放大 1.05 + 影子；接近正确格显示半透明预放虚影（读既有校验只做映射）；放对：吸附落定 + 四角星闪 + 「咔」的视觉顿帧；放错：轻弹回 + 摇头 ±3°（不批评，reduced 瞬回）。 |
| **完成仪式** | 一关拼满：城堡剪影全亮 + 升旗动画（旗子沿旗杆升起 400ms）+ 彩纸 + `drawStars` 的星星逐颗弹入（reduced 同时亮）。 |
| **形状架与顶栏** | `paintRack` 待选块下加木架横条与投影；`paintHeader` / `paintReadout` 卡片化（关卡 / 剩余块 / 目标）；`drawMetrics` 保持数据语义只换卡片壳。 |
| **场景氛围** | 背景淡色天空 + 远山 + 两朵云（缓移，reduced 静止）；棋盘外框画成城墙垛口边框。 |

- 色板走 `src/art/kit/palette.ts`；星闪走 `sparkle.ts` 等价；宝石渐变可复用 `volume.ts`。
- `prefers-reduced-motion`：吸附动画、升旗、云移全停，保留静态质感与点亮结果。

图层序（DOM 从底到顶）：天空 + 远山 + 云 → 城堡剪影背景层（分段点亮）→ 城墙垛口棋盘外框 → 棋盘格（地基石纹 + 目标虚线）→ 已放置宝石块 → 拾起态浮层（抬升块 + 影子 + 预放虚影）→ 星闪 / 彩纸层 → 顶栏与形状架。浮层与粒子层 `pointer-events:none`。

### 4.2 宝石块工序单

1. 表面：形状原轮廓内填三停线性渐变（135°，受光在左上），**轮廓路径与比例零改动**；
2. 切面高光：中央偏左上放小三角高光（白 35% 透明度，尺寸 = 块宽 22%）；
3. 描边：1.5px 同色系最深色；底部再叠 2px 暗边条（只在下边缘，2.5D 厚度）；
4. 拾起态：整块 `translateY(-4px) scale(1.05)` + 底部椭圆影（`rgba(0,0,0,.15)`）；
5. 预放虚影：目标格上画该形状 40% 透明度同色填充 + 虚线描边（读既有校验结果做映射）；
6. 小格降级：格宽 < 32px 时省略切面三角，保留渐变 + 描边（360px 规则）。

### 4.3 动效时序表

| 触发 | 动画 | 时长/缓动 | reduced 行为 |
| --- | --- | --- | --- |
| 拾起 | 抬升 + 放大 + 影子展开 | 140ms / ease-out | 保留（功能反馈） |
| 放对 | 吸附落定 + 顿帧一格 + 四角星闪 | 220ms / cubic-bezier(.34,1.56,.64,1) | 瞬落 + 静态星点 |
| 放错 | 轻弹回 + 摇头 ±3° | 320ms / ease-out | 瞬回 |
| 进度更新 | 城堡剪影逐段点亮（描金过渡） | 400ms / ease-in-out | 瞬时点亮 |
| 一关拼满 | 升旗 400ms + 彩纸 20 粒 + 星星逐颗弹入 | 1s 序列 | 旗到顶 + 星同时亮 |
| 待机 | 两朵云缓移 | 12s / linear 循环 | 静止 |
