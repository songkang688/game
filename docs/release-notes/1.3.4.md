### 🔒 存档保险箱:卸载重装,进度也不丢

以前星星和关卡进度只存在应用自己的数据里,**卸载软件时会被系统一起删掉**,重装回来就是一片空白。这一版起,进度会自动**多存一份到应用外面的文件里**,重装后打开就自动接回来。

| 你的设备 | 存到哪儿 | 重装以后 |
| ---- | ---- | ---- |
| Windows / Mac 安装包 | 系统「文档 / 一朵一星存档」 | **全自动**,卸载不会删文档目录 |
| 电脑浏览器(Chrome、Edge) | 家长自己选的文件夹 | 重新选一次同一个文件夹就接回来 |
| 安卓 APK(Android 10 及以下) | 手机公共「文档」目录 | **全自动** |
| Android 11 及以上 / 手机浏览器 | 系统不允许应用直接写公共目录 | 用家长面板「导出进度」存一个文件,重装后「选择备份文件」导入 |

几件让人放心的事:

- **不会误覆盖**:只有本地确实是空的(新装、卸载重装、刚清空)才自动恢复。已经在玩的进度绝不会被自动盖掉,要覆盖得家长在面板里点两次确认。
- **仍然不联网**:全程只碰你自己设备上的文件,没有账号、没有云端、不上传任何数据。
- **不耽误孩子**:开机最多等 1.5 秒,读得慢就先进游戏。

### 📄 家长面板更好用了

- 新增「卸载也不丢」一段:能看到进度当前存在哪儿,可以立即备份一次,也能从备份恢复。
- 导入进度多了「选择备份文件」:手机上不用再手抄一长串备份文本了。
