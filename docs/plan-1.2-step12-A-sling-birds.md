## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **弹道预测** | 拉弓时给 8–12 个衰减小点的抛物线预测（前 60% 精确、后 40% 淡出），**不要给完整落点圈**——留出学习空间。 |
| **材质与结构** | 木 / 冰 / 石三种材质各有硬度、碎裂动画与音效；连锁倒塌要有传递（上面的塌下来砸到下面的）。 |
| **鸟的能力** | 至少 3 种能力鸟，空中点按触发；触发窗口写成常量并单测。 |
| **无尽「打靶塔」** | **补做**：随机生成越来越高的塔，弹数固定，塔倒得越多分越高，`save.recordEndlessBest("sling-birds", n)`。 |
| **关卡可解性** | 用模拟测试证明每一关**存在一条能通关的弹道**（可用现有 sim 工具或新写一个），后段关卡尤其要验。 |

## 六、2.5D / 3D 决策

**保持 2D 侧视**。弹道是这个玩法的核心可读性，透视会让孩子瞄不准。允许远景视差与云层。

## 七、视觉 · 建模 · 手感

- 拉弓橡皮筋要有张力形变；释放有轻微镜头拉伸与 `api.play("pop")`。
- 碎裂用小方块粒子（数量按画质自适应），`prefers-reduced-motion` 下减少粒子但保留结果。
- 命中反馈：结构变形 → 倒塌 → 结算，三段之间不许瞬变。
- 小鸟与绿绿豆都是本作原创角色，**禁止任何同类商业作品的角色形象、配色与命名**。

## 八、手机 360px

- 竖屏时画布必须撑满舞台（1.1 已修，不要回退）；拉弓热区在左下但**手指不许挡住弹弓**，用「拖动锚点偏移」解决。
- 关卡目标与剩余鸟数一行显示，字号 ≥ 14px，热区 ≥ 44px。
