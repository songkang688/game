## 三、现状审美评测（先开代码再动笔）

打开 `src/games/prince-princess/index.ts`，绘制入口是 `render` / `drawHero` / `drawParallax` / `drawPushCrate` / `drawStandSlab` / `drawHazardSpikes` / `drawHazardMark` / `drawRewardGem` / `drawCheckpointFlag` / `drawExitArch`。已核实的问题：

1. `drawHero`（约 834 行起）已经在剪影上做了区分（王子 = 圆角矩形上衣、公主 = 梯形裙，860–871 行）——方向对，但精度太低：服装就是**一块纯色几何**，无衣褶、无花纹、无渐变；「王子公主」的贵气一分没有；
2. 皇冠是一条 5 点折线（886–893 行）、公主头饰是**一个圆**（894 行）——皇冠没有宝石镶嵌，头饰连蝴蝶结都算不上；
3. 剑 = 两个 `roundRect` 拼的（915–920 行），魔杖 = 一条线 + 挥动时贴一个 ⭐ emoji（926–933 行）——武器是全款最敷衍的部件；
4. 披风 / 裙摆（850–856 行）只有一层 `cloakDark` 纯色，没有内外双层、没有飘动；
5. 脸部（眼睛 + 腮红笑弧）底子可以，保住；`drawParallax` 远景、`drawPushCrate` 箱子、`drawHazardSpikes` 尖刺、`drawRewardGem` 宝石、`drawExitArch` 出口拱门逐个自查，把结论记进开工 commit。
