## 三、现状审美评测（先开代码再动笔）

打开 `src/games/prince-princess/index.ts`，绘制入口是 `render` / `drawHero` / `drawParallax` / `drawPushCrate` / `drawStandSlab` / `drawHazardSpikes` / `drawHazardMark` / `drawRewardGem` / `drawCheckpointFlag` / `drawExitArch`。已核实的问题：

1. `drawHero`（约 834 行起）已经在剪影上做了区分（王子 = 圆角矩形上衣、公主 = 梯形裙，860–871 行）——方向对，但精度太低：服装就是**一块纯色几何**，无衣褶、无花纹、无渐变；「王子公主」的贵气一分没有；
2. 皇冠是一条 5 点折线（886–893 行）、公主头饰是**一个圆**（894 行）——皇冠没有宝石镶嵌，头饰连蝴蝶结都算不上；
3. 剑 = 两个 `roundRect` 拼的（915–920 行），魔杖 = 一条线 + 挥动时贴一个 ⭐ emoji（926–933 行）——武器是全款最敷衍的部件；
4. 披风 / 裙摆（850–856 行）只有一层 `cloakDark` 纯色，没有内外双层、没有飘动；
5. 脸部（眼睛 + 腮红笑弧）底子可以，保住；`drawParallax` 远景、`drawPushCrate` 箱子、`drawHazardSpikes` 尖刺、`drawRewardGem` 宝石、`drawExitArch` 出口拱门逐个自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **王子重绘** | 上衣加立领 + 双排金扣（4 点）+ 肩章两枚 + 腰带扣；披风双层（外层主色渐变 + 内层衬色）随移动速度摆动 2 帧；皇冠改 3 齿实心 + 齿尖圆珠 + 正中红宝石（椭圆 + 高光点）；发型画出刘海分缝。 |
| **公主重绘** | 裙摆双层（外裙渐变 + 内衬波浪下摆）+ 裙面三点小星纹；头饰改成蝴蝶结 + 小皇冠组合（区别于王子的大皇冠）；加披肩短纱（半透明白 30%）；发型画出长发侧束 + 发梢卷。 |
| **可区分性验证** | 16px 灰度自测：大皇冠 vs 蝶结小冠、裤装 vs 裙装、剑 vs 杖三通道可分辨，结论写进回复。 |
| **武器精修** | 剑：剑刃两段渐变（脊线高光）+ 护手弧 + 柄尾圆珠，挥动时刃口白光扫过一帧；魔杖：杖头**自绘五角星**（替换 ⭐ emoji）+ 星心渐变 + 挥动时星尘轨迹 5 颗（`sparkle.ts`）。 |
| **场景升级** | `drawParallax` 升级为城堡远景（塔楼剪影两层 + 旗帜）+ 中景灌木；尖刺 `drawHazardSpikes` 改成圆头软刺 + 警示条纹底座（危险语义靠 `drawHazardMark` 保住）；宝石切面化 + 呼吸微光；箱子木纹 + 角铁；出口拱门加花藤缠绕与门内暖光渐变；存档旗 `drawCheckpointFlag` 加飘动 2 帧。 |
| **布局与结算** | 双人头像徽章 + 宝石计数卡片化；通关时两人对视击掌 + 彩纸（reduced 静止）。 |

- 渐变 / 描边 / 落影统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：披风摆动、星尘、微光、旗帜全停，保留静态渐变与层次。
