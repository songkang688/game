## 六、2.5D / 3D 决策

**保持 2D**。立体棋子会挡住后面的子和九宫线。允许木纹棋盘 + 棋子极轻的投影。

## 七、视觉 · 建模 · 动效（硬性）

- 棋子：楷体字 + 圆底，红黑对比度 ≥ 4.5:1（红别用浅粉字）。
- **将军**：飞出「将！」徽章 400ms + 被将一方帅 / 将脉冲描边；应将成功后描边消失。
- **将死**：棋盘轻微变暗 + 鼓励文案；困毙单独一句提示，别让孩子以为是 bug。
- 选中棋子后合法落点用小圆点标出；不合法走子要给一句话解释（「马腿被别住啦」「将帅不能照面哦」）。
- `prefers-reduced-motion`：徽章静帧、不脉冲。

## 八、手机 360px

- 棋盘正方形自适应，交叉点热区 ≥ 44px（用不可见 hit slop）。
- **落子确认默认开**：点子 → 高亮 → 点落点 → 半透明预览 → 再点确认。双人同屏两边都要确认。
- 记谱条可横滑，不许把棋盘挤窄。
