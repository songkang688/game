## 99 → 188 硬规则

1. 前 99 关一个字不动：章节切分、每关生成参数、seed、难度曲线保持 1.0 原样，新内容只在末尾追加。
   开工前先把四个游戏前 99 关的生成结果做了 FNV 摘要，写进回归测试当"指纹"，任何改动都会被测出来。
2. 每款游戏追加 89 关，拆成 ≥3 个全新主题章节（原创中文名 + emoji + 粉彩色 + 一句话介绍），
   并引入 ≥2 个前 99 关没有的新机制（不是把数值调大）。
3. `totalSize(CHAPTERS) === 188` 有断言；1.0 的前 99 关章节切分（17/17/17/16/16/16）硬编码进测试做回归。
4. 第 100–188 关逐关做可通关 / 可解性校验。
5. 新关面向约小学六年级：多步推理、限时、组合机制；失败文案永远只鼓励不批评。
6. 存档 key 不动（`yiduo-yixing.l99.<id>`），老的长度 99 存档由框架补 0。
