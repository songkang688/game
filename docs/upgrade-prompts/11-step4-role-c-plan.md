## 边界

本步**只改战役关卡表与主题**。2.5D 伪三维、跳跃/左右/下滑手感重做、无限模式
程序化拼接、宠物 / 人物 / 装备，全部属于第 6 步角色 A 的活，这一步不动。
渲染层只做「让新章节的新机制画得出来、玩得到」这一点必要的加法，
既有的三车道俯视画法、滑动操作、无尽模式入口一律保持原样。

## 目标拆解

1. **关卡表 99 → 188**（前 99 关一字不动，只在末尾追加）
   - 章节长度表 `THEME_SIZES = [11×9, 30, 30, 29]`，合计 188。
   - 三个新世界：霓虹地铁站（100–129）、云上索道（130–159）、星屑隧道（160–188）。
   - 章节下标 / 偏移 / 归属全部改成按长度表查，`LEVELS_PER_THEME` 只保留给经典九章。

2. **新机制（要求 ≥2，实做 4）**
   - **可破坏障碍**：彩纸箱。下滑铲过去能撞碎并计数，起跳能越过，平跑会撞。
     这是第一种「两种动作都有解」的障碍。
   - **加速滑轨**：踩上去获得一段限时加速，跑得更快但反应窗口更短。
   - **节奏段**：连续三次「完美跳」（起跳后极短时间内蹭过障碍）算完成一组，
     成组给奖励；新任务类型「完成 N 组三连完美跳」。
   - **随机分岔路线**：赛道中途出现岔路牌，站在左道走左边、右道走右边，
     两条岔路是不同的障碍花样序列。

3. **新 Boss（要求 ≥1，实做 3，每章一个）**
   - 霓虹地铁站 · 霓虹车长；云上索道 · 索道风王；星屑隧道 · 星屑之主。
   - Boss 关有独立胜负：砸碎彩纸箱、打出三连完美跳都能给 Boss 掉血，
     跑到终点时血没打完就算输——所以 Boss 关既能打赢也能打输。

4. **共享模拟工具** `src/games/__tests__/campaignSim.ts`（新文件，只有 C 能建）
   - 与游戏无关的「固定策略跑完整战役」框架：确定性随机源、批量跑关、
     多随机种子重跑、失败清单汇总。
   - 本步先给 `rainbow-run` 接上（`src/games/rainbow-run/sim.ts` 提供无头跑图循环）；
     A/B 在下一步之后复用。
