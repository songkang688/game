## 一句话产品定位

横版跳跃 + 清洁大作战。主角是披着披风的「噗噗超人」，把捣蛋的「臭臭怪」轻轻一踩就变成小花肥料，
让香香街到云端净化厂的每一段路重新香喷喷。全程干净、可爱、粉彩，不做任何生理细节。

## 三种模式

1. **闯关**：走 `src/games/level99.ts` 通用框架，188 关 / 8 章，存档 key 用框架默认的
   `yiduo-yixing.l99.poop-hero`，不动平台任何已有约定。
2. **无尽**：清洁马拉松。街区无限延伸，身后有越追越快的「臭味潮」，3 颗心用完结算，
   成绩走平台 `save.recordEndlessBest`。
3. **双人合作**：两人同屏共用心数与倒计时，把整段街清到 100% 再一起站到净化门前才算赢。

## 键位（双人）

- 朵朵：`W A S D` 移动 / 蹲，`F` 冲刺清扫，`G` 扫一扫
- 星星：`↑ ← ↓ →` 移动 / 蹲，`L` 冲刺清扫，`K` 扫一扫
- `Esc` 暂停；手机 / 平板给两侧独立的虚拟摇杆 + 两颗动作键，375×667 可玩

## 三星标准

清洁度 100%、用时不超过本关标准时间、香香星收够，三条各算一颗；达成 3 条 3 星，2 条 2 星，其余 1 星。

## 验收

- `npm test` 只增不减、新增用例 ≥ 15（实际按 40+ 写）；`npm run build` 全绿。
- 机器人在测试里把多关实打实打到「胜」，不是只检查数据结构。
- 手动冒烟：mount → 玩到真实胜负 → destroy → 再 mount 不报错；375×667 与 1280×800 都能玩。
- 通读全部可见文案做「不恶心」自审：只出现干净、可爱、粉彩的表达，不写任何生理细节。
