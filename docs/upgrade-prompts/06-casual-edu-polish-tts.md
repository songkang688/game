# 第 6 步：休闲对战学习 22 款文案适龄打磨 + 学习类语音朗读

## 具体要做

1. **语音朗读（重点）**：
   - 在 `quiz99.ts` 加一个可复用的朗读模块：用浏览器内置 `speechSynthesis`（`zh-CN` voice，rate ≈0.85 放慢），**零新依赖、离线可用（系统自带语音包）、不可用时静默降级**（按钮隐藏）。
   - 题目切换时自动朗读 `ask` 引导语；题干旁加「🔈 再听一遍」大按钮；答对/答错的鼓励语也朗读。
   - 学习 6 款逐一接入并核对 `ask` 文案是口语化短句（≤15 字，如「哪个是小猫的猫？」）。
   - 注意 destroy 时 `speechSynthesis.cancel()`，切题/退出不叠音。
2. **文案适龄走查**：22 款的标题、blurb、地图提示、章节描述、结算语逐条过一遍：不认识的字多的句子换口语短句；语气全部是鼓励式；对战 3 款的「胜负」文案对输家也要温柔（「红队赢啦！蓝队也好棒！」）。
3. **关卡重复感抽验**：22 款各抽第 1、25、50、75、99 关共 110 关。重点看：中后期是否只有数值变化没有新元素；同款相邻关是否明显雷同。发现「从第 N 关起到 99 关体验完全一致」的游戏，允许做**轻量节奏调剂**：在既有参数空间内让章节切换处有感知变化（新颜色主题已有；可调网格尺寸、目标类型组合等既有参数），禁止新增玩法系统、禁止改关卡总数与存档 key。
4. **学习类正确性抽查**：算数小农场的算式答案、识字小花园的字词配对、拼音小火车的拼音、时钟小屋的时刻、形状王国的图形判定——每款抽 20 题机器校验（写成测试），杜绝错题。
5. **失败与鼓励回归**：确认 22 款失败路径全部走 `level99.ts` 的温柔结算 +「再试本关」；`quiz99.ts` 答错只鼓励（现状已达标，回归确认即可）。
