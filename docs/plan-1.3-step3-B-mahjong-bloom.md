打分制：草稿 / 能认 / 可爱 / 精美。

| 对象 | 现状代码 | 评分 | 问题点名 |
|---|---|---|---|
| 牌面（核心资产） | `tileEl()` 第 196–219 行：纯 DOM 两行文字——`tileFace()`（tiles.ts 105–111 行）返回「数字+花色字」，如 `3` + `筒` | **能认** | 麻将牌没有麻将图案：**筒子没有圆饼、条子没有竹节、万字没有书法感**，全部退化成印刷体文字；字牌（东南西北中发白）无红中绿发的传统配色 |

| 牌背 | `backsEl()` 第 222–231 行 + CSS `.mj-back`（83 行）：10×20px 紫色小长条 | **草稿** | 对家手牌是一排紫色小药片，完全没有「麻将牌背」感 |

## 二、极高质量改进方案（可执行绘制规格）

### 1. 牌面 → 真正的麻将图案（核心工程）

在 `tileEl` 内为数牌插入一块小 Canvas 或内联 SVG（推荐 SVG，DOM 复用现有结构），按花色绘制传统图案：

- **筒子（o）**：同心圆饼。1筒 = 一个大饼（外环深青、内环白、中心红点花芯）；2–9 筒按传统排布（2 纵列、3 斜线、4 四角、5 四角+中、9 三行三列），饼 = 外圈色环 + 内圈浅色 + 中心点三层；
- **条子（t）**：竹节。1条按传统画一只小鸟（简笔孔雀：绿身红尾圆头，8×12 路径即可）；2–9 条画竹节棒（圆角矩形 + 两道竹节线 + 顶端叶芽），绿色为主、5条中间一根红色；
- **万字（w）**：保留汉字但升级排版——上方红色数字汉字（一~九，楷感用 `font-weight:900` + 文字描边），下方黑色「万」字；
- **字牌（z）**：东南西北黑字、**中=红色、发=绿色、白=蓝色空框**（传统白板画双线框）；
- **花牌（f）**：真的画花——梅兰竹菊四瓣小花图标 + 角标字。
- 图案规格统一：viewBox 28×38，线宽 2，配色从传统三色（青 `#1B7A65` / 红 `#C43B3B` / 蓝黑 `#2B3A55`）取，圆角收笔。
- `tileFace` 的文字保留为 `aria-label` 与超小屏退化方案（<340px 时只显示文字层）。

### 2. 牌体 → 象牙白立体牌

- `.mj-tile` 增加三层结构：顶面（象牙白渐变 `#FFFEF9 → #F4EDDD`）+ 右/下侧墙 2px（米黄 `#D8CBAE`）+ 底座绿（传统牌背绿 `#2E8B6A` 露出 2px），厚度感从「一块贴纸」变成「一块牌」；
- 选中（`mj-cur`）：上浮 4px + 底部阴影拉长；可胡/可吃碰杠（`mj-hot`）：金色描边呼吸（`prefers-reduced-motion` 时改为静态金边）。

### 3. 牌背 → 花纹牌背

- `.mj-back` 从紫色小药片改为：绿色渐变底 + 中心一朵四瓣小花压纹（SVG 重复背景），比例改为真实牌背 3:4，宽 ≥ 14px；对家手牌排成一行微弧（每张 rotate 差 1.5°）。

### 4. 牌桌 → 毛毡与木框

- `board` 区加牌桌质感：深绿毛毡径向渐变（中心亮边缘暗）+ 外圈 8px 木纹边框（两色条纹渐变模拟）；牌河区改为毛毡上的浅色投影区；
- 全局背景保留粉白渐变，但加入 4–6 朵超淡樱花装饰角贴（CSS 伪元素）。

### 5. 动画与结算 → 名副其实的「开花」

- 打牌：`mj-fly` 升级为两段——手牌上抬 60ms → 弧线飞到牌河落位（scale 1.1→1，带 2° 旋转落定）；
- 摸牌：从右侧滑入 + 轻微弹跳；
- **胡牌开花**：`showFanSheet` 弹层前，牌面区播放 0.8s 樱花绽放动画（中心开一朵 5 瓣花 + 12 片花瓣飘落，CSS keyframes，`soft` 时只闪金光一次）；番种列表逐条弹入（已有 `popFans`，加花瓣图标前缀）；
- 流局：牌河整体灰化 + 一片落叶。

### 6. HUD

- 圈风/位风徽章改成罗盘小圆盘（东南西北方位点亮）；「N 番起和」徽章加火焰/花苞等级色。

## 三、2D / 2.5D / 3D 决策
