## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **手感常量化** | 移动 / 跳跃 / 清扫范围 / 冷却全部抽常量 + 单测；帧率无关（30/60fps 位移差 < 2%）。 |
| **分类玩法** | 补「垃圾分类」机制：可回收 / 厨余 / 其他三色桶，投对给额外星星、投错只温和提示（不扣分）。分类表写成数据 + 用例，内容要真实正确（这是给孩子的常识）。 |
| **关卡类型** | 补 3 种：限时清扫、护送清洁车、暴雨天（地滑，移动惯性变大）。 |
| **合作深化** | `coop` 两人分工（一人扫、一人运），有共同目标条；必须两人配合才能拿三星。 |
| **无尽「打扫不完的城市」** | 区块随机拼接，脏乱度随时间上升；坚持到脏乱度满结束；成绩 `save.recordEndlessBest("poop-hero", blocks)`。 |

## 七、视觉 · 建模 · 手感

- 清扫有扫帚弧线拖尾 + `api.play("pop")`；清干净的地面变亮。
- 「便便豆豆」造型统一：圆润、有笑脸、粉彩色，**不用棕色写实**。
- 结算文案正向（「城市干干净净，大家都笑啦！」）。
- `prefers-reduced-motion`：关抖动与拖尾。

## 八、手机 360px

- 摇杆 + 清扫钮不重叠，热区 ≥ 44px；分类桶提示图标 ≥ 32px。
- 目标 / 计时一行显示，字号 ≥ 14px。
