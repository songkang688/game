## 四、这不是什么（别和已有 55 款撞玩法）

- **不是** `ocean-munch`「海底大胃王」：那是侧视横版大鱼吃小鱼闯关，没有分身、刺球、孢子、封闭大地图、实时排行榜。
- **不是** `bubble-pop` / `balloon-pop` 那种点一下就消的休闲。
- 本款是**俯视 IO 竞技场**：质量、分身、合并、吐孢子、刺球、地图边界、AI 冒充的实时排行榜。全程离线，**禁止 socket / 服务器 / 联网**，其他「玩家」一律本地 AI。

## 五、完整规则（核心全部写成纯函数，可单测）

世界坐标，地图矩形 `MAP_W × MAP_H`（战役按关缩放，对战 / 无尽默认 4000×4000）。摄像机跟随本方最大分身并平滑插值，视野随总质量放大。

### 质量与吞噬
- 每个圆有 `mass`；半径 `r = K_R * sqrt(mass)`。
- 速度 `v = V0 / (1 + mass / MASS_SPEED_REF)`：越大越慢，小圆永远比大圆快。
- 质量衰减：`mass' = mass * (1 - DECAY * dt)`，只在 `mass > DECAY_START` 后启用，逼玩家持续进食。
- 场上维持 `PELLET_COUNT` 颗「彩豆」，吃到 `+PELLET_MASS`。
- **吞噬判定**：两圆心距 `< |rA - rB| * OVERLAP`（建议 0.75），且大方质量 ≥ 小方 × `EAT_RATIO`（建议 1.25）。成立则质量 100% 转移，小方消失。
- 同一玩家的多个分身**不能互吞**，除非进入可合并窗口。

### 分身（上限 16）
- 按 `F` / 触屏「分身」钮：把当前最大分身沿瞄准方向弹出一半质量，弹速先快后阻尼。
- 分身后双方都必须 ≥ `MIN_SPLIT_MASS`，否则忽略输入；已有 16 个不能再分。
- 合并：分身出生 `MERGE_DELAY` 秒后可合（建议 18–30s，质量越大越久），距离足够近则质量相加、位置插值。

### 吐孢子
- 按 `G` / 「吐」钮：每个足够大的分身沿瞄准方向吐一颗质量 `SPIT_MASS` 的孢子，从本体扣除。孢子飞一段停下，谁都能吃。
- **对刺球吐孢子**：刺球被推动并增重，超过阈值后沿吐入方向弹出一颗新刺球——这是把刺球推向对手的进攻手段。

### 刺球
- 场上维持 `VIRUS_COUNT` 颗刺球（海胆状，短刺会呼吸）。
- 分身质量 > 刺球且几何满足 → 该分身**爆开**成最多 8–16 个小分身（总数仍封顶 16），并吃下刺球质量；已有 16 个分身时只加质量不爆。
- 质量 ≤ 刺球：碰上去无事发生或被轻轻弹开，**绝不秒退场**。

### 地图边界与缩圈
- 圆心夹在 `[r, MAP_W-r] × [r, MAP_H-r]`。
- 无尽后期开「缩圈」：安全区每 `ZONE_PERIOD` 秒内收，圈外持续掉质量（表现为圆圆变淡、掉小彩纸），掉到 `MIN_MASS` 就判「先去休息」。对战默认不缩圈。

### 排行榜与胜负
- HUD 右上按总质量取 Top 10，自己那行高亮；不在前十时底部固定显示「第 N 名 · 质量 xxx」。
- 名字只用本作原创：朵朵、星星、糯糯、云云、墩墩、闪闪、绿绿豆、啾啾，以及「圆圆 3 号」这类占位。
- 全部分身消失 = 本局结束（闯关失败 / 对战淘汰 / 无尽结算），文案「圆圆先去休息啦，下次一定更稳！」。
- 对战计时结束比总质量，平局比存活时长。闯关三星 = 目标质量余量 + 用时 +（可选）是否爆过刺球。

## 九、前端建模与视觉（含 360px）

- Canvas 2D 画世界（圆、刺球、孢子、网格背景），DOM 画 HUD（质量、排行榜、技能钮）。
- 圆用径向渐变 + 浅色高光 + 名字标签（贴最大分身）。
- **禁止瞬变**：被吃要 200–350ms 缩小 + 彩纸粒子；分身弹出有拉伸残影；刺球爆开先向四周弹刺再变小圆。
- `prefers-reduced-motion`：关掉拉伸和抖动，保留位置更新。
- 360px：摇杆左下、分身/吐孢子在右下，排行榜默认收成一行「第 N」，点开才展开；HUD 字号 ≥ 13px，不断字不溢出。1280×800 桌面显示完整排行 + 小地图。
