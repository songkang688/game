# 1.1 第 10 步 · A 档工作计划 —— `fight-king`「朵星格斗王」

> 本文件只记录 A 档的开工计划，不涉及 B/C 档目录，也不动 `src/ui/home.ts`。

## 目标

在 `src/games/fight-king/` 新建一款 2D 卡通对打游戏，分类 `party`。
八位本作原创角色，每人 3 个必杀技 + 1 个超必杀，五种模式，188 关格斗塔。

## 格斗系统

- **三段帧**：起手帧 startup → 命中帧 active → 收招帧 recovery，命中框只在 active 段生效。
- **格挡**：按住"后退键"（远离对手的方向）自动格挡，站挡挡中段 / 上段，蹲挡挡中段 / 下段。
- **破防**：格挡消耗格挡槽，槽空 → 破防僵直，可被追击。
- **投技**：贴身且对手不在硬直 / 空中时成立，投技不可被格挡，但起手慢。
- **连段**：轻 → 轻 → 重 → 必杀的取消表；连段递减（第 n 段威力递减）。
- **连段上限**：单次连段最多 6 段，超上限后受击方进入"不可连"状态（无限连防护）。
- **受身**：倒地瞬间按轻击可缩短起身帧。
- **能量槽**：出招 / 被击都涨，满槽可放超必杀。

## 五种模式

1. **双人对战**：同屏键盘，朵朵 `WASD` + `F` 轻击 / `G` 重击；星星 方向键 + `L` 轻击 / `K` 重击。
2. **人机对战**：AI 三档（轻松 / 普通 / 高手），高档会防会反击但带反应延迟。
3. **格斗塔 188 关**：走 `src/games/level99.ts` 的 `mountLevelGame`，8 章，每章 Boss，越后期 AI 越强并带增益。
4. **无尽**：连胜挑战，每胜一场对手更强一点。
5. **训练模式**：显示帧数据与连段计数，练连段不结算胜负。

## 手感

- 命中顿帧、轻微屏幕抖动、星星特效；`prefers-reduced-motion` 下抖动与闪烁全关。
- 触屏：左右半屏虚拟摇杆 + 轻击 / 重击按键。

## 红线自查

- 无血、无伤、无死亡描写；武器不写实，被击中只有星星飞溅 / 眩晕转圈 / 弹开。
- 体力条叫「元气」，招式只写「威力」，不写"伤害"这类词。
- 不出现任何商业商标或官方角色名（注释里也不许）。
- 角色只用本作原创：朵朵、星星、糯糯、云云、墩墩、闪闪、绿绿豆、啾啾。
- 音效只用 `api.play("tap"|"win"|"oops"|"coin"|"pop"|"meow"|"jump")`。
- `destroy` 清干净监听 / 定时器 / rAF / AudioContext。
- 不改 `src/ui/home.ts`，不动其他已有游戏，只增测试不删测试、不调低断言。

## 验收

- `npm test` 全绿；`npm run build` 全绿；新增用例 ≥ 30。
- 冒烟：mount、真实胜负、双人两套键位互不抢占、destroy 后再进不报错；375×667 与 1280×800 都可玩。
