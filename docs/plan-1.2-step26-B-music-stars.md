## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **音准正确性（硬性）** | 频率表按十二平均律 `f = 440 * 2^((n-69)/12)` 计算并写单测（断言 C4≈261.63、A4=440、C5≈523.25，误差 < 0.01Hz）；音程名称表对照乐理写死并全覆盖单测（小二度到纯八度）。**教错音程名是教学事故。** |
| **节奏判定分级** | 三档窗口：完美 ±60ms、良好 ±120ms、勉强 ±200ms，超出算漏。窗口常量化 + 单测。**判定基准用 `AudioContext.currentTime` 而不是 `Date.now()`**，并在开局做一次输出延迟补偿。 |
| **多点触控（duet 硬性）** | 双声部关必须支持同时按下两个星星：用 `pointerdown` 按 `pointerId` 独立记录，写单测模拟两个 pointerId 交叠。现在做不到就是必修 bug。 |
| **示范与练习** | 每关开头可「听一遍范奏」（视奏章除外，那章本来就是不给范奏）；新增**慢速练习**（0.6× / 0.8× / 1.0×），慢速通关只给一星，全速才给三星。 |
| **自由弹奏沙盒（新增）** | 一个不计分的键盘：五声音阶 + 可切换成七声，能录 30 秒并回放，最多存 6 段（key 走 `yiduo-yixing.` 前缀）。**沙盒不产星、不影响关卡进度。** |
| **音色** | 至少三种合成音色（星铃 / 木琴 / 软风琴），用不同波形 + ADSR 包络实现，可在设置里切换。全部现场合成。 |
| **视觉化反馈** | 音高越高星星位置越靠上（音高与纵坐标线性对应），让孩子看得见「高低」；节奏关用横向滚动的节拍条。 |

## 六、2.5D / 3D 决策

**保持 2D**。

## 七、视觉 · 建模 · 手感

- 星星按下时发光 + 轻微下沉 4px，松开回弹；发声与视觉同帧。
- 范奏播放时对应星星依次点亮，**播放中禁用输入并给出「听」的字样**，避免误判。
- 答对：星星连成星座 + `api.play("win")`；答错温和提示，不刺耳、不打叉。
- **音量默认 0.35 上限 0.6**，任何情况下不许突然全音量。提供静音按钮，状态存本地。
- `prefers-reduced-motion`：关星座连线动画与节拍条滚动（改为逐格跳动）。

## 八、手机 360px

- 星星（琴键）热区 ≥ 56px 且彼此间距 ≥ 8px，防误触；五个星星在 360px 下必须一行放得下。
- 双声部关两个可能同时按的键**不能挨在一起**（间距 ≥ 24px），否则一根手指会盖住两个。
- 简谱区字号 ≥ 20px，八度点清晰可见。

## 九、平台接线

- `openCampaignLevel(n)` / `initialLevel` / `?level=` 直开第 N 关；Skip 走 `requestSkip`。
- 首次用户交互时解锁 `AudioContext`（`resume()`），页面隐藏时 `suspend()`，`destroy` 时关闭并断开所有节点。
- `meta.platform` 按实测填；`blurb` 与事实对齐（现文案「十场音乐会 188 关」正确）。
