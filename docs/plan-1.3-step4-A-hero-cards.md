## 二、极高质量改进方案（可执行绘制规格）

### 1. 卡面 → 真正的卡牌（核心资产）

- 统一卡框规格（DOM+SVG，保持 button 结构与 aria-label）：
  1. 左上角标：花色符号（♠♥♦♣ 用 SVG 画，红黑传统色）+ 点数竖排；
  2. 中央卡图区：每类卡一张简笔图标（攻击=交叉剑、回血=桃心汤碗、防御=盾、马=小马、锦囊=卷轴…），SVG 路径 ≤ 20 笔，双色填充 + 描边；
  3. 底部名牌：圆角色条 + 卡名（攻击红、防御蓝、锦囊紫、装备棕）；
  4. 卡体：白底 + 1px 米色内框 + 底部 2px 厚度阴影（立体感）；
  5. 不可出（`hc-card-dim`）：整卡去饱和 + 灰罩，保留可读。
- 手牌横排改扇形微倾（每张 rotate 差 2°，中间高两边低；360px 下退化为平排）。

### 2. 英雄 → 立绘与技能面板

- `heroes.ts` 每位英雄加 `look` 外观字段（主色/副色/头饰 id）；`index.ts` 新增 `heroPortrait(heroId)`：48×48 SVG Q 版头像（2 头身、大眼、按英雄配头饰：将军盔/羽扇/发簪等原创造型）；
- `skillChip` 升级为英雄面板：头像 + 名字 + 技能按钮化（技能名带小图标）；
- 座位卡（420–435 行）加对手小头像 + 体力值改为绘制的心形排（红心/空心，替代纯文本）。

### 3. 桌面 → 战桌中心区

- 新增桌面中心区：左侧牌堆实体（3 张叠起的牌背，牌背花纹 = 云纹 + 「令」字圆章）+ 右侧弃牌堆（最近一张弃牌可见）；
- 牌背规格：深蓝底 + 金色云纹边框 + 中心圆章，SVG 一次生成复用。

### 4. 出牌动画与效果差异（重点）

- 出牌：手牌飞到中心区（0.3s 弧线 + 放大 1.1 倍停留 0.4s 展示卡面）再入弃牌堆；
- 攻击类：从出牌者座位到目标座位画一道剑光箭头（0.25s）+ 目标座位震动 + 红色受击闪边；
- 回血：目标座位绿光上浮 + 心形 +1 飘字；
- 装备：卡片飞到座位装备栏并缩小定位；
- 延时锦囊（🪁）：卡片旋转落到目标头顶悬浮区；
- 全部动画在 `prefers-reduced-motion` 时退化为 0.1s 淡入淡出。

### 5. 结算

- 胜利面板：胜者英雄大头像 + 彩带（复用现有花瓣粒子通道）+ 本局出牌统计（攻击/防御次数图标条）。

## 三、2D / 2.5D / 3D 决策

**保持 2D**（棋牌规范），卡牌立体感 = 厚度阴影 + 悬停上浮 + 扇形排列；禁止 3D 翻转库、禁止 three.js。DOM+SVG 优先（保留按钮语义与键盘操作）。
