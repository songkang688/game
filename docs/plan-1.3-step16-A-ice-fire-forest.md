## 三、现状审美评测（先开代码再动笔）

打开 `src/games/ice-fire-forest/index.ts`，绘制入口是 `render` / `drawParallax` / `drawTile` / `drawHero` / `drawGem` / `drawGate` / `drawIcePool` / `drawLavaPool` / `drawSlime` / `drawKit` / `drawCheckpoints` / `drawArrows`。已核实的问题：

1. `drawHero`（约 1444 行起）的两位主角就是**同一个圆**：圆身 + 描边 + 两点眼 + 笑弧，凛凛与焰焰的全部区别 = 换色 + 头顶一个小尖（冰是三角雪簇、火是一撇火苗，1489–1501 行）。**剪影完全一样**，色弱的孩子基本分不清谁是谁——这正是主管点名的「草稿圆」反面教材；
2. 圆身是纯色平涂 `ICE_BODY` / `FIRE_BODY`，没有一处渐变、材质高光（冰的通透、火的发光都没有）；
3. 借位小云朵（1464–1478 行）是三个白圆 + 两点眼，可以更软；
4. `drawParallax`（1560 行起）的三层远景就是三排**白色半透明圆**（`#ffffff5c` 等），号称「森林」的背景里一棵树都没有；
5. `drawTile` 地形、`drawGem` 宝石、`drawLavaPool` / `drawIcePool` 两池、`drawSlime` 果冻怪逐个自查：预期平涂为主，把每个的结论记进开工 commit。当前控制角色的虚线圈（1512–1520 行）是功能件，保住。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **凛凛（冰）重绘** | 剪影改「水滴形」：身体上窄下宽的水滴轮廓（贝塞尔两段），头顶三枝冰晶发饰（六角雪花簇）、脖子围冰蓝渐变围巾；材质：主体三停径向渐变（冰蓝 → 白芯）+ 内部两道冰棱反光斜线 + 边缘 1px 冷白 rim light；走路时围巾摆动 2 帧、跳跃时水滴尾端拉长 8%（判定格不动）。 |
| **焰焰（火）重绘** | 剪影改「火苗形」：身体下圆上尖、头顶三簇跳动火苗发型（相位差 0.3s）、腰间暖橙腰带；材质：主体径向渐变（橙红 → 明黄芯）+ 外缘 2px 暖光 glow（`shadowBlur` 4，reduced 关）+ 脚下暖色光斑；跑动时火苗后倒、静止时直立。 |
| **可区分性验证** | 把两角色缩到 16px 灰度截图自测：剪影（水滴 vs 火苗）+ 头饰（雪晶 vs 火簇）+ 附件（围巾 vs 腰带）三通道必须仍可分辨，验证结论写进回复。 |
| **森林背景** | `drawParallax` 三层白圆替换为：远层雾色树冠剪影带、中层冷暖两色树干 + 蘑菇点缀、近层草叶与藤蔓（视差比例 0.18/0.34/0.55 原样保留）；冰半场偏冷蓝、火半场偏暖橙，中缝渐变过渡。 |
| **两池与机关** | 岩浆池加流动高光条 + 上浮气泡（2s 循环）+ 池沿焦糖色描边；冰池加镜面反光斜带 + 池沿霜花；机关门 `drawGate` 加石框立面与开门尘土两缕；宝石 `drawGem` 切面化（三角切面高光 + 旋转闪点，reduced 静止）。 |
| **特效与布局** | 双人集合点 `drawCheckpoints` 加旗帜飘动；屏幕边缘找伴箭头（`drawArrows`）保持功能只精修描边；HUD 双人头像 + 宝石计数卡片化。 |

- 渐变 / 描边 / 落影统一走 `src/art/kit/`；光源统一左上 45°；冰阴影冷蓝、火阴影暖褐。
- `prefers-reduced-motion`：火苗跳动、围巾摆动、气泡、闪点全停，保留静态渐变与 rim light。
