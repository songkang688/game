## 二、极高质量改进方案（可执行绘制规格）

### 1. 水下 2.5D 景深（本步核心，规范点名）

- **三层深度**（绘制顺序由远到近，不改任何实体坐标与判定）：
  1. 远景层：深色调剪影水草/礁石（视差 0.3 跟随镜头）+ 2–3 条远景小鱼剪影（纯装饰，非实体）；
  2. 主层：现有实体（鱼/水母/BOSS）不动；
  3. 前景层：3–4 株近景水草大剪影（视差 1.3，半透明 35%）+ 前景气泡（大而虚）；
- **光柱**：水面向下 3–4 道斜光柱（线性渐变白 8% → 透明，缓慢摆动 ±3°，`reduced` 静止）；
- **深度着色**：背景按 y 从浅青到深蓝渐变（越深越暗），实体在深水区叠加极淡蓝罩（y > 70% 屏高时 alpha 0.08）——低成本的深度感；
- 气泡系统：上浮小气泡对象池 ≤ 24（走现有画质开关），玩家转向时嘴边冒 1–2 颗。

### 2. 玩家鱼 → 主角待遇

- 身体改双色渐变（背深腹浅，沿用现 `color` 为基准生成两档）+ 3 片弧形鳞纹（极淡）；
- 增加背鳍/胸鳍：胸鳍随游动每 0.4s 摆一帧；尾鳍从三角改两叉弧形，游动时摆动 ±12°（`reduced` 幅度减半）；
- 成长升档（吞吃变大）时：一圈金光扩散 + 短暂 1.15 倍弹性缩放；
- 金冠保留（玩家标识），双人模式 P2 换银星头饰（形状+色双通道）；
- **吞吃瞬间**：嘴巴张大一帧 + 被吞方缩小旋入嘴 0.2s + 3 颗气泡 + 分数飘字——大胃王的爽感落到画面。

### 3. NPC 材质升级（保留各自造型骨架）

- 水母：伞盖改半透明径向渐变（中心亮）+ 伞缘 8 个发光点（呼吸，`reduced` 静态）；
- 河豚：鼓起瞬间 2 帧弹性过冲（1.5→1.65→1.5 倍）；刺尖加高光点；
- 海胆：刺根粗尖细渐变 + 中心宝石眼；鱿鱼：身体半透明 + 喷墨后退时墨雾粒子 3 团；
- 毒物：加危险绿色气泡光环（缓慢脉动）——「不能吃」一眼可辨。

### 4. BOSS → 出场演出

- BOSS 进场：屏幕边缘暗角 0.5s + 低鸣（现有 sfx 通道）+ BOSS 从阴影中游出（剪影→实体渐变 0.8s）；
- BOSS 本体加：体侧条纹/伤疤特征、愤怒状态红眼 + 加速尾流气泡；
- 击败：BOSS 翻白肚缓沉 + 大量气泡 + 金币星星迸出（共享 kit）。

### 5. 分区主题差异强化

- `drawZoneDecor` 各区加标志物剪影：珊瑚区=大珊瑚扇、沉船区=船骨剪影、冰海区=浮冰底光、深渊区=发光灯笼鱼点缀（纯装饰）；
- 区间过渡：跨区时背景色 1s 插值（复用现有主题色变量）。

### 6. 结算

- 结算：本局吞吃链回顾（吃过的最大三种鱼图标）+ 体型成长条 + 名次。

## 三、2D / 2.5D / 3D 决策（规范：尽量 2.5D）

**侧视 2.5D**：不做透视投影（吞吃判定是 2D 距离，透视会破坏大小判断——大小可读性是本玩法的生死线），用「三层视差 + 深度着色 + 光柱气泡」做水体纵深。禁止 three.js。前景/远景层走画质开关（低端机先砍前景层）。
