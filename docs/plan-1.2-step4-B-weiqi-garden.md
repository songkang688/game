## 五、完整规则

- 路数：**19 / 13 / 9** 三种。落在交叉点。气 = 同色连通块的正交空邻点。
- **提子**：落子后先提对方无气的块，再判自己。
- **自杀禁手**：落子后己方无气且没有提到对方 → 非法。
- **打劫**：刚被提的单子形成劫，立即回提非法，必须先在别处下一手或停一手。全局同形用**位置超劫（positional superko）**：禁止全盘同形再现。必须单测简单劫，以及至少一个连环劫场景。
- **停一手**：双方连续停手 → 终局。
- **数子法（中国规则，默认）**：终局填完单官后按「子 + 围空」计算，黑贴还 `KOMI_CN`（默认 3¾ 子）。
- **数目法（日本规则，对战选项）**：只数空目 + 提子，贴目 6.5；需要「标记死子」工具（AI 可自动标）。
- **两种计分都必须实现**，默认数子，设置可切；各写至少 2 个终局盘用例。
- 活棋判定：双真眼判活、双活（seki）与公气按约定处理，写在 `life.ts` 并注释清楚采用哪一套约定。
- 让子：9 路可让 2 / 3 子，贴目相应调整。
- 胜负：分差 > 0 胜；数目法允许和棋；闯关限时超时判负（文案温和）。
