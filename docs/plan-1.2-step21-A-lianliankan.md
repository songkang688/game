## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **连线动画** | 消除时画出真实路径（含转弯点）的发光折线，180–260ms 后两块一起缩小消失。**禁止「点两下直接不见」。** |
| **洗牌公平** | 洗牌算法必须在洗完后校验「存在可消对」，不满足就重洗（上限 50 次后改用「保证可解的构造式重排」）。写断言。 |
| **收拢模式** | 补齐 4 种收拢：不动 / 向下 / 向中间 / 向左；每关数据指定，收拢过程要有滑动动画（每格 60–80ms）。 |
| **提示经济** | 每关 3 次提示（高亮一对），用掉不给三星；提示要走真实求解，不许随便高亮。 |
| **无尽「连到底」** | 盘面清空后自动补新盘，累计消除对数计分；每 3 盘加一次难度（图案数 +1 或加限时）。成绩 `save.recordEndlessBest("lianliankan", pairs)`。 |

## 七、视觉 · 建模 · 手感

- 选中第一块有描边 + 轻微放大；选错组合时两块一起抖 120ms 并取消选择（不惩罚）。
- 图案用原创可爱图形，**同色系图案要有形状差异**（色觉友好）。
- `prefers-reduced-motion`：折线直接显示 1 帧后消除，仍走同一状态机。
