## 四、1.2 内容与玩法升级

| 项 | 规格 |
| --- | --- |
| **题型补齐到六年级** | 四则混合（含括号）、竖式进退位、分数加减与通分、小数四则、百分数与折扣、比与比例、简单方程（x + 3 = 8 这类）、应用题（行程 / 单价 / 面积）、找规律。**每种题型一个生成器纯函数 + 校验器**。 |
| **生成器约束** | 结果非负、除法整除（或明确保留一位小数）、分数结果最简、应用题语境是农场（喂鸡 / 摘果 / 分苹果），数字规模按关号上升。写断言：随机生成 5000 题全部合法且有唯一答案。 |
| **干扰项策略** | 干扰项来自典型错误（忘记进位、约分错误、单位没换算），**不许纯随机数**；写用例断言干扰项与正解差异合理。 |
| **分步提示** | 连错 2 次给「方法提示」（例如「先算括号里的」），**不给答案**；再错给「拆一步」（把题拆成两小步问）。保留 1.1 的闪烁提示与朗读。 |
| **错题本** | 每关记录错题类型，关卡结束推荐「练一练」同类新题；数据存本地 key 走 `yiduo-yixing.` 前缀。 |
