## 三、学习方法（只学两件事，禁抄一切素材）

1. **画面密度**：同题材头部作品一屏里有几层视觉信息（背景层数 / 装饰物件数 / 动效通道数）？对每个题材记一组数字基准。例如打砖块：背景 2 层 + 砖阵配色 4 组 + 粒子 3 通道。
2. **角色剪影**：头部作品的主角缩成 16px 后凭什么还认得出？（帽子 / 轮廓 / 配件的哪一笔在起作用）每个题材记 1–2 条剪影经验。
3. **红线**：只记结论文字，**不下载、不截图入库、不描摹任何具体造型**；商标、logo、官方角色连「像」都不许像——你的报告里要专设一节提醒 C 档哪些题材容易踩线（如坦克类像 Battle City、火车类像托马斯、猫类像 Hello Kitty）。
