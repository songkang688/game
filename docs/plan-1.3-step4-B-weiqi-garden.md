## 一、现状审美评测（基于 origin/game-1.2 真实代码，`src/games/weiqi-garden/index.ts`）

打分制：草稿 / 能认 / 可爱 / 精美。

## 二、极高质量改进方案（可执行绘制规格）

### 1. 棋盘 → 温润木盘

- 底色改三层：木色线性渐变（`#E8C98F → #D9B26E`，左上亮右下暗）+ 6–8 条极淡木纹曲线（波浪 bezier，透明度 5–8%，用棋盘尺寸做确定性种子）+ 四周 10px 深木色边框（内侧 1px 高光线）；
- 网格线颜色改深棕 `#8A6A3B`，星位点加 1px 高光偏移（内嵌感）；
- 「花园」主题落地：棋盘四角外侧（边框上）各画一枝小花藤装饰（两叶一花，SVG/路径 ≤ 12 笔，不进入棋盘内部、不干扰落点）。

### 2. 棋子 → 玉石质感（核心资产）

- **黑子**：径向渐变（高光点在左上 30% 处：`#5A554C → #22201B`）+ 左上 20% 半径柔高光斑 + 底部外侧 2px 半透明投影（`rgba(0,0,0,.25)` 偏移 y+1.5）；
- **白子**：径向渐变（`#FFFFFF → #E9E2D0`）+ 蛤碁石弧纹 2–3 道（极淡米色弧线，`globalAlpha 0.15`）+ 同规格投影；替代现有的「白圆+描边」；
- 预渲染：黑白各一张 offscreen sprite（按 `metrics.stone` 尺寸缓存，resize 时重建），19×19 满盘 361 子必须走 `drawImage`，不许逐子画渐变；
- ghost 落子预览沿用 alpha 0.4，但用同款 sprite（保持质感一致）。

### 3. 落子与提子动画

- 落子：新子 0.15s 从 1.25 倍缩到 1 倍 + 落定时 4 根极短振纹线（`soft`/`reducedMotion` 关闭，直接出现）；
- **提子 → 化作花瓣**：被提的子播放 0.35s 动画——棋子缩小同时原位绽放一朵对应色的小花瓣（黑子→紫瓣、白子→白瓣）飘起淡出（对象池 ≤ 16）；这是「围子花园」主题的点题特效；
- 打劫提示：劫争点画一朵小红花标记替代纯圆圈。

### 4. 标记系统统一

- 最后一手：红圈改为小枫叶标记（不遮子中心）；
- 提示点：绿圈改为发芽小点（两片子叶）；
- 键盘光标：保留蓝色但改圆角方框（与提示点形状区分，色弱友好）；
- 死子确认：alpha 0.35 之外加斜向叉纹。

### 5. 数目与结算可视化

- 数目阶段：黑白领地用极淡色块渐进铺开（0.6s 波纹扩散铺色，黑territory 淡紫、白 territory 淡米），配合 `score.ts` 现有结果只做展示；
- 结算面板：目数对比双色条 + 奖杯 + 「花园收成」文案（花朵数=目数差可视化，≤ 20 朵）。

## 三、2D / 2.5D / 3D 决策

**严格保持 2D 俯视**（棋类规范）。立体感只来自棋子渐变+投影与棋盘边框。禁止透视、禁止 three.js。Canvas 保留（现有 `draw()` 架构不换）。
