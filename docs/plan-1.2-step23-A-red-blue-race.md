## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **交替节奏模型** | 采用「左右交替按更快」的模型：连续同键按下的收益递减（写纯函数 + 单测），奖励节奏稳定而不是乱砸键。 |
| **公平性** | 两位玩家的赛道障碍**完全镜像**（写断言）；起跑口令有随机延迟，抢跑要有明确回退（后退 0.5 秒而不是判负）。 |
| **AI 四档** | 菜鸟 / 普通 / 高手 / 地狱：用「目标节奏 + 失误率」建模，**不许用玩家做不到的频率**（上限写常量，测试断言）。 |
| **让分开关** | 大人带小孩时可给落后方 ≤ 8% 助推，默认关，HUD 显示。 |
| **无尽「跑不完的跑道」** | 障碍密度随距离上升，撞 3 次结束；成绩 `save.recordEndlessBest("red-blue-race", meters)`。 |
