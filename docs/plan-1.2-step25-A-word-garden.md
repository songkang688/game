## 四、1.2 内容与玩法升级

| 项 | 规格 |
| --- | --- |
| **字库正确性（硬性）** | 全表过一遍：无错别字、无繁体、无异体字；每条字卡补 `pinyin` 与 `meaning` 字段。写一个「字库自检」单测：所有字都在常用字范围、拼音格式合法、同一章内不出现重复字、每题的正确答案在选项里且唯一。**教材内容错一个都是教学事故。** |
| **笔顺描红（新增题型）** | 给核心字补笔顺数据（分段折线路径），玩家按顺序描；描错顺序温和提示重来，不扣分。笔顺数据与判定写成纯函数 + 单测（至少 20 个字的顺序断言）。数据量大就只覆盖前两章的高频字，**宁可少而对，不许多而错**。 |
| **题型补齐** | 看图认字 / 认字选图 / 拼音选字 / 给字组词 / 形近字辨析 / 成语补全 / 近反义 / 句子填空 / 偏旁推字义 / **笔顺描红** / **多音字辨析**（同一个字在两句话里读不同音）。 |
| **干扰项质量** | 形近字题的三个干扰项必须与正确答案共享部件或只差一笔；组词题的干扰项必须是真词而非生造词。写单测断言干扰项来自受控词表。 |
| **错题本** | 错的字进错题本，关卡结束用同一个字的**不同题型**复查；错题存本地 key 走 `yiduo-yixing.` 前缀。 |
| **朗读** | 题干与字音走 `speech.ts` 朗读，没有中文语音包时隐藏按钮但不影响做题。 |

## 七、视觉 · 建模 · 手感

- 汉字用清晰字体，字号 ≥ 28px；田字格辅助线在描红时显示。
- 描红时手指/鼠标轨迹留彩色花瓣痕迹，完成一笔开一朵小花。
- 答对：花园里长出一朵花 + `api.play("win")`；答错温和提示，**不打叉不扣星**。
- `prefers-reduced-motion`：关生长动画，直接显示结果。

## 八、手机 360px
