## 四、这不是什么

- 不是 `xiangqi`（中国象棋，9×10 带河界与九宫），不是 `gomoku`（五子棋），不是 `dark-chess`（暗棋）。
- 本款是**国际象棋**，FIDE 关键规则一条都不能少。

## 五、完整规则（必须全部实现）

- 8×8，白先。六种棋子走法全对（王 / 后 / 车 / 象 / 马 / 兵）。
- 兵：首步可走两格；斜吃；到底线**必须升变**（默认后，提供后 / 车 / 象 / 马 四选一）。
- **王车易位**（长易位与短易位）：王与该车都没动过、之间无子、王的起点 / 经过格 / 落点都不被将军。
- **吃过路兵**：对方兵刚走两格越过的格子，己方兵可**立即**（只在下一手）吃过路。
- **将杀 / 逼和**：无合法走法且被将 = 负；无合法走法且未被将 = 和（逼和）。
- **50 回合规则**：连续 50 回合无吃子无兵动可判和。
- **三次重复局面**判和：局面哈希（Zobrist 或等价）要包含轮走方、易位权、过路格。
- 子力不足判和（王对王、王象对王、王马对王）。
- 认输与（可选）超时都要能正确结算。

## 九、前端建模与视觉（含 360px）

- Canvas 或 DOM 棋盘，粉彩双色格；棋子可以是原创花瓣 / 星星造型，但**六种兵种必须一眼可区分**（形状 + 文字角标可选）。
- 走子滑行 150–220ms；吃子淡出；**被将时王格柔和高亮（不要血红）**；升变弹出四选一。
- 可走点提示（可在难度设置里关）；最近一手高亮。
- `prefers-reduced-motion`：缩短滑行。
- 360px：格子 ≥ 36px（棋盘占满宽），记谱区折叠在下方抽屉；字号 ≥ 13px。
