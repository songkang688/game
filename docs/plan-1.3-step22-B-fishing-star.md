## 三、现状审美评测（先开代码再动笔）

打开 `src/games/fishing-star/index.ts`，绘制入口是 `render` / `drawWater` / `drawShore` / `drawSwimmers` / `drawLine` / `drawAim` / `drawBand` / `drawRuler`。已核实的问题：

1. **鱼是 emoji**：`drawSwimmers` 就是 `g.fillText(s.fish.emoji, px, py)` 加 0.55 透明度（822–834 行）——「钓鱼小达人」的鱼群是一排半透明字符，游动只有正弦上下漂，没有转向、没有摆尾、没有深浅水的体感；
2. `drawWater` 水面 / `drawShore` 岸边自查：预期是色带渐变，有没有波光、涟漪、深度光衰要评；
3. `drawLine` 钓线预期是直线（自查确认）：真钓线该有垂坠弧与入水折射断点；浮标有没有、上钩时有没有「点头」提示自查；
4. `drawAim` 瞄准与 `drawBand` / `drawRuler` 力度条刻度是功能件（保住），但观感预期是 debug 风，自查；
5. 钓上来的瞬间（收获展示）画法自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **鱼群自绘（核心）** | emoji 替换为参数化矢量鱼：纺锤身 + 尾鳍 + 背鳍 + 圆眼，6–8 个鱼种各自差异（体型胖瘦 / 尾形叉圆 / 花纹条点 / 稀有鱼加金鳞高光）；游动加摆尾两帧（相位随 `speed`）与朝向翻转（沿速度方向）；深水鱼加饱和度衰减与轮廓虚化（读 `depth` 只做映射）。**游动坐标演算一行不动。** |
| **水体质感** | `drawWater` 升级三层：水面波光网（两条正弦高光带缓慢平移）+ 中层光柱两道（斜向白 6%）+ 深层暗蓝渐变；水面与岸交界加浪花白边；随机小气泡上浮（≤ 6 颗，reduced 静止）。 |
| **钓线与浮标** | 钓线改两段：空中段贝塞尔垂坠 + 入水点折射错位 2px + 水下段颜色变淡；入水点涟漪圆环扩散（上钩窗口时涟漪加密——读既有判定窗口只做映射）；浮标自绘（红白双色 + 上钩时点头下沉 3px）。 |
| **收获仪式** | 钓起：鱼跃出水面沿弧线到岸（240ms）+ 水花皇冠 5 瓣 + 星屑；展示卡（鱼名 + 大小）做成木牌样式；稀有鱼加金光描边一闪。 |
| **岸上场景** | `drawShore` 升级：钓鱼小人（Q 版背影：草帽 + 钓竿，拉杆时后仰 8°）、岸边草丛与小桶（钓到的鱼进桶，桶口露鱼尾）；远景山影 + 云两朵视差。 |
| **布局与 HUD** | 力度条 `drawBand` 改成钓竿弯曲量的图形化（映射不变）；`drawRuler` 深度刻度做成木尺质感；分数 / 目标卡片化。 |

- 渐变 / 描边 / 星屑统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：波光、气泡、摆尾、跃出弧线全停（钓起改瞬移展示），保留静态层次。

### 四·补二：鱼种矢量工序单（`fishArt.ts`，6–8 spec）

1. 纺锤身路径（宽高比按 spec 0.9–1.6 变化）+ 三停渐变（背深腹浅）；
2. 尾鳍（叉尾 / 圆尾 / 扇尾三型）+ 背鳍小三角；
3. 花纹层：条纹 / 圆点 / 无纹 / 金鳞四选一（< 15px 省略本层）；
4. 圆眼 + 高光点 + 微笑嘴（全程开心）；
5. 摆尾两帧：尾鳍 ±14° 摆动，相位 = `x × 0.05 + speed × 2`；
6. 朝向 = 速度符号翻转（`scaleX(±1)`）；深水鱼饱和度 -30%、轮廓 alpha 0.7。
