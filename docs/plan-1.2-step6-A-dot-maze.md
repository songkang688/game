## 四、这不是什么

- 不是 `ocean-munch`（侧视吃鱼），不是 `snake-snack`（贪吃虫），不是 `alien-seek`（找找看）。
- 本款是**街机式格子迷宫吃豆**：墙 + 豆 + 能量豆 + 隧道 + 四只性格不同的追逐者 + 巡游/追击/惊吓状态机。

## 五、完整规则（格子逻辑写成纯函数）

- 地图用字符网格描述（`#` 墙、`.` 豆、`o` 能量豆、`-` 隧道口、空格通路），解析成 `Maze` 结构。
- 玩家按格移动，速度常量；**只能在交叉口转向且目标方向无墙**；输入缓冲窗口 `TURN_BUFFER`（建议 1 格 / 200ms）。
- 隧道左右相通，穿隧道时可加速或减速（写成常量）。
- **四只小幽灵性格必须不同**（名字原创：直直 / 拐拐 / 绕绕 / 乱乱）：
  - 直直：目标 = 玩家当前格。
  - 拐拐：目标 = 玩家前方 4 格。
  - 绕绕：目标 = 以「直直所在格」为中心，对玩家前方 2 格取中心对称点。
  - 乱乱：距离玩家远时随机游走，靠近到阈值才追。
- 状态机：**巡游（各回自己的角落）→ 追击 → 惊吓（吃到能量豆）→ 回家（被碰到后眼睛飘回巢）**。巡游与追击按时间表切换，节奏参数写常量表。
- 惊吓：所有在场幽灵变「昏昏蓝」并反向逃跑；玩家碰到 → 幽灵眼睛回家，连击得分 200 × 2^n（一次能量豆内累计）。惊吓结束前有闪烁预警。
- 水果奖励：地图中央定时出现原创水果（星果、糖梨、蜜柑），吃到加分。
- 吃光所有豆与能量豆 → 过关。被幽灵碰到 → 掉一颗小星命，重置位置；命为 0 → 本局结束。
- **禁止穿墙**：任何时候玩家与幽灵都必须在通路格上。

## 九、前端建模与视觉（含 360px）

- Canvas 网格渲染，粉彩墙体（圆角描边）+ 小星星豆子。
- 豆子被吃有小缩放消失；幽灵变蓝有过渡；回家是「一双眼睛飘回去」。**禁止爆炸、禁止恐怖脸**。
- 玩家造型是原创小圆脸（不是任何官方角色），张嘴动画。
- `prefers-reduced-motion`：关闪烁，惊吓预警改为边框粗细变化。
- 360px：整张迷宫完整入屏（必要时等比缩放），格子 ≥ 14px；HUD 命数与分数字号 ≥ 13px；虚拟方向键半透明不遮挡。

## 十、AI 档位

幽灵本身就是 AI，另外提供整体难度四档：菜鸟（速度慢、追击时间短）、普通（标准表）、高手（追击更长、拐拐预判更远）、地狱（会包抄：两只走对侧路线）。
固定 seed 下地狱档让玩家假人存活时间显著更短——写成断言。
