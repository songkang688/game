## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **收杆博弈** | 做成「张力条 + 鱼的挣扎节奏」：按住收线张力上升，松开下降；张力进红区 1.2 秒线断（给明显预警震动条）。鱼的挣扎是可预测的节奏型（3 种模式，随稀有度混合）。全部纯函数 + 单测。 |
| **抛竿落点** | 蓄力条决定距离，远处鱼更稀有；加轻微风向影响（可视化箭头），让抛竿有技巧。 |
| **鱼类与图鉴** | ≥ 24 种原创鱼，分 4 个稀有度；图鉴记录首次捕获时间、最大尺寸；序列化往返测试；图鉴 key 走 `yiduo-yixing.` 前缀。 |
| **装备（用星星）** | 鱼线（张力上限）、鱼饵（稀有度加权）、浮标（预警更早）。**只用星星，不许出现任何内购或货币**；加成封顶，写断言。 |
| **无尽「钓到天黑」** | 时间推移（晨→昼→夜）改变鱼群，总重量计分；成绩 `save.recordEndlessBest("fishing-star", weight)`。 |

## 六、2.5D / 3D 决策

**保持 2D 侧视**（水面 + 水下剖面），可加水波与水下光柱。**不做真 3D。**

## 七、视觉 · 建模 · 手感

- 咬钩瞬间浮标下沉 + `api.play("pop")` + 轻微延迟（给反应窗口 400ms）。
- 张力条颜色分区（绿 / 黄 / 红）+ 形状变化（色觉友好）。
- 上鱼有「举起来展示 + 图鉴记录」的小演出（≤ 900ms，可跳过）。
- **无伤害表达**：鱼被放进小水桶，可选「放生」（给额外星星，鼓励温柔）。
- `prefers-reduced-motion`：关抖动。

## 八、手机 360px

- 蓄力与收线用同一个大按钮（长按），热区 ≥ 64px；张力条在上方清晰可见。
- 图鉴面板可滚动，卡片 ≥ 88px 宽。
