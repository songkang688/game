## 二、极高质量改进方案（可执行绘制规格）

### 1. 角色 → 全员绘制脸谱系统（核心资产）

- 保留纯色圆身体 + 队伍光圈的结构（对战可读性好），但升级为三层：队伍色外环（描边化，4px，不再是实心大圆）→ 身体径向渐变（`a.char.color` 亮 12% → 原色）→ 底部 20% 加暗色弧当阴影；
- **删除 `fillText(emoji)` 脸**，新增 `art.ts` 的 `drawCharFace(ctx, id, x, y, r, mood)`：按 `roster.ts` 的角色 id 查表绘制专属特征——朵朵=花瓣发饰+粉腮红、星星=星形呆毛+金腮红、墩墩=小熊耳、啾啾=尖嘴+头顶呆毛、泡泡=头顶小泡、云云=蓬蓬云发……每个角色 2–3 个专属几何特征（≤12 条绘制指令/角色，保证性能）；
- 眼睛统一「白球+黑瞳+高光」三层；`mood` 状态查表：普通/攻击瞪眼/被击 ×眼/眩晕螺旋眼+头顶 2 星公转（**替代 💫 字符**，`soft` 时静止）；
- 身体随水平速度微倾斜（≤8°）、落地压扁 0.15s（scaleY 0.85），`soft` 时关闭。

### 2. 攻击与命中演出

- 挥击「小手」改「拳套弧线」：实心拳头圆 + 3 根弧形拖影线沿挥击方向展开，重击加冲击星（4 芒）+ 半径不变（判定数值 793–799 行的位置与大小口径不动，只加装饰层）；
- 命中爆字（bursts）从 emoji 字符改绘制粒子：轻击=3 粒星屑、重击=5 粒星屑+白色冲击圈；保留飘字文本但换圆角底板白字；
- 出界演出：`fillText("⭐")` 改绘制五角星粒子（金渐变+旋转），沿抛物线飞散，`soft` 时减半。

### 3. 平台与场地主题化

- 平台通用升级：纯色圆角矩形加「顶面高光条（上 25% 亮 10%）+ 底面投影（下方 4px 半透明暗带）」；
- 机制视觉差异化（数据不动，只改画法）：传送带 `▶▶▶` 字符改绘制箭头齿带（滚动动画，`soft` 静止）；弹簧平台底部画 2 个弹簧圈；冰面加冰裂纹 2 条+高光斜条；会塌的平台（collapse）摇晃时加裂纹逐渐变多；隐形平台（hidden）改虚线轮廓+微光；
- 10 张场地按 `stages.ts` 的 `name` 加主题装饰层（各 ≤3 个元素）：云朵广场=3 朵扁云、摇摇浮岛=水面波光、传送带工厂=背景齿轮剪影、弹簧糖果地=棒棒糖柱、咕嘟糖浆池=保留现有波浪+加气泡、夜空跳台=星空点+月牙、滑滑冰湖=冰晶闪点、风车原=远景风车剪影（慢转，`soft` 静止）、星光升降台=光柱、全明星决战场=看台剪影+彩旗；
- 糖浆池波浪（650–661 行）是好实现，保留并加 2–3 粒上浮气泡。

### 4. 道具绘制化（14 种全换）

- 白圆底改「泡壳」：白→透明径向渐变 + 顶部高光弧 + 按道具类别描边色（攻击类粉/移动类蓝/防护类绿）；
- 每种道具画极简图标（≤10 条指令）：软软锤子=圆头锤、弹簧鞋=鞋+弹簧圈、护盾泡泡=双层圈、加速羽毛=羽形曲线、大力饼干=咬缺圆+芝麻点、迷你蘑菇=菇帽点点、蜂蜜罐=罐+滴落、冰淇淋=锥+球、小气球=椭圆+线、星星喷泉=星+喷线、吸铁石=U 形磁铁、彩虹翅膀=三色弧翅、咚咚鼓=鼓身横纹、叮叮铃=铃形+音符线；
- 道具上下漂浮（713 行 bob）保留。

### 5. 结算与 UI

- 等待重生 `drawWaiting`：☁️ 字符改绘制蓬蓬云（3 圆并排+底部平），角色小头像（脸谱系统复用）坐在云上，倒计时进度弧；
- 胜利结算：胜者头像放大 + 主题色粒子雨（花瓣/星屑按角色），比分数字滚动；`soft` 时静态展示；
- 元气数字双通道（814–818 行）与挣扎 ←→ 提示（809–813 行）**原样保留**，可以给 ←→ 加白色圆角底板提高可读。

## 三、2D / 2.5D / 3D 决策

- 本款为**横版乱斗平台跳跃，保持 2D**；层次感来自：背景装饰层（视差 0.1 微移）→ 平台阴影 → 角色投影（脚下椭圆随高度缩放）；
- 不引入 three.js，不做透视投影（平台坐标是判定数据）。
