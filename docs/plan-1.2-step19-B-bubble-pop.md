## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **塌陷时间线** | 消除 180ms → 同列下落（每格 60–80ms，错峰 20ms）→ 空列左移（120ms）→ 稳定后判定。**禁止一次 render 直达终态**；`prefers-reduced-motion` 下压到 1 帧但走同一状态机。 |
| **预览高亮** | 手指按住时高亮整个连通群并显示「×N」预计得分，松手才消（**手机默认开，桌面 hover 高亮**）。 |
| **死局处理** | 无可消群时自动「吹一口气」重排（有动画、不扣分），或给一次「彩虹泡」道具；检测函数要有单测。 |
| **特殊泡** | 彩虹泡（消同色全部）、冰泡（要相邻消两次）、连锁泡（消掉后炸开一圈）。 |
| **无尽「泡泡海」** | 底部持续上推新行，顶到线结束；成绩 `save.recordEndlessBest("bubble-pop", score)`。 |

## 六、2.5D / 3D 决策

**保持 2D**。泡泡用径向渐变 + 高光做出体积感即可。

## 七、视觉 · 建模 · 手感

- 消除是「噗」的一圈水花 + `api.play("pop")`，颜色跟随泡泡色。
- 大群消除（≥ 8）给一次轻微屏幕波纹（reduced-motion 关闭）。
- 颜色 + 图案双通道（色觉友好）。
