## 四、这不是什么（别和已有 55 款撞玩法）

- **不是** `snake-snack`「迷宫贪吃虫」：那是格子迷宫里吃果子的经典贪吃蛇，有墙、有格子步进、单人闯关。
- 本款是**开放大场竞技（IO 型）**：连续坐标、平滑转向、加速掉长度、撞到别人身体才结束、死后掉一串光点、实时排行榜、皮肤与长度成长。
- 全程离线，其他「玩家」全是本地 AI，**禁止 socket / 服务器**。

## 五、完整规则（核心写成纯函数，可单测）

场地：圆形或矩形大地图（默认半径 `MAP_R = 2200`），边界是发光围栏。摄像机跟头，视野随长度略微拉远。

### 移动与身体
- 蛇由头 + 一串「节点」构成，节点沿历史轨迹等距采样：`sampleBody(path, spacing, count)` 为纯函数。
- 转向有最大角速度 `TURN_RATE`，禁止瞬间掉头。手机拖拽给目标角度，键盘给左右转。
- 长度 `length` 决定节点数与半径：`bodyRadius = R0 + K_B * sqrt(length)`。
- **加速**：按住 `F` 速度 ×`BOOST_MUL`（建议 1.9），每 `BOOST_TICK` 毫秒掉一点长度并在尾部掉一颗光点。长度到 `MIN_LEN` 时不能再加速。

### 吃与成长
- 场上散布「星光豆」，吃到 `+FOOD_GAIN`。
- 淘汰的蛇会沿身体轨迹掉一串**高价值光点**（总量 ≈ 其长度 × `DROP_RATE`），谁先捡到谁赚。
- 成长是连续的：长度变化要有 tween，**禁止长度瞬跳**。

### 碰撞与淘汰
- **头撞到别人身体 → 自己被淘汰**（这是唯一的淘汰方式，写清楚）。
- 头对头：两条都淘汰（或按长度判定，选一种写进常量并测）。
- 身体互相穿过不判定，**自己的身体也不判定**（IO 型规则，和 `snake-snack` 明确区分）。
- 撞围栏：不淘汰，沿墙滑行 + 轻微减速（缩圈模式除外，见下）。

### 围杀
- 高阶技巧：绕到对手前面切它的头。AI 高手档必须会这一手。
- 提供「围圈奖励」：一次淘汰 ≥ 2 条时给额外光点与 HUD 提示（原创文案「绕出一个圈啦」）。

### 缩圈（无尽后期与部分关卡）
- 安全区半径每 `ZONE_PERIOD` 秒收缩；圈外每秒掉长度，掉到 `MIN_LEN` 判「先去休息」。

### 排行榜与胜负
- HUD 按长度取 Top 10，自己高亮；不在前十时底部显示「第 N 名 · 长度 xxx」。
- 名字只用原创：朵朵、星星、糯糯、云云、墩墩、闪闪、绿绿豆、啾啾，以及「小青 7 号」这类占位。
- 淘汰文案：「长蛇打了个盹，下一局再长大！」

## 九、前端建模与视觉（含 360px）

- Canvas 2D：网格 / 花纹背景 + 身体用圆链绘制（渐变 + 高光 + 尾部渐细），头上有小眼睛与名字。
- 皮肤：≥ 8 套原创配色（条纹、点点、彩虹、糖果），按关卡星数解锁，只存进本游戏自己的存档字段，不改平台 key 语义。
- **禁止瞬变**：淘汰要有 250–400ms 的「身体断成光点」动画；加速有尾焰与轻微拖影；吃豆有小缩放。
- `prefers-reduced-motion`：关拖影与屏幕抖动。
- 360px：加速钮在右下、拖拽区在全屏；排行榜收成一行；HUD 字号 ≥ 13px。桌面 1280×800 显示完整排行 + 小地图。
