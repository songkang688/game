## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **农场舞台（核心）** | 整屏搭农场景：天空渐变 + 太阳 / 云两朵、远景谷仓 + 风车（叶片缓转，reduced 静止）、中景三块菜畦（土垄剖面：深土 + 浅土 + 垄沟线）、近景木栅栏。全部 SVG/CSS 原创。 |
| **题目实物化** | 题面加实物插图层（**题目文本原样保留**）：加减法配上自绘作物图组（如 3+2 显示 3 个萝卜 + 2 个萝卜，作物随题号轮换：萝卜 / 番茄 / 玉米 / 南瓜，各自专属剪影 + 渐变）；数量 > 10 时改用「一筐 = 10」的筐子图约定（图例说明）。插图由题目数据驱动，**不改题目数据本身**。 |
| **种植成长反馈** | 答对一题 = 菜畦里种下一棵作物并快速长大三阶段（发芽 → 长叶 → 结果，450ms，reduced 直接结果）+ 浇水壶洒水两滴动画；答错 = 作物歪头 + 「再想想」木牌（不批评、不拔苗）。 |
| **选项按钮** | 选项做成木牌钉在栅栏上（木纹 + 钉点 + hover 抬起）；正确后木牌变亮绿描边、错误选项灰化。 |
| **收获仪式** | 一轮答完：篮子收获动画（作物跳进竹篮）+ 收成计数板（今日收获 N 棵）+ 彩纸；连对加小蜜蜂绕场一圈（reduced 静止贴花）。 |
| **布局与 HUD** | 进度改成「菜畦占格」可视化（一畦 = 一题）；题目卡片置顶（圆角 + 麻绳吊挂样式）；TTS 朗读按钮做成小喇叭木牌。 |

| token | 色值 | 用途 |
| --- | --- | --- |

图层序（DOM 从底到顶）：天空渐变 + 太阳云 → 远景谷仓风车 → 中景菜畦三块 → 作物层（按题号落位）→ 近景栅栏 + 选项木牌 → 题目卡片（吊挂）→ 浇水壶 / 蜜蜂动画层 → 彩纸层。动画层 `pointer-events:none`。

### 4.2 作物工序单（crops.ts 四种 × 三阶段）

1. 发芽阶段（共用骨架）：土面小土包 + 两片子叶（`leafGreen` 椭圆对生）；
2. 长叶阶段：茎秆 + 3–4 片真叶（`leafGreen`/`leafDark` 相间，叶脉一条中线）；
3. 结果阶段各自专属剪影：萝卜 = 倒锥形橙身半埋土 + 顶叶三束；番茄 = 圆果两颗 + 蒂星形；玉米 = 长棒 + 格纹粒 + 苞叶两片；南瓜 = 扁圆 + 4 条棱线 + 卷须一根；
4. 统一规格：2px `outline` 深色描边、左上 25% 高光斑、果实底部椭圆投影 `rgba(0,0,0,.10)`；
5. 接口 `crop(kind, stage, size)` 返回 SVG 字符串，纯函数可单测；
6. 筐子图（数量 > 10）：竹篮剪影 + 「×10」角标，图例文字说明放题目卡底部。

### 4.3 动效时序表

| 触发 | 动画 | 时长/缓动 | reduced 行为 |
| --- | --- | --- | --- |
| 答对 | 作物三阶段连播 + 浇水两滴 | 450ms / ease-out | 直接显示结果阶段 |
| 答错 | 作物歪头 ±6° + 「再想想」木牌淡入 | 400ms / ease-out | 只显木牌 |
| 选项点击 | 木牌按下 2px + 阴影收缩 | 120ms / ease-out | 保留（功能反馈） |
| 一轮答完 | 作物跳进竹篮 + 彩纸 20 粒 + 计数板翻牌 | 900ms 一次性 | 静态收成画面 |
| 连对 | 小蜜蜂绕场一圈（贝塞尔路径） | 1.2s 一次性 | 静止贴花 |
| 待机 | 风车叶片缓转、云平移 | 8s / linear 循环 | 静止 |

## 九、测试（只增不减，新增 ≥ 12 个视觉用例）

1. 实物插图数量 = 题目操作数（3+2 → 3 图 + 2 图断言，题目数据不变）；
2. 数量 > 10 时切筐子约定且角标「×10」正确（11 / 20 两例）；
3. `crop(kind, stage, size)` 四种作物结果阶段路径两两不同（组合断言）；
4. 同一作物三阶段路径不同且共用描边规格（抽样断言）；
5. `renderSpec` 输出文本换肤前后一字不差（回归断言，钉死）；
6. `gen.ts` 出题分布换肤前后一致（种子固定回归）；
7. 答对走三阶段成长、答错走歪头分支，两分支互斥且不拔苗（类名断言）；
8. 作物插图种类随题号轮换（萝卜→番茄→玉米→南瓜序列断言）；
9. 菜畦进度格数 = 题目总数，已答格与未答格类名区分；
10. TTS 朗读按钮接线换肤后原样（回归断言）；
11. reduced 下风车 / 蜜蜂 / 成长动画停，静态阶段图与反馈色仍在；
12. 360px 下实物图组换行、单作物 ≥ 16px、木牌高 ≥ 44px（样式断言）；
13. `destroy` 后风车 / 蜜蜂 / 彩纸计时器归零；
14. 既有出题与判定测试断言一个不许改（跑全量确认）。
