## 要做的事

### 1. 2.5D 伪三维(纯 Canvas 2D,不引入任何依赖)

新建 `view3d.ts`,把透视投影抽成纯函数:

- 三条车道向地平线收敛,`scale = camDepth / (camDepth + depth)`,`y = hy + (py - hy) * scale`
- 地面横向网格线按世界深度铺,随跑动向观察者涌来
- 远景视差层 2–3 层(远山 / 云带 / 近景带),各层速度不同
- 远端雾化:越靠近地平线越淡,盖一层与天空同色的雾

模拟仍然跑在原来的「平面轨道坐标」里(障碍存 `trackY`),
投影只发生在绘制那一刻——这样命中判定、`HIT_WINDOW`、`ROW_GAP` 全都不变,
战役可通关性不会因为换了画法而漂移。

### 2. 操作三件套

新建 `controls.ts`:

- 跳跃:上滑 / `W` / `↑` / 空格
- 换道:左右滑 / `A` `D` / `←` `→`
- 滚翻:下滑 / `S` / `↓`
- **土狼时间** `COYOTE_TIME = 0.09`(离地 90ms 内仍可跳)
- **输入缓冲** `INPUT_BUFFER = 0.12`(提前 120ms 按下也算数)

两个手感参数抽成常量,配一套纯函数状态机(`feelTick` / `feelPress` /
`feelWantsJump` / `feelConsume`),单测覆盖边界值。

### 3. 无限模式

新建 `endless.ts`:

- 分段模板拼接(直道糖果雨 / 之字换道 / 跳栏节奏 / 趴杆走廊 / 纸箱仓库 / 混合考验)
- 难度随距离升:障碍密度、可用种类、段落长度都跟着涨
- **必过窗口**:每一段按构造保证存在一条「一个动作都不用做」的空车道路线,
  相邻两行之间横移不超过一格。`segmentClearPath()` 是纯函数校验器,
  单测随机 2000 段全部要能找出这条路线
- 记录最远距离与最高金币数

### 4. 三种失败

- 撞障碍(心掉光)
- 掉坑(无尽模式里踩空即结束,战役维持原来的掉心规则,不动可通关性)
- 被追赶物追上(追风棉花云:撞一次被追近,平稳跑就能拉开)

失败文案只鼓励不批评。

### 5. 性能

- 帧率自适应:`smoothFps` 做指数平滑,`nextQualityTier` 带迟滞,
  掉帧自动降视差层数与粒子数
- 全程 delta time,不按帧步进;`smoothing(dt, rate)` 保证 60fps 与 30fps 手感一致
