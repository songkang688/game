## 三、现状审美评测（先开代码再动笔）

打开 `src/games/clock-house/dial.ts` 与 `index.ts`，渲染入口是 `paint`（约 89 行起）与表盘 SVG 构建段。已核实的问题：

1. `paint` 只做一件事：挪两根指针的 `x2/y2` 端点（92–95 行）——指针就是两条 SVG 线段，没有箭头造型、没有轴心铆钉、没有粗细层次，时针分针只靠长短区分；
2. 表盘本体（自查 SVG 构建段）预期是圆 + 刻度线 + 数字的裸排：「小屋」的题眼在名字里，画面上没有屋顶、没有窗、没有摆锤——主题与画面脱节；
3. 精确模式切换按钮是文本按钮（98–99 行 `toggle.textContent`），无状态视觉差异；
4. 读数条 `readout` 预期是裸文本；
5. 答对 / 答错的反馈画法自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **表盘小屋化（核心）** | 表盘外壳画成布谷鸟小屋：三角屋顶（瓦纹三排 + 烟囱）+ 屋身木纹壁板 + 表盘嵌在屋身正中（圆框加双色木圈）+ 屋底摆锤（左右摆动 2s 周期，reduced 静止）+ 两侧小窗（暖光）。全部 SVG 矢量。 |
| **指针精修** | 时针改胖箭头造型（短粗 + 圆尾配重）、分针细长箭头（带尾羽），两针颜色差异（时针暖橙 / 分针青蓝）+ 轴心铆钉双圆盖住交点；**端点坐标仍由 `handTip` 算出**，只换 `line` 为 `path` 造型层。分针整点跨越时轻微「哒」一格弹性（reduced 关）。 |
| **刻度与数字** | 12 个数字换成小木牌（圆角牌 + 钉点），5 分钟刻度粗、1 分钟刻度细；12/3/6/9 四主位牌加大加色。 |
| **答题反馈** | 答对：屋顶小鸟弹出「咕咕」两下 + 星屑；答错：小鸟探头歪脑袋（不批评）+ 正确指针位置柔光提示（读判定结果只做映射）。 |
| **精确模式视觉** | 开 / 关两态按钮做成拨杆样式（拨上 / 拨下 + 色变）；精确模式下分针刻度增亮提示「要看细」。 |
| **布局与场景** | 背景加温馨房间语义（墙纸淡纹 + 地板线 + 左右盆栽）；读数条卡片化（木牌样式）；题目区与表盘上下排布留白 ≥ 16px。 |

- 色板走 `src/art/kit/palette.ts`；星屑走 `sparkle.ts` 的 SVG/CSS 等价。
- `prefers-reduced-motion`：摆锤、弹格、小鸟弹出全停，保留静态造型与柔光提示。

### 4.1 配色板与图层序

| token | 色值 | 用途 |
| --- | --- | --- |
| `houseWood` / `houseWoodDark` | `#d9a066` / `#a06b3a` | 屋身壁板 / 木纹线与描边 |
| `roofRed` / `roofRedDark` | `#e8735a` / `#c25542` | 屋顶瓦片双色交错 |
| `dialCream` | `#fff8ec` | 表盘底色 |
| `hourOrange` | `#ff9f43` | 时针主色（胖箭头） |
| `minuteTeal` | `#2ec4b6` | 分针主色（细长箭头） |
| `windowGlow` | `#ffe9a8` | 小窗暖光 |
| `wallPaper` / `floorLine` | `#f6eef7` / `#e0d4e4` | 房间墙纸 / 地板线 |

图层序（SVG 从底到顶）：房间背景（墙纸 + 地板线 + 盆栽）→ 小屋屋身 → 屋顶与烟囱 → 摆锤（屋底）→ 表盘底 → 刻度与数字木牌 → 时针 path → 分针 path → 轴心铆钉 → 小鸟弹出层 → 星屑层。指针拖拽热区透明层保持最顶（**尺寸与事件不动**）。

### 4.2 指针与小屋工序单

1. 时针：`path` 胖箭头（杆宽 7px、头部三角宽 12px、尾部圆配重 r=4），填充 `hourOrange` + 2px 深色描边；**端点由 `handTip` 原函数算出**，path 只做旋转对位；
2. 分针：`path` 细长箭头（杆宽 4px、尾羽两片小三角），填充 `minuteTeal` + 2px 描边；层级在时针之上；
3. 轴心：双圆铆钉（外圆 r=7 木色、内圆 r=3.5 深色 + 高光点）盖住两针交点；
4. 屋顶：三排交错瓦片（每片圆底矩形 `roofRed`/`roofRedDark` 相间），烟囱带三圈砖线；
5. 数字木牌：圆角矩形（12×16px）+ 顶部钉点圆，12/3/6/9 主位放大 1.25 倍并用 `roofRed` 描边；
6. 摆锤：细杆 + 圆锤（金色渐变 + 高光弧），`transform-origin` 在屋底锚点。

### 4.3 动效时序表

| 触发 | 动画 | 时长/缓动 | reduced 行为 |
| --- | --- | --- | --- |
| 待机 | 摆锤左右摆 ±14° | 2s / ease-in-out 循环 | 静止垂直 |
| 分针跨整点 | 「哒」一格弹性回弹 | 180ms / cubic-bezier(.34,1.56,.64,1) | 直接到位 |
| 答对 | 小鸟弹出咕咕两下 + 星屑 6 粒 | 700ms 一次性 | 静态小鸟 + 柔光 |
| 答错 | 小鸟探头歪脑袋 + 正确位柔光 | 500ms / ease-out | 只留柔光 |
| 精确模式切换 | 拨杆滑动 + 分针刻度增亮 | 200ms / ease-out | 瞬时切换 |
| 小窗 | 暖光呼吸 ±8% 透明度 | 3s 循环 | 恒定亮度 |
