## demo-home · 首页（40 秒）

1. 朵朵和星星的欢迎气泡：**76 款原创小游戏，闯关最长 188 关**（证明是 1.2 版本）。
2. 分类页签：全部 / 闯关 / 休闲 / 对战 / 学习 / 动手，演示切换休闲和学习分类。
3. 搜索：输入「彩虹」，找到 1 个游戏，显示彩虹跑跑卡片。
4. 点开卡片进游戏，落在彩虹跑跑的十二大世界地图上，显示 0/564 星星总数。

## demo-rainbow-run · 彩虹跑跑（40 秒）

1. 世界地图：十二大世界、共 188 关。
2. 进第 1 章「青草世界」的选关地图，点第 1 关「青草热身跑」。
3. 实机跑一关：三条车道向地平线收敛的 2.5D 视角，演示 ← → 换道、↑ 跳、任务是吃到 6 颗糖果币。
4. 过关结算面板：获得 2 星，有「回地图」和「下一关」按钮。
5. 进入第 2 关「跳跳栏比赛」，演示跳跃失败机制（温柔提示「摔了一跤，鼻平平……」）。
6. 返回地图，显示第 1 关已完成（2 星）、第 2 关已解锁，星星计数 2/33。

## demo-duo · 朵星双人冲刺（35 秒）

1. 模式选择界面：显示四种比赛方式（无尽竞速、幽灵对战、无尽对战、抢金币赛）和四种对手选择（两个人一起玩、电脑·新手、电脑·稳当、电脑·高手）。
2. 选中「两个人一起玩」和「无尽竞速·先撞 3 次输」。
3. 开跑：画面左右分屏，左侧粉色赛道（朵朵用 W A S D），右侧蓝色赛道（星星用方向键 ←↑→↓）。
4. 展示两套键位同时操作，互不冲突的双人同屏玩法。
5. 结算面板：显示「真了不起！」或「太棒啦！」，平局或分出胜负，星星奖励，有「再玩一次」和「回首页」按钮。

## 技术参数

- **录制方式**：ffmpeg x11grab 实时录屏，无后期剪辑。
- **编码**：H.264 / yuv420p，CRF 20，`+faststart`。
- **帧率**：25 fps。
- **分辨率**：1280×800（浏览器窗口实际大小）。
- **文件大小**：全部 < 1.5 MB，方便直接在 GitHub 页面播放和嵌入 README。

## 想自己重录

```bash
npm run build
npm run preview        # 默认 http://localhost:4173/
```

然后用任意录屏工具对着浏览器窗口拍即可。
