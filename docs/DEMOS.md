# 🎬 演示片说明（1.2.0 沿用 1.1 占位片）

`docs/demos/` 里的三条短片全部在本机 `npm run build` + `npm run preview` 的产物上实拍录制，
不是设计稿，也没有后期剪辑或加速。

画面里的粉色小圆点是录制时叠加的「假光标」，底部深色气泡是解说字幕，键盘方块是按键提示——
这三样只存在于录制脚本里，游戏本身没有这些东西。

> ⚠️ **这三条还是 1.1.0 时录的，1.2.0 先原样留作占位。** 1.2 相对 1.1 的可见差异：
> 首页欢迎气泡按实际收录数动态渲染，现在是 **76 款**（1.1 是 55 款）；首页多了
> **📱 手游 / 💻 端游** 筛选芯片；选关地图在 root 管理员门打开时多一个「直达第 N 关」入口。
> **重录由另外的子代理接手**，换片时把 `docs/demos/*.mp4` 换掉、再把下面的逐镜说明改成新画面即可，
> 文件名保持不变（`release.yml` 按 `docs/demos/*.mp4` 挂 Release 资产）。

## demo-home · 首页

1. 朵朵和星星的欢迎气泡：**55 款原创小游戏，闯关最长 188 关**
   （录制时是 1.1；这句是照实际收录数动态生成的，1.2 上跑会显示 **76 款**）。
2. 分类页签：全部 / 闯关 / 休闲 / 对战 / 学习 / 动手，来回切三次。
3. 玩法芯片：只看**双人**、只看**无尽**，上方实时显示「找到 N 个游戏」。
4. 搜索：先打中文「彩虹」，清空后再打拼音首字母「chpp」，两种都能搜到彩虹跑跑。
5. 心形收藏：点一下白心变红心，「💖 我的最爱」分区立刻出现在最上面。
6. 点开卡片进游戏，落在彩虹跑跑的十二大世界地图上。

## demo-rainbow-run · 彩虹跑跑（2.5D 三车道跑酷）

1. 世界地图：十二大世界、共 188 关、星星总数 0/564。
2. 进第 1 章「青草世界」的选关地图，点第 1 关「青草热身跑」。
3. 实机跑一关：三条车道向地平线收敛，地面网格、三层视差、远端雾化都在动；
   演示 ← → 换道、↑ 跳、↓ 趴，任务是吃到 6 颗糖果币。
4. 过关结算面板：按表现给 1–3 颗星，可以「回地图」或「下一关」。
5. 回到世界地图，点顶部横幅进「无尽彩虹跑」，再跑一段程序化路段。

## demo-duo · 朵星双人冲刺（2.5D 分屏）

1. 开局先选比赛方式（无尽竞速 / 幽灵对战 / 无尽对战 / 抢金币赛）和对手
   （两个人一起玩 / 电脑新手、稳当、高手）。
2. 选「两个人一起玩」开跑，画面左右分屏，两条赛道一模一样。
3. 双人键位同时在动：朵朵用左手 `W A S D`，星星用右手方向键，
   两套键位零交集，同屏两个人各按各的互不抢键。
4. 结算面板：先撞满 3 次的人输。

## 想自己重录

```bash
npm run build
npm run preview        # 默认 http://127.0.0.1:4173/
```

然后用任意录屏工具对着浏览器窗口拍即可。原始录制是 25fps，
成片统一转成 H.264 / yuv420p（`-crf 20 -movflags +faststart`），
单条控制在 5 MB 以内，方便直接在 GitHub 页面里播放。
