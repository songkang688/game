## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **地形五件套** | 砖（可破，四分之一格粒度）、钢（需强化弹）、水（弹可过、车不可过）、草（遮挡视线）、冰（滑行惯性）。每种一个纯函数判定 + 用例。 |
| **弹道** | 基础弹直线；补「反弹弹」（墙面反射 1–2 次，角度用反射公式，写单测）与「穿甲弹」（破钢）。反弹弹要有预测虚线（短，只画第一段反射）。 |
| **AI 寻路** | 用网格 A\* 或 BFS，避免卡墙角；三档：会乱转 / 会追人 / 会绕后与卡位。固定 seed 胜率断言。 |
| **地图编辑（轻量）** | 关卡数据是二维字符表，能被测试直接构造；补 3 张对战专用对称地图（**对称性写断言**）。 |
| **无尽「守老巢」** | 波次无限，敌车越来越多越硬，成绩 `save.recordEndlessBest("tank-battle", wave)`。 |

## 五、模式矩阵

四种模式全保留（玩不了就修好或从 `modes` 删）；闯关 **前 99 关地图不改**；`coop` 双人共守老巢，`versus` 双人对抗 + 可选 AI。

## 六、2.5D / 3D 决策

**保持 2D 俯视**。地形与弹道必须精确可读。允许坦克有轻微斜投影厚度感。

## 七、视觉 · 建模 · 手感

- 炮口有短前摇与后坐位移（4–6px），命中有火花状彩纸。
- 被击中：零件飞散 + 3 秒后在出生点「组装回来」，**无死亡**。
- 草丛遮挡要半透明可辨（避免完全看不到导致挫败）。
- `prefers-reduced-motion`：关屏震。

## 八、手机 360px

- 摇杆 + 开火钮不重叠，热区 ≥ 44px；双人同屏时左右各一套。
- 小地图（若有）可折叠，默认折叠在角落，不遮战场。

## 九、平台接线
