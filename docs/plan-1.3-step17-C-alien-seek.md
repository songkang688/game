## 三、现状审美评测（先开代码再动笔）

打开 `src/games/alien-seek/index.ts`，绘制入口是 `draw` / `drawBackdrop` / `drawAlien` / `drawSpotShape` / `drawTrinket` / `drawThumb`。已核实的问题：

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **六只外星朋友差异化** | 每只独立特征（剪影级差异，不只换色）：①独眼圆胖 + 单触角；②三眼瘦高 + 双触角；③大耳朵 + 无触角 + 头顶光环；④双尾巴 + 蘑菇头；⑤方脑袋 + 天线三根；⑥小翅膀 + 螺旋触角。每只加三停径向渐变 + 肚皮浅色域 + 1.5px 描边 + 独立 idle 小动作（眨眼 / 触角弹动 / 翅膀扇动，相位错开，reduced 静止）。 |
| **藏匿点空间感** | `drawSpotShape` 升级为「可掀开的藏身处」：草丛（三簇叠层 + 被点到时拨开两瓣）、窗帘（布褶渐变 + 掀角）、陨石（受光面 + 影子后的空隙）、飞船残骸（舱门半开缝隙光）。点错时藏身处轻晃 + 冒出小问号云（不批评）。 |
| **星空氛围** | `drawBackdrop` 加：星云双色径向渐变底、亮星 12 颗（大小两级、缓慢闪烁）、流星每 8–14s 随机一条（斜线渐隐尾迹）、地面加两层丘陵剪影视差。reduced：闪烁与流星停。 |
| **找到的仪式感** | 找到时：UFO 从画外飘入 → 光束锥（半透明渐变）罩住外星人 → 外星人挥手上升 → 星屑彩纸（`sparkle.ts`）。全程 ≤ 1.2s，reduced 时改为静态光圈 + 挥手一帧。 |
| **目标缩略图** | `drawThumb` 升级为「通缉令小卡」：圆角卡 + 别针 + 外星人半身像 + 名字条，剩余目标横排。 |
| **布局与 HUD** | 计时 / 已找到计数卡片化；提示按钮画成小望远镜图标。 |

- 渐变 / 描边 / 落影统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：idle 动作、闪烁、流星、光束动画全停，保留静态层次。

### 四·补一：配色板与图层序（落成常量块再引用）

| token | 色值 | 用途 |
| --- | --- | --- |
| `asNebulaA` / `asNebulaB` | `#2E2A55` / `#4A3E78` | 星云双色渐变两端 |
| `asStar` | `#FFF3C9` | 亮星与流星尾迹 |
| `asHillFar` / `asHillNear` | `#3E3A66` / `#524A80` | 两层丘陵剪影 |
| `asBeam` | `rgba(180,230,255,.4)` | UFO 光束锥 |
| `asCard` | `rgba(255,255,255,.9)` | 通缉令小卡底 |
| 六只 tint | 沿用既有 `tint[]` | 身体主色（保持存档一致性） |
| `asShadow` | `rgba(30,26,60,.3)` | 夜景统一落影 |

图层序（`draw` 从底到顶）：① 星云渐变 → ② 亮星 / 流星 → ③ 远丘 → ④ 近丘 → ⑤ 藏匿点 → ⑥ 外星人（peek 态半露）→ ⑦ 掀开 / 问号云 / UFO 仪式 → ⑧ 通缉令小卡 → ⑨ HUD。

### 四·补二：六只外星朋友工序单（共用骨架 `alienBody(spec)`，六份 spec 常量）

1. 落影椭圆（夜景色 `asShadow`）；
2. 身体剪影按 spec：圆胖 / 瘦高 / 大耳 / 蘑菇头 / 方脑袋 / 带翅（路径级差异，禁止只换色）；
3. 三停径向渐变（tint 主色 → 顶光 +22%）+ 肚皮浅色域 + 1.5px 描边；
4. 特征件按 spec：单触角 / 双触角 / 光环 / 双尾 / 三天线 / 螺旋触角 + 小翅膀；
5. 眼睛按 spec：独眼 / 三眼 / 双眼下垂 / 豆豆眼 / 方框眼 / 星星眼；
6. idle 小动作按 spec 错相位：眨眼（3s）/ 触角弹动（1.4s）/ 翅膀扇动（600ms）；
7. `peek` 探头态：只露上半身 + 眼睛左右瞟（读既有 peek 参数不改）。

### 四·补三：动效时序表（毫秒写死成常量并被测试引用）

| 动效 | 触发 | 时长 | 缓动 | reduced 行为 |
| --- | --- | --- | --- | --- |
| 亮星闪烁 | 常驻 | 两级 1800/2600ms | sin | 恒亮 |
| 流星 | 随机 8–14s | 700ms 尾迹渐隐 | easeIn | 不生成 |

## 九、测试（只增不减，新增 ≥ 12 个视觉用例）

1. palette token 合法且与四·补一表一致（六只 tint 沿用既有数组，断言未改）；
2. `alienBody` 六份 spec 剪影路径两两不相等（可区分性断言，至少抽 3 对）；
3. 特征件分支（独眼 / 三眼 / 光环 / 双尾 / 天线 / 翅膀）存在性断言六条（可参数化）；
4. idle 动作相位错开（六只相位常量互不相等）；
5. `peek` 探头态只读既有 peek 参数（断言参数不被写）；
6. 藏匿点掀开动画不改命中区坐标（前后相等断言，逐藏匿点类型）；
7. UFO 仪式全链 ≤ 1200ms（分段常量求和断言）；
8. 找到仪式在 reduced 下走静态分支、点错只出问号云一帧；
9. 流星生成间隔在 [8s,14s] 且可 seed 复现；
10. 通缉令小卡渲染含半身像与名字条（DOM/canvas 断言）；
11. `destroy` 后流星计时与粒子归零；
12. 既有判定与计时测试断言一个不许改（diff 不出现玩法测试文件）。
