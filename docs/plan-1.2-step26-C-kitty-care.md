## 13.1 现状审查（逐条对着第三节回答）

1. **`index.ts` 630 行里塞了几种任务、状态机怎么组织**
   七种任务（`taskFeed` / `taskPlay` / `taskWash` / `taskSleep` / `taskDress` / `taskCure` / `taskStyle`）
   全部塞在同一个 `playLevel()` 闭包里，加上猫的 SVG（90 行模板串）、CSS（45 行）、
   顶部任务条 / 心情条 / 多猫舞台的渲染函数，一个文件从数据画到判定。
   状态机是一组闭包变量：`taskIdx` / `mistakes` / `mood` / `activeCat` / `ended` / `destroyed`，
   靠 `startTask()` 按 `cfg.tasks[taskIdx]` 分派，任务内部各自再开局部变量（`taps` / `left` / `step` / `slot`）。
   **没有任何一处判定是纯函数**，所以现在这一款一个玩法单测都没有，只有关卡表的数据测试。

2. **七种任务的判定，哪几种是「点 N 下」换皮**
   - 喂饭：从 `FOODS` 抽一个 `want`，选项里点中同一个对象引用即过 —— **单选题**。
   - 打扮：从 `ACCS` 抽一个 `want`，同样是选项点中即过 —— **和喂饭同一段代码换了个数组**。
   - 逗猫：一个会每 1.1 秒随机瞬移的按钮，点满 `playTaps` 下 —— **点 N 下**。
   - 洗澡：撒 `washSpots` 个泡泡按钮，逐个点掉 —— **也是点 N 下**，只是按钮长得不一样。
   - 哄睡：先显示 3–6 个音符 2.4 秒，再按记忆顺序点 —— 记忆序列，算有自己的手感。
   - 看病：护理单把顺序**明写在屏幕上**，照着点，点错只提示「这一步还用不上它」，**不能回退**。
   - 搭配：每个部位点一件，最后一次性算分；`< 60%` 就整套推倒重来。
   结论：**七种里有四种（喂饭 / 打扮 / 逗猫 / 洗澡）本质是同一个「点对/点够」**，
   1.2 必须按第四节把七种手感做出七种交互。

3. **心情值掉到 0 会怎样**
   `mistake()` 里 `mood <= 0` 直接 `ctx.lose()` → 框架弹「就差一点点」+「再试本关」，
   也就是**本关从头重来**。心情章起点最低 5，`moodMistakeBudget(5,10) = 2`，
   意味着后段关卡**错 3 次就得重打整关**（前面做完的两三个任务全部作废），挫败感偏重。
   另外非心情关还有一条 `mistakes > 4` 也判负，同样是重来。

4. **双猫关怎么切目标猫**
   `activeCat = catForTask(taskIdx, catCount)` —— **由系统按任务序号轮流指派，玩家不能选**。
   高亮只是 `.kc-cat-on` 的透明度 0.55 → 1，名字牌一直挂着。
   「喂错猫」这件事在现在的实现里根本发生不了（操作永远作用在系统选中的那只身上），
   代价是孩子对「我在照顾谁」没有主动权，多猫关的存在感只剩一张换色皮肤。

5. **看病是几步、有没有医学上不妥的表述**
   `cureSteps` 2→4 步，每步在 `CURE_TOOLS` 里单选。**词表有问题**：
   症状「有点发烧」「咳嗽个不停」「爪子擦破皮」「肚子不舒服」，
   处置「小药丸」「药水」「体温计」「创可贴」「听诊器」——
   既有**给动物吃药**，又有**破皮流血**的联想，还暗示孩子自己就能诊治，
   全部踩 1.2 的红线，必须整表换掉。

6. **搭配评分是主观的还是有规则**
   有规则但**不透明**：`styleItemScore` 是「最搭 2 分 / 百搭 1 分 / 不搭 0 分」，
   而「搭不搭」只由 `item.theme === theme` 这个隐藏字段决定，屏幕上只给一个 `4/6 · 好看`，
   **一句为什么都不说**；分数低于 60% 还要整套重搭。孩子无从知道是哪一件拖了后腿。

7. **猫是怎么画的、有没有表情**
   纯手写 SVG（`catSvg()`，220×210 视口，原创线稿，毛色由 `CAT_CREW` 换色），
   表情只有两组眼睛（睁眼 / 弯眼）和一个张嘴椭圆，靠 `display` 切换 0.8 秒；
   **没有呼吸、没有尾巴摆动、没有困 / 好奇 / 委屈 / 躲的状态**。

8. **有没有跨关卡长线养成**
   没有。每关是一次性的，出关只写一个星级到 `yiduo-yixing.l99.kitty-care`，
   猫不会长大，小屋没有家具，也没有相册。
