## 三、现状审美评测（先开代码再动笔）

打开 `src/games/memory-cards/index.ts` 与 `art.ts`，渲染入口是 `renderAll` / `renderSlot` / `paintFace` / `paintIcon` / `renderTheme` / `renderAssist` / `renderTop`，图标出自 `art.ts` 的 `drawIcon`（约 251 行起，shape 驱动的矢量绘制）。已核实的问题：

1. `drawIcon` 是**全库少有的自绘矢量图标系统**（好底子，保住并扩充），但图标只有单层填充：无渐变、无高光、无描边统一规范，自查 `Icon.shapes` 的用色确认；
2. 卡背（`paintFace` 的背面分支）预期是纯色或简单纹理，自查确认——卡背是记忆游戏出镜率最高的画面，值得一块精修；
3. 翻牌动画自查：有没有 3D `perspective` 翻转？预期是瞬间换面或简单缩放，把结论记进开工 commit；
4. 配对成功 / 失败的反馈差异自查（预期只有消失 / 翻回）；
5. `renderTheme` 主题切换对卡面的影响范围与 `renderTop` 顶栏样式自查。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **卡背设计（核心）** | 卡背统一设计：深色底 + 星月环形纹样（细线几何 + 中心小徽章「朵朵星星」双星图案）+ 四角圆花角饰 + 1.5px 金色描边；主题色只换底色相，纹样结构不变——任何角度扫一眼都知道「这是记忆卡」。 |
| **3D 翻转** | 翻牌改 CSS 3D：`perspective(600px)` + `rotateY` 180° 双面（背面 `backface-visibility: hidden`），180ms 缓动；翻开瞬间卡面轻微上抬 2px；reduced 时直接淡入换面。**记忆窗口时长与判定时序一律不动。** |
| **图标精修** | 在 `drawIcon` 体系上加统一后处理：每个图标加 1.5px 深色描边层 + 左上高光小斑 + 底部软影；**新增**至少 4 个新图标（丰富主题，shape 数据只增不改）；图标绘制尺寸与卡面留白比统一为 64%。 |
| **配对反馈** | 配对成功：两卡相互轻碰（各向对方位移 3px 回弹）+ 之间冒出小爱心与星屑 → 双卡定格为亮色收纳态（不消失的设计若已有则保住）；配对失败：两卡轻轻摇头 ±3° 再翻回（时序不变），无惩罚色。 |
| **记忆阶段仪式感** | 开局记忆窗口内全场卡面朝上时，边框呼吸微光提示「快记住」；窗口结束集体翻回加波浪时差（每卡 30ms 交错，总时长不超过既有窗口收尾，reduced 同步翻回）。 |
| **布局与 HUD** | `renderTop` 卡片化（回合 / 配对数 / 主题）；`renderAssist` 辅助提示保住语义，视觉统一为柔光样式。 |

- 色板走 `src/art/kit/palette.ts`；描边 / 星屑走 kit 公共件。
- `prefers-reduced-motion`：翻转 3D、波浪时差、爱心星屑全停，保留静态层次。

### 四·补一：配色板与卡背规格（落成常量块再引用）

| token | 色值 | 用途 |
| --- | --- | --- |
| `mcBackBase` | `#4A3E78`（主题换色相） | 卡背深色底 |
| `mcBackLine` | `rgba(255,255,255,.35)` | 星月环形细线纹 |
| `mcBackGold` | `#F0C25A` | 1.5px 金描边 + 中心徽章 |
| `mcFace` | `#FFFDF6` | 卡面底 |
| `mcMatchGlow` | `rgba(255,214,120,.4)` | 配对成功亮色收纳态 |
| `mcAssist` | `rgba(159,217,139,.3)` | 辅助提示柔光 |
| `mcShadow` | `rgba(60,50,90,.18)` | 卡片软影 |

卡背构成（从底到顶）：深色底 → 环形细线纹样两圈（半径 62% / 78% 卡宽）→ 中心双星徽章（「朵朵星星」两枚五角星交叠）→ 四角圆花角饰（卡 < 48px 省略）→ 金描边。主题切换只换 `mcBackBase` 色相，结构与纹样零变化。

### 四·补二：图标后处理工序（在 `drawIcon` 输出之上统一叠加）

1. 底部软影椭圆（图标宽 70%、高 12%）；
2. 逐 shape 描边 1.5px（深 20%，新处理层实现，**不改 shape 数据**）；
3. 左上高光小斑（图标宽 10%）；
4. 绘制区统一为卡面 64%，各图标包围盒归一化后再画。
新增 ≥ 4 个图标（例：风筝 / 灯笼 / 贝壳 / 橡果），shape 数据只增文件末尾、不动已有条目的顺序与数值。

### 四·补三：动效时序表（CSS 动画时长写成自定义属性）

| 动效 | 触发 | 时长 | 缓动 | reduced 行为 |
| --- | --- | --- | --- | --- |
| 3D 翻转 | 翻牌 | 180ms rotateY | ease-in-out | 淡入换面 120ms |
| 翻开上抬 | 翻开 | 2px、120ms | ease-out | 关闭 |
| 配对轻碰 | 成功 | 各 3px 回弹 200ms | ease-out-back | 直接进入收纳态 |
| 爱心星屑 | 成功 | 320ms | ease-out | 不生成 |
| 失败摇头 | 失败 | ±3°、240ms | ease-in-out | 直接翻回 |
| 记忆窗口呼吸边框 | 开局窗口 | 1200ms 周期 | sin | 恒定微光 |
| 集体翻回波浪 | 窗口结束 | 每卡 30ms 交错 | step | 同步翻回 |

**翻回波浪的总时长必须 ≤ 既有窗口收尾时长**（读常量断言），记忆判定时序一毫秒不动。
