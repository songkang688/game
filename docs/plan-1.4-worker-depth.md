## 做法

1. **先读**：`docs/qa/1.4/infra-runner.md`（接入指南与本款建议接法）、`.cursor/skills/gamedev/game-feel/SKILL.md`（镜头部分）、宪法第五节；本款 `docs/qa/1.4/{{ID}}-audit.md` 的纵深定级建议。
2. **不改玩法坐标**：所有判定仍在原平面 / 轨道坐标里；透视只在绘制时 `project`。写一条「关掉透视（`cam.kind="flat"`）后判定结果不变」的测试。
3. **四件套 + 伪 3D 两件**按定级落地；`prefersReducedMotion` 为真：视差停、网格停、镜头不倾不抖，透视本身保留（透视不是动效）。
4. **性能**：低端安卓目标——每帧深度排序只对可见实体做，远处精灵合批或跳帧；`npm run build` 后用无头 Chrome 跑 10 秒取 rAF 间隔，p95 ≤ 20 ms（915×412 与 390×844 各一次），数字写进回复。
5. **素材**：深度精灵用该款已有的 kit 角色绘制函数，阴影 / 雾化走套件；不新增任何位图。
6. **测试**：契约 ≥ 10 例（相机参数在 `MIN_SCALE..MAX_SCALE`、远处 alpha 单调下降、reduced 下 `cameraNudge` 为 0、分屏两相机独立、flat 模式判定等价）。现有 `logic.test.ts` / `levels.audit.test.ts` 全绿不改。
7. **验收截图**：五视口各一张关内截图留 `/tmp`，回复里描述远近对比（近大远小、远处淡、地平线位置）。
