## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **蓄力与落点** | 蓄力 0–1.2 秒映射到初速，落点圈随蓄力变化实时显示（越远越模糊）。空气阻力与重力常量化 + 单测。 |
| **雪球经济** | 手里最多 3 颗，蹲下搓 0.6 秒得 1 颗（可被打断）；地面积雪厚度会消耗——引入「阵地选择」的策略。 |
| **掩体** | 三种掩体：雪墙（可被打碎 3 次）、木箱（不可破但会被推）、雪坡（蹲下时半隐藏）。判定写纯函数。 |
| **命中反馈** | 被砸中 = 「变雪人 1.5 秒不能动」，不是扣血；连中三次进「暖手休息」5 秒再回场。**无伤害语义**。 |
| **无尽「雪季」** | 一波波雪人对手，越来越准；撑过几波记 `save.recordEndlessBest("snow-fight", wave)`。 |

## 七、视觉 · 建模 · 手感

- 雪球飞行有旋转与轻微拖尾；命中溅开雪花粒子。
- 变雪人有可爱造型（胡萝卜鼻子），倒计时圈清楚。
- 场景昼夜 / 飘雪层随关卡变化，掉帧时减粒子。
- `prefers-reduced-motion`：关屏震与飘雪抖动。

- 雪球数 / 比分 / 计时一行显示，字号 ≥ 14px。
