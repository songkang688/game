# 一朵一星 1.3 · 多窗口派发登记表（视觉升级）

> **这张表是唯一的防重派机制。** 派发前先把那一格从「未派」改成「在跑」并提交，再去开子代理；
> 没登记就派 = 重派事故。主管文档：[`plan-1.3-supervisor.md`](./plan-1.3-supervisor.md) ·
> 目录：[`plan-1.3-index.md`](./plan-1.3-index.md) · 视觉宪法：[`plan-1.3-visual-bible.md`](./plan-1.3-visual-bible.md)

## 〇、怎么用

1. **同一时刻只有 3 个窗口在跑**（W1 / W2 / W3）。窗口空出来 → 从上往下找第一格「未派且依赖已满足」→ 先登记 → 再派。
2. 一行 = 一格 =「某一步的某一档」。**一格只许一个窗口**；已写窗口号的行不许再派。
3. 状态五种（含义与 1.2 相同）：`未派` / `在跑` / `待验` / `已验收` / `打回`。打回占原窗口，不算新格。
4. 每次改状态**单独提交一次**（`docs(1.3 tracker): 第 N 步 X 档 → 在跑/已验收`）。
5. 「用例水位」填该格合入后 `npm test` 用例总数，下一格必须 ≥ 这个数。
6. 1.3 特有验收项（勾完才能标已验收）：宪法负面清单抽验、素材契约测试新增 ≥ 8 例（第 1 步 ≥ 16 例）、
   360px 门槛、reduced-motion 降级、玩法与数值零 diff、商标扫描（排除 `.cursor/skills/**`）0 命中。
