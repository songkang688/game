## 一、现状审美评测（基于 origin/game-1.2 真实代码，`src/games/star-estate/index.ts`）

打分制：草稿 / 能认 / 可爱 / 精美。

| 对象 | 现状代码 | 评分 | 问题点名 |
|---|---|---|---|
| 棋子（角色） | 第 399–405 行：`el.textContent = p.emoji`——棋子就是一个系统 emoji 字符 | **草稿** | 跨平台长相不可控（安卓/iOS/桌面各不同），无立牌感、无朝向、无走格弹跳 |
| 骰子 | 第 389–391、817、955 行：`diceEl.textContent = DICE_FACES[...]` emoji 骰子文字 | **草稿** | 掷骰是地产游戏最高频动作，现在只是换一个字符，无滚动动画、无停格弹跳 |
| 地格 | `render()` 第 486–513 行：`innerHTML` 拼 emoji + 价格 + 色带 `se-tile-band` | 能认 | 色带分组是对的，但格子是「贴 emoji 的白卡」，无地皮/建筑质感 |
| 房屋/酒店 | 第 496–503 行：`se-pip` 小圆点、酒店 `se-pip-hotel` | **草稿** | 盖房子的成就感 = 几个小圆点，必须画成真的小房子 |
| 中心区 | 第 387–397 行：骰子 + 文字预览 + 3 行 log | 草稿 | 棋盘中心是最大的一块视觉空地，现在是文本堆 |
| 棋子移动 | `drawTokens()` 450–471 行：改 `left/top` 百分比 + CSS transition | 能认 | 有平滑位移，但无逐格跳、无落格尘土 |
| 地契抽屉 | `renderDeeds()` 539–568 行：文字按钮列表 | 能认 | 可用，无地契卡片感 |
| 破产/收摊 | 第 460 行 `opacity = "0"` 直接消失 | 草稿 | 玩家收摊无任何仪式感 |
| 结算 | 文本为主 | 能认 | 缺资产条形对比图 |

结论：规则层经过 1.2 多轮 QA 很扎实，视觉层全是 DOM 文本拼装。棋牌类保持 2D，但棋子/棋盘必须精美立体。

## 二、极高质量改进方案（可执行绘制规格）

### 1. 棋子 → 立牌小角色（核心资产）

- 每位玩家一个 24×30px 内联 SVG 立牌：底部椭圆基座（玩家色 `seatColor`，535–537 行已有四色）+ 基座高光 + 上方 Q 版角色（朵朵=粉花小人、星星=金星小人、AI 两位=云朵/月亮小人；圆头大眼小身，2 头身）；
- 替换 `el.textContent = p.emoji`，emoji 保留进 `aria-label`；
- **走格动画**：`drawTokens` 的直线 transition 改为逐格跳（每格 120ms：上抛 6px 抛物线 + 落地压扁 0.9 倍回弹；`prefers-reduced-motion` 时退回现有直线位移）；
- 多子同格错位排布保留（466–469 行 bucket 逻辑不动）。

### 2. 骰子 → 会滚的立体骰

- `se-dice` 区改为两枚 Canvas/SVG 骰子：白底圆角立方体（顶面亮、左右侧面各暗 10%/20% 的伪 3D 三面体）+ 红/黑圆点点数；
- 掷骰动画 0.5s：随机翻面闪动 6 帧 → 停格弹跳 scale 1.15→1 → 双骰同点时金色描边闪（对应「掷同点出小黑屋」规则可读性）；
- `soft` 模式：直接显示结果面，无翻面动画。

### 3. 地格 → 地产卡片

- 每格三层：色带屋顶（保留 `se-tile-band` 但改成带屋檐斜切的「屋顶条」）+ 中部图标 + 底部价签（金币小图标 + 数字，替代裸数字）；
- 拥有者标记 `se-tile-own` 从色点升级为「小旗子」（旗杆+三角旗，玩家色）；
- 抵押 `se-tile-mort`：盖半透明灰罩 + 斜向「抵押中」纸条；
- 车站/公用格加专属底纹（铁轨纹 / 水波纹淡纹理）。

### 4. 房屋 → 真的盖楼

- `se-pip` 圆点改为 SVG 小房子（三角屋顶 + 方身 + 门窗点），1–4 栋横排；满 4 换酒店（两层楼 + 星星招牌，红金配色）；
- 盖房瞬间：新房子从上落下 + 尘土 2 粒（`soft` 关）。

### 5. 中心区 → 星城广场

- 棋盘中心画一张「星城广场」装饰底图（CSS/SVG：环形道路 + 中央喷泉星星 + 四角草地），骰子居中其上；
- 收租/交税时金币飞行动画：从付款方席位卡飞 3–5 枚金币（**金币规格：金黄渐变圆 + 内圈亮环 + 星形压印，不是纯色圆**）到收款方席位卡，0.5s 抛物线；
- log 区改为带气泡尾巴的消息条（最近 3 条，淡入淡出）。

### 6. 席位卡与破产仪式

- `seatEls`（477–484 行）加立牌小头像 + 现金变化滚动数字（涨绿跌红闪 0.3s）；
- 破产：立牌角色播放 0.6s「鞠躬收摊」帧（下弯 15°）→ 变灰坐到席位卡上，不再瞬间消失；席位卡盖「已收摊」印章。

### 7. 结算

- 结算面板加净资产条形对比图（四色横条 + 名次奖杯）、本局最贵一笔租金回放文本。

## 三、2D / 2.5D / 3D 决策

**保持 2D 俯视棋盘**（棋牌规范）。立体感来源：骰子三面体、地格屋顶斜切、立牌基座阴影。禁止棋盘透视旋转、禁止 three.js。DOM+SVG 为主（保留现有 aria 与按钮结构），动画走 CSS transform。
