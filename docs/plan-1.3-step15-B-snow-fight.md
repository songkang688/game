## 三、现状审美评测（先开代码再动笔）

打开 `src/games/snow-fight/index.ts`，绘制入口是 `draw` / `drawSky` / `drawBackdrop` / `drawGround` / `drawFighter` / `drawFoe` / `drawBall` / `drawLanding` / `drawCover` / `drawFort` / `drawChargeBar` / `drawAimArrow` / `drawWindFlag` / `drawPuffs`。已核实的问题：

1. `drawFighter`（约 522 行起）的角色本体就是**一个圆**（`full` 半径），下蹲 = 半径缩放，没有五官朝向、没有投掷手臂、没有围巾手套——雪仗打得再热闹，人是一颗光球；
2. 变雪人惩罚态（534 行起）是两个白圆叠放 + 描边，胡萝卜鼻 / 树枝手 / 纽扣一个都没有，「变雪人」的喜感全靠脑补；
3. 脚下的「站位光圈」是一个黄色正弦椭圆（529–532 行），与雪地语境无关，像 debug 标记；
4. `drawSky` / `drawBackdrop` / `drawGround` 已有天空 / 远景 / 地面分层（这是本款的好底子，保住），但逐行自查配色层次与雪的质感（有没有雪粒、脚印、堆雪细节），把结论记进开工 commit；

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **角色建模** | 圆球升级为「裹成球的小孩」：主体圆保持 `full` 半径（判定不动），加针织帽（阵营色 + 顶球）、围巾（两段飘带，投掷时甩动）、连指手套；投掷三帧：后仰蓄力（手臂后摆 30°）→ 跨步出手（前倾 12°）→ 收势。下蹲态帽子压低 + 手抱头，可爱不惊恐。 |
| **变雪人惩罚态** | 补齐雪人三件套：胡萝卜鼻（橙三角）、树枝手（两侧折线）、三粒纽扣；解冻倒计时画成雪人身上的融化高光从脚往头爬（读既有时长，不改）。 |
| **雪球与弹道** | 雪球加三停径向渐变 + 底部冷阴影 + 随飞行距离滚动的表面雪纹两道；出手瞬间加雪粉喷散 4 颗；落点圈 `drawLanding` 改成雪面凹陷椭圆 + 溅雪 6 瓣（时序沿用既有落点提示）。 |
| **场景升级** | 雪地加：随机雪丘高光斑（seed 固定可复现）、两队脚印淡痕（走过 2s 渐隐）、掩体画成堆雪墙（顶部圆鼓 + 侧面冷蓝阴影 + 被打耗损三阶段缺口，耗损阶段读既有血量）；远景加松树剪影两层视差与飘雪粒子（reduced 关）。 |
| **功能件换皮** | 蓄力条改成「雪球从小滚大」的图形化表达（数值映射不变）；风旗加旗面波浪两帧与风向箭头描边；瞄准箭头加渐隐点阵。 |
| **布局与结算** | 双人 / 对战比分卡片化（圆角 12px、白 72% 底）；胜利结算撒雪花 + 彩带（`sparkle.ts`），失败方雪人也一起笑。 |

- 渐变 / 描边 / 落影统一走 `src/art/kit/`；光源统一左上 45°，雪地阴影一律冷蓝 `rgba(120,150,200,.18)` 而不是黑。
- `prefers-reduced-motion`：飘雪、围巾甩动、滚雪纹全停，保留静态层次与功能提示。
