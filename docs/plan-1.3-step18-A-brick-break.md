## 三、现状审美评测（先开代码再动笔）

打开 `src/games/brick-break/index.ts`，绘制入口是 `draw` / `drawBrick` / `drawMark` / `drawPaddle` / `drawBallWithTrail` / `drawCapsule` / `drawParticles` / `drawPortal` / `renderTop`。已核实的问题：

1. `drawBrick`（约 179 行起）就是**一行 `roundRect` 平涂**加一个 `drawMark` 标记——没有顶亮边、没有底影、没有多血砖的裂纹中间态，砖阵是一张色卡；
2. `drawPaddle`（206–211 行）= 单色 `roundRect`，磁铁模式只是换成绿色——挡板没有立体面、没有磁力线特效；
3. `drawBallWithTrail`（213 行起）的拖尾方向做对了（保住），但球本体预期是纯色圆，自查确认；
4. `drawCapsule` 掉落胶囊、`drawParticles` 碎粒、`drawPortal` 传送门逐个自查：预期是简单几何，把每个的结论记进开工 commit；
5. 背景与边墙（预期纯色）与 `renderTop` 的 HUD 样式也要自查。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **糖果砖块** | 每块砖三层：顶部 35% 高度的亮色带（果冻高光）+ 主体色 + 底部 2px 暗边；外描边 1.5px 深 20%；左上角一粒 2px 圆形光斑。多血砖每掉一档血叠加一层裂纹路径（两段折线，不改血量逻辑）；特殊砖（`drawMark` 的标记）把标记升级为小图标浮雕（内凹阴影）。 |
| **挡板质感** | 三停线性渐变（顶亮 → 主体 → 底暗）+ 两端圆头高光点；磁铁模式加上表面电弧微光（两条抖动细线，reduced 静止为常亮线）+ 球吸附点提示凹槽；接球瞬间挡板下压 2px 回弹（80ms，纯视觉）。 |
| **球体积** | 三停径向渐变（左上高光）+ 速度越快拖尾越长的既有逻辑保留，拖尾改双层（芯亮外晕）；穿透态加星屑环绕 2 颗。 |
| **打碎特效** | `drawParticles` 升级：砖块四角碎片（同砖色小方块 4 片，带旋转抛物线 300ms）+ 星屑 3 颗；连击 5 起画面边缘细彩带一闪（120ms，reduced 关）。 |
| **胶囊与传送门** | 胶囊画成两半色药丸 + 图标 + 下落摆动 ±4°；传送门双环旋转渐变（进口 / 出口互为反色），球进出时门圈涨缩 8%。 |
| **场景与布局** | 背景改上下渐变 + 顶部装饰灯带（关卡主题色）；边墙画内凹槽质感；`renderTop`（分数 / 关卡 / 球数）卡片化一行，球数用小球图标不是数字裸奔。 |

- 渐变 / 描边 / 落影统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：回弹、电弧、彩带、门旋转全停，保留静态渐变层次。

### 四·补一：配色板与图层序（落成常量块再引用）

| token | 色值 | 用途 |
| --- | --- | --- |
| `bkBgTop` / `bkBgBottom` | `#FDEFF5` / `#F3E4F0` | 背景上下渐变 |
| `bkWall` | `#E0D2E8` | 边墙内凹槽 |
| 砖排色带 | 沿用关卡 palette | 砖主体色（数据不动） |
| `bkBrickLit` | 主色 +28% | 砖顶部 35% 亮带 |
| `bkBrickDark` | 主色 -18% | 砖底部 2px 暗边 |
| `bkPaddle` | `#7FB2F0` | 挡板主色（磁铁态 `#8FD98B`） |
| `bkTrailCore` / `bkTrailGlow` | `#FFFFFF` / `rgba(255,214,120,.4)` | 拖尾芯 / 外晕 |
| `bkShadow` | `rgba(93,74,110,.16)` | 统一落影 |

图层序（`draw` 从底到顶）：① 背景渐变 + 灯带 → ② 边墙 → ③ 砖阵 → ④ 传送门 → ⑤ 胶囊 → ⑥ 拖尾 → ⑦ 球 → ⑧ 挡板 → ⑨ 碎片 / 彩带 → ⑩ HUD。

### 四·补二：果冻砖工序单（`candyBrick.ts`，五道工序）

1. 底影：砖下 1px `bkShadow` 线；
2. 主体圆角矩形（圆角 = 砖高 22%）主色平涂；
3. 顶部 35% 高度亮带（主色 +28%，同圆角裁剪）；
4. 底部 2px 暗边（主色 -18%）+ 外描边 1.5px 深 20%；
5. 左上 2px 圆形光斑（砖高 < 10px 时省略，只留亮带）。
多血砖附加：每掉一档血叠一层裂纹路径（两段折线，起点随 seed 固定）；特殊砖标记升级为内凹浮雕小图标（阴影偏移 1px）。

### 四·补三：动效时序表（毫秒写死成常量并被测试引用）

| 动效 | 触发 | 时长 | 缓动 | reduced 行为 |
| --- | --- | --- | --- | --- |
| 挡板下压回弹 | 接球 | 2px、80ms | easeOutBack | 关闭 |
| 磁铁电弧抖动 | 磁铁态 | 两条线 90ms 抖 | step | 常亮直线 |
| 砖碎四角碎片 | 砖碎 | 300ms 旋转抛物线 | easeOutQuad | 不生成 |
| 连击彩带 | 连击 ≥ 5 | 120ms 边缘一闪 | easeOut | 关闭 |

| 门圈涨缩 | 球进出 | 8%、160ms | easeOutQuad | 关闭 |
| 胶囊下落摆动 | 下落 | ±4°、600ms 周期 | sin | 竖直下落 |
