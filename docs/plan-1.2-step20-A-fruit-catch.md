## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **可达性生成** | 生成器必须保证「上一颗落点 → 下一颗落点」的横向距离在篮子速度 × 时间差之内（留 15% 余量）。随机 2000 次生成全部可达（断言）。同帧多颗时，至少有一颗必然可接，其余算奖励。 |
| **磁力与手感** | 篮子有 8px 吸附；水果入篮有轻微弹入动画；连接 5 颗给「稳稳的」倍率。 |
| **水果与道具** | 普通 / 稀有（高分）/ 冰冻（暂停下落 2 秒）/ 磁铁（3 秒吸附增强）/ 辣椒（接到扣一次机会，**要有明显红色 + 形状差异 + 掉落更慢的预警**）。 |
| **双人同屏** | 补 `twoPlayer`：朵朵 `A/D`、星星 `←/→`，两个篮子各接各的，比谁接得多；手机左右半屏。 |
| **无尽「水果雨」** | 速度与密度渐进（seeded 可复现），掉 3 颗结束；成绩 `save.recordEndlessBest("fruit-catch", score)`。 |

## 七、视觉 · 建模 · 手感

- 水果是原创手绘感 Canvas 图形；接住有「咚」的轻音与篮子下压 3px。
