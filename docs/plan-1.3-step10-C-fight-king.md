## 二、极高质量改进方案（可执行绘制规格）

### 1. 角色 → 各有行头的格斗家（核心资产）

- `hero.ts` 每位英雄加 `look` 纯外观字段（发型/头饰/服装二色/腰带色），`drawFighter` 按 look 叠装备层（骨架与判定不动）：
  - 朵朵系：花瓣头饰 + 短裙摆（裙摆随 stride 摆动 1 帧）；星星系：星形发卡 + 披风（跳跃时展开）；其余英雄各配拳套/头巾/护腕等差异件，**剪影两两可辨**；
  - 身体色块改双色（上衣+下装）+ 描边保留（1041 行 ink）；
- 表情扩展：normal/攻击瞬间（咬牙）/受击（><）/眩晕（螺旋眼——替代现有闭眼线的其中一态）/胜利（大笑）5 款，按 phase 查表；
- 拳脚末端加圆手套/鞋头（`limbs()` 末端 lineCap round 已是圆头，补一个亮色端点圆）。

### 2. 打击感 → 分级演出

- 命中：轻招 4 根放射短线 + 白闪点；重招 8 根 + 星形爆点 + 停帧沿用引擎 hitstop；破防：盾碎三角 6 片；
- 击飞落地：地面扬尘 3 团 + 弹地小跳（视觉，物理不改）；
- 出招残影：重招 active 帧留 1 帧半透明轮廓（`reduced` 关）；
- 连击计数：≥3 连击屏幕角弹跳数字（描边圆体）。

### 3. 舞台 → 2.5D 纵深（规范点名）

- 视差从两层扩到四层（远天/远山/近树/前景花瓣，前两层沿用现图元升级为主题剪影）+ **地面纵深带**：擂台地面画 3 条横向渐变带（近亮远暗）+ 中线，producing 站位纵深感；
- 角色接地影已好（保留），加对手距离过近时双影交叠加深；
- `reduced` 改为「静态版视差」（画一帧不动），不再整层消失（921 行改造）——保氛围不保动效；
- 舞台主题查表（按 levels 分段）：樱花山道 / 星空擂台 / 海边木台 / 雪夜灯笼，每主题换视差剪影与地面色。

### 4. 超必杀 cut-in 升级

- `drawSuperCut` 加：斜向速度线 12 根 + 角色特写（放大版头部绘制复用）+ 主题色纵条底 + 0.1s 白闪入场（`reduced` 只显示静态卡 0.4s，闪光去掉）。

### 5. HUD 与结算

- 血条端头加角色头像（复用头部绘制 24px）+ 回合星（画的星形）；能量满槽流光（`reduced` 静态金框）；
- KO：慢放 0.3s（时间缩放仅视觉帧，engine 照常推进则跳过此项改为震屏）+ 胜者胜利姿态 + 彩带 20 片；结算卡显示最大连击/使用招式统计。

## 三、2D / 2.5D / 3D 决策（规范：尽量 2.5D）

**横版 2D + 四层视差 + 地面纵深带的 2.5D**。格斗判定是 1D 距离，禁止透视变形战场；纵深感全部由分层视差与地面渐变承担。禁止 three.js。
