## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **判定窗口** | 明确「钻出 120ms 内 = Perfect、停留期 = Good、缩回中 60ms 内 = 擦边」三档，分数不同；写成纯函数 + 单测。 |
| **谱面化** | 每关一张轻量谱面（出洞时间表 + 洞位 + 类型），数据驱动、可测试、可复现；后段用**节奏型变化**（切分、连打、假动作）而不是单纯加速。 |
| **角色体系** | 补齐：普通鼠、帽子鼠（要打两下）、闪光鼠（高分限时）、**花花兔（不能打，打了扣分并给温和提示）**、群鼠（同时出三只）。 |
| **连击** | 连续命中给倍率，打错 / 漏打清零；倍率封顶。 |
| **无尽「地鼠夜市」** | 谱面无限生成（seeded），密度与节奏型渐进；成绩 `save.recordEndlessBest("mole-pop", score)`。 |

## 六、2.5D / 3D 决策

**保持 2D**。洞与地鼠的位置要一眼对得上手指。

## 七、视觉 · 建模 · 手感

- 命中：地鼠转圈变星星缩回 + `api.play("pop")`；Perfect 有额外光圈。
- 打错花花兔：兔子鼓腮帮子，**文案温和**（「哎呀，那是花花兔，它不参加游戏～」），不批评。
- 手感三件套：命中顿感 3 帧、锤子挥动前摇 60ms、屏幕不震（改用洞口轻微下沉）。
- `prefers-reduced-motion`：关抖动，保留光圈。

## 八、手机 360px
