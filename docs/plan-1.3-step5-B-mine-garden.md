## 二、极高质量改进方案（可执行绘制规格）

### 1. 格子 → 草皮与泥土（核心资产）

- **未翻开**：草皮质感——绿底渐变（`#A8D08C` 保底色，顶 +8% 亮）+ 顶部 1px 高光 + 底部 1px 暗边（微凸起）+ 每格 2–3 根小草叶（伪元素或 SVG 背景，用格子索引哈希决定朝向，避免整齐划一）；相邻格草色 2 档轻微交替（棋盘格 3% 明度差）；
- **翻开（空地）**：泥土色内凹（`#F3F7EA` 改暖土色 `#F5EFDF`，inset 阴影 1px）+ 随机 1–2 个小石子点缀（哈希决定）；
- **hover/光标**：草皮格微亮 + 小铲子光标提示（`mn-cursor` 描边保留并加圆角）。

### 2. 刺种 / 旗 / 问号 → 画出来的图标

- 刺种开花 `🌼` → SVG 五瓣花（花瓣白粉渐变 + 黄芯 + 花芯高光点），输局揭开时每颗播放 0.3s「破土绽放」两帧（土裂→花开），沿用现有逐颗延时节奏（`bloomStepMs` 不改）；
- 旗 `🚩` → SVG 小旗（木杆 + 红色三角旗带一道褶皱高光），插旗 0.2s 从上插入 + 微弹；错插 `🍀` → SVG 四叶草；
- 问号 `❓` → 画的木牌问号（小木牌 + 刻字）；
- 所有 emoji 移入 `aria-label` 文案，不再作为视觉主体。

### 3. 连锁翻开 → 波纹开垦

- 大片连开时按与起点的曼哈顿距离分批翻开视觉（每圈延迟 30ms，`reduced` 时一次性）：格子翻开瞬间草皮「掀开」动画（scaleY 1→0.1→1 换土色，0.15s）+ 偶发 1 粒草屑粒子；
- 逻辑上仍是一次性翻开（`board.ts` 不动），只是 `paintCell` 的视觉延迟队列。

### 4. 数字 → 浮雕种子牌

- 数字保留 `hintColor` 色系，但加 0.5px 白色文字投影（浮雕感）+ 数字 8 档色的底部各配一个极小种子点图标（数字越大点越多上限 3，形状第三通道）。

### 5. 小地图 → 花园鸟瞰

- `drawMini()` 三色升级：未开=深草绿、已开=浅土色、旗=小红点（2×2 像素旗形），加 1px 圆角边框与标题「🗺 花园鸟瞰」；光标框保留红色。

### 6. HUD 与结算

- 旗预算 `🚩 N` 徽章加旗形 SVG 前缀；进度 `🌼 %` 改成小花进度条（花苞→开花随进度）；
- 胜利结算：整片花园盖一层 0.8s 花开波（每隔 40ms 一列格子上冒小花，≤ 30 朵，`reduced` 关）+ 面板配大花环；
- 失败结算：文案保留温柔口径，背景加一只浇水壶插画（SVG ≤ 15 笔）。

## 三、2D / 2.5D / 3D 决策
