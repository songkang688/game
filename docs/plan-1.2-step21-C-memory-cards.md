## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **翻牌动画** | 3D 感翻转用 CSS `rotateY`（180–220ms）或 Canvas 横向压缩模拟；**中途不能露馅**（背面到正面的切换必须在 90° 那一帧）。狂点保护：动画期间忽略新输入，但记录最后一次点击在结束后生效。 |
| **主题包** | 至少 6 套主题（动物 / 水果 / 交通 / 乐器 / 天气 / 朵朵一家），每套 ≥ 12 种图案，全部原创 Canvas 绘制。 |
| **进阶机制（后段章节）** | 会移动的牌（每 10 秒交换两张位置，有预警）、三连牌（三张一组）、单面牌（背面也有区别的干扰）。 |
| **辅助档** | 关外可选「记忆辅助」：翻错时短暂显示上一张位置（低年级），开启后仍可拿三星但结算显示辅助徽章。 |
| **无尽「记忆挑战」** | 对数递增，错误 3 次结束；成绩 `save.recordEndlessBest("memory-cards", pairs)`。 |

## 六、2.5D / 3D 决策

**2D + CSS 翻转的伪 3D 卡片**即可，不引入 3D 渲染。

## 七、视觉 · 建模 · 手感

- 配对成功：两张牌一起弹一下 + 星星 + `api.play("coin")`，然后淡出留空位（不塌陷）。
- 配对失败：轻微摇头动画后盖回，**文案不批评**。
- 卡背图案统一且好看，正面图案 + 名称双通道（帮助识别）。
- `prefers-reduced-motion`：翻转改为淡入淡出，仍保留 90° 切换的时序语义。

## 八、手机 360px

- 卡片最小 56×72px，整盘不滚动（大盘自动缩小间距）；对数 / 步数一行显示，字号 ≥ 14px。
