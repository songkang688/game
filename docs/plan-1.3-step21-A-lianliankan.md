## 三、现状审美评测（先开代码再动笔）

打开 `src/games/lianliankan/index.ts`，渲染入口是 `renderTop`（约 509 行起）与牌面渲染段。已核实的问题：

1. `renderTop` 一行三个 emoji（🧸⏰🔀💡🔍，509–518 行）——顶栏信息全是「emoji + 文本」裸排，无卡片层次；
2. 牌面图案预期是 emoji 字符直出（自查牌面渲染段确认）：连连看的核心视觉就是牌，牌却是系统字体贴片，配对的「一眼认同款」体验被字体渲染差异拖累；
3. 牌块本体预期是纯色圆角 DOM（自查 `llk-` CSS 类）：没有瓷砖厚度、没有选中抬起、没有 hover 反馈层次；
4. **连线消除的路径动画**是本款灵魂，自查现状：预期是简单线条或瞬间消失，把「连线怎么画、拐点怎么表现、消除有没有过程」的结论记进开工 commit；
5. 时间紧迫的 `llk-hurry` 状态（512 行）画法自查。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **麻将砖质感** | 牌块改三层：顶面（米白渐变 + 圆角 10px）+ 侧沿（底部 3px 暖灰立面，2.5D 厚度）+ 落影（1px 软影）；hover 抬升 2px、选中抬升 4px + 主题色描边 + 底光；已消除的格位留极浅凹槽痕迹（盘面「越玩越空」的进度感）。 |
| **牌面图标** | emoji 替换为 SVG 图标组（≥ 12 种原创小图案：花 / 星 / 伞 / 铃 / 果 / 云 / 蝶 / 帽 / 杯 / 月 / 鱼 / 叶），统一双色渐变 + 1.5px 描边 + 左上小高光；同款图案在任何机器上渲染一致。可复用 `memory-cards/art.ts` 的 `drawIcon` 思路但**不去改那个文件**——在 kit 里落共享版。 |
| **连线流星化（灵魂）** | 配对成功时沿连通路径画流星光带：SVG polyline 圆角拐点 + 渐变描边（头亮尾淡）+ 3 颗星尘沿路径滑过（240ms）；随后两张牌同步翻转缩小消散成星屑。路径坐标**必须用既有连通判定算出的拐点**，一个点都不许自己算。 |
| **提示与洗牌** | 提示的「指个方向」保留语义，视觉升级为盘面对应区域泛柔光 2s；洗牌时全部牌小幅腾空转位（180ms 交错，reduced 瞬换）。 |
| **场景氛围** | 背景改成茶室木桌语义：木纹底 + 四角茶点小装饰；`llk-hurry` 时计时卡片变暖橙 + 轻微心跳缩放（reduced 只变色）。 |
| **布局与 HUD** | `renderTop` 卡片化：剩余对数 / 计时 / 洗牌 / 提示四枚圆角卡片一行，按钮加按下下沉 1px。 |

- 色板走 `src/art/kit/palette.ts`；SVG 图标落 `src/art/kit/icons.ts`（若别人已落则只增图标不改已有导出）。
- `prefers-reduced-motion`：流星、腾空、心跳全停，保留静态层次与柔光提示。
