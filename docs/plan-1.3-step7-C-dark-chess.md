## 二、极高质量改进方案（可执行绘制规格）

### 1. 牌背 → 真正的暗棋背

- `🌸` → SVG 牌背：深棕木底渐变 + 中央圆形「暗」字印章（或团花纹）+ 双线描边 + 底部 2px 厚度阴影；红蓝双方翻开前**牌背完全一致**（信息红线）；
- 牌背加极淡木纹 2 道（哈希相位，避免 32 张一模一样的死板）。

### 2. 翻开的棋子 → 图形化兵种

- 保留汉字主体（认字教学价值），四周升级：
  1. 外圈圆形棋子造型：象牙底 + 红/蓝阵营环 + 底部厚度阴影（中国象棋棋子制式）；
  2. **战力可视化**：汉字下方一排小点（帅 7 点 → 兵 1 点，`RANK` 数据直读）——不认字/记不住相克的孩子按点数比大小；炮加小弧线标记（隔子吃的特殊性）；
  3. 汉字用双钩描边（红方深红字金描、蓝方深蓝字银描）。
- 翻子动画升级两面感：前半段（0–90°）显示牌背、后半段（90–180°）显示棋面（两个 span 层 backface-visibility 或 JS 中点换面），沿用 `dc-flip` 时长与 `animate()` 回调时序。

### 3. 吃子 → 相克表达

- 吃子：攻方滑向目标（120ms transform）→ 目标 `dc-gone` 缩小淡出 + 3 片花瓣飘出；
- **提示教学**：选中己方子时，`dc-can` 高亮里可吃的目标格角落显示「↓」小箭头（我方点数 ≥ 对方）；炮的跳吃路径画虚线弧（仅视觉提示，读 `movesFrom` 现有结果，不算新规则）；
- 被将死/困毙无表现 → 结算时输方剩余棋子整排变灰鞠躬（rotate 15°）。

### 4. 棋盘与记牌面板

- 棋盘加 6px 木框 + 桌面底色（米色 → 淡木纹渐变）；格子底色微调为「石板格」（交替 2% 明度差）；
- 记牌面板 `dc-count` 升级：每兵种一个迷你棋子图标 + 数字（替代纯文字），翻光的兵种显示灰色小图标划线——保留 `counterLine` 的排序逻辑；
- 和棋倒数/手数上限 chip（42–44 行）保留双色区分，加小沙漏图标。

### 5. 结算

- 胜利：胜方棋子列队 + 金花瓣雨（≤ 12 片，`reduced` 关）；和棋：双方各留一枚棋子碰杯（tilt 15° 相对）。

## 三、2D / 2.5D / 3D 决策

**保持 2D**（棋类规范）。翻面用 CSS rotateY 的伪 3D 已够；棋子立体感 = 圆子制式 + 厚度阴影。禁止 three.js。
