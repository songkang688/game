## 二、极高质量改进方案（可执行绘制规格）

### 1. 棋子 → 军衔徽章棋子（核心资产）

- 每颗棋子三层（保持 DOM button + `faces[p]` 结构）：
  1. 底座：现有双方渐变保留（朵朵暖橙/星星蓝），加 1px 深色描边 + 底部 2px 厚度阴影（立牌感）；
  2. **军衔条**：汉字上方加一排小星/杠（SVG）——司令 3 星、军长 2 星、师长 1 星、旅长 3 杠、团长 2 杠、营长 1 杠、连排长小点、工兵扳手小图标、地雷圆雷带引线、炸弹圆炸弹、军旗小旗——**不认字的孩子也能比大小**；
  3. 汉字保留（`LABEL[kind]`），字体加极淡浮雕投影。
- 盖着的子 `🎖️` → SVG 牌背：深色底 + 五角星徽章压纹 + 双线边框，双方牌背同款（不泄露信息）。

### 2. 地形 → 沙盘化

- 行营 `⛺` → SVG 帐篷图标（三角帐 + 门帘）+ 格底淡绿圆环（保护区暗示）；
- 大本营 `🏠` → SVG 碉堡（拱门 + 旗杆小旗，双方旗色不同）；
- 铁路线 `jq-rail` 升级为真铁轨（两根钢轨 + 枕木短线，CSS repeating-gradient 即可）；公路保留细线；
- 上下半场底色之上叠加极淡地形纹（等高线弧 2–3 根，5% 透明）。

### 3. 对局反馈

- 走子：棋子滑动位移（120ms transition，现 class 切换基础上补 transform）；
- **吃子对撞**：攻方滑入后两子相碰 0.25s——赢方原地一圈金光，输方 `jq-gone` 淡出前加左右摇晃 2 次；同归于尽（炸弹）：两子同时弹开淡出 + 一朵卡通烟云（SVG，非写实爆炸）；
- 翻开（`jq-open`）：牌背 rotateY 翻面 0.2s（`reduced` 直接换面）；
- 选中/目标/光标改三形状：选中金色实框、可走点绿色圆点角标、光标虚线框（保留现配色，色弱三通道）。

### 4. HUD 与结算

- 顶部双方军旗徽标 + 剩余棋子数（图标 + 数字）；
- 胜利：胜方军旗升旗动画 0.6s（旗子从杆底升到顶 + 飘动 2 帧）+ 结算面板军功章图。

## 三、2D / 2.5D / 3D 决策

**保持 2D 俯视**（军棋规范）。立体感 = 棋子厚度阴影 + 牌背压纹；缩放平移是长盘刚需（250–278 行），装饰不得增加合成层导致手势卡顿。禁止 three.js。
