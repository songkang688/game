## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **小猫立绘（核心）** | 自绘 SVG 小猫（参数化）：圆脸 + 立耳（内耳粉）+ 大眼 + 短须三根 + 圆身 + 卷尾；**三态立绘**随 `curePlan` 进度切换：待照护（耳朵耷拉 + 眼睛半闭 + 头顶小旋涡）、照护中（眼睛睁开 + 尾巴轻摆两帧）、痊愈（跳起 + 眼睛弯月 + 头顶爱心）；毛色按局随机三选一（橘 / 灰 / 三花，花纹层参数化）。reduced：三态静止切换。 |
| **步骤链图标化** | 「1.xx → 2.xx」文本链升级为步骤卡链：每步一张圆角小卡（道具图标 + 步骤名 + 状态：待办灰 / 进行中亮边呼吸 / 完成打勾绿）+ 卡间箭头描边化；完成一步该卡盖上小爪印章。 |
| **照护道具图标** | 每个操作按钮配自绘图标（奶瓶 / 梳子 / 澡盆 / 毛巾 / 体温计 / 玩具铃铛，统一双色渐变 + 描边）；选对道具时该图标飞向小猫 + 使用动画（如梳子在背上刷两下）；选错时小猫歪头「喵?」（不批评）。 |
| **小屋场景** | 背景搭猫咪小屋：窗（阳光斜带）+ 地毯（椭圆双色）+ 猫窝 + 猫爬架剪影 + 墙上相框；痊愈次数越多（读既有进度）窗台摆件越多（纯装饰陈列）。 |

### 4.2 小猫立绘工序单（kittySvg.ts）

1. 接口 `kitty(state, fur, size)` 纯函数返回 SVG：`state ∈ {sick, caring, cured}`、`fur ∈ {orange, gray, calico}`；
2. 脸：圆脸（毛色渐变顶亮 8%）+ 立耳两只（内耳 `earPink` 三角）+ 大眼（虹膜圆 + 高光两点）+ `nosePink` 小三角鼻 + 短须每侧三根（1px 弧线）；
3. 身体：圆胖椭圆 + 前爪两只搭地 + 卷尾一条（贝塞尔 S 形）；胸口浅色毛斑；
4. 三态差异：sick = 耳朵下垂 25°、眼睑半闭、头顶灰色小旋涡；caring = 眼睛全开、尾巴摆动两帧（±12°）；cured = 四爪离地跳起 6px、弯月眼、头顶爱心一颗；
5. 花纹层：橘猫三条背纹弧、灰猫尾环两圈、三花随机两块斑（斑位参数固定两套避免闪变）；
6. 统一 2px 深毛色描边 + 底部椭圆投影；痊愈跳起时投影缩小 20%。
