## 五、完整规则（帧数据驱动，全部纯函数）

- 60 逻辑帧/秒。每招三段：`startup / active / recovery`，判定框只在 active 生效。
- 命中量：`hitstun`（受击硬直）、`blockstun`（格挡硬直）、`hitstop`（顿帧 3–8 帧，`prefers-reduced-motion` 下为 0）。
- 格挡：按后方向自动挡。上段（跳攻）蹲挡挨打；下段站挡挨打；中段都能挡。投技不能挡，但要贴近且对方不在投无敌帧。
- **跳投**：空中按投技键，落地前判定；被投中是「抱起来转个圈」再放下，卡通化。
- 能量：出招、命中、被挡都涨（挡少）。LV1 超必 50，LV2 100。超必有明确的无敌帧写进帧表。
- 元气 ≤ 0：本回合结束。BO3 先赢两回合者胜。时间耗尽比元气；元气相同判该回合重来（对战）或按剩余时间判（闯关）。
- **无限连防护**：连段内 hitstun 递减 + juggle 衰减 + 超过 8 段强制倒地。必须单测。
- 每名角色至少：`5L 5H 2L 2H jL jH` + 投技 + 2 个必杀 + LV1/LV2 超必。帧数据放纯数据表 `frames.ts`。
