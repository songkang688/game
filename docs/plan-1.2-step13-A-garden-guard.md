## 五、模式矩阵

闯关 188 保留（**前 99 关波次数据不许改**）；无尽补做；对战不做（同屏塔防对抗对孩子太复杂，写明理由）。

## 六、2.5D / 3D 决策

**保持 2D 俯视 / 斜俯视**。塔的射程圈与路径必须精确可读；只允许地形贴片有轻微高低差描边。

## 七、视觉 · 建模 · 手感

- 选中塔要显示射程圈（半透明），拖拽预览时非法格子明确变红并给原因。
- 敌人受击是「弹开 + 星星」，被清除是「变成花瓣飞走」，**无血无伤**。
- 波次开始 / 结束、最后一只敌人被清都有独立提示音（用 `api.play`）。
- `prefers-reduced-motion`：关闭抖动与闪烁，保留状态变化。

## 八、手机 360px

- 塔选择条横滑一行、图标 ≥ 44px；升级面板从底部弹出，不遮当前格子。
- 生命 / 金币 / 波次一行显示，字号 ≥ 14px，不横向溢出。

## 九、平台接线

- 自建战役地图就提供 `openCampaignLevel(n)`；接 `api.initialLevel` 与 `?level=`，越界 clamp；Skip 走 `getLevelExtras().requestSkip`，本关 0 星并解锁下一关。
- `meta`：补 `"endless"`；`platform` 按实测填；`blurb` 与事实对齐。
