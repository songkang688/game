## 三、现状审查（先读代码，回复里逐条回答）

必须通读 `src/games/gomoku/{ai.ts,puzzles.ts,index.ts,meta.ts,guide.ts}` 与全部 `*.test.ts`。已知硬伤：

1. **AI 只有 4 档**：`export type Difficulty = "easy" | "normal" | "smart" | "master"`（1.1 第 5 步加的「棋灵象·大师」是最高档）。**没有「菜鸟」，也没有「地狱」**，梯度不成立。
2. **188 道残局是「按主题参数化展开」**：`puzzles.ts` 里 `PLANS.flatMap(...)` 用对称变换（翻转 / 旋转 / 平移）把一批母题铺成 188 道。数量够了，**解局质量不够**：同一母题的 8 个变体本质是一道题，缺少「唯一胜点」「三手杀」「四手杀」「抓禁手」「先手弃子」这类真正的解题分类。
3. **禁手（三三 / 四四 / 长连）**是否实现、是否可开关、是否进过残局，必须实测确认。
4. **落子无确认**：手机上点下去就落子，误触毁一盘。
5. **提示**几乎免费，残局里点提示等于给答案。
6. **跳关**：残局有自己的解锁链，`getLevelExtras().requestSkip` 与「直开第 N 题」是否接通要确认。
7. **动画**：落子基本瞬现，五连没有沿路径点亮，禁手只弹文字。

## 四、规则与通行体验（写成纯函数，不许只写进文案）

- 15×15 标准盘（教学可切 9×9），黑先，横竖斜连续五子胜，盘满和棋。
- **无禁·自由**（默认，给低年级）：长连也算胜。
- **禁手规则**（给高年级，可开关，只约束黑）：
  - 三三：一子同时构成两个及以上活三；四四：同时构成两个及以上冲四 / 活四；长连：黑六子及以上。
  - **五连优先**：黑同时成五与踩禁手 → 判黑胜。
  - 白方长连仍算胜。三三 / 四四由白方「指出禁手」触发（UI 给 8 秒按钮，超时视为放弃）。
- 活三 / 眠三 / 活四 / 冲四 判定各配至少 4 张棋谱用例。
- 解局定义：给定残局 + 行棋方 + 限步，必须在 N 手内成五或抓禁；**解唯一或解集明确**，禁止随便下一手也能过。
- 结构参考（只看结构，不引依赖、不带商标）：常见开源五子棋的棋盘位棋 / Zobrist 置换表 + 极小极大 + 迭代加深。**不要上神经网络。**

### 人机 6 档（菜鸟 → 地狱，硬性）

档位 id：`novice | easy | normal | smart | master | hell`；中文名原创（棋灵苗 / 喵 / 狐 / 鹿 / 象 / 渊之类，**沿用已有档的中文名不要改**，只补首尾两档）。

| 档 | 行为 | 搜索 |
| --- | --- | --- |

## 六、2.5D / 3D 决策

**保持 2D。** 立体棋盘会挡住交叉点、破坏读盘，得不偿失。只允许木纹底 + 轻投影。

## 七、视觉 · 建模 · 手感

- 棋盘：浅木纹 + 粉彩交叉线，5 个星位点；黑白子改成「朵朵墨子 / 星星珠子」的原创质感，不要纯黑白刺眼。
- 落子：140–180ms 缩放落下 + `api.play("tap")`；`prefers-reduced-motion` 下瞬落但保留音效。
- 五连：沿连珠路径依次点亮，不要整盘闪。
- 禁手被指出：该子轻抖一次 + 说明「这里是三三，换一个点试试」。
- **落子确认**（硬性）：默认手机开、桌面关。点交叉点 → 半透明预览 → 再点同点或按「落下」才提交；点别处取消；双人同屏两边都要确认。
- **提示限次**：自由对战每局 3 次、解局每题 1 次（用掉不给三星）；提示只高亮区域并说「往这附近想想」，**不许直接报坐标**。
