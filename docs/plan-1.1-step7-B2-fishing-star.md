## 文件划分

- `meta.ts`：纯数据，首页卡片用，不 import 玩法代码。
- `logic.ts`：全部纯函数 —— 抛竿蓄力曲线、水层判定、鱼种图鉴表（≥20 种原创鱼）、
  **张力拉扯判定**（断线 / 跑鱼 / 收竿成功）、计分与连击、图鉴存档序列化。
- `levels.ts`：8 个主题章节合计 188 关的确定性关卡生成器 + 评星。
- `guide.ts`：8 条章节攻略 + 通用心得，只讲方法不给答案。
- `index.ts`：顶部 `export { meta } from "./meta"`，导出 `mount(api)`；
  开场模式选择（闯关 / 无尽 / 图鉴），闯关走 `level99.ts` 的 `mountLevelGame`。
- `logic.test.ts` / `levels.test.ts`：合计远超 15 个用例，张力边界与 188 关章节和都要断言。

## 玩法回路

1. **抛竿**：按住蓄力，力度条来回摆动，松手定深度；深度决定能碰到哪一层的鱼。
2. **等咬钩**：该水层按稀有度权重抽一条鱼咬钩。
3. **拉扯**：按住收线张力涨、松手张力落；张力冲顶断线，长时间过松跑鱼，
   进度拉满即收竿成功。张力判定 `stepFight` 是纯函数，逐帧可重放。
4. **结算**：按目标（钓够几条 / 攒够分数 / 钓到指定鱼）判胜负，评 1–3 星。
