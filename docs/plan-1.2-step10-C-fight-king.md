## 四、通行体验（2D 格斗基础，儿童化）

- 招式三段：startup / active / recovery；命中框只在 active 帧存在。
- 命中硬直（hitstun）与防御硬直（blockstun）决定「谁先能动」，必须是数据表里的数字，不是手写魔法值。
- 取消：只有取消表里允许的路线（轻 → 重 → 必杀）才能连。
- 无限连防护：连段伤害递减 + 段数上限（保持 6），并加**受身 / 倒地无敌**帧。
- 无血表现：元气条、星星爆、眩晕转圈；**禁止伤口、血迹、死亡描写**。

### AI 加到 5 档

在现有档之间插入「会跳会投」和「会防反」两档。最高档留有余地——**地狱级深度是新格斗那款的定位**，本款最高档做到「稳定压制高手档、但会给孩子留反打窗口」即可。固定 seed 下高档胜率显著高于低档，写成断言。

## 六、2.5D / 3D 决策

**保持 2D 侧视。** 只允许背景加一层视差与前景轻粒子；**判定绝不改成 3D**（会毁掉帧数据的可预测性）。

## 七、视觉 · 建模 · 手感

- 命中顿帧 4–8 帧（`prefers-reduced-motion` 下为 0），命中特效用星星与光圈。
- 防御成功有金属亮边 + `api.play("tap")`；破防有明显不同的音与闪。
- 眩晕、倒地、起身各有独立姿态，不许共用一张图。
- 超必杀演出 ≤ 1.2 秒，可跳过（连点任意键）。

## 八、手机 360px

- 摇杆不许盖住元气条与连段计数；轻 / 重 / 必杀 / 防御四钮热区 ≥ 44px 且互不重叠。
- 角色名过长要缩写，不许把 HUD 顶出屏幕；对战倒计时字号 ≥ 16px。

## 九、平台接线

- 格斗塔 `openCampaignLevel(n)` 直达第 N 层；接 `api.initialLevel` 与 `?level=`，越界 clamp。
- Skip 走 `getLevelExtras().requestSkip`，成功后本层 0 星并解锁下一层。
- `meta.platform` 建议 `"both"`（手机有触屏控件），按实测填；`blurb` 与事实对齐。
