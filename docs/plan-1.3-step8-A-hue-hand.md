## 二、极高质量改进方案（可执行绘制规格）

### 1. 卡面 → 印刷质感卡（核心资产）

- `paintCard` 升级为四层（保持函数签名与 DOM button）：
  1. 卡底：主色对角渐变（左上 +12% 亮）+ 2px 白色内框 + 圆角 10px；
  2. 中央白椭圆保留但改斜切椭圆（UNO 制式 −20° 旋转）+ 椭圆内主色数字/图标；
  3. **功能牌图标**（SVG 替代文字缩写）：跳过=圆圈斜杠、反转=双弯箭头、加二=两张小叠卡、万能=四色花瓣扇、加四=四色扇+「+4」；数字牌保留大数字 + 底部小花色点缀；
  4. 角标双处保留（286–298 行结构），字体加细描边。
- 万能/加四：卡底改四色花瓣旋转渐变（conic-gradient 或四块 SVG 扇形）——「花色接龙」的「花」落在这里。
- 不可出 `hh-card-dim`：去饱和灰罩保留。

### 2. 牌背 → 花背卡

- `🂠` 与 `hh-back-c` 统一为 SVG 牌背：深紫底 + 中心四色小花 logo + 细白双框；牌堆显示 3 张微错位叠放 + 数量徽章；
- 对手手牌条 `hh-backs` 用缩小牌背（≤ 10 张排列）。

### 3. 桌面与动画（核心体验）

- 桌面中心区：弃牌堆顶牌下面垫 2 张随机微旋转的历史牌（−6°/4°，出过牌才有），营造牌桌堆叠感；
- **出牌飞行**：手牌 → 桌面中心 0.3s 弧线飞行 + 落定微旋转（每张随机 ±5°）；对手出牌从其头像区飞出；
- **摸牌**：牌堆 → 手牌 0.25s 飞行（对手摸牌飞向对手区，牌背朝上）；叠加惩罚（一次抽 N 张）时 N 张连续快速飞出（间隔 60ms）；
- 变色仪式：万能牌选色后 `colorBar` 播 0.4s 色彩波纹扩散（旧色→新色，`reduceMotion` 直接切）；
- 「就一张!」气泡加弹跳入场；点破成功时对手区抖动 + 惩罚牌飞行。

### 4. HUD 与结算

- 颜色条加当前色大圆点呼吸（`reduceMotion` 静态）；剩余手数低警示 `hh-turns-low` 保留；
- 结算：名次列表带头像 + 剩余手牌小图；胜者卡牌扇形展示 + 彩带。

## 三、2D / 2.5D / 3D 决策

**保持 2D**（牌类规范）。立体感 = 卡片厚度阴影 + 堆叠微旋转 + 飞行动画；禁止 3D 翻牌库、禁止 three.js。DOM 架构保留（按钮语义 + `scrollIntoView` 光标跟随，587–589 行注释的行为不能坏）。
