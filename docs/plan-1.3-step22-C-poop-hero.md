## 三、现状审美评测（先开代码再动笔）

打开 `src/games/poop-hero/index.ts`，绘制入口是 `render` / `drawHero` / `drawMonster` / `renderHud`。已核实的问题：

1. `drawHero`（661 行起）的超人有披风 / 眼罩 / 徽章的骨架，但**通体没有一处渐变**：披风两层纯色（683–696 行）、身体一个 `roundRect`（707 行）、头一个圆（720–723 行）——「超人」的英气全靠脑补，主管说的「太简陋」句句属实；
2. 挥扫帚就是两个 `roundRect` 拼的直棍（748–757 行），没有挥动残影、没有握持手；
3. 冲刺气流直接贴一个 💨 emoji（764 行）——英雄时刻用系统字符打发；
4. 没有奔跑姿态：跑动 / 站立 / 冲刺画面一模一样，只有 x 在动；
5. `drawMonster` 的豆豆怪（769 行起）配色注释明确「糖果色不搞脏」——底子可爱（保住），但清扫完成变花也是 emoji `FLOWERS[]`（779 行）；`render` 的背景 / 地面与 `renderHud` 自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **超人精修（核心）** | 全面上渐变与细节：披风双层各自线性渐变（外层主色顶亮 → 底暗、内层衬色）+ 边缘 1px 亮边，随速度三段飘动（静止垂落 / 跑动后飘 / 冲刺水平拉直）；身体加胸口菱形高光 + 腰带（双色 + 圆扣）；头部加发型（前额三撮小刘海露在眼罩上方）+ 眼罩加反光斜杠 + 下巴阴影；手套 / 靴子色块收边。 |
| **奔跑姿态** | 三态绘制：站立（微呼吸 ±1px，reduced 停）、奔跑（身体前倾 10° + 两腿交替摆 4 帧 + 披风后飘）、冲刺（前倾 18° + 残影两帧 + **自绘星星尾流**替换 💨 emoji：3 颗渐隐小星沿轨迹）。判定盒 `PLAYER_W/H` 不动。 |
| **扫帚升级** | 扫帚画成魔法扫帚：木柄渐变 + 金色捆环 + 帚毛扇形（8 根须状线）；挥动时帚毛弯曲 + 弧形残影一道 + 接触豆豆怪瞬间星花 4 颗；扫除判定窗口 `sweepT` 时序不动。 |
| **豆豆怪与变花** | 豆豆怪保住既有糖果色画法，加三停渐变体积与被扫中的「转圈眩晕星」；清扫完成的 emoji 花替换为自绘五瓣花（花心渐变 + 展开动画 3 帧，reduced 一帧）。 |
| **章节主题场景** | 按 `world.def.chapterIndex` 轮换背景：街道（路灯 + 橱窗剪影）、公园（树 + 长椅）、星空屋顶（烟囱 + 月亮），双层视差；地面加扫过区域「发亮干净带」的渐变痕迹（纯装饰）。 |
| **布局与 HUD** | `renderHud` 卡片化（进度 / 连击 / 章节）；连击时超人徽章发光脉冲。 |

- 渐变 / 描边 / 星花统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：飘动、残影、尾流、脉冲全停，保留静态渐变与层次。
