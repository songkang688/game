# 1.2 第 24 步 · B 档 —— `math-farm`「算数小农场」升级计划(窗口 5)

> 执行分支:`game-1.2-window5`。独占目录 `src/games/math-farm/**`,一个字都不碰 `clock-house`(A 档)与 `pinyin-train`(C 档)。
> `quiz99.ts` / `speech.ts` / `level99.ts` / `src/ui/parentAuth.ts` 是公共资产,**只读**。CSS 前缀本款用 `mtf-`,只许追加,不改别人的规则。
> 一句话目标:**把「20 以内加减 + 一点乘除分数」补成一整套小学数学**——九类题型各有生成器与校验器、干扰项全部来自典型错误、连错给方法提示再给拆一步、关末错题回顾。

## 一、现状审查(动代码前先把基线读清楚)

| 问 | 现状 |
| --- | --- |
| 题型有哪些,到六年级了吗 | 13 个 `kind`。前 99 关 6 类:数一数 `count`、加 `add`、减 `sub`、填空 `missing`、比大小 `compare`、连加连减 `chain`;第 100–188 关 7 类:乘 `mul`、整除 `div`、带余除法 `divmod`、分数 `frac`(比大小 / 约分 / **同分母**加减)、一位小数 `dec`(只有加减)、括号混合 `paren`、两步应用题 `word`。**离六年级还差:竖式进退位、异分母通分、小数乘除、百分数与折扣、比与比例、简单方程、行程 / 单价 / 面积三类应用题、找规律**——整整九个缺口里缺了七个 |
| 会不会出超纲题 | 目前**不会出负数、不会出除不尽**:`qSub` 用 `b = randInt(0, a)`、`qDiv` 先摇商再乘回被除数、`qDivMod` 先摇余数再拼被除数、`qDec` 走「十分之几的整数」通道躲开浮点毛刺、`qParen` 对非整数结果直接 `continue`。**但这些约束是散在各生成器里的 `while` 与 `continue`,没有一个统一的校验器**,新加题型很容易漏一条;而且 `qFrac` 同分母加减的结果**不保证最简**(2/8 + 2/8 会答 4/8) |
| 干扰项怎么造 | 两套都偏随机:前 99 关 `numChoices` 取 `answer + randInt(-3, 3)`;第 100 关后 `bigChoicesFor` 取 `answer ± pick([a, b, 10, 1, a+b])`。**没有一个干扰项是从「孩子会怎么错」推出来的**——不会出现「忘记进位」「约分只约了一半」「打八折算成付两成」这种真正有教学价值的错项 |
| 188 关难度曲线 | 靠 `CHAPTERS` 十章 + `kindPool(level)` 的 if-else 阶梯 + `questionCount(level)`(前 99 关 4→7 题,后 89 关 6→10 题)。**没有一张能读、能断言的表**,「第 150 关到底在练什么」得翻代码 |
| 朗读 | 走公共 `quiz99` + `speech`:切题自动读 `ask`、答对答错读评语、结算浮层由 `level99` 朗读整句、「🔈 再听一遍」按钮。没有中文语音包时 `speechReady()` 为 false,按钮保持隐藏、全程静默,**文字全在,降级正常** |
| `guide.ts` 泄题吗 | **不泄**。10 条章节条目全是方法与自检思路,没有一个得数;全局 `copy.test.ts` 的 `ANSWER_WORDS` 与 `EQUATION_RE` 也在盯着 |

## 二、本步要落地的六件事

1. **题型补齐到六年级(九类,每类一个生成器纯函数 + 一个校验器)**
   - ① 四则混合(含括号)`paren`:补两级运算与「先乘除后加减」的对照题。
   - ② **新增** 竖式进退位 `vertical`:两三位数进位加 / 退位减,题面就是竖式。
   - ③ 分数 `frac`(比大小 / 约分 / 同分母)+ **新增** 异分母通分 `fracLcd`。
   - ④ 小数四则:`dec`(加减,保留)+ **新增** `decMul`(乘除,结果明确保留一位小数)。
   - ⑤ **新增** 百分数与折扣 `percent`:求一个数的百分之几 / 打折后的价 / 求百分率。
   - ⑥ **新增** 比与比例 `ratio`:化简比 / 按比分配 / 解比例。
   - ⑦ **新增** 简单方程 `equation`:`x + 3 = 8` 这一类,含加减乘除四种逆运算。
   - ⑧ 应用题 `word`:保留 1.1 的四种农场情境,**新增行程 / 单价 / 面积**三类。
   - ⑨ **新增** 找规律 `pattern`:等差 / 等比 / 二阶等差 / 前两项相加。
   - 1.1 的 `mul` / `div` / `divmod` 续写保留,一并纳入新的生成器 + 校验器体系。
2. **生成器约束写成一个校验器,而不是散在 while 里**:结果非负、除法整除(或明确保留一位小数)、分数结果最简、比是最简整数比、应用题语境是农场且算式里每个数都在题面上出现、数字规模按关号上升。断言:**随机生成 5000 题全部合法且有唯一答案**——「唯一」包括「三个选项里没有第二个和正解数值相等的写法」。
3. **干扰项全部来自典型错误**:每个生成器配一张「错法表」(忘记进位、退位当成大减小、忽略括号从左往右算、分母也相加、约分只约一半、小数点错位、打八折算成付两成、比反着写、解方程用错逆运算、把等比当等差、面积算成周长、应用题只算第一步)。选项只许从这张表里挑,**代码里不留纯随机兜底**;用例断言每个干扰项都带得出「错在哪一步」的标签,而且与正解差异合理(同量级、非负、不等值)。
4. **分步提示**:连错 2 次给按题型的**方法提示**(「先算括号里的」),连错 3 次给**拆一步**(把题拆成两小步问),两句都**一个数字都不出现**,用例扫 188 关全部答案兜底。1.1 那条链路原样保留——`quiz99` 照旧让正确项一闪一闪并朗读,本款只是把同一行文字换得更有用。
5. **错题本**:每关按**题型**记错题,存 `yiduo-yixing.math-farm.mistakes`(平台统一前缀,只存类型不存题目);关末推荐「练一练」——把错过的题型换数字重出一轮,回顾轮不判失败、不改星级。
6. **手感与可读性**:答对有农场动物欢呼小动画;答错只温和提示,不打红叉;竖式在 360px 上完整显示(字号 ≥ 14px);`prefers-reduced-motion` 关抖动与闪烁,提示改用描边加粗。

## 三、模式矩阵

`campaign` 188 关保留,`levels: 188` 不变。**对战 / 无尽不做**——理由:这是学习内容,竖式、通分、解方程要的是「算准」,套上抢答会把孩子逼成蒙选项,和教学目标反着来;真要做也只能是「限时口算挑战」(只出前 99 关那种一步口算),本步不做。

**前 99 关题型参数一个字不改**:`questionCount` / `kindPool` 在 0–98 上的返回值,以及 `buildQuestions(0..98)` 的完整输出,全部写进回归测试(逐关摘要哈希)。

## 四、2.5D / 3D 决策

**保持 2D**。数学题要的是数字大、对比清楚、竖式对齐,任何伪 3D 都只会挡住读数。不引入 three.js,不引入任何依赖。

## 五、视觉 · 建模 · 手感

- 题干区与选项区分明:题干白底大字,竖式用等宽数字右对齐;正文对比度 ≥ 4.5:1。
- 答对:农场小动物冒出来欢呼(纯 CSS 动画,`mtf-cheer`);答错只换一句温和的话,**不打红叉**。
- 朗读按钮「🔈 再听一遍」由公共壳在有语音包时显示,本款不动。
- `prefers-reduced-motion`:关掉欢呼与提示的位移 / 闪烁,提示改用描边加粗。

## 六、手机 360px

- 选项按钮 ≥ 44px 高、单行不折断(公共壳 `.qz-choice` 已经是 64px 起,本款不动它)。
- 长应用题题面可滚动,选项固定可见:题面 `max-height` + 自身滚动,不挤走按钮。
- 竖式在窄屏缩到 ≥ 14px 但保持数位对齐。

## 七、平台接线

- `mountLevelGame` / `runQuiz` 的既有链路不动;`ctx.skipped`(跳过后重玩的温柔提示)与「直开第 N 关」实测。
- `quiz99` 没有开放「按题型给提示」「关末回顾」的接口,而它是只读的公共资产,所以这两件事在本款目录里用 `ctx` 代理 + 捕获阶段监听 + `MutationObserver` **只读观察**实现,不拦点击、不改判分。折中点写在代码注释与回复里。
- `meta.platform` 补 `"both"`,`blurb` 与事实对齐(补上竖式、百分数、比例、方程);`guide` 挂进 `mountLevelGame`,并补三条新章节的方法(仍不给答案)。

## 八、测试(新增 ≥ 22 个用例)

九类题型逐类的生成器合法性(随机 5000 题:无负数、整除或规范一位小数、分数最简、比最简、唯一答案)、干扰项全部来自典型错误表且差异合理、难度权重表(区间连续铺满 100–188、每段权重和为 1、高段必含方程与比例)、前 99 关逐关摘要哈希回归、方法提示与拆一步都不含数字也不含任何一关的答案、错题本存取与迁移、朗读降级(无语音包时静默但文字全在)、`destroy` 归零与样式只追加的源码巡检。
