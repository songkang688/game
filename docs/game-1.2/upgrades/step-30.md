## 1. 现状审查（先读源码，再动手）

## 2. 通行规则对照（已检索，必须写进实现与攻略）

竞技五子棋（连珠 / 中国五子棋竞赛规则，含 2025 版要点）与街头无禁规则要同时支持，用开关，默认「无禁·自由」适合入门，「连珠禁手」给高年级。

规则要点（实现成纯函数，禁止只写在文案里）：

- 15×15 标准盘（自由对战可切 9×9 教学盘）。黑先。横竖斜连续五子胜。
- **无禁（Gomoku）**：长连也算胜；盘满和棋。
- **连珠禁手（只约束黑）**：
  - 三三：一子同时形成两个或以上**活三**，且该子为共用构成子；
  - 四四：一子同时形成两个或以上冲四/活四；
  - 长连：黑六子及以上连；白长连仍算胜；
  - **五连优先**：黑同时成五与禁手 → 黑胜；
  - 三三/四四需白方**立即指出**（UI：白方有 8 秒「指出禁手」按钮，超时视为放弃）；长连在终局前指出都有效。
- 活三 / 眠三 / 活四 / 冲四 的判定必须有单测图（至少各 4 张棋谱）。
- 解局：给定残局 + 轮次 + 限步，黑（或指定行棋方）必须在 N 手内成五或抓禁。每题**解唯一或解集明确**，禁止「随便下一手也能过」。

开源结构参考（只看结构，不引入依赖、不带商标）：`github.com/gomoku/gomoku` 类的棋盘/Zobrist；搜索用极小极大 + 置换表即可，不要上神经网络。

### 人机 6 档（菜鸟 → 地狱，硬性）

档位 id 建议：`novice | easy | normal | hard | master | hell`。中文名原创：棋灵苗 / 喵 / 狐 / 鹿 / 龙 / 渊（不要用商标名）。

| 档 | 行为 | 搜索 | 必须有的「人味」 |
| --- | --- | --- | --- |

### 其他硬性体验

- **落子确认**：设置默认「手机开启、桌面关闭」。流程：点交叉点 → 半透明预览棋子 → 再点同一点或点「落下」才提交。点别处取消。双人同屏两边都要确认。
- **提示限次**：自由对战每局 3 次；解局每题 1 次（用掉不给三星）。提示走 `hintMove`，不能直接弹答案坐标数字给孩子（高亮交叉点 +「可以往这附近想想」）。

## 2. 通行规则对照（三消工业界通行体验）

CS50 2D / 各类 match-3 的标准时间线（必须按这个状态机实现，时间可调、顺序不可跳）：

1. **输入**：点选相邻两格 → **交换动画**（120–160ms）→ 检测匹配。
2. 无匹配 → **换回动画**（同时长）→ 解锁输入。
3. 有匹配 → 匹配格 **爆开**（缩放+淡出 180–220ms，计步）→ 不可输入（`busy`）。
4. **重力**：每一列独立，现存块计算目标行，**从旧像素坐标 tween 到新坐标**（每格约 60–80ms，同列错开 20ms 更有「瀑布」感）。禁止 `innerHTML` 重排冒充下落。
5. **补块**：新块在棋盘顶外生成，tween 落入空位（可与重力重叠播放，但逻辑上先算重力再算补块）。
6. **连锁**：落地稳定后再检测；有匹配则回到第 3 步，连锁不耗步。直到稳定。
7. 稳定后才结算传送带 / Boss 吼 / 胜负。传送带也要滑移，不要瞬跳。

`prefers-reduced-motion`：时长降到 1 帧（约 16–32ms），但**仍走同一状态机**（方便测试），不要另写一套「逻辑瞬变」分支导致 bug 只在动画模式出现。

开源结构参考：CS50 match-3 的 tween 队列；Cocos 三消的 FallManager。不引入 Cocos/Godot。

## 2. 通行规则对照（跑酷手感，非某商业作）

高水平无限跑酷的通行体验（研究结论只许变成参数，禁止出现原作名）：

- 三车道；跳过矮障、滑过高障、左右换道躲整列。
- 速度用 **delta time**，30fps 与 60fps 同一手感。
- 土狼时间 ~90ms、跳跃缓冲 ~120ms、下滑锁定短于跳跃。
- 失败三种：撞、掉坑、被追赶物追上（若有追赶物）。
- 复活一次（已有星星花费）后短暂无敌。
- 程序化路段必须有「必过窗口」：任意连续 3 行不能三车道全是不可跳过且不可滑过的组合。

2.5D 决策：**做 2.5D，不做真 3D。** 真 3D 需要深度缓冲/模型管线，会引入依赖且拖垮低端机。2.5D = Canvas 2D 透视投影 + 视差层 + 雾化远端。
