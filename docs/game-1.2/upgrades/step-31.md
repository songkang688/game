## 2. 通行规则对照（大鱼吃小鱼通行体验）

- 只能吃半径明显更小的（建议阈值 **对方半径 ≤ 自己 × 0.85**，不要 0.99 擦边秒杀，手感会脏）。
- 吃掉后质量守恒式长大，用平滑插值，不要一帧跳半径。
- 越大越慢，但有短冲刺（冷却）。被更大的咬到掉一块质量（卡通：掉泡泡，不是流血）。
- 地图有边界或环形；无尽是「往深处游」，层数增加新鱼种。
- 图鉴收集是核心上瘾点，无尽里也要掉新种。

2.5D/3D：**保持 2D 俯视**，可加一点视差水层与气泡。真 3D 海洋会挡住「谁比谁大」的阅读性。

开源结构参考：各类 agario-clone 的四叉树/网格查询（O(n²) 在鱼多时会卡）。不抄皮肤、不联网。

## 3. 玩法升级

### 无尽「深海马拉松」

- 入口与战役并列。失败条件：被吃到半径 ≤ 起始值，或卡住 90 秒。
- **成长曲线（必须写成纯函数并单测）**：
  - 半径 r 从 14 起；每吃一只 `r' = r + k * (preyR / r)`，k 随层递减（防止 2 分钟撑破屏幕）。
  - 速度 `v = v0 / (1 + a*(r-14))`，冲刺倍率 1.8，冷却 2.4s。
  - 每 400 米（或 45 秒）换一层：鱼种表、洋流、毒藻密度上升。
  - 第 5 层起出现「深渊压力」：超过半径上限会缓慢掉质量，鼓励冲刺吃精英鱼破上限 10 秒。
- 记录最深距离与图鉴新发现。最高分走平台 `bestStars` 或本游戏 `yiduo-yixing.ocean-munch.endless.v1`（新 key 必须带 `yiduo-yixing.`）。

### 战役

不改前 99 关。可为无尽服务抽出 `growth.ts` 给战役 Boss 战复用「弹性吞咽」，但 Boss 血条/胜负公式保持。

### 对战

可选「限时谁更胖」人机三档（乱游 / 会躲 / 会反杀）。不做无尽 PVP。

## 4. 视觉 / 建模 / 动效（含手机）

- 吞咽：180ms 椭圆拉伸朝向猎物再回正。
- 360px：摇杆或「滑动游动」必须让朵朵鱼完整可见；图鉴名允许两行，字 ≥ 14px。HUD 半径/层数不要挡住鱼。
- 毒鱼用形状+纹路，不只靠红绿（色觉）。

## 5. 跳关 API

## 2. 通行规则对照（中国象棋竞赛规则要点）

- 红先。帅/将九宫内直行一格；士斜一格不出宫；象田字不过河、塞象眼不可走；马日字、蹩马腿；车直线无限；炮平移同车、吃子隔一子；兵未过河向前、过河可横不可退。
- **将帅对面**：同一直线无子则走后形成对面者负（或禁止该走）。
- 将军必须应将：垫、吃、逃。无法应将 = 将死负。无子可走 = 困毙负。
- **禁止单方面长将**（循环照将达三次）。本项目做简化：同一将军着法循环 3 次判走方负，并有提示「换一条进攻路线吧」。
- 残局：双方大子（车马炮）很少，讲究杀法（海底捞月、马后炮、双车错等）。闯关就用这些杀法主题，名称用中文原创描述，不要用竞赛专用过难术语吓孩子，但逻辑要真。

开源结构参考：`xqbase` 规则说明、各类 `chinese-chess` 合法走法生成。不要用引擎 .dll，自写 2–4 层搜索足够。
