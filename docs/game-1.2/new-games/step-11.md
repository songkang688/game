### 完整规则（帧数据驱动，纯函数）

- 60 逻辑帧。每招：`startup / active / recovery`，判定框仅 active。
- 命中：hitstun、blockstun、hitstop（顿帧 3–8 帧，reduced-motion 则 0）。
- 格挡：后方向。上段（跳攻）蹲挡挨打；下段站挡挨打；中段都可挡。投技不能挡，但要贴近且对方不在投无敌。
- **跳投**：空中按投技键，落地前判定；被投中播放抱起转圈（卡通），落地对方坐地上。
- 能量：打中加、挡中加得少；LV1 超必 50，LV2 100。超必有投无敌或全身无敌帧（写在帧表）。
- 元气 ≤ 0：本回合负。BO3 先赢 2 回合者胜。平局双倒：血多者胜，一样则「时间耗尽双方坐下」判负双方（对战重开该回合）。
- 无限连防护：连段 hitstun 递减 + juggle 衰减 + 上限 8 段后强制倒地。单测这条。

## 本款采用的规则（写清，不要含糊）

**主规则：国标麻将竞赛规则的可玩简化落地。**

- 牌张：筒条万 1–9 各 4，风 4 种×4，箭 3 种×4，花 8 张，共 **144**。
- 四人：下家 / 对家 / 上家。玩家永远坐「南」视角（自己在下方）。
- 起手 13，庄 14。逆时针抓打。
- **吃**：只能吃上家打出的牌，组成顺子。
- **碰**：任何一家打出，组成刻。碰后必须打出一张。
- **杠**：明杠（碰后再抓到第 4 张或别人打出第 4 张）、暗杠、加杠。杠后补牌（从牌尾）。
- **胡**：基本型 4 面子 + 将，或七对、十三幺、全不靠、七星不靠、组合龙等国标特殊型。
- **8 番起和**：对战默认开（不足 8 番点胡 = 错和，赔每家 10 分）。闯关第 1–3 章把门槛降到 1/2/4 番教学，第 7 章起恢复 8 番。
- **截和**：一炮只胡一家，顺序下家>对家>上家。
- **不计连庄**：对战一局 16 盘（四圈）或快棋 4 盘（闯关用快棋）。
- 计分：国标 **81 番种**，分值 88/64/48/32/24/16/12/8/6/4/2/1。花牌计分不计番。遵循不重复、不拆移、就高不就低。自摸：(8+番)×3；点炮：点炮者付 8+番，其余付 8。
- 必须实现并单测的番种 **至少 40 个**（含平和、碰碰和、混一色、清一色、七对、十三幺、大三元、大四喜、清龙、三色三同顺、杠上开花、抢杠和、妙手回春、海底捞月、门前清、不求人、全求人、断幺、无字、一般高、喜相逢、老少副、边张、坎张、单钓、自摸、四归一、箭刻、圈风刻、门风刻……）。其余番种可在 `fan.ts` 列全表，遇到就算，没覆盖到的要在 README 注释里标「识别器未做」——但 40 个常用必须绿。

### 完整规则（破产必须写清）

- 2–4 人。开局现金 `START_CASH`（建议 1500「星币」）。过出发 +200。
- 两颗骰子。双数再掷一次；**连续三次双数 → 进小黑屋**（不经过出发、不拿 200）。
- 停无人地：可买；不买则 **拍卖**（AI 与玩家出价，无底价）。
- 停别人地：付租金。垄断同色且无抵押：租金 ×2；有小屋 1–4 / 大屋，用表。
- **建屋**：必须垄断该色组；必须 **平均建**（任何一块不能比同色最高的少超过 1 屋）。建屋只能在自己回合掷骰前。
- **抵押**：先卖掉该色组全部建筑（半价回收），再抵押地皮得半价现金；抵押中不收租。赎回 = 抵押价 × 110%。
- **小黑屋**：三种出狱——付 50、用「出门卡」、掷双数。第三回合必须付 50 并按刚掷点数走。狱中仍可收租、交易、建屋。
- **机会 / 命运**：各 ≥ 16 张原创卡（进小黑屋、前进到出发、维修费每屋 40 每大屋 115、生日向每人收 10、赠 50、缴税……）。抽完洗回。
- **破产**：
  1. 欠债时必须先卖建筑（半价）、再抵押、再和他人交易（闯关 AI 可拒绝敲诈）。
  2. 仍无法付清 → 破产出局。资产（含出门卡）交给 **债权人**；若债权人是银行（税/卡），银行收回后把地皮 **无底价拍卖**。
  3. 抵押地转交时，新主人立刻付抵押价 10% 税，并选择立即赎回或维持抵押。
  4. 最后未破产者胜。限时模式：到点比净资产（现金 + 地价 + 建筑价，抵押地只计半价）。
- 交易：只能地皮和出门卡和现金，**不能交易建筑**（先拆）。

胜负判定边界：
- 同时因卡牌「每人付 50」而多人付不起：按当前行动者逆时针顺序结算，先破产先给银行拍卖，后面的人可能因为拍卖买地而改变。要写测试。
- 只剩一人未破产立即结束，不要再掷。

### 前端
- Canvas 或 DOM 棋盘（DOM 更易点选）。棋子是朵朵/星星/糯糯/云云。
- 走格子：**棋子沿格跳跃动画**，不要瞬移。收租时金币飞行动画。破产：棋子收起+钱包倒空粒子。
- 360px：棋盘最小缩放后当前格放大预览；文字 13px+。

### AI 档位
菜鸟见地就买直到没钱；普通会补同色；高手会卡关键色组、会抵押周转；地狱会拍卖抬价、会交易勒索（有上限，避免死锁）。
