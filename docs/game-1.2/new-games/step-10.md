### 这不是什么
- **不是** `ocean-munch`「海底大胃王」复刻：那是侧视大鱼吃小鱼闯关，没有分身、刺球、孢子、排行榜、封闭大地图。

### 完整规则（必须写成纯函数，可单测）

坐标系：世界坐标，地图矩形 `MAP_W × MAP_H`（战役按关缩放，无尽/对战默认 4000×4000）。摄像机跟随玩家最大分身，带平滑。

#### 质量与吞噬
- 每个圆有 `mass`。半径 `r = k * sqrt(mass)`（k 抽成常量）。
- 速度 `v = v0 / (1 + mass / MASS_SPEED_REF)`，质量越大越慢。小圆永远比大圆快。
- 质量随时间衰减：`mass' = mass * (1 - DECAY * dt)`，衰减在 `mass > DECAY_START` 后启用，保证必须持续进食。
- 场上刷「彩豆」：随机点，质量 `PELLET_MASS`，吃到 +质量。密度保持在 `PELLET_COUNT`。
- **吞噬判定**：两圆圆心距 `< |rA - rB| * OVERLAP`（建议 OVERLAP=0.75，抽常量），且较大方质量 ≥ 较小方 × `EAT_RATIO`（建议 1.25）。满足则大吃小，质量 100% 转移，小吃方消失。
- 同一玩家的多个分身：**不能互相吞噬**，除非处于「可合并窗口」（分身出生 `MERGE_DELAY` 秒之后，建议 18–30s，质量越大合并越慢）。合并时质量和并、位置插值。
- 队友（双人合作关）：同样不能误吞最后一个分身。

#### 分身（最多 16）
- 按 `F` / 触屏「分身」：把**当前最大的那个分身**沿瞄准方向弹出一半质量。弹出速度先快后阻尼。已有 16 个则不能再主动分。
- 分身瞬间若质量不足以双方都 ≥ `MIN_SPLIT_MASS`，忽略输入。
- 分身是进攻手段（拍到远处小吃）也是风险（自己变小）。

#### 吐孢子
- 按 `G` / 「吐」：从每个足够大的分身沿瞄准方向吐一颗孢子（质量 `SPIT_MASS`，从本体扣除）。孢子是可被任何人吃的小圆，飞行一小段后停下。
- 对刺球吐孢子：刺球被推动，质量增加；到阈值后**沿吐入方向弹出一颗新刺球**（这是进攻：把刺球推向对手让对方爆开）。

#### 刺球
- 场上维持 `VIRUS_COUNT` 个「刺球」（海胆状圆，带短刺动画）。质量固定，半径大于中型圆。
- **吃刺球**：若玩家某个分身质量 > 刺球质量，且吞噬几何满足：该分身 **爆开** 成最多 8–16 个小分身（总数仍封顶 16），并获得刺球的质量。已有 16 个分身时：只加质量、不再爆。
- 质量 ≤ 刺球：碰上去无事发生（或被轻微弹开，不要秒死）。
- 刺球不是「毒海藻鱼」，也不是 `ocean-munch` 的毒鱼。

#### 地图边界
- 圆不能出界：圆心夹在 `[r, MAP_W-r] × [r, MAP_H-r]`。
- 无尽后期可加「缩圈」：安全区矩形每 N 秒内收，出圈持续掉质量（卡通：圆圆变淡、掉彩纸），质量掉到 `MIN_MASS` 判休息。这是大逃杀边界，不是碰到边就死。
- 对战默认不缩圈。

#### 排行榜
- HUD 右上：当前场上玩家（含 AI）按 **总质量** 取 Top 10，自己那一行高亮，即使不在前十也在底部显示「第 N 名 · 质量 xxx」。
- 名字用原创：朵朵、星星、糯糯、云云、墩墩、闪闪、绿绿豆、啾啾、以及「圆圆 3 号」这类占位。**禁止网游昵称梗和商标。**

#### 胜负
- **被吃光**：所有分身消失 → 本局结束（闯关失败 / 对战淘汰 / 无尽结算）。文案：「圆圆先去休息啦，再出发一定更稳！」
- **对战计时结束**：质量第一获胜；平局比存活时间。
- **闯关**：见章节目标表。三星 = 目标达成质量余量 + 用时 + 是否爆过刺球（可选）。

### 完整规则

#### 身体与转向
- 蛇是一组间距均匀的关节点（不是格子）。头按当前朝向前进，身体点追上一节。
- 转向：瞄准方向（鼠标 / 摇杆 / WASD 合成向量）以 `TURN_RATE` 弧度/秒转向，**不能原地掉头**（最小转弯半径随长度略增）。
- 撞到 **自己身体** 默认 **不死**（避免新手自杀过虐；战役后段可开「自碰休息」作为机制关）。
- 头撞到 **别人身体**（非头）→ 自己出局。头对头：双方都出局，或质量/长度较长者胜（抽成常量 `HEAD_TIE`，默认双方出局）。
- 头撞 **地图圆边界** → 出局，**不掉尸体光点**（边界击杀没奖励，鼓励往场中对决）。

#### 加速
- 按住 `F` / 加速钮：速度 × `BOOST_MUL`（约 1.8）。
- 代价：每秒消耗约 1% 当前长度（抽 `BOOST_COST`），并把消耗的质量以光点洒在轨迹上。
- `length < BOOST_MIN`（约 30 单位）时不能加速。
- 加速时蛇身闪「亮斑」，别人能看见你在加速。

#### 击杀与吃光
- 出局者身体 **全部变成光点**（比普通彩豆更大更亮，颜色随皮肤）。
- 任何人都可以吃这些光点。**吃光** = 尽量把这一团吃完，这是快速变长的主途径。
- 普通彩豆刷在全图，小、暗；尸体光点亮、大。长度增量：尸体 > 亮彩豆 > 暗彩豆。

#### 皮肤与长度

### 完整规则（Guideline 核心，必须写对）

场地：**10 列 × 20 可见行 + 2 隐藏出生行**。隐藏行有块且锁定后仍露出 = 顶出，判负。

#### 七种积木（不要用商标名，内部用 I O T S Z J L）
标准形状与出生朝向按 SRS：I 横在 21–22 行中间；O 在中间；其余以 SRS spawn 为准。

#### 7-bag
一个袋子装 I O T S Z J L 各一，洗匀后发完再新袋子。禁止纯 Math.random 连续同一种。单测：连续 700 块每种正好 100，且任意窗口 7 块是一个 bag 的排列。

#### SRS 旋转 + 踢墙
- 基本旋转：绕 SRS 中心转 90°。
- 若重叠：按 **SRS wall-kick 表** 依次试偏移（JLSTZ 一套，I 一套，O 无踢或全 0）。五次都失败则旋转取消。
- 必须带 **0→R、R→2、2→L、L→0** 及反向表。单测至少：I 贴墙可踢成竖；T 贴地可做 T-spin 位移（哪怕闯关前期不加分，函数要在）。

#### Hold
- `Hold` 把当前块与暂存互换；若暂存空，当前进暂存并发下一块。
- **同一块落地前只能 Hold 一次**（locking 后刷新）。单测这条。

#### Ghost
- 当前块按硬降位置画半透明影子。影子必须与 `hardDropY` 一致。

#### 锁定与 DAS
- 落地后 **lock delay**（约 500ms）内仍可左右移动/旋转重置锁定（移动重置次数封顶，防无限拖）。
- DAS/ARR：按住左右先延迟再连移，用自己的定时器，**不要用操作系统键盘重复**。

#### 消行（禁止瞬变）
1. 满行标记；
2. 闪光 120–200ms（reduced-motion 则缩短为变色一帧）；
3. 上方砖块 **下落 tween** 80–160ms；
4. 再生成下一块。
分数在动画开始时就算，但视觉必须走完。**禁止「满行直接 splice 下一帧已是新堆」。**

#### 计分（Guideline 简化）
- 单/双/三/四消：100 / 300 / 500 / 800 × (level+1)
- 软降 +1/格，硬降 +2/格
- 连消（back-to-back 四消）× 1.5（可选，要单测）
- T-spin 识别可选，若做：T 最后一次踢墙成功且三角占用 ≥ 3 算 T-spin。
- 升级：每 10 行 level+1，重力表必须单调变快，level 0 约 1G/48 帧，后期封顶。

#### 顶出 / 胜利
- 无尽：顶出结束，记分 `recordEndlessBest`。
- 闯关：目标行数 / 目标分数 / 限定块数内清掉垃圾行。
- 对战：双方场地，消 2/3/4 行给对手送 1/2/4 行垃圾（左侧有洞的垃圾行），先顶出者负。
