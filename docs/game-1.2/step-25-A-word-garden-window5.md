## 二、本步要落地的七件事

1. **字库自检单测(硬性)**:`bank.test.ts` 把六张字卡表 + 五张高年级表全量扫一遍——
   单字、拼音只由合法声母+韵母+声调组成、同一章内不重复、`meaning` 人人有且不含答案字、
   emoji 不空;每一道生成出来的题「正确答案在选项里且只出现一次」。**教材内容错一个都是教学事故。**
2. **每条字卡补 `meaning`**:96 张字卡 + 数字 / 家人 / 食物三张表,一句话说清这个字是什么意思。
   `pinyin` 本来就有,逐条复核。`meaning` 只进数据、不进题面,**前 99 关生成结果一字不变**。
3. **笔顺描红(新增题型)**:`strokes.ts` 给 **29 个前三章高频字**补分段折线笔顺(名 + 路径),
   判定写成纯函数;`tracing.ts` 是田字格描红台,描错顺序只温和提示重来、**不扣分不判失败**。
   数据宁可少而对:只收笔顺我能逐笔说清楚的字,`田`这种社会上都有两种写法的一律不收。
4. **题型补齐到 11 类**:看图认字 / 认字选图 / 拼音选字 / 给字组词 / 数一数 / 形近字辨析 /
   成语补全 / 近反义 / 句子填空 / 偏旁推字义 —— 已有;本步新增 **笔顺描红** 与 **多音字辨析**
   (同一个字在两句话里读不同音,三个选项都是拼音)。
5. **干扰项质量**:形近字组全部补到 **≥3 个字**,干扰项**只从组内取**,再不跨组抓随机字;
   每组内两两之间「共享部件」或「笔画数只差一笔」,写进 `parts` / `strokes` 字段由单测反查。
   「戴 / 带」这组同音不形近的拆开:`戴 / 栽 / 裁`(共享 𢦏)与 `带 / 帮 / 常`(共享 巾)。
   组词题的干扰项本来就取自字卡的真实词,补一条「选项全部来自受控真词表」的断言钉死。
6. **错题本 + 关末换题型复查**:答错的**字**记进 `yiduo-yixing.word-garden.mistakes`,
   本关答完用**同一个字的另一种题型**再考一遍;复查轮不判失败、不改星级。
7. **朗读**:答题走 `quiz99` 既有的 `speech.ts` 链路;组字工坊与描红台自己补「🔈 读一读」,
   `speechReady()` 为假时按钮隐藏,做题一点不受影响。

## 三、模式矩阵

`campaign` 188 关保留,`levels: 188` 不变。**对战 / 无尽不做**——理由:识字要的是「看清楚、想明白、写出来」,
两人抢答只会奖励猜得快的那个;描红更是一笔一画的慢功夫,套进无尽计分就变成了乱涂。
188 关的章节推进 + 错题复查已经是这类内容合适的节奏。

**前 99 关题型参数一个字不改**:`kindPool` / `questionCount` / `CHAPTER_POOLS` / `mulberry32(5200 + level*7919)`
在 0–98 上全部原样;`buildQuestions(0..98)` 的完整输出摘要哈希继续钉在测试里,
再补一张「逐章摘要 + 题型直方图」的第二道锁。

## 四、2.5D / 3D 决策

**保持 2D**。笔顺描红是纯 2D 路径动画:田字格辅助线、按笔画高亮下一笔、指尖拖出彩色花瓣痕迹。
汉字是平面的字形,任何伪 3D 都只会让笔画互相遮挡。不引入 three.js,不引入任何依赖。

## 五、视觉 · 建模 · 手感

- 汉字字号 ≥ 28px,描红台的大字用 `min(56vw, 200px)`;田字格米字辅助线只在描红时出现。
- 描红时轨迹留彩色花瓣痕迹,完成一笔开一朵小花;整字描完花园长出一朵大花。
- 答对:`ctx.sfx("coin")` + 花开;答错温和提示,**不打叉、不扣星、不判失败**。
- `prefers-reduced-motion`:关掉花朵生长与笔画流光,直接显示结果。

## 六、手机 360px

选项按钮 ≥ 44px;描红区域 ≥ 240×240px;手指遮挡时字头顶上有一行「正在描第 N 笔:横折钩」的预览条。
长句填空横向不溢出(`word-break` 允许换行不截断)。

## 七、平台接线

- `mountLevelGame` / `runQuiz` / `runTimed` 的既有链路不动;`ctx.skipped` 与地图直开第 N 关实测。
- `quiz99` 没有开放「关末回顾」的接口,公共文件只读,所以复查轮在本款目录里用 `ctx.win` 代理实现。
- `meta.platform` 补 `"both"`(描红同时吃 pointer 与鼠标);`blurb` 补上笔顺与多音字,
  「十一座花园 188 关」原样保留。

## 八、测试(新增 ≥ 22 个用例,既有测试一个都不许删)

字库自检(拼音合法 / 章内不重复 / `meaning` 齐全且不泄答案 / 答案在选项里且唯一)、
形近字组内两两共享部件或只差一笔、形近字干扰项 100% 来自组内、组词干扰项全部来自受控真词表、
成语干扰项不会凑出另一条成语、多音字两句读音不同且选项三个拼音互不相同、
笔顺 ≥ 20 字的逐笔顺序断言 + 笔画数校验 + 描错顺序的判定、
错题本读写与迁移、关末复查换题型且换的是同一个字、朗读降级、攻略不含任何答案字、
前 99 关摘要哈希 + 逐章直方图双重回归、`destroy` 归零与样式只追加的源码巡检。

## 九、红线

学习内容必须正确(字库与笔顺错一处就是教错人);失败只鼓励;攻略只讲方法不给答案;
无商标;角色只用朵朵 / 星星;无血无死亡;无广告 / 内购 / 账号 / 联网;禁止 three.js;
`destroy` 拆干净监听 / timer / rAF。
