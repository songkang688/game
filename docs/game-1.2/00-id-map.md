**C 升级稿里另有一套补位**（`bowling-lane` `jump-chess` `animal-chess` `merge-stars` `sudoku-house` `star-soccer` `star-hoops` `billiard-stars` `kart-dash` `merge-fruit` `run-fast-cards` `navy-grid`，见 [upgrades/step-51.md](./upgrades/step-51.md)–[54.md](./upgrades/step-54.md)）。

派发规则：

1. 先做完 B 的 21 个施工 id。
2. 再派 C 升级：点名 9 款按上表改成施工 id；C 补位里与 B 同玩法的（2048 / 扫雷 / 数独 / 合成 / 台球 / 卡丁 / 跳一跳）**并到 B 的施工 id 上升级**，不要建第二个目录。

4. A catalog 里 B 没有的（`petal-scout` `lily-hop` `reversi-ink` `klondike-cards` `beat-tap` `kart-dash` `glow-survivor` `air-puck` 等）同样视为别名/候选；**第一波以 B 的 21 个施工 id 为准**。
