## 二、本步要落地的六件事

1. **交替节奏模型**(新文件 `rhythm.ts`,纯函数):
   - 左右交替按满收益;**连续同键每多一次乘一次衰减系数**,有地板不至于卡死;
   - 快过「人真按得出来的上限」不再多给距离(`MIN_EFFECTIVE_GAP_MS`),**乱砸键不会更快**;
   - 与上一拍间隔接近就攒「稳」,攒满给固定上限的加成——**奖励的是节奏稳定,不是砸键**;
   - 基线定成「交替 + 不稳」= ×1.0,所以 `logic.ts` 的 188 关可通关模拟仍是保守下界,前 99 关难度不动。
2. **公平性**(新文件 `fair.ts`,纯函数):两条赛道的机关**完全镜像**并写断言;起跑口令**随机延迟** 700–2100ms;
   抢跑**回退 0.5 秒**(每次 500ms、封顶 1500ms)且**永远不判负**(`disqualified` 恒 `false`,写死在测试里)。
3. **AI 四档**(新文件 `ai.ts`):菜鸟 / 普通 / 高手 / 地狱,用「目标节奏 + 失误率 + 反应时间」建模。
   目标节奏一律 ≤ `HUMAN_TAP_CAP_HZ` 这个常量(**不许用玩家做不到的频率**),固定 seed 的无头对局断言四档强度严格单调。
4. **让分开关**:落后方 ≤ **8%** 助推(差距越大越接近上限,封顶写死),**默认关**,HUD 上常驻一颗可点的芯片。
5. **无尽「跑不完的跑道」**:机关密度随距离上升(`endlessDensity` 单调不减、有封顶),**撞 3 次结束**;
   星星改成**陪跑员**(速度仍走 `endlessChaserSpeed`),被超过只是提示,不再直接结束;成绩 `save.recordEndlessBest("red-blue-race", meters)`。
6. **手感与结算**(新文件 `feel.ts`):跑步动画周期随速度变频;冲线彩带 + 300ms 慢镜;
   `prefers-reduced-motion` 关掉速度线抖动与彩带;自建浮层接上与平台同一把尺的 400ms 冷静期。

## 三、模式矩阵

`campaign` / `versus` / `endless` 三模式全留。

- `campaign`:188 关单人对小电脑,**前 99 关的关卡数据一个字不改**(`levels.ts` 只读不动);
- `versus`(**本命**):新增「对战场」页,两种对局——**本地两人**(朵朵 `A/D` + `W`,星星 `←/→` + `↑`)与**挑战小电脑四档**;
- `endless`:见上,撞 3 次结束。

## 四、2.5D / 3D 决策

**保持 2D 侧视**,只加地面速度线。理由:本款的核心是「两个人并排、一眼能比出谁在前面」,
侧视双跑道把差距摊在同一根横轴上,换成 2.5D 跑道反而看不清相对位置;
2.5D 跑道归 `rainbow-run` 与 `duo-rush`,红蓝三连不做,也**不引入 three.js 或任何依赖**。

## 五、手机 360px

左右半屏各一颗大按钮(交替时左右两颗都给),按钮热区 ≥ 64px;双人时左半屏归朵朵、右半屏归星星,互不遮挡;
比分与距离在顶部一行,字号 ≥ 14px。

## 六、平台接线

`mountLevelGame` 的选关 / 跳关照旧走框架(`requestSkip` 由壳层注册);无尽成绩走 `save.recordEndlessBest`;
`meta.modes` 保持三模式并补 `twoPlayer`,`platform` 按实测填(键盘双人 + 触屏双人都能玩 → `both`),`blurb` 与事实对齐。

## 七、测试(新增 ≥ 16 个用例)

`rhythm.test.ts` 交替 / 同键递减 / 砸键上限 / 稳定加成 · `fair.test.ts` 镜像(含 188 关全表)/ 起跑延迟 / 抢跑回退不判负 / 让分封顶 ·
