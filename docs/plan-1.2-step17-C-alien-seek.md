## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **点击容错** | 目标周围 44px 内点击都算命中；两个目标靠得近时取最近的那个（写纯函数 + 用例）。点空 3 次给一次温和提示（不扣星）。 |
| **摆放校验** | 程序化摆放必须保证：每个目标至少 70% 面积可见、不被 UI 遮挡、彼此中心距 ≥ 阈值。随机 1000 次布局全部通过（断言）。 |
| **缩放与拖动** | 大场景支持双指缩放 / 拖动，缩放范围 0.8–2.5×；缩放时命中判定按世界坐标算（写用例）。 |
| **提示经济** | 每关 2 次「望远镜」（缩小到某一区域），用掉不给三星；提示不许直接高亮目标本体。 |
| **双人抢答 / 无尽** | `twoPlayer`：同屏各半，先找到者得分；`endless`：目标源源不断，限时找，成绩 `save.recordEndlessBest("alien-seek", n)`。 |

## 五、模式矩阵

四模式全保留（玩不了就修好或删声明）；闯关 **前 99 关场景数据不改**。

## 六、2.5D / 3D 决策

**保持 2D**。找物类的可读性完全依赖清晰的平面布局。

## 七、视觉 · 建模 · 手感

- 找到目标：目标弹一下 + 飞到清单栏打勾 + `api.play("coin")`。
- 清单栏用缩略图而不是文字（低年级也能玩），可横滑。
- 场景元素密度分级：前几章疏、后段密，**不能靠把目标画得极小来提难度**（最小可视尺寸 24px）。
- `prefers-reduced-motion`：关抖动。

## 八、手机 360px

- 清单栏一行横滑，缩略图 ≥ 40px；缩放手势不与壳层手势冲突。
- 剩余目标数与计时在顶部一行，字号 ≥ 14px。
