## 三、现状审美评测（先开代码再动笔）

打开 `src/games/brave-path/index.ts`，渲染入口是 `paint`（迷宫格子）/ `render` / `renderMenu` / `renderPrep` / `renderCampaign` / `renderArena` / `renderEndless` / `renderActions` / `drawTeam` / `drawBag` / `drawGear` / `drawSkill`。已核实的问题：

1. `paint`（约 422 行起）的迷宫就是 DOM 格子换 class（`bvp-mz` 一族）+ emoji 文本：墙、路、勇者、怪物全是字符贴片，没有一笔自绘——「勇者小路」的冒险感等于一张 emoji 表格；
2. `renderArena`（1422 行起）的战斗界面就是「标题 + 按钮列表」，没有立绘框、没有出手动画、没有血条质感；
3. 队伍面板 `drawTeam`、背包 `drawBag`、装备 `drawGear`、技能 `drawSkill` 预期都是文本行 + emoji 图标，逐个打开自查并把结论记进开工 commit；
4. 迷宫没有视野氛围（迷雾、火把光圈）；走过的路与没走过的路对比不足；
5. `ghostAt` 提示的画法（预期是变色格）也要自查。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **迷宫 2.5D 格子** | 每格 CSS 加「顶面 + 底边」伪厚度：路面浅色 + 4px 深色底边 + 1px 亮顶边；墙格画成矮石墙（两层砖缝渐变 + 顶部青苔线）；勇者所在格加暖光圈（径向渐变 60% 透明），相邻可走格微亮——2.5D 观感靠格子厚度与光圈成立。 |
| **迷雾与探索** | 未探索区盖雾层（`backdrop-filter: blur` 或半透明灰渐变 + 边缘羽化 8px）；走过的路留浅色脚印点；宝箱 / 出口在迷雾边缘露出轮廓剪影勾引探索。 |
| **勇者与怪物徽章** | emoji 替换为**SVG 圆徽章**：勇者 = 圆底 + 职业色环 + 自绘小图标（剑士 = 交叉双剑、法师 = 星杖、牧师 = 花十字）；怪物 = 圆底 + 怪物剪影（果冻怪 / 蘑菇怪 / 石头怪三套原创剪影）+ 等级角标。徽章直径吃满格子 82%，带 1.5px 描边与底部小影。 |
| **战斗界面卡片化** | `renderArena` 升级：上方敌我立绘框（SVG 徽章放大 + 姿态倾斜 ±6°）、血条圆角渐变（绿 → 黄 → 粉三段色）+ 受击时数字上飘与徽章抖动 2 帧（reduced 关）；出手方徽章前移 8px + 高亮描边。 |
| **背包 / 装备 / 技能** | 三面板统一卡片：图标格 44px 圆角 10px、稀有度用边框色阶（灰 / 蓝 / 金）、hover / 选中抬升 2px + 阴影加深；技能按钮加冷却扇形罩（读既有冷却数据）。 |
| **布局与结算** | 顶栏（层数 / 金币 / 队伍状态）卡片化一行；过层时小路延伸动画（虚线路径点亮）；胜利撒星屑彩纸（`sparkle.ts` 的 CSS 等价物）。 |

- 色板走 `src/art/kit/palette.ts` 的 token；DOM 游戏的渐变 / 阴影写成共享 CSS 自定义属性。
- `prefers-reduced-motion`：抖动、上飘、点亮动画全停，保留静态层次。

### 四·补一：配色板与层级序（CSS 自定义属性统一管理）

| token | 色值 | 用途 |
| --- | --- | --- |
| `--bvp-floor` | `#F6EFE4` | 路面顶色 |
| `--bvp-floor-edge` | `#D9C9A8` | 路面 4px 深色底边 |
| `--bvp-wall` | `#C7B8D8` | 石墙主色（两层砖缝渐变基色） |
| `--bvp-moss` | `#9FD98B` | 墙顶青苔线 |
| `--bvp-fog` | `rgba(120,120,140,.55)` | 未探索迷雾 |
| `--bvp-torch` | `rgba(255,200,120,.35)` | 勇者暖光圈峰值 |
| `--bvp-hp-hi/mid/low` | `#8FD98B` / `#F0C25A` / `#F4859F` | 血条三段色 |

DOM 层级（z-index 从低到高）：① 迷宫格底 → ② 格内徽章 → ③ 迷雾层 → ④ 暖光圈 → ⑤ 战斗浮层 → ⑥ 顶栏 HUD → ⑦ 结算浮层。迷雾必须盖住徽章但不得盖顶栏。

### 四·补二：徽章工序单（`badge.ts` 参数化 SVG，六套起步）

1. 圆底：直径 = 格宽 82%，底色按阵营（勇者暖白 / 怪物淡紫）；
2. 职业 / 怪物色环：3px，剑士金 / 法师蓝 / 牧师粉；果冻绿 / 蘑菇橙 / 石头灰；
3. 中心图标自绘路径：交叉双剑 / 星杖 / 花十字；果冻怪（半圆 + 波浪底）/ 蘑菇怪（伞盖 + 斑点）/ 石头怪（圆角多边形 + 裂缝线）；
4. 等级角标：右下小圆 + 数字（怪物专用）；
5. 底部小影：椭圆 `rgba(0,0,0,.12)`；
6. 全部产出为字符串模板函数 `badge(kind, opts)`，禁止运行时拼接魔法色值。

### 四·补三：动效时序表（CSS 动画时长写成自定义属性）

| 动效 | 触发 | 时长 | 缓动 | reduced 行为 |
| --- | --- | --- | --- | --- |
| 暖光圈呼吸 | 常驻 | 2000ms 周期 | ease-in-out | 静态光圈 |
| 迷雾揭开 | 探索到新格 | 280ms 羽化淡出 | ease-out | 立即消失 |
| 受击数字上飘 | 战斗受击 | 420ms | ease-out | 数字原地显示 |
| 徽章受击抖动 | 战斗受击 | 2 帧 160ms | step | 关闭 |
| 出手方前移 | 回合切换 | 180ms | ease-out | 只换高亮描边 |
| 过层小路点亮 | 过层 | 每格 90ms 逐格 | linear | 一次性全亮 |
