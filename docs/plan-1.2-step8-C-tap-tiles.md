## 五、这不是什么

- 不是 `music-stars`（自由创作乐器），不是 `red-blue-tap`（双人抢点）。
- 本款是**四轨下落节奏点击**：判定窗口、长按条、连击、点空判罚。

## 六、完整规则

- 4 条轨道，音符块从上往下落到判定线。
- **判定窗口**（写成常量并单测）：`|Δt| ≤ 45ms` 完美；`≤ 100ms` 良好；超出或没点 = miss。
- **点空白**：点到没有块的轨道 —— 经典规则是立即失败；本款把它做成开关：闯关第 1–2 章只扣连击，第 3 章起「点空即结束」。
- **长按条**：按住到尾端才算完成；中途松手判 miss（要单测）。
- 速度随关卡 / 无尽时长递增（速度表单调，写成纯数据）。
- 连击与分数：连击越高倍率越高；miss 断连击。
- 生命：无尽 0 容错；闯关允许 3 次 miss。
- **谱面生成**：`chartFromSeed(seed, density, speed)`，约束：
  - 同一时刻**最多 2 条轨道**有块（Boss 关可显式放开到 3，但要在关卡数据里标明）。
  - 相邻音符最小间隔 ≥ `MIN_GAP`（按速度换算，保证人类可点）。
  - 长按条不与同轨其他块重叠。
  - 测试对 ≥ 50 个随机谱断言这三条约束。

胜负：闯关是打完整张谱且 miss 不超上限；无尽是结束前的分数；对战是同谱比分或比谁先 miss。

## 十、前端建模与视觉（含 360px）

- Canvas 四列 + 判定线（在下方约 20% 高度处）。
- **命中禁止只是消失**：块要碎成向上飘的小音符粒子 + 轨道底部亮一下；完美与良好用不同颜色。
- miss 用温柔提示（轨道边框轻微变暗 + 一句鼓励），**不要刺眼红闪**。
- 长按条要画成拉长的圆角条，按住时有流动效果。
- `prefers-reduced-motion`：减少粒子数量，保留命中反馈。
- 360px：四列占满宽（每列 ≥ 80px），判定线清晰，分数与连击在顶部且字号 ≥ 16px。
