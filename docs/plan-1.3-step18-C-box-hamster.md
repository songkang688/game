## 三、现状审美评测（先开代码再动笔）

打开 `src/games/box-hamster/index.ts`，渲染入口是单个 `render`（约 310 行起）。已核实的问题：

1. 箱子就是一个 📦 emoji（327 行）：推到目标点只是加 `bh-done` 类——「推箱」的主角道具没有一笔自绘，压根看不出「推」的费劲与「到位」的满足；
2. 仓鼠是 emoji 字符脸（`HAMSTERS[hi].face`，331 行），朝向靠 `faceStyle` 的 transform 翻转——emoji 翻转在不同系统上表现不一，且没有推箱姿态；
3. 格子是 class 换色的平涂 DOM（`bh-cell` / `bh-wall` / `bh-ice` / `bh-goal` / `bh-portal`，313–321 行）：墙没有厚度、冰没有反光、目标点没有引导光、传送门没有旋涡；
4. 推动 / 滑冰 / 传送三种移动在画面上是同一种平移（自查过渡动画确认），孩子分不清「我推的」和「它自己滑的」；
5. 关卡完成的庆祝画法自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **仓鼠自绘（SVG）** | emoji 替换为参数化 SVG 仓鼠：圆滚身体 + 鼓腮帮 + 小圆耳 + 短尾巴；双仓鼠款式差异化（毛色 + 耳形 + 头顶花 / 呆毛，剪影可分）；四朝向各自姿态（不是翻转）：推箱时身体前倾 12° + 两只小爪抵住箱面 + 后腿蹬地；idle 时腮帮咀嚼两帧（reduced 静止）。 |
| **木箱自绘** | 📦 替换为 SVG 木箱：木板纹三条 + 四角铁片 + 顶面亮侧面暗（2.5D 双面）；被推动时箱底冒两粒尘土；**到位时变成礼物盒**（缎带 + 蝴蝶结 + 一圈金光脉冲），`bh-done` 语义不变。 |
| **地形质感** | 墙格画矮木栅栏（顶亮边 + 立柱投影）；冰面加对角高光条 + 三粒气泡冻结点，滑行时冰面拉出短擦痕线；目标点画成草窝圆环（内圈虚线呼吸微光）；传送门双色旋涡（CSS `conic-gradient` 旋转，进出口反色，reduced 静止）。 |
| **移动语义区分** | 推动：仓鼠推箱姿态 + 尘土；滑冰：仓鼠张开小爪「哇」的表情 + 冰擦痕；传送：入口缩小旋入 → 出口放大旋出（200ms，reduced 瞬移）。三种移动一眼可分。 |
| **关卡氛围** | 背景按章节轮换仓鼠小屋主题（木屋 / 冰窖 / 花园）装饰角标；完成关卡时所有礼物盒同时放彩带 + 仓鼠抱腮转圈。 |
| **布局与 HUD** | 步数 / 目标进度 / 撤销按钮卡片化一行；撤销按钮画成小时钟回转图标。 |

- 色板走 `src/art/kit/palette.ts`；2.5D 双面块可复用 kit 已有能力（若 tank-battle 档已落 `block25d.ts`）或自建 CSS 等价。
- `prefers-reduced-motion`：咀嚼、旋涡、脉冲、转圈全停，保留静态层次。

### 四·补一：配色板与 DOM 层级（CSS 自定义属性统一管理）

| token | 色值 | 用途 |
| --- | --- | --- |
| `--bh-floor` | `#F8F1E4` | 地板格 |
| `--bh-wall` | `#C89B6C` | 栅栏墙主色（立柱 `shade(-22)`） |
| `--bh-ice` | `#DDF2FF` | 冰面（高光条白 45%） |
| `--bh-goal` | `#B8E39B` | 草窝圆环 |
| `--bh-box` | `#D9A06B` | 木箱主色（侧面 -22%） |
| `--bh-gift` | `#F4859F` | 礼物盒缎带 |
| `--bh-portal-in` / `--bh-portal-out` | `#9F8FF0` / `#F0C25A` | 传送门进 / 出反色 |
| `--bh-hamster-a` / `--bh-hamster-b` | `#E8B27A` / `#C9CFEA` | 双仓鼠毛色 |

格内层级（z-index 从低到高）：① 地形底（地板 / 冰 / 草窝）→ ② 传送门旋涡 → ③ 箱子 / 礼物盒 → ④ 仓鼠 → ⑤ 尘土 / 擦痕 / 彩带 → ⑥ 完成金光。滑动手势热区在棋盘容器上，几何与 1.2 完全一致。

### 四·补二：仓鼠 SVG 工序单（`hamsterSvg.ts` 参数化，双款 × 四朝向）

1. 底影椭圆（格宽 60%、高 14%）；
2. 圆滚身体（两段贝塞尔，宽高比 1.1:1）+ 三停渐变（顶光 +20%）；
3. 鼓腮帮两团（左右各一，咀嚼时交替鼓起）；
4. 小圆耳一对（款式 A 圆耳 / 款式 B 折耳）+ 头饰（A 小花 / B 呆毛）；
5. 豆豆眼 + 三瓣嘴 + 短尾巴；
6. 四朝向独立姿态：上（背影 + 尾巴居中）/ 下（正脸）/ 左右（侧脸单腮）；推箱姿态前倾 12° + 双爪抵箱 + 后腿蹬地；
7. 滑冰姿态：张开小爪 +「哇」圆嘴。

### 四·补三：动效时序表（CSS 动画时长写成自定义属性）

| 动效 | 触发 | 时长 | 缓动 | reduced 行为 |
| --- | --- | --- | --- | --- |
| 移动平移 | 每步 | **沿用既有过渡时长** | 原样 | 原样（功能动画） |
| 推箱尘土两粒 | 推动 | 240ms | ease-out | 不生成 |
| 冰面擦痕 | 滑行 | 300ms 渐隐 | linear | 不生成 |
| 传送旋入旋出 | 传送 | 200ms | ease-in-out | 瞬移切换 |
| 礼物盒金光脉冲 | 到位 | 500ms 一圈 | ease-out | 静态金边 |
| 腮帮咀嚼 | idle | 两帧 1200ms | step | 静止 |
| 完成转圈彩带 | 过关 | 800ms | ease-out | 静止合影 + 静态彩带 |
