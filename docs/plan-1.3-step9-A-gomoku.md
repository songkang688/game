## 二、极高质量改进方案（可执行绘制规格）

### 1. 棋盘 → 精装木盘

- 保留现有渐变与木纹（190–205 行一笔不动），外圈加 10px 深木边框（双色渐变 + 内侧 1px 金线）+ 四角包角铜饰（SVG 四分之一圆弧）；
- 星位点（219–227 行）加 0.5px 高光偏移（内嵌钉感）；
- 棋盘外背景加一圈桌面色（深茶色渐变），棋盘投 4px 柔影（悬浮在桌上）。

### 2. 棋子 → 抛光到精美

- 黑子渐变三档微调（244–246 行）：`#8E7E92 → #4A4054 → #2E2837`（更沉的墨玉感，减少紫味）；白子保留；
- 新增**落定波纹**：落子回弹结束瞬间一圈细波纹扩散（0.25s，`reduced` 关）——配合现有 `dropScale` 不改其公式；
- 预渲染黑白两张 sprite（尺寸变化重建），13×13/15×15 满盘时用 `drawImage`（性能加固，视觉不变）。

### 3. 标记与提示统一质感

- 最后一手标记：改为棋子上一个小红点漆印（半径 0.12r，带高光）；
- `drawHint` 的教学区块：虚线框保留，底色改极淡金色（与木盘同族，不再是绿色荧光）；脉动幅度减半（更稳重）；
- 禁手红叉保留（抖动是好反馈），叉线端点改圆头（313 行 lineCap 已是 round，确认保留）。

### 4. 对局氛围

- 思考方指示：轮到谁走，棋盘对应侧亮一枚小棋子图标 + 呼吸（`reduced` 静态）；
- AI 思考时棋盘右上角小沙漏旋转（DOM，非画布）；
- 连击威胁提示（活三/冲四教学模式下）：沿用 hint 区块系统，不新加形式。

### 5. HUD 与结算（本步主要增量）

- 顶部座位条：黑白双方各配棋子小图标 + 名字 + 计时；轮到方金色描边；
- **胜利结算仪式**：胜利线扫光（现有）结束后，五连子逐颗跳起 0.15s（间隔 60ms），弹出结算卡——胜方棋子大图 + 手数 + 「复盘」按钮（沿用现有 session 数据只做展示）；
- 谜题模式（puzzles）：过关时目标点开花标记（金色小花，共享 kit）。
