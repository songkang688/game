## 二、极高质量改进方案（可执行绘制规格）

### 1. 金币 → 会转的星币（最高优先级，主管点名）

- 新 `drawCoin(spin)` 规格（预渲染 8 帧旋转序列到 offscreen，`drawImage` 播放）：
  1. 外环：金色径向渐变（`#FFE9A0 → #F0A828`）+ 边缘 1.5px 深金描边；
  2. 内环：亮环凹槽（内径 0.68r 浅金线）；
  3. 中心：五角星压印（深金色，呼应「星币」）；
  4. 旋转：8 帧横向压缩模拟绕 Y 轴转（宽度 1 → 0.25 → 1，侧面帧露出厚度侧棱 2px 深金）；
  5. 光：每 1.2s 一道斜向扫光帧；被磁铁吸附时拖 2 帧金色残影；
- 吃到金币：金色 +5 飘字 + 3 粒星屑（走现有 `particleCount` 画质分档）。

### 2. 玩家 → 彩虹跑者（核心资产）

- 保留全部动画骨架（跳跃 lift、滑铲压扁、侧倾、影子公式一行不动），重画身体：
  1. 造型：2 头身跑者——圆头 + 短身，头顶彩虹色发带（飘 2 帧）、背后小披风（奔跑/飞行时飘动，滑铲收起）；
  2. 奔跑循环：现有双脚交替（2035 行 step 公式保留）+ 新增双臂前后摆（反相位）；
  3. 姿态脸：奔跑=专注眼、跳跃=张嘴笑、滑铲=眯眼、无敌闪烁保留（1979 行）+ 添金色残影 2 帧、撞击=×眼 0.3s；
  4. 滑板/火箭道具态：滑板保留（2009–2019 行）加轮子转动线；火箭喷焰从随机圆改为锥形三层焰（芯白/中黄/外橙，1.5 帧抖动）；
- 双人模式（若入口存在）：P2 换蓝发带 + 星星披风（形状+色双通道）。

### 3. 障碍 → 有体积的障碍（2.5D 立面）

- 每种障碍加「顶面/立面」双色（利用现有投影缩放，不改判定）：
  - rock → 彩虹水晶簇：3 根斜晶柱（亮面/暗面双色 + 顶端高光），替代淡紫椭圆；
  - hurdle → 糖果栏架：双圆柱腿（侧面暗色）+ 条纹横杆；
  - bar → 彩虹光栅门：三色横条保留 + 两侧立柱加顶面椭圆 + 底部投影；
  - pit → 坑洞加内壁渐变（上缘亮 → 底黑）+ 边缘碎石 3 粒；
  - roller → 保留旋转纹路，加左右高光带 + 底部接地阴影加深；
- 所有障碍统一在脚下画接地椭圆影（与玩家影子同规格），把「贴片感」压下去。

### 4. 道具 → 图标化

- `🧲🚀🛹` emoji 改为绘制图标（磁铁=红蹄形+银端、火箭=白身红头蓝窗、滑板=板+双轮），白圆底保留改为泡泡球（渐变+高光），浮动 ±3px 正弦（`reduced` 静止）。

### 5. 世界与关卡差异（吃现有系统红利）

- `PARALLAX_LAYERS` 三层剪影按世界主题换形状常量：糖果世界（棒棒糖树/软糖山）→ 海岛（棕榈/浪线）→ 雪原（雪杉/冰峰）→ 星夜（星山/极光带）；每 1600 米随 `mixHex` 换色时同步换剪影表；
- 地面：车道线（`laneDashes` 档位保留）加彩虹渐变路肩 2 条；
- 追风棉花云：加卷云眉毛（生气脸），警告红晕保留。

### 6. 结算

- 里程碑（每 1600 米）：横幅「第 N 世界」+ 世界图标飞过 0.8s；
- 结算面板：里程/金币/最高连击 + 世界进度带（小图标点亮），幽灵对比（超过上次的里程点金色标记）。

## 三、2D / 2.5D / 3D 决策（按 1.3 规范：本款必须地铁跑酷级纵深）

- **维持并强化现有 Canvas 2.5D 方案**：`view3d.ts` 的透视相机 + 分层精灵正是「Canvas 透视+分层精灵」的标准答案，**禁止引入 three.js**（离线 PWA 体积与低端机帧率优先，注释与画质自适应系统都是为此设计的）；
- 纵深增强三件套（全部走现有 `QUALITY_TIERS` 分档）：
  1. 障碍/金币接地影（近大远小，跟随投影 scale）；
  2. 金币旋转帧与障碍立面（贴片变体积）；
  3. 视差剪影主题化（远景不再是抽象带子）。
