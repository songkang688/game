## 三、现状审美评测（先开代码再动笔）

打开 `src/games/red-blue-race/index.ts`，渲染入口是 `render`（多处）/ `renderFoes` / `renderGear` 与车道构建段（约 398–409 行）。已核实的问题：

1. **赛道是两条平铺 DOM 横条**：跑者用 `left` 百分比平移（`rbr-runner` 类，98 行），赛道没有任何纵深——没有透视收敛、没有地平线、没有观众席，「赛跑」的现场感为零；
2. **跑者是头像圆片**：40px 圆形头像图 + 白描边（86 行），跑步动画就是整个圆上下摆（`rbrStride`，99 行）——没有腿、没有摆臂、没有跑姿，圆片漂移不像在跑；
3. 跳跃只有 `rbrJump` 一个位移动画（100–101 行）；
4. 障碍与道具（水坑 💧 / 栏架 🚧 / 星星 / 礼物箱）预期是 lane 里的 emoji（自查 `table` 渲染段确认）；
5. 冲线结算浮层信息设计不错（保住），但 🏁 也是 emoji；`renderFoes` 多人模式的画法自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **2.5D 赛道（核心）** | 双车道改伪透视：整个赛道容器用 CSS `perspective(720px) rotateX(18°)` 做地面倾斜（近端宽远端窄），车道分隔线与米数刻度沿透视收敛；跑者 `left` 百分比映射公式不变，只是贴到倾斜面上。天空 / 地面分界加地平线与远景剪影（看台 + 彩旗两层视差）。 |
| **跑者小人（核心）** | 头像圆片替换为侧视 SVG 小人：头（保留头像圆做脸）+ 躯干 + 两腿两臂；跑姿两帧交替（摆臂 + 跨步，频率映射 `setStride` 的既有输出）；跳跃时腿收起 + 落地小尘土；被水坑滑到时坐地转圈星星（不痛苦）；红蓝两人服装差异（背心号码 1 / 2 + 鞋色）。 |
| **障碍与道具自绘** | 水坑 = 椭圆水洼（反光高光 + 溅水两滴）；栏架 = 双腿小跨栏（条纹杆）；星星 / 礼物箱自绘（渐变 + 描边）；被拾取时飞向对应跑者头顶化为 +8 米飘字（结算逻辑不动）。 |
| **冲线仪式** | 终点画格纹拱门 + 缎带；冲线慢镜（时长沿用 `FINISH_SLOWMO_MS`）中加速度线与彩纸（`spawnConfetti` 已有则精修粒子形状为星星 / 纸带混合）；🏁 emoji 换自绘格纹旗。 |
| **起跑与犯规** | 起跑指示灯三盏（红红绿，读既有 `createStartGate` 状态）；抢跑时裁判小哨音气泡「再等等哦」（不批评）。 |
| **布局与 HUD** | 米数对比 `distEl` 升级为双色进度双条 + 领先方小皇冠标；比分 `scoreEl` 卡片化。 |

- 色板走 `src/art/kit/palette.ts`；星屑 / 彩纸走 `sparkle.ts` 的 CSS 等价。
- `prefers-reduced-motion`：跑姿交替、视差、慢镜特效全停（保留位置更新与结算），静态层次保留。
