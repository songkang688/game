## 三、现状审美评测（先开代码再动笔）

打开 `src/games/mole-pop/index.ts`，渲染入口是 `renderHole` / `renderTop` / `renderTorch`。已核实的问题：

1. `renderHole`（约 205 行起）把整只地鼠画成 `innerHTML` 里的一个 emoji：普通鼠 = `MOLE_SPECS[kind].emoji`，带护盾 / 帽子的也是同一个 🐹（216–218 行）——「打地鼠」的主角是系统字体字符，种类差异全靠 emoji 换字，护盾态与普通态**画面完全一样**只剩逻辑不同，孩子分不清哪只要打两下；
2. 洞本体预期是 DOM 圆或纯色块（自查 CSS `mp-` 类确认）：没有洞口土堆、没有洞内阴影，「地下冒出来」的空间感为零；
3. 出洞 / 缩回只有 `mp-face-drop` 一个下落类（211 行），没有冒头预告、没有被敲扁的反馈帧；
4. 算术卡 `mp-card`（212–214 行）是文本片，缺卡片质感；
5. `renderTorch` 火把与场景背景自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **地鼠自绘（SVG）** | emoji 替换为参数化 SVG 地鼠：圆头 + 大门牙两颗 + 圆爪扒洞沿 + 腮红；种类差异画在装备上——普通鼠素颜、护盾鼠抱一面小盾牌（第一下敲掉盾，盾裂开飞走）、帽子鼠戴安全帽（第一下帽子飞）、算术鼠举一块小黑板。**装备是独立 SVG 层**，`hits` 逻辑不动，只按剩余次数显示 / 隐藏装备层。 |
| **洞口空间感** | 每个洞三层 DOM：后沿土堆（深色弧）→ 地鼠层（`overflow: hidden` 裁剪，从洞里升起）→ 前沿土堆（浅色弧盖在地鼠下半身前）——「从地下冒出来」的遮挡关系立刻成立；洞内加径向渐变暗部。 |
| **动作三帧** | 冒头预告（洞口土粒抖两下，150ms）→ 升起（`translateY` 既有时序）→ 被敲中（压扁 0.8 倍 + 星星圈 3 颗 + 滑回洞，不痛苦、吐舌笑）。缩回未敲中则打个哈欠再降。reduced：全部瞬时切换。 |
| **算术卡质感** | `mp-card` 升级为木质小黑板（木框 + 深色板面 + 手写体算式 + 挂绳），出题时轻摆 ±3°。 |
| **场景氛围** | 背景画成草地果园：三排草丛错落、远景两棵圆树 + 栅栏；夜场（若 `renderTorch` 对应夜关）火把改成自绘火苗（双层摇曳，reduced 静止）+ 洞口暖光圈。 |
| **布局与 HUD** | 分数 / 连击 / 倒计时卡片化一行；连击数字跳动（scale 1.2 → 1，120ms）。 |

- 色板走 `src/art/kit/palette.ts`；SVG 徽章可复用 `badge.ts`（若 A 档已落）或自建。
- `prefers-reduced-motion`：土粒抖动、摆动、跳动全停，保留静态层次。
