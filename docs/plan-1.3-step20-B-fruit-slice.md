## 三、现状审美评测（先开代码再动笔）

打开 `src/games/fruit-slice/index.ts`，绘制入口很多：`drawFruit` / `drawHalf` / `drawTrail` / `drawBanana` / `drawBomb` / `drawIce` / `drawBoomFruit` / `drawDoubleFruit` / `drawFlower` / `drawTwinFruit` / `drawShell` / `drawCommand` / `drawKing` / `drawMenu` / `drawMap` / `drawThemes` 等。已核实的问题：

1. `drawFruit`（约 1725 行起）的果身已有径向渐变 + 描边 + 高光 + 呆萌表情（1778–1876 行）——**底子是全库水果里最好的**，但致命伤在剪影：除香蕉有 `drawBanana` 外，瓜瓜 / 桃桃 / 橙橙 / 莓莓 / 柠柠**全都是同一个 `arc` 正圆**（1785 行），差异全靠圆内表面纹理（瓜纹 / 桃缝 / 皮孔 / 籽点 / 点阵）——飞起来的时候全是圆球，「切什么水果」只能看颜色；
2. `drawHalf`（1880 行起）切半后的切面自查：预期是半圆填充，果肉纹理（橙瓣放射 / 瓜瓤黑籽 / 莓芯）有没有画出来要评；
3. `drawTrail` 刀光轨迹自查：预期是单色线条，缺丝带感与切中白闪；
4. 菜单 / 地图 / 面板一族（`drawMenu` / `drawMap` / `drawIntroPanel` 等）是本款自绘 UI 的好底子，逐个自查排版与质感，把结论记进开工 commit；
5. `drawKing` 国王 / `drawFlower` 花朵等特殊目标的观感自查。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **专属剪影（核心整改）** | 五种圆果改专属路径：桃桃 = 心形带尖 + 侧叶；瓜瓜 = 宽椭圆 + 深浅条纹随形；橙橙 = 正圆保留但加顶部凸脐 + 叶柄斜出；莓莓 = 倒水滴 + 蒂部五角叶盖；柠柠 = 橄榄形两端小凸。渐变 / 表情 / 高光的既有画法迁移到新剪影上；判定仍用 `f.r` 圆（画大不改判）。 |
| **切面果肉** | `drawHalf` 每种画专属切面：橙橙放射八瓣 + 中轴白膜；瓜瓜红瓤 + 黑籽 6 粒 + 白皮环；桃桃黄瓤 + 中心核；莓莓白芯放射细纹；柠柠瓣格 + 汁泡点。切开瞬间切面亮 1 帧再落定。 |
| **刀光升级** | `drawTrail` 改三层丝带：芯线白 → 中层主题色 → 外晕渐隐；切中瞬间接触点白闪星花 2 帧 + 果汁液滴 3 颗沿切向飞出（同果色，300ms 渐隐）。 |
| **特殊物精修** | 炸弹改「乌云娃娃」（皱眉 + 引信星火，不写实）；冰果加冰晶棱面与寒气丝两缕；加倍果金边脉动；连切 combo ≥ 5 时背景飘落同色花瓣雨 1s（reduced 关）。 |
| **舞台氛围** | 游戏背景加砧板 / 果园舞台语义（下方木纹台面 + 上方轻纱幕布渐变）；`drawMenu` / 面板一族统一圆角卡片 + 标题缎带。 |
| **布局与 HUD** | 分数 / 连击 / 剩余目标卡片化；连击数字弹跳 + 描边。 |

- 渐变 / 描边 / 星花统一走 `src/art/kit/`（A 档若已落 `fruit.ts` 剪影库，优先复用对齐观感）；光源统一左上 45°。
- `prefers-reduced-motion`：花瓣雨、脉动、液滴、弹跳全停，保留静态渐变与切面。

### 四·补一：剪影与切面规格明细（逐果写死比例）

| 果 | 整果剪影 | 切面规格 |
| --- | --- | --- |
| 桃桃 | 心形带尖（顶凹 0.12r、底尖 0.08r）+ 侧叶一片 | 黄瓤 + 中心核（0.22r 椭圆）+ 核纹两道 |
| 瓜瓜 | 宽椭圆（宽:高 = 1.25:1）+ 随形条纹 5 道 | 红瓤 + 白皮环 0.1r + 黑籽 6 粒（弧形排布） |
| 橙橙 | 正圆 + 顶凸脐 0.1r + 叶柄斜出 25° | 放射八瓣 + 中轴白膜 2px + 瓣间细线 |
| 莓莓 | 倒水滴 + 蒂部五角叶盖 | 白芯放射细纹 12 条 + 外圈籽点 |

## 九、测试（只增不减，新增 ≥ 12 个视觉用例）

1. 五种新剪影路径函数两两不相等（至少抽 3 对断言）；
2. `drawFruit` 主干不再是统一 `arc` 正圆（对桃 / 瓜 / 莓断言走专属路径分支）；
3. 剪影外接尺寸 ≤ 1.15 × `f.r`（上限常量断言，判定不改）；
4. 六种切面绘制分支各自可调用不抛错（domStub 2D 桩）；
5. 切面细节常量（黑籽 6 / 放射 8 瓣 / 细纹 12 / 瓣格 8）一测；
6. 刀光三层与白闪帧只在切中时出现（未切中不出）；
7. 液滴颜色 = 对应果主色（映射断言）、上限 3 颗 / 次；
8. 炸弹分支为乌云娃娃路径、无写实炸弹元素（字符串断言）；
9. 花瓣雨仅 combo ≥ 5 触发、时长 1000ms、reduced 关闭；
10. 冰冻 / 加倍状态映射只读效果逻辑（断言状态不被写）；
11. `destroy` 后液滴与花瓣粒子归零；
12. 既有抛物线与判定测试断言一个不许改（diff 不出现玩法测试文件）。
