## 三、现状审美评测（先开代码再动笔）

打开 `src/games/sky-squad/index.ts`，绘制入口是 `draw` / `drawPlane` / `drawFoe` / `drawBoss` / `drawBullets` / `drawShots` / `drawEnemyShape`。已核实的问题：

1. `drawPlane`（约 1409 行起）的主机 = 两个纯色椭圆机翼 + 一个 `roundRect` 机身 + 白椭圆驾驶舱 + 一个色点，通体没有一处渐变、描边或高光，粉 / 蓝两架只换 `fillStyle`，像两粒药丸；
2. 僚机（1467–1478 行）就是 16×24 的圆角矩形加一个 2.4px 圆点，连机翼都没有——「小队」的僚机比主机还敷衍；
3. `drawFoe`（1481 行起）四种敌机 = 三角形（scout）/ 圆加两圆（puff）/ 菱形（kite）/ 圆角矩形（tanker）纯色几何 + 两颗定位眼，剪影之间只差一个多边形，没有任何「飞行器」特征（机翼、尾翼、螺旋桨全无）；
4. 尾焰是一个三角形 `#FFD678` 正弦抖动（1431–1437 行），没有内焰 / 外焰层次；
5. 画面没有任何纵深：没有云层视差、没有飞机在云上的投影，`drawBoss` 的 BOSS 你要逐行读完，把它的问题一并记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **2.5D 天空** | 三层云海视差：高空薄云（速度 0.2×、`rgba(255,255,255,.28)`）、中层棉花云（0.5×、自绘三球云朵 + 底部投影）、低层大朵云（0.9×、边缘受光）。飞机在中层云上投一个 0.12 透明度的椭圆影子，随高度（y 坐标）缩放——纵深靠影子讲出来。 |
| **主机建模** | 机身三停线性渐变（顶光 +25% → 主体 → 腹部 -15%）+ 1.5px 深色描边；机翼改后掠剪影（贝塞尔前缘）带翼尖小灯（红 / 绿交替闪，reduced 时常亮）；驾驶舱玻璃加斜向高光条；左右平移时机身 `scaleX(0.82)` 侧倾 + 内侧机翼抬起，做出压坡度转弯的 2.5D 感（只在绘制层做，判定坐标不动）。 |
| **僚机** | 缩小版主机剪影（同一份路径函数按 0.55 缩放复用），带半透明牵引光索连到主机，一眼看出「这是编队」。 |
| **敌机剪影** | scout=纸飞机折痕剪影；puff=气球飞艇（吊篮 + 系绳）；kite=风筝（十字骨架 + 飘尾）；tanker=胖运输艇（舷窗两枚 + 底部浮筒）。保持原 `info.r` 判定半径，只在半径内重画。每种加受光面与 1.5px 描边。 |
| **BOSS 与弹幕** | BOSS 加分层：底盘暗色 → 主体渐变 → 顶部炮台独立小剪影；蓄力提示 `cueLeft` 映射成机身外圈红晕渐亮（功能不变画法升级）。敌弹加拖尾渐隐 3 帧，我方弹加星星头 + 光带尾。 |
| **HUD 布局** | 双人分数 / 火力等级 / 护盾各自卡片化（圆角 12px、白 72% 底、描边 1.5px）；boss 血条加圆角壳与分段刻度。 |

- 渐变 / 描边 / 落影 / 粒子统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：视差减速为 0、侧倾与翼灯闪烁关闭，保留静态层次。

### 四·补一：配色板与图层序（落成常量块再引用）

| token | 色值 | 用途 |
| --- | --- | --- |
| `sksSkyTop` | `#BDE3FF` | 天空线性渐变顶 |
| `sksSkyBottom` | `#E8F6FF` | 天空线性渐变底 |
| `sksCloudHi` | `rgba(255,255,255,.28)` | 高空薄云 |
| `sksCloudMid` | `#FFFFFF` | 中层棉花云主体 |
| `sksPlanePink` | `#F4859F` | 朵朵机身主色 |
| `sksPlaneBlue` | `#7FB2F0` | 星星机身主色 |
| `sksFlameIn` | `#FFF4C2` | 尾焰内焰 |
| `sksFlameOut` | `#FFB36B` | 尾焰外焰 |
| `sksShadow` | `rgba(70,90,120,.12)` | 飞机投在云上的影子 |

图层序（`draw` 每帧从底到顶）：① 天空渐变 → ② 高空薄云（0.2×）→ ③ 中层棉花云（0.5×）+ 飞机投影 → ④ 低层大朵云（0.9×）→ ⑤ 敌机与敌弹 → ⑥ 我方弹 → ⑦ 主机 + 僚机 → ⑧ 粒子 → ⑨ HUD。判定核心永远画在主机层最顶，不许被云盖住。

### 四·补二：主机工序单（`drawPlane` 重写为固定 7 道工序）

1. 云上投影：`softShadow`，偏移 (0, +26px)，大小随 y 越低越大（0.8–1.15 倍），透明度 0.12；
2. 后掠机翼路径（贝塞尔前缘，翼展 = 原椭圆宽，路径函数抽成 `planePath(scale)` 供僚机复用）；
3. 机身三停线性渐变（顶 +25% → 主体 → 腹 -15%）+ 1.5px `shade(-30)` 描边；
4. 驾驶舱玻璃：椭圆 + 斜向白高光条（宽 0.3 舱宽、倾角 45°）；
5. 翼尖小灯：左红右绿交替闪（周期 800ms，reduced 常亮）；
6. 尾焰双层：外焰 `sksFlameOut` 三角正弦抖动（沿用原抖动参数）、内焰 `sksFlameIn` 0.6 倍缩放同步；
7. 侧倾：水平速度映射 `scaleX` 0.82–1.0 + 内侧机翼抬 3px，只包 `ctx.save/restore`，world 坐标不动。

### 四·补三：动效时序表（毫秒写死成常量并被测试引用）

| 动效 | 触发 | 时长 | 缓动 | reduced 行为 |
