## 三、`bumper-cars` 独立评测与改进

### 3.1 现状审美评测（先开代码再动笔）

打开 `src/games/bumper-cars/index.ts`，绘制入口是 `render` / `drawSprings` / `drawCliffs` 与 `emojiAt`。已核实的问题：

1. **车就是一个 emoji 字符**：`emojiAt(car.emoji, ...)`——号称「碰碰车」的主角没有一笔自绘，复活预告也是 28% 透明度的同一个 emoji（约 746–750 行）；不同机器 emoji 字形不一致，阵营辨识与大小都不可控；
2. 油渍 = 紫色平涂圆 + 💧 emoji（689–702 行）；滚桶 = 平涂圆 + 内圈描边 + 🛢️ emoji（726–737 行）；旋转盘 = 平涂圆 + 4 根线（705–723 行）——全部道具是「圆 + emoji」的偷懒画法；
3. 场地是 `traceField` 平涂两层（融冰圈粉、地面一色），俯视图没有任何厚度：没有围栏立面、没有场边灯串、没有地板反光，「乱斗竞技场」的气氛为零；
4. 蓄力环 / 冲刺残影是纯色圆弧与圆（752–767 行），功能对但观感是 debug 图形；
5. `drawSprings` / `drawCliffs` 逐行自查，把弹簧与悬崖边缘的画法结论记进开工 commit。

### 3.2 改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **碰碰车自绘（2.5D）** | 顶视碰碰车三层：底层防撞橡胶圈（深色环 + 高光弧）、中层车壳（阵营色三停径向渐变，左上受光）、顶层座舱（圆头小司机：朵朵花发卡 / 星星呆毛 + 扶方向盘的两只手）+ 车尾集电杆（斜线 + 顶端小旗，转向时摆动）。半径仍是 `car.r`，只在半径内重画。 |
| **碰撞与蓄力** | 撞击瞬间车壳 squash（受击方向压扁 12%、80ms 回弹，reduced 关）+ 接触点星花 4 颗；蓄力环改成车壳外圈流光跑道（进度映射不变），满蓄时旗子竖起。 |
| **场地 2.5D** | 场地边缘画围栏立面（高 10px 的双色栏板 + 支柱投影）、四角灯柱 + 灯串（灯泡交替亮，reduced 常亮）；融冰边缘改成冰层断面（浅蓝立面 + 裂纹），一眼看出「掉下去就出局」的空间关系；地板加放射状灯光反射斑两块。 |
| **道具自绘** | 油渍改成彩虹肥皂渍（多色薄膜渐变 + 泡泡两颗）替代 💧；滚桶改成木纹滚筒（横纹 + 端面年轮）替代 🛢️；加速带箭头加流光推进；旋转盘画成唱片机转盘（同心纹 + 中心星标）。 |
| **布局与结算** | 存活数 / 计时卡片化；胜利车绕场一周撒彩纸，出局车画成「降落伞飘回看台」不惨烈。 |

## 四、`bowling-lane` 独立评测与改进

### 4.1 现状审美评测（先开代码再动笔）

打开 `src/games/bowling-lane/index.ts`，绘制入口是 `render` / `band` / `rail` 与 `laneProject`。已核实的问题：

1. `laneProject` 已经有近大远小投影、`band` 用 10 段折线画出会聚形（687–704 行），**透视骨架是好的**——但球道面就是一块 `#f7e6c8` 平涂梯形：没有木纹板缝、没有油区镜面反光（油区只是一层半透明蓝，746 行）、没有球道尽头的瓶台灯箱，透视有骨没有肉；
2. 球瓶 = 白椭圆 + 粉描边（789–799 行）：真保龄瓶的「细颈宽肩」剪影没有、红颈环没有、瓶身高光没有；倒瓶就地变成一个躺平椭圆（794 行），没有倒下的过程；
3. 球 = 纯色圆 + 3 个白点公转（810–827 行）：白点是「转」的功能表达（保住），但球体没有径向渐变、没有指孔、没有地板反射；
4. 特殊瓶靠 emoji `fillText(pinFace(kind))` 贴在瓶身上（800–805 行）；
5. 跟球运镜（730–738 行）是好底子，保住；犯规线 / 教学线画法自查后把结论记进开工 commit。

### 4.2 改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **球道透视补肉** | 沿 `laneProject` 会聚线画 6–8 条木板缝（远端变密变淡）、左右沟改成有内壁立面的凹槽（内壁深 22%）；油区改成镜面高光带：纵向白色渐变条 + 球经过时的倒影拉丝；尽头加瓶台灯箱立面（暖光渐变 + 顶部小星招牌），透视灭点感立刻成立。 |
| **球瓶重绘** | 用两段贝塞尔画「细颈宽肩」标准瓶剪影 + 双红颈环 + 左上高光条 + 脚下椭圆落影；特殊瓶把 emoji 换成瓶身彩绘徽章（自绘星星 / 花朵 / 盾牌小图案）；击倒动画：瓶绕底部支点旋转倒下 250ms + 弹跳一次（reduced 直接躺平），倒下方向沿受击矢量。 |
| **球体积** | 三停径向渐变（高光偏左上）+ 三指孔（随既有白点相位公转，替代白点）+ 球下镜面倒影椭圆；出手时球道接触点微光。 |
| **氛围层** | 馆内背景：天花板垂灯两盏暖光晕、两侧霓虹装饰线（粉 / 蓝呼吸，reduced 常亮）；全中（strike）时瓶台灯箱闪三下 + 星星彩纸雨。 |
| **布局与计分** | 计分板卡片化（圆角、白 72% 底、当前格高亮描边）；aim 调整箭头加圆钮质感。 |

## 五、光照与统一规格（两款通用）
