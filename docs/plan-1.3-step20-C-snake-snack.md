## 三、现状审美评测（先开代码再动笔）

打开 `src/games/snake-snack/index.ts`，绘制入口是 `draw`（约 314 行起）/ `renderTop` / `renderPace`。已核实的问题：

1. **「毛毛虫」没有一节是圆的**：蛇身就是逐格 `fillStyle` 方块，头一色、身体两色交替（387–392 行）——名字叫毛毛虫，画出来是一列色块火车，没有头脸、没有触角、没有体节的圆润感；
2. 场景元素全部 emoji 直出：墙 🌿（327 行）、待踩圈 🌼🔐（347 行）、传送 🌀（354 行）、门 🚪🔒（362 行）、石头 🪨（367 行）、刺猬 🦔（372 行）、食物 `snackEmoji`（377 行）、奖励 ⭐（379 行）——一屏九种 emoji，是全库 emoji 拼贴最重的一款；
3. 绕圈机制的「踩过点亮」用平涂半透明黄块（332–334 行），功能对但与场景无融合；
4. 移动是逐格瞬跳（自查确认有无插值），转弯处直角生硬；
5. 吃到食物 / 撞墙的反馈画法自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **毛毛虫化（核心整改）** | 蛇身改「圆节相连」：每节画圆（半径 = CELL×0.42，向尾部递减到 0.34）+ 相邻节间用胶囊连接补隙，转弯处圆自然圆滑；节色双色交替 + 每节顶部小高光点；头部大圆 + 两根球头触角 + 大眼（朝移动方向看）+ 微笑；尾节小圆带尖。**格子判定完全不动，只是把「方块」画成「圆节」。** |
| **移动与吃食动画** | 逐格移动加绘制层插值（上一格 → 当前格 80ms 平滑，逻辑 tick 不变）；吃到食物时头部张嘴一帧 + 「咕」的鼓包沿身体传导两节（纯视觉波，reduced 关）；奖励星吃到时全身闪金 1 帧。 |
| **场景自绘** | 九种 emoji 全部替换：墙 = 草丛簇（三球叠层 + 深浅两色）；待踩圈 = 花砖（未踩灰花 / 踩过亮花 + 微光）；传送 = 双色旋涡；门 = 木门 + 锁牌（开门时门板旋开 150ms）；石头 = 三棱面岩石；刺猬 = 自绘圆背小刺球（友好脸，碰到只是「哎呀」弹回语义不变）；食物 = 自绘小果子（三停渐变 + 叶）；奖励 = 自绘五角星 + 光晕。 |
| **场地质感** | 棋盘底改双色格（明度差 4%）+ 四周花园栅栏边框；绕圈路径用花砖串联出「一条小路」的视觉语义。 |
| **布局与 HUD** | 长度 / 目标 / 节奏档卡片化一行（`renderTop` 精修）；`renderPace` 节奏提示做成小鼓图标 + 点点节拍。 |

- 渐变 / 描边 / 星光统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：插值平滑、鼓包传导、旋涡全停（逐格瞬跳保留），保留静态圆节与层次。

### 四·补二：毛毛虫工序单（`caterpillar.ts`，六道工序）

1. 逐节落影小椭圆（仅头与偶数节，避免过密）；
2. 节圆：半径 CELL×0.42 → 尾部线性递减至 0.34，双色交替 + 三停渐变；
3. 节间胶囊补隙（相邻节中心连线方向，宽 = 较小节径 0.9）；
4. 每节顶部高光点一粒（偏左上 30%）；
5. 头部：大圆 + 球头触角两根（< 12px 头径省略）+ 大眼朝移动方向 + 微笑弧；
6. 尾节小圆带尖 + 摆尾 2 帧（reduced 静止）。
