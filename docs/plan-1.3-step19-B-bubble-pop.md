## 三、现状审美评测（先开代码再动笔）

打开 `src/games/bubble-pop/index.ts`，泡泡出自 `paintCell`（约 121 行起）与 `paintBoard`。已核实的问题：

1. **普通泡泡是平涂**：非彩虹非连锁的泡泡就是 `el.style.background` 一个纯色（自查确认具体行），高光 / 体积 / 通透感为零——泡泡消除游戏里泡泡没有「泡」感；
2. 只有彩虹泡有 `conic-gradient`（132 行）+ 🌈 emoji 兜底、连锁泡待自查——特殊泡靠 emoji 是偷懒；
3. 铁泡 / 双子泡靠 `box-shadow` 双圈（`bp-` 类自查），本体仍是平涂；
4. 消除反馈（预期是删除节点或简单缩放）没有「噗」的破裂过程；
5. 盘面背景与列对齐的视觉（自查 CSS）预期是纯色底，缺水下 / 天空氛围。逐条把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **泡泡体积（核心整改）** | 每颗泡泡三层叠加：`radial-gradient` 左上白高光斑（55% → 0）+ 主体色渐变（中心透亮 → 边缘深 12%）+ 底部内缘反光弧（`inset box-shadow` 白 20%）；加 `::before` 小月牙副高光。**盘面上不许存在纯色平涂泡**。 |
| **特殊泡本体差异** | 彩虹泡：conic 渐变保留 + 缓慢旋转（`@property` 或旋转伪元素，reduced 静止），🌈 emoji 换成中心白星 SVG；连锁泡：本体加闪电纹路径；铁泡：金属纵纹 + 铆钉（圈保留）；双子泡：双球相切 + 连结点高光。 |
| **破裂动画** | 点消时三阶段：鼓 1.12 倍（50ms）→ 薄膜白环扩散（120ms）→ 水珠 4 滴溅落渐隐（240ms）；连消时同批泡泡按距离波次破裂（每波 40ms 延迟，读既有消除集合只做时序展示，**结算时机不变**）。reduced：直接淡出。 |
| **盘面氛围** | 背景改水下光柱两道（斜向白 8% 渐变）+ 缓升小气泡装饰（3–5 颗，避开盘面主体，reduced 静止）+ 底部水草剪影一排；盘底加浅色圆角池壁。 |
| **掉落与补位** | 泡泡下落补位加轻微果冻落定（scaleY 0.92 → 1，90ms，reduced 关）——只改过渡样式，不改补位逻辑与时序。 |
| **布局与 HUD** | 目标 / 步数 / 分数卡片化一行；连消数字带彩色描边跳动。 |

- 渐变规格与 A 档 `balloon-pop` 对齐（同用 `src/art/kit/` 的 token 与皮肤函数），三款泡泡 / 气球观感一致。
- `prefers-reduced-motion`：旋转、波次、果冻、装饰气泡全停，保留静态体积。
