## 三、现状审美评测（先开代码再动笔）

打开 `src/games/bubble-pop/index.ts`，泡泡出自 `paintCell`（约 121 行起）与 `paintBoard`。已核实的问题：

1. **普通泡泡是平涂**：非彩虹非连锁的泡泡就是 `el.style.background` 一个纯色（自查确认具体行），高光 / 体积 / 通透感为零——泡泡消除游戏里泡泡没有「泡」感；
2. 只有彩虹泡有 `conic-gradient`（132 行）+ 🌈 emoji 兜底、连锁泡待自查——特殊泡靠 emoji 是偷懒；
3. 铁泡 / 双子泡靠 `box-shadow` 双圈（`bp-` 类自查），本体仍是平涂；
4. 消除反馈（预期是删除节点或简单缩放）没有「噗」的破裂过程；
5. 盘面背景与列对齐的视觉（自查 CSS）预期是纯色底，缺水下 / 天空氛围。逐条把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **泡泡体积（核心整改）** | 每颗泡泡三层叠加：`radial-gradient` 左上白高光斑（55% → 0）+ 主体色渐变（中心透亮 → 边缘深 12%）+ 底部内缘反光弧（`inset box-shadow` 白 20%）；加 `::before` 小月牙副高光。**盘面上不许存在纯色平涂泡**。 |
| **特殊泡本体差异** | 彩虹泡：conic 渐变保留 + 缓慢旋转（`@property` 或旋转伪元素，reduced 静止），🌈 emoji 换成中心白星 SVG；连锁泡：本体加闪电纹路径；铁泡：金属纵纹 + 铆钉（圈保留）；双子泡：双球相切 + 连结点高光。 |
| **破裂动画** | 点消时三阶段：鼓 1.12 倍（50ms）→ 薄膜白环扩散（120ms）→ 水珠 4 滴溅落渐隐（240ms）；连消时同批泡泡按距离波次破裂（每波 40ms 延迟，读既有消除集合只做时序展示，**结算时机不变**）。reduced：直接淡出。 |
| **盘面氛围** | 背景改水下光柱两道（斜向白 8% 渐变）+ 缓升小气泡装饰（3–5 颗，避开盘面主体，reduced 静止）+ 底部水草剪影一排；盘底加浅色圆角池壁。 |
| **掉落与补位** | 泡泡下落补位加轻微果冻落定（scaleY 0.92 → 1，90ms，reduced 关）——只改过渡样式，不改补位逻辑与时序。 |
| **布局与 HUD** | 目标 / 步数 / 分数卡片化一行；连消数字带彩色描边跳动。 |

- 渐变规格与 A 档 `balloon-pop` 对齐（同用 `src/art/kit/` 的 token 与皮肤函数），三款泡泡 / 气球观感一致。
- `prefers-reduced-motion`：旋转、波次、果冻、装饰气泡全停，保留静态体积。

### 四·补一：泡泡皮肤规格（`bubbleSkin.ts`，与 A 档 `balloonSkin` 同族）

`bubbleSkin(base: string): string` 输出三层叠加 background：

1. `radial-gradient(circle at 30% 24%, rgba(255,255,255,.8), transparent 40%)` —— 主高光；
2. `radial-gradient(circle at 50% 46%, shade(base,+10), shade(base,-12) 94%)` —— 主体明暗；
3. `inset box-shadow: 0 -2px 4px rgba(255,255,255,.2)` —— 底部内缘反光弧（写在同一函数返回的样式对象里）。

副高光 `::before` 小月牙（白 45%、宽 22% 高 12%、左上 18% 处；泡泡 < 32px 时省略）。

| token | 色值 | 用途 |
| --- | --- | --- |
| `--bp-water-top` / `--bp-water-bottom` | `#DFF4FF` / `#C9E8F8` | 水下背景渐变 |
| `--bp-lightbeam` | `rgba(255,255,255,.08)` | 两道斜向光柱 |
| `--bp-weed` | `#9FD9B8` | 底部水草剪影 |
| `--bp-pool` | `rgba(255,255,255,.5)` | 池壁圆角框 |
| `--bp-splash` | `rgba(190,230,255,.9)` | 破裂水珠 |

### 四·补二：动效时序表（CSS 动画时长写成自定义属性）

| 动效 | 触发 | 时长 | 缓动 | reduced 行为 |
| --- | --- | --- | --- | --- |
| 破裂三阶段 | 点消 | 鼓 50ms + 白环 120ms + 水珠 240ms | 分段 | 直接淡出 |
| 连消波次 | 连消 | 每波延迟 40ms、上限 6 波 | step | 全部同时淡出 |
| 彩虹泡旋转 | 常驻 | 3000ms/圈 | linear | 静止 |
| 补位果冻落定 | 下落 | scaleY 0.92→1、90ms | ease-out | 关闭 |
| 装饰气泡缓升 | 常驻 | 3–5 颗、8s 循环 | linear | 静止 |
| 连消数字跳动 | 连消 | 120ms | ease-out | 关闭 |

波次只改展示延迟：消除集合、得分、结算时机全部沿用既有逻辑（结算在动画前完成，动画纯观赏）。

### 四·补三：特殊泡规格明细

1. 彩虹泡：conic 渐变保留 + 旋转伪元素；中心白星 SVG（五角、直径 40% 泡径）替换 🌈；
2. 连锁泡：本体叠闪电纹路径（两段折线、白 65%、宽 2px），触发连锁时闪电亮 1 帧；
3. 铁泡：金属纵纹（`repeating-linear-gradient` 条宽 3px）+ 铆钉两点；`box-shadow` 圈保留；
4. 双子泡：双球相切（各 78% 缩放）+ 连结点白高光一粒；
5. 全部特殊件在泡径 < 32px 时按「纹样保留、点缀省略」降级（闪电留、铆钉省）。

盘面破裂波次的视觉次序：以点击格为圆心按曼哈顿距离分波，同波内随机 0–12ms 抖动让破裂更自然（抖动只作用于展示）。
