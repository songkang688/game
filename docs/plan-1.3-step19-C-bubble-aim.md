打开 `src/games/bubble-aim/index.ts`，绘制入口是 `draw` / `drawBackground` / `drawGrid` / `drawBubbleAt` / `drawBombAt` / `drawStoneAt` / `drawRainbowAt` / `drawShooter` / `drawAim` / `drawFlight` / `drawObstacles` / `drawAnims` / `drawFloatText` / `drawColorMark` / `drawOverlays`。已核实的问题：

3. `drawBombAt` / `drawStoneAt` / `drawRainbowAt` 三种特殊泡的差异化程度自查（石泡的裂纹两态已有参数，画得够不够醒目要评）；

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **泡泡薄膜升级** | 在既有径向渐变上加：边缘 1px 彩虹薄膜描边（同色系偏移色，低于 6px 半径省略）+ 底部月牙反光 + 贴附成串时相邻泡间的挤压高光点——与 A/B 档观感对齐但保持 canvas 实现。 |
| **发射器剧场化** | `drawShooter` 升级为小炮台：木质底座（木纹两条 + 顶亮边）+ 旋转炮管随瞄准角转动（读既有角度）+ 座舱小星星徽章；下一发泡泡在装填槽里待命并轻微弹跳（reduced 静止）；换弹时旋转交换动画 150ms（逻辑交换时机不变）。 |
| **瞄准线升级** | `drawAim` 虚线改成渐隐圆点串（点径沿路径递减、反弹点画小星花标记）——预测路径的**每个坐标点都用既有物理计算结果**，一个点都不许自己算。 |
| **特殊泡精修** | 炸弹泡：黑猫造型（耳朵 + 引信星火）替代裸炸弹感；石泡：岩石棱面三块 + 裂纹两态加宽至醒目（读既有 cracked 状态）；彩虹泡：旋转七彩环 + 中心白星。 |
| **场景氛围** | `drawBackground` 加：顶部藤蔓与吊灯装饰带（泡泡从「藤架」上垂下的语义）、背景双色渐变 + 远处光斑两粒；掉落的泡泡串加拖尾渐隐；顶板下压（若有压顶机制）时藤架阴影加深。 |
| **布局与 HUD** | 剩余泡 / 分数 / 目标卡片化；`drawFloatText` 飘分加描边与轻弹入场。 |

- 渐变 / 描边 / 落影统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：弹跳、旋转、星火、拖尾全停，保留静态体积与瞄准点串。

### 四·补二：发射器工序单（`drawShooter` 重写为六道工序）

1. 底座落影椭圆；
2. 木质底座（木纹两条 + 顶亮边 + 两颗铆钉）；
3. 炮管旋转层（`ctx.rotate(瞄准角)`，只读角度）：圆管 + 口部亮环；
4. 座舱星星徽章（`star.ts` 若已有则复用）；
5. 装填槽：当前泡右侧小槽，下一发待命泡轻微弹跳（±2px、700ms 周期）；
6. 换弹旋转交换动画 150ms（逻辑交换时机不变，只做视觉过渡）。
