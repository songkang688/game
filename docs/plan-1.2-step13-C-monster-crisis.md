## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **关内成长三选一** | 每 3 波给一次三选一（范围 + / 攻速 + / 多向 + / 吸附 + / 护盾泡），选项从池里按稀有度抽，**同一次不出重复**；组合要有 build 感。写成纯函数 + 单测。 |
| **怪物行为** | 补齐：直冲 / 绕行 / 远程吐泡泡 / 召唤小怪 / 精英护盾。每种有明显外形差异（不只是颜色）。 |
| **对象池与性能** | 怪物、弹幕、粒子全部走对象池；上限敌人数下仍要 60fps（低端机降粒子）。写一个「1000 次生成回收后池不膨胀」的用例。 |
| **无尽深化** | 每 5 波一个「小 boss」，每 10 波换场景；成绩 `save.recordEndlessBest("monster-crisis", wave)`。 |
| **合作 / 对战** | `coop`：两人共享波次、分别成长；`versus`：两人各守一半，先失守者输。两种都要能真的打到结算，不然就从 `meta.modes` 里删掉（**不许留声明了却玩不了的模式**）。 |

## 七、视觉 · 建模 · 手感

- 出手有明确前摇与命中反馈；被撞是「转圈 + 短无敌」，**无血无伤无死亡**。
