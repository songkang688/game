## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **牌力提示（给孩子的教学）** | 三档可选：关（挑战）/ 高亮可出的牌组 / 推荐一手 + 一句理由（「先出小单张探探路」）。推荐要走真实搜索，**不许胡说**。 |
| **AI 三档 + 队友配合** | 菜鸟（乱出）/ 普通（能压就压）/ 高手（记牌、算剩余、农民之间会让牌与配合）。固定 seed 下高档胜率显著更高（断言）。 |
| **出牌动画** | 牌从手牌飞到桌面（180–240ms）+ 轻微旋转；不许瞬间出现在桌上。手牌重排也要有滑动。 |
| **关卡化牌局** | 188 关每关固定发牌（seed 存在关卡数据里）+ 目标（赢 / 几手内赢 / 不出炸弹赢），**用 `sim.ts` 证明每关都存在必胜或高胜率线路**。前 99 关数据不改。 |
| **无尽「牌局连胜」** | 连续对局，AI 档随连胜升级；成绩 `save.recordEndlessBest("landlord-cards", streak)`。 |

## 五、模式矩阵

四模式全保留（玩不了就修好或删声明）；`twoPlayer` 是本地两人 + 1 AI 的坐庄玩法，要能真的玩到结算。

## 六、2.5D / 3D 决策

**保持 2D**。卡牌可有轻微透视排布（扇形手牌），但不做真 3D。

## 七、视觉 · 建模 · 手感

- 手牌扇形排列，选中上移 12px；不合法出牌时轻抖并说明原因（「要比上家大哦」）。
- 剩余牌数用图标 + 数字；地主标记明显。
- 结算面板给「本局亮点」（例如「你留住了炸弹，关键时刻打出来！」）。
- `prefers-reduced-motion`：飞牌改为短淡入，仍走同一状态机。

## 八、手机 360px

- 手牌横滑可见，牌宽 ≥ 44px，选中区域不被下方按钮遮挡。
- 「不出 / 提示 / 出牌」三钮固定底部一行，热区 ≥ 44px。

## 九、平台接线

- `openCampaignLevel(n)` / `initialLevel` / `?level=` 直开第 N 局；Skip 走 `requestSkip`。
- 无尽成绩 `save.recordEndlessBest`；`meta.platform` 按实测填；`blurb` 与事实对齐。
