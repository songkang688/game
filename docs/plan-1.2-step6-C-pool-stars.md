## 四、这不是什么

- 不是 `bubble-aim`（泡泡瞄准射击），不是 `sling-birds`（弹弓）。
- 本款是**美式八球的简化落地**：分组、犯规、自由球、指定袋、黑八胜负边界都要正确。

## 五、完整规则（美式八球简化，写清楚）

### 球与开球
- 母球 + 15 颗目标球：**暖色组 7 颗**（代替实心）、**冷色组 7 颗**（代替条纹）、**黑星球 1 颗**（代替 8 号）。
- 三角形摆球，母球放在开球区。开球必须让球过中线并撞到球堆，否则算犯规重摆。
- 开球后，第一颗**合法落袋的非黑星球**决定双方分组；开球即进黑星球 → **重摆**（不判胜负，避免秒胜）。

### 击球与犯规
- 母球第一颗碰到的必须是自己组的球（清完己组后是黑星球），否则犯规。
- 犯规惩罚：对方获得**自由球**（可把母球放到台面任意合法位置）。
- 母球落袋：犯规 + 自由球。
- 打进自己组的球：继续击球。打进对方的球：算对方的（不影响自己继续与否，按常量写清并测）。
- 连续 3 次犯规判负（对战可选开关）。

### 黑星球
- 必须在自己组清完后再打黑星球；对战模式要**指定袋口**（闯关可关闭指定）。
- 未清完己组就把黑星球打进 → 判负。
- 黑星球与母球同时落袋 → 判负。
- 合法打进黑星球（指定袋、无犯规） → 胜。
- 己组最后一颗与黑星球同一杆进袋且无犯规 → 判胜（写清并单测）。

### 物理
- 击球给母球冲量：方向 + 力度（力度条），可选加一点上下旋（`spin`，闯关后期解锁）。
- 摩擦让球逐渐停下；库边按入射角 = 反射角并损耗能量；袋口有吸入半径。
- 固定步长子步进，保证高速球不穿过库边（连续碰撞检测或足够小的 dt，必须单测「高速球不穿墙」）。
- 全部核心写成纯函数。

## 九、前端建模与视觉（含 360px）

- Canvas 俯视球桌，粉彩台呢 + 圆角库边 + 六个袋口。
- 瞄准线 + 力度条 + 预测第一碰撞点（闯关前期显示，后期可关，作为难度）。
- **入袋禁止瞬删**：球落入袋口要缩小 + 下沉淡出；母球犯规有提示文案与放球提示。
- `prefers-reduced-motion`：去掉屏幕轻微抖动。
- 360px：球桌旋转成竖向（短边朝上）或整体缩放，球直径 ≥ 14px；力度条与击球钮 ≥ 44px；字号 ≥ 13px。
