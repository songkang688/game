## 完整规则（美式八球简化，写清）
- 球：母球 + 1–7 实心组 + 9–15 条纹组 + 8 号（用颜色组代替条纹：暖色组 / 冷色组 + 黑色 8）。
- 开球：三角排，母球在开球区。开球必须过线撞击，否则重摆（犯规）。
- 开球后：先合法打进的非 8 球决定组别。开球进 8：重摆或判胜（本款 **重摆**，避免秒胜）。
- 击打：先碰到的必须是自己组；否则犯规，对方 **自由球**（母球可放开球区）。
- 进自己组继续击打；进对方球算对方的；进白球（母球落袋）犯规，取出白球自由球。
- **8 球**：必须己组清完后指定袋口（简化：闯关可不指定，对战指定袋）。8 球与白球同进或未清完先打进 8 = 负。
- 胜：合法打进 8。负：8 犯规。
- 物理：摩擦让球停下；袋口吸引半径；库边反射角=入射角。全部纯函数可测。

边界：
- 同时进 8 和己方最后一颗：算胜（若未犯规）。
- 未清完进 8：负。
- 连续 3 次犯规可判负（对战选项）。

无尽：挑战残局链，`recordEndlessBest` 记连续清台数。
