# 1.1 第 12 步 · 角色 B 工作计划(文案 + 攻略)

只做两件事:**把面向孩子的可见文案重写到约小学六年级**,以及**给每一款游戏补一本攻略**。
不碰任何玩法逻辑、关卡数据、物理、AI。

## 独占范围

- 全部 `src/games/*/index.ts` 里的**文案字符串**(引导语、提示、胜负、章节介绍、道具说明)
- 新建全部 `src/games/*/guide.ts`(默认导出 `GuideBook`,类型见 `src/ui/level188Contract.ts`)
- 新建 `src/games/copy.test.ts`

## 明确不碰

- `meta.ts`(归 A)、`home.ts` / `types.ts`(归 A)
- `styles.css` / `gameShell.ts` / `dialogs.ts` / `index.html`(归 C)
- 任何 `logic.ts` / `levels.ts` / `physics.ts` / `sim.ts` / `ai.ts` / `combat.ts`

## 和别的窗口共处

`garden-guard`、`sprout-defense`、`ocean-munch`、`fruit-slice`、`brave-path` 正在被别的窗口改:
这些目录**只新增 `guide.ts`,不动 `index.ts`**,避免抢同一片代码。

## 文案口径

1. 去掉「宝宝」「乖乖」「小笨蛋」这类过低幼措辞,保持中文粉彩萌系。
2. 允许连击、命中率、回合、资源、克制、策略这类六年级读得懂的词。
3. **失败文案永远只鼓励不批评**,不出现「笨」「差」「不行」「又输了」这类话。
4. 一律不出现任何商业游戏商标与官方角色名。

## 攻略口径

- `general`:3–6 条通用心得。
- `entries`:按章节至少一条;188 关的游戏 ≥8 条。
- 学习类(`math-farm` / `word-garden` / `pinyin-train` / `clock-house` / `shape-kingdom` / `find-diff`)
  **只讲方法与检查思路,严禁写出题目答案**。

## 验收

- `npm test` 全绿,用例只增不减
- `npm run build` 全绿
