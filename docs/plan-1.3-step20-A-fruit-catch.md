## 三、现状审美评测（先开代码再动笔）

打开 `src/games/fruit-catch/index.ts`，绘制入口是 `draw` / `drawItem` / `drawBasket` / `drawSparks`。已核实的问题：

1. **果子是 emoji**：`drawItem` 的主体就是 `c2d.fillText(it.emoji, 0, 0)`（约 166 行）——「接住小水果」的水果没有一笔自绘，字形、大小、基线全看系统字体脸色；
2. **篮子也是 emoji**：`fillText("🧺", x, H - 18 + press)`（约 180 行）——主角道具是一个字符，接住时只有 `press` 一个下压量；
3. 背景装饰同样是 emoji 直出：🌠⭐☁️（391–394 行）；一屏之内自绘元素几乎为零，本款是全库「emoji 拼贴」的重灾区之一；
4. 警告物的红圈脉动（127–136 行）是功能件（保住），但圈里的物体还是 emoji；
5. `drawSparks` 接住火花与冰冻 / 磁铁两个道具底板（138–142 行的圆角矩形）自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **水果自绘（核心整改）** | 全部 emoji 替换为专属剪影 + 三停径向渐变 + 高光 + 1.5px 描边的自绘水果，且**剪影层面互不相同**：苹果（心形圆 + 凹顶 + 叶）、香蕉（月牙弯 + 两端褐点）、葡萄（六球簇 + 藤须）、橙子（正圆 + 脐点 + 皮孔点阵）、草莓（倒水滴 + 籽点 + 蒂叶）、梨（上窄下宽葫芦形）。落下时每种有 ±8° 慢旋（reduced 停）。 |
| **警告物自绘** | 红圈脉动保留，圈内物换成自绘的「小捣蛋云」（皱眉乌云 + 两滴小雨）——语义是「别接它」，不吓人。 |
| **编织篮自绘** | 🧺 替换为自绘藤篮：横三条纵五条交叉编织纹 + 篮口高光沿 + 双侧提耳；接住瞬间篮身压扁 8% 回弹（沿用 `press` 变量）+ 果子落入篮内可见（篮口裁剪层，最近三个果子小图标堆在篮里）；磁铁道具生效时篮沿泛蓝微光、冰冻时篮口挂两根小冰凌（读道具状态只做映射）。 |
| **接住反馈** | `drawSparks` 升级：接住普通果 = 星屑 4 颗 + 飘分；连接 5 个不落地 = 篮上方小彩虹一闪（300ms）；接到警告物 = 灰色小云雾 + 「哎呀」气泡（不批评）。 |
| **场景层次** | 背景改三层：远层渐变天空 + 自绘太阳 / 月亮（按关卡昼夜）、中层两朵程序云（缓移，reduced 停）、近层果树枝从顶部探入（果子「从树上掉下来」的语义成立）；地面草地条 + 落空的果子在地面弹一下变成半透明再消失（不改扣分逻辑）。 |
| **布局与 HUD** | 分数 / 生命 / 连击卡片化一行；生命用小果子图标不是数字裸奔。 |

- 渐变 / 描边 / 落影统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：旋转、云移、彩虹、回弹全停，保留静态层次。
