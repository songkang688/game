## 二、极高质量改进方案（可执行绘制规格）

### 1. 朵朵/星星 → 真正的双主角（核心资产）

- **drawFlower 重画**：花瓣 6 片改「双层错位」（后层深粉 `#F27BA8` 旋转 30°，前层亮粉 `#FF9EC4`），每片加 `createRadialGradient` 从瓣根到瓣尖提亮；花芯改三层（深金环 `#E8B84B` → 亮黄 `#FFE58A` → 中心 3 粒花蕊点）；整体加 2px 暖白描边保证在粉色场地上可读；
- **drawStarShape 重画**：五角星加「立体切面」——把星形按顶点切成 10 个三角，交替填亮金 `#FFD86B` / 深金 `#E8A93C` 形成折纸立体感；外描边 2px `#B87A18`；星尖加 1 粒白高光；
- **drawFace 重写**：眼睛改「白眼球+黑瞳+高光点」三层；腮红两粒椭圆（朵朵粉 `rgba(255,140,170,.45)`、星星橙 `rgba(255,180,90,.45)`）；嘴按状态查表：待机微笑弧 / 抓取张嘴（小椭圆）/ 领先眯眼笑；
- **眩晕「@ @」必须删除**：改为「螺旋眼（两圈 `arc` 螺线）+ 头顶 3 颗小星绕圈公转（`reduceMotion` 时静止摆放）」；
- 身体加呼吸缩放（scale 0.98–1.02 正弦，reduceMotion 关闭）；影子椭圆（1144–1147 行）保留但随跳跃/移动速度压扁拉伸。

### 2. 目标物 → 全部绘制化（禁 emoji）

- 花朵目标：缩小版朵朵花（无脸），星星目标：缩小版切面星——直接复用第 1 条的绘制函数传小半径；
- **金币（🪙 → 绘制）**：金渐变圆 + 深金内环 + 五角星压印 + 左上高光弧，规格向全产品金币标准对齐，**优先 `import` 共享 kit（`src/art/kit/`，路径以主管 visual-bible 为准；若 kit 尚未建立则本地实现同签名函数并注明待上移）**；
- 炸弹（💫 → 绘制）：紫黑圆体 + 麻绳引信 + 火花 2 帧闪烁 + 表面高光；礼盒（🎁 → 绘制）：双色盒身 + 缎带十字 + 蝴蝶结；
- 白圆底改「软气泡」：白→透明径向渐变 + 顶部高光弧；目标临期闪烁（1126 行 alpha 逻辑）保留。

### 3. 擂台场地主题化（吃 stages.ts 数据红利）

- 每张场地按 `id` 查表配「地面纹理 + 边界装饰 + 角落装饰」，全部纯 Canvas：
  - cloud-square 云台广场：地面淡蓝白渐变 + 3 朵扁云剪影，边界描白绒边；
  - flower-isle 花田小岛：圆形边界外圈画一圈小花瓣点缀，地面撒 6–8 粒微型花点；
  - star-bridge 星桥回廊：地面加淡星光点 + 桥面木纹 3 条横线；其余场地同理按 `name`/`emoji` 意象展开；
- 地块软垫改「果冻垫」：主色随场地 tint 加深 15%，顶部 30% 高光条 + 底部 2px 深色缝线；**会滑动的垫子（sway>0）加左右两侧速度线**提示它会动；
- 座位底色保留粉/蓝区分（对战可读性），但改为顶部到底部 4% 明度差的线性渐变，去掉「纯色大平面」。

### 4. 技能与状态特效

- 出手圈：细线改「双环脉冲」（外环扩散淡出 + 内环实线），active 段换暖橙加粗——判定半径 `grabRadius` 的数值不动，只改画法；
- 护盾：单线圈改六边形微光盾面（`rgba(120,200,255,.25)` 填充 + 亮边）；
- 冰冻：纯色圆罩改冰晶罩（浅蓝径向渐变 + 3 根冰锥刺 + 2 粒闪点）；
- 双倍 ✨ → 绘制的四芒星徽章挂在头顶，随呼吸微浮动；
- 抓到目标时加 3 粒星屑爆开 + 白色小冲击圈（0.25s，reduceMotion 只留飘字）。

### 5. UI 与结算

- 技能冷却裸字改「技能徽章」：左上角圆形图标（技能各自的绘制图标替代 `spec.emoji`）+ 环形冷却进度扫描（`cooldownRatio` 数值不动）；
- AI 标识与让分文字加半透明白圆角底板；
- 回合结算：胜者放大 + 花瓣/星屑各自主题的粒子雨（reduceMotion 静态展示），比分数字滚动跳字。

## 三、2D / 2.5D / 3D 决策

- 本款为**俯视双人对战，保持 2D**，不做透视改造（沙漏/圆形边界的 0..1 相对坐标系是逻辑判定的一部分，动它就是动玩法）；
- 立体感全部来自**资产本身**：角色双层花瓣/切面星、果冻垫高光缝线、场地渐变与影子。禁止引入 three.js。

## 四、共享 kit 与学习方法

- 朵朵、星星、金币三件资产是全产品通用件：优先 `import src/art/kit/`（路径由主管规定；**若主管文件尚无，服从 visual-bible**）；本地实现时函数签名保持 `(ctx, x, y, r, opts)` 形式便于上移；
- 参考 4399 双人对战小游戏的信息密度：角色大而醒目、状态图标挂头顶、场地装饰不抢角色。**禁止抄任何商标与原图**。

## 五、边界与红线

- 独占目录 `src/games/duo-arena/**`，允许 import 共享 art kit；禁止改其他游戏目录；
- 不改 `arena12.ts`/`match.ts` 任何数值；`stages.ts` 只许动 `tint` 类视觉字段，boundary/blocks/paceScale 不动；
- 360px 最小宽度下双半场角色仍清晰；`prefers-reduced-motion` 时关闭公转星/脉冲环/粒子；
- 双人色弱可读：朵朵/星星除颜色外必须有形状差（花形 vs 星形已天然满足，保持并强化轮廓差）；
