## 四、1.2 玩法升级（把「能玩」做到「想再来一局」）

| 项 | 规格 |
| --- | --- |
| **三局两胜赛制** | 单局短（30–60 秒），赛制层负责比分与赛点提示；赛点局有明显氛围（背景变色 + 提示语）。 |
| **人机四档** | 菜鸟 / 普通 / 高手 / 地狱：低档反应延迟大、会失误；高档会预判但**必须保留可反打的窗口**（不许 0 帧完美反应）。固定 seed 胜率断言。 |
| **技能 / 道具** | 2–3 个温和技能（护盾泡、弹开波、加速），有冷却与前摇，全部纯函数状态机；**不许出现伤害 / 血量语义**，用「元气」「星星点数」。 |
| **场地变化** | 至少 3 张擂台：平台数量 / 移动地块 / 边界形状不同，随机或轮换；场地效果写成数据表。 |
| **让分开关** | 大人带小孩玩时可给落后方温和助推（≤ 8%），默认关闭，HUD 要显示。 |
