## 三、现状审美评测（先开代码再动笔）

打开 `src/games/landlord-cards/index.ts`，渲染入口是 `render` / `renderHand` / `renderCenter` / `renderFoes` / `renderMeHead` / `renderButtons` / `renderHintLine` / `renderKeys` / `renderCover` 与 `cardFaceHTML`（约 310 行起）。已核实的问题：

1. `cardFaceHTML` 的牌面就是「角标数字 + 花色字符」的 DOM 文本排版，大小王直接一个 🃏 emoji + 「大 / 小」字（315–317 行）——牌没有边框装饰、没有中心图案、没有牌面身份，像一张便签；
2. 手牌扇形 `fanLayout` 布局是好底子（保住），但牌与牌之间无层叠阴影，选中态预期只是位移（自查确认）；
3. 出牌过程预期是瞬间出现在桌面中央（`renderCenter` 自查）：没有飞行轨迹、没有落桌感——「出牌」这个最高频动作零反馈；
4. 对手区 `renderFoes` 与自己头像 `renderMeHead` 预期是文本 + emoji 头像，地主身份标识的显眼度自查；
5. 桌面背景（预期纯色）、按钮区 `renderButtons`、提示线 `renderHintLine` 逐个自查，把结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **牌面重设计（核心）** | 牌面三层：白底圆角 8px + 内圈细线框（双线，主题色）+ 角标（左上 / 右下对角，数字 + 自绘花色 SVG）；花色四色自绘（红桃 / 方块暖色系、黑桃 / 梅花冷色系，形状加小高光）；**大小王替换 🃏**：画朵朵（花冠 Q 版半身）与星星（星冠 Q 版半身）原创立绘小图，大王金框、小王银框。10/J/Q/K/A 加中心大花色浮雕淡纹。 |
| **手牌层次** | 扇形坐标不动，加：每张牌 1px 右侧层叠阴影、可出牌抬升 6px + 底光、选中再抬 6px + 主题色描边；轮到自己时手牌区整体呼吸微光（reduced 常亮）。 |
| **出牌轨迹** | 出牌：牌从手牌位飞到桌面中央（180ms 弧线 + 轻微旋转落定）+ 落桌软影一闪；炸弹 / 王炸出牌时桌面震一下 + 星屑环（reduced 只落定）；上一手牌渐隐让位。**出牌合法性与时序逻辑不动，只包装展示。** |
| **身份与桌面** | 地主帽子徽章（自绘小皇冠）挂在头像角上；农民头像挂小草帽；桌面改毛毡质感（深绿 / 深蓝渐变 + 中央淡纹圆环 + 四角木沿）；叫抢阶段的倍数牌做成翻牌小卡。 |
| **换人遮挡幕** | `renderCover` 保住「不渲染手牌」逻辑，视觉升级为可爱幕布（布褶渐变 + 中央「请交给 XX」缎带牌 + 小星星装饰）。 |
| **布局与 HUD** | 按钮区（出牌 / 不出 / 提示）圆角胶囊化 + 按下下沉；`renderHintLine` 提示文字加气泡框；键位说明 `renderKeys` 卡片化。 |

- 色板走 `src/art/kit/palette.ts`；星屑走 `sparkle.ts`。
- `prefers-reduced-motion`：飞行、震动、呼吸全停，保留静态层次。
