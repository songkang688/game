## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **火车舞台（核心）** | 画一列 SVG 小火车：车头（圆头锅炉 + 烟囱 + 排障器 + 大圆灯）+ 车厢若干节（圆角车身 + 双轮 + 挂钩）；底部铁轨双线 + 枕木，向右延伸并透视收窄到远山隧道（2.5D 灭点）；背景远山 + 云两朵 + 站台一角。 |
| **音节车厢化** | 每答对一个音节 = 一节车厢从站台滑入挂上列车（220ms + 挂钩「咔」一顿，reduced 瞬挂）；车厢侧面写该音节（大字 + 声调标色）；车头烟囱冒圈圈白烟（每挂一节喷一朵，reduced 停）。 |
| **声韵调三色助记** | 声母一律暖橙牌、韵母青绿牌、整体认读紫牌、声调符号红色加粗——颜色即语法的助记通道（**正字法与题库不动**，只上色）；选项牌做成车票样式（锯齿边 + 圆孔）。 |
| **答题反馈** | 拼对：车灯亮一下 + 鸣笛音效对应的视觉汽笛圈两圈；拼错：车厢轻晃不脱钩 + 站牌提示「再听一遍」（配 TTS 重读按钮，接线不动）。 |
| **发车仪式** | 一轮拼完全部音节：火车鸣笛发车驶向隧道（600ms 驶出 + 车尾小旗，reduced 淡出）+ 站台挥手小人 + 彩纸；下一轮新列车进站。 |
| **布局与 HUD** | 进度 = 已挂车厢数 / 目标节数（列车本身就是进度条）；朗读按钮做成站台广播喇叭；题目区（听音选拼 / 看图拼音）卡片化置顶。 |

- 色板走 `src/art/kit/palette.ts`；火车部件可**新增** `src/art/kit/train.ts`（车头 / 车厢 / 轨道参数化）并配套单测。
- `prefers-reduced-motion`：滑入、白烟、发车、汽笛圈全停，保留静态列车与三色助记。

### 4.1 配色板与图层序

| token | 色值 | 用途 |
| --- | --- | --- |
| `locoRed` / `locoRedDark` | `#e8574e` / `#b93f38` | 车头锅炉主色 / 描边阴影 |

图层序（DOM/SVG 从底到顶）：天空 + 远山 + 隧道口 → 铁轨（透视收窄，枕木随距离变密变短）→ 站台一角 + 广播喇叭 → 列车（车头在右、车厢向左依次挂）→ 白烟 / 汽笛圈层 → 车票选项区 → 题目卡片 → 彩纸层。动画层 `pointer-events:none`。

### 4.2 火车工序单（train.ts）

1. 车头：圆头锅炉（`locoRed` 纵向渐变 + 左上高光弧）+ 烟囱（顶口外扩）+ 排障器（三角裙板）+ 大圆灯（金色 + 白高光点）+ 驾驶室方窗；可画笑眼弯线但**造型必须独立，不像托马斯**（无立体人脸浮雕）；
2. 车厢：圆角矩形车身（`carriageCream` + 语法类别色顶边条）+ 侧面音节大字（声调符号 `toneRed` 加粗）+ 双轮（外圈深灰 + 内毂亮灰 + 辐条 4 根）+ 挂钩短杆；
3. 轨道：双线 `railGray` 向右收窄至灭点（隧道口），枕木间距按 0.85 等比递减营造 2.5D 纵深；
4. 车票选项：锯齿边圆角卡（`mask` 或 `clip-path` 锯齿）+ 左侧圆孔 + 类别色边条 + 音节文字；
5. 白烟：三档大小圆（r=4/6/8）沿烟囱上方贝塞尔漂移放大淡出；
6. 接口 `loco(size)` / `carriage(syllable, kind, size)` 纯函数返回 SVG 字符串，可单测。

### 4.3 动效时序表

| 触发 | 动画 | 时长/缓动 | reduced 行为 |
| --- | --- | --- | --- |
| 拼对挂厢 | 车厢从站台滑入 + 挂钩「咔」一顿 | 220ms / ease-out + 60ms 顿帧 | 瞬挂 |
| 挂厢同时 | 烟囱喷一朵白烟 + 车灯亮一下 | 500ms / ease-out | 停 |
| 拼错 | 车厢轻晃 ±3px 不脱钩 + 站牌「再听一遍」 | 320ms / ease-out | 只显站牌 |
| 一轮拼完 | 鸣笛汽笛圈两圈 + 发车驶向隧道 + 车尾小旗 | 600ms / ease-in | 淡出换新列车 |
| 发车同时 | 站台小人挥手 + 彩纸 16 粒 | 800ms 一次性 | 静态挥手帧 |
| 待机 | 车头微颤 ±1px（蒸汽感） | 1.6s 循环 | 静止 |

## 九、测试（只增不减，新增 ≥ 12 个视觉用例）

1. 车厢数 = 已答对音节数（0 / 3 / 全对三点映射断言，数据不变）；
2. 车厢侧面文字 = 题库音节原文（含 `ā á ǎ à` 声调符号逐字符断言，正字法钉死）；
3. 声 / 韵 / 整体认读三色分类与语法类别一致（抽 6 例断言，覆盖三类）；
4. 声调符号使用 `toneRed` 且不因样式裁切（overflow 断言）；
5. `loco` / `carriage` 纯函数输出含必备节点（锅炉 / 车灯 / 双轮 / 挂钩）；
6. 车头造型无人脸浮雕节点（禁抄托马斯断言）；
7. 枕木间距 0.85 等比递减（前三格数值断言，2.5D 纵深钉死）；
8. 拼对 / 拼错走不同视觉分支且车厢不脱钩（类名断言）；
9. 发车仪式只在整轮拼完触发（中途不触发断言）；
10. TTS 朗读按钮接线换肤后原样（回归断言）；
11. 列车横向滚动时当前待拼车厢居中可见（scroll 位置断言）；
12. reduced 下滑入 / 白烟 / 发车 / 汽笛圈全停，三色助记仍在；
13. `destroy` 后白烟 / 发车计时器归零；
14. 既有题库与判定测试断言一个不许改（跑全量确认）。
