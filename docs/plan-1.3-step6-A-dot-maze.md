## 二、极高质量改进方案（可执行绘制规格）

### 1. 玩家 → 有眼睛的豆豆勇士

- 保留扇形嘴（张嘴动画节奏不动），加：朝向侧的一只眼睛（白底黑瞳 + 高光点，位置随 `base[state.dir]` 旋转）+ 头顶一根小呆毛（2px 曲线）；
- 身体改径向渐变（中心 `#FFE27A` → 边 `#F5B93D`）+ 底部 15% 暗晕；
- 无敌闪烁（`graceMs`）保留换色逻辑，但加一圈淡金护盾光环（`soft` 时只换色）；
- 被抓：0.4s 委屈脸（嘴闭上 + 眼睛下垂）再重生，不做死亡旋转（低龄向）。

### 2. 幽灵 → 强化既有优点

- 裙边从 2 尖增加到 4 尖波浪（moveTo/lineTo 序列扩展）；
- 瞳孔随幽灵移动方向偏移 1.2px（`g.dir` 已有数据）；
- 身体加顶部 20% 高光弧；fright 蓝态加锯齿嘴（害怕表情）；eyes 态保留；
- 「星星幽灵」（`isStar` 圈，393–398 行）：描边圈改为头顶小星星标记（共享 kit 星星）。

### 3. 豆子 / 能量豆 / 星星 → 发光资源

- 豆子：中心亮黄 + 外圈 1.5 倍柔光晕（预渲染 sprite，一张 8×8 贴图 `drawImage` 全场复用，性能反而更好）；
- 能量豆：升级为四芒星光点（旋转 8s/圈 + 脉动保留），色 `#FFC9E5 → #FF8FC7` 渐变；
- 抢豆星星：真五角星（金黄渐变 + 描边 + 光晕），不再是蓝圆。

### 4. 果子 → 画的果子

- `FRUITS[kind].emoji` 改为 Canvas 小果子贴图（樱桃=两颗红圆+梗、草莓=三角红+籽点、橘子=橙圆+叶）：每种 ≤ 12 笔路径，预渲染 3 张贴图；emoji 保留在 HUD 文案。

### 5. 墙 → 霓虹迷宫

- 逐格方块改「连通墙面」：同行/同列相邻墙格之间补画连接段（判断 `maze.wall[i±1]`/`[i±w]`），外缘走 2px 霓虹描边（`#6E82D9`）+ 内部深色填充（`#39406E`），拐角圆滑；
- 背景 `#241f3a` 上加极淡星点（20 颗静态，哈希撒点）；
- 每 47 关换墙色主题：蓝紫 → 青绿 → 橙红 → 金紫（查表换常量）。

### 6. HUD 与结算

- 生命数改为小豆豆脸图标排；连吃幽灵 combo 时分数飘字（200/400/800 翻倍感）；
- 结算加吃豆率进度环。

## 三、2D / 2.5D / 3D 决策

**保持 2D 俯视**（迷宫格玩法规范）。发光感用预渲染光晕贴图，不用 shadowBlur 逐帧（性能红线）；禁止 three.js。
