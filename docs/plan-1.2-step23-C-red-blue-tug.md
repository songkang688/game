## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **力量模型** | 引入体力条：按下消耗、松开恢复；连续猛按体力见底后力量骤降（写纯函数 + 单测）。最优策略是**有节奏地发力**而不是狂按。 |
| **节奏点** | 绳子上有随机出现的「加油点」，在它经过中线时按下给额外拉力（判定窗口 ±120ms），双方对称出现。 |
| **反拉机制** | 落后一方在极端位置（≥ 80%）时获得「拼一把」窗口 2 秒（拉力 +15%），避免一边倒；这条要能开关，默认开。 |
| **AI 四档** | 用「体力管理水平 + 节奏点命中率」建模，档位差可量化（固定 seed 断言）。 |
| **无尽「拉不完的绳」** | 一局接一局，AI 随连胜变强；成绩 `save.recordEndlessBest("red-blue-tug", streak)`。 |

## 七、视觉 · 建模 · 手感

- 绳子有张力形变与抖动，力量越大抖得越厉害；中线旗帜随位置移动。
- 体力条颜色 + 形状双通道；见底时角色喘气动画（可爱，不难受）。
- 胜负是「另一边坐到软垫上，大家一起笑」，**无伤害**。
- `prefers-reduced-motion`：关抖动，用形变幅度表达。
