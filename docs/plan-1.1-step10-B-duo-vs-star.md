# 1.1 第 10 步 · B 档工作计划 —— `duo-vs-star`「朵朵大战星星」

> 本文件只记录 B 档的开工计划。B 档只新建 `src/games/duo-vs-star/`，
> 不碰 A（`fight-king`）/ C（`shoot-range`、`sky-squad`）的目录，不改 `src/ui/home.ts`，
> 不动任何已有游戏。

## 目标

在 `src/games/duo-vs-star/` 新建一款**全明星弹飞式派对混战**，分类 `party`。
核心机制：**不扣血**，被打中只会累积「击退值」，击退值越高被撞飞得越远，
把对手撞出场地边界（弹飞线）就得一分。全程无血、无伤、无死亡描写。

## 五种模式

1. **双人对战**：同屏键盘，朵朵 `WASD` + `F`（挥击）/`G`（重击），星星 `↑←↓→` + `L`/`K`，`Esc` 暂停。
2. **人机混战**：最多 4 人（1 人 + 最多 3 个小电脑），AI 三档可选。
3. **闯关 188 关**：走 `src/games/level99.ts`，10 个主题章节，每关给定场地 / 对手 / 特殊规则。
4. **无尽**：车轮战，赢一场换一个更强的对手，记 `endlessBest`。
5. **团队赛**：2v2，两队共享「队伍分」，先撞飞够数的队获胜。

## 触屏

窄屏自动出现左右两侧虚拟按键（← → 跳 挥击 重击），与键盘完全等价，
两套键位各走各的，互不抢占。

## 红线自查

- 不扣血、不掉血条：只有「击退值」与「撞出场外」，被击中只有星星飞溅 / 转圈 / 弹开。
- 「上升岩浆」改成卡通的**咕嘟糖浆**，碰到只会被弹得高高的，不写任何烫伤 / 灼烧。
- 可见文案全部原创中文，不出现任何商业商标或官方角色名（注释里也不许）。
- 角色只用本作原创：朵朵、星星、糯糯、云云、墩墩、闪闪、绿绿豆、啾啾、泡泡、团团、麦麦、灯灯。
- 音效只用 `api.play("tap"|"win"|"oops"|"coin"|"pop"|"meow"|"jump")`，无任何外部资源。
- `destroy` 清干净 rAF / 定时器 / `window` 键盘监听 / resize 监听。
- `prefers-reduced-motion` 下关闭屏幕抖动与闪烁。
- 不改 `src/ui/home.ts`，不动其他已有游戏，只增测试不删测试。

## 验收

- `npm test` 全绿且用例只增不减；`npm run build` 全绿。
- 击退 / 弹飞纯函数用例 ≥ 20。
- 冒烟：五种模式都能玩到真实胜负；双人键位同屏互不抢占；375×667 与 1280×800 都不溢出。
