# 1.1 第 9 步 · B 档工作计划 —— `brave-path`「勇者小路」

> 本文件只记录 B 档的开工计划，不涉及 A/C 档目录与 `src/ui/home.ts`。

## 目标

在 `src/games/brave-path/` 新建一款轻 RPG 闯关 + 装备成长游戏，分类 `action`。

## 文件切分

| 文件 | 职责 |
| --- | --- |
| `meta.ts` | 纯数据（id / title / emoji / category / color / blurb），不 import 任何玩法代码 |
| `combat.ts` | 回合制战斗结算，**全部纯函数**：属性克制、暴击边界、防御减伤、技能冷却、Boss 机制 |
| `logic.ts` | 角色成长：装备槽、技能点、有限背包位、无尽深渊难度曲线、对战双方 AI 结算 |
| `levels.ts` | 188 关关卡表（≥8 个主题章节，每章一个 Boss），确定性生成 |
| `index.ts` | 顶部 `export { meta } from "./meta"`；三种模式的 UI 与 `mount(api): { destroy }` |
| `combat.test.ts` | 战斗结算 ≥ 25 个用例 |
| `levels.test.ts` | 章节和恒等 188、Boss 分布、难度单调性 |
| `logic.test.ts` | 装备/技能点/背包/无尽/对战结算 |

## 三种模式

1. **闯关**：走 `src/games/level99.ts` 的 `mountLevelGame`，188 关、8 个主题章节，每章末一个 Boss。
2. **无尽**：无尽深渊，层数越深越难；结束用「探险结束 · 回城休息」的说法，不写任何死亡 / 流血描写。
3. **对战**：自己的养成角色对阵「星星的队伍」，双方 AI 自动结算，可反复调整配装再打。

## 策略深度（面向约小学六年级）

- 五系属性克制：火 → 草 → 水 → 火，光 ↔ 暗 互相克制。
- 技能冷却：强技能有 CD，需要规划回合顺序。
- 有限背包位：道具带不满全部，出发前要取舍。
- Boss 机制：读条大招（需防御）、护盾（需破盾）、弱点系（打弱点才能高效）。

## 红线自查

- 可见文案全部原创中文，不出现任何商业商标或官方角色名（注释里也不许）。
- 角色只用本作原创：朵朵、星星、糯糯、云云、墩墩、闪闪、绿绿豆、啾啾。
- 无血、无伤、无死亡描写；被击中只有星星飞溅 / 眩晕 / 弹开这类卡通反馈。
- 音效只用 `api.play("tap"|"win"|"oops"|"coin"|"pop"|"meow"|"jump")`。
- `destroy` 清干净监听 / 定时器 / rAF / AudioContext。
- 不改 `src/ui/home.ts`，不动其他已有游戏，只增测试不删测试。

## 验收

- `npm test` 全绿且用例只增不减；`npm run build` 全绿。
- 战斗结算用例 ≥ 25。
- 能 mount、打到真实胜负、destroy 后再进不报错；375×667 与 1280×800 都可玩。
