## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **瞄准线** | 显示第一段反射（撞左右墙）的虚线预览，长度有限（不给完整解）；触屏时用「拖动调整角度 + 松手发射」，并加**角度微调放大**（拖得越远越精细）。写纯函数 + 用例。 |
| **掉落物理** | 三消之后，与顶部不连通的泡泡群必须**真的掉下去**（重力 + 轻微散开 + 落出屏幕），并计入连锁分。这是本步硬指标：**禁止瞬间消失**。 |
| **发射器** | 当前 + 下一颗预览，可交换（`Tab` / 点击换弹钮）；颜色只从墙上还存在的颜色里出（避免死球）。 |
| **特殊泡** | 炸弹泡（清一圈）、彩虹泡（任意色）、石头泡（不可消，只能靠掉落清除）。 |
| **无尽「无尽墙」** | 每 N 发下推一行，顶到底线结束；成绩 `save.recordEndlessBest("bubble-aim", score)`。 |

## 七、视觉 · 建模 · 手感

- 吸附时有轻微「啵」的形变；三消是水花，掉落是重力下坠 + 淡出。
- 连锁掉落分数用飘字显示，数值随链长变大。
- `prefers-reduced-motion`：掉落时长压短但仍要经过中间位置。
