## 二、极高质量改进方案（可执行绘制规格）

### 1. 方块 → 糖果果冻块（核心资产）

- **单格规格**（在 `drawCell` 内重写，保持函数签名不变）：
  1. 底层：格色加深 18% 的圆角矩形（沉底 1px，当阴影）；
  2. 主体：垂直线性渐变（顶 +14% 亮 → 底 −8%）；
  3. 顶面高光：上缘 30% 高度的白色 25% 透明圆角条；
  4. 左侧亮边 1px、右下暗边 1px（伪 2.5D 斜面）；
  5. 中心 mark 字保留（低龄玩家靠字母认块），字色从 `#00000055` 改为格色深 40% 版本。
- **预渲染**：7 色 × 1 尺寸 offscreen canvas 缓存（尺寸变化时重建），主循环 `drawImage`，替代每格 5 次路径绘制。
- 影子改为「只描边 + 内部斜纹」形态，与实体块形成形态差，不再仅靠 alpha。

### 2. 消行 → 真的开花

- 消行动画三段（总时长沿用 `CLEAR_ANIM_SEC`，不改节奏判定）：
  1. 0–30%：整行泛金光（渐变白→金）；
  2. 30–70%：每格中心弹出一朵 5 瓣小花或星星粒子（每行 ≤ 10 个，对象池）向上飘散淡出；
  3. 70–100%：行高度压缩到 0（视觉挤压，落格逻辑不变）。
- 一次消 4 行（Tetris）时全屏边缘闪彩虹描边 0.3s；`soft` 模式退化为现有单色闪。

### 3. 井与背景 → 花园积木箱

- 井体三面画木质/糖果井壁（左右 6px、底 8px，双色条纹 + 高光线），井口画两颗装饰螺钉。
- 背景改上下渐变（`#F7FAFF → #E9EFFC`）+ 顶部一排远景小云朵（静态，预渲染）。
- **关卡主题查表**：按 `levels.ts` 现有分段每 ~47 关换井壁与背景配色（木箱 → 冰晶 → 黄昏 → 星夜），只换常量不改任何判定。

### 4. 暂存 / 下一个 → 迷你画布

- `holdBox` / `nextBox` 从 textContent 改为小 canvas：用同一套 `drawCell` 预渲染贴图画出真实形状的迷你块（每块 4×4 格、格 10–12px），下一个队列显示 3 个（360px 下 2 个）。
- 当前不可暂存（本回合已换过）时 hold 画布盖 45% 灰罩 + 锁图标。

### 5. 硬降与垃圾行反馈

- 硬降落点：落地行喷 4–6 粒尘土粒子（灰白小圆，0.25s），配合现有 `slam` 下沉。
- 收到垃圾行（`receive`）：井壁红光脉动 0.4s + 底部升起的行带警示斜纹，让「待落 N」（537 行文本）有画面对应。

### 6. 双人对战布局

- `bd-split` 双席位保持现有栅格，但每席位加彩色描边席位卡（P1 粉 / P2 蓝）+ 头顶名牌；发送垃圾行时从我方井顶飞一颗星弹到对方井顶（0.4s 抛物线，纯视觉）。

### 7. 结算

- 结算面板画奖杯 + 本局最大连消徽章；「X 行 · Y 分」改为图标化统计行。

## 三、2D / 2.5D / 3D 决策
