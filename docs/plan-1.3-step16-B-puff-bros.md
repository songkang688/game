## 三、现状审美评测（先开代码再动笔）

打开 `src/games/puff-bros/index.ts`，绘制入口是 `render` / `drawBro` / `drawPuffRing` / `drawBubble` / `drawCrate` / `drawSpring` / `drawGoo` / `drawBrittle` / `drawUpdraft` / `drawWarp` / `drawClimbLine` / `drawGadget` / `drawTumbleRing`。已核实的问题：

1. `drawBro`（约 897 行起）的两兄弟 = 椭圆身体 + 肚皮椭圆 + 两点眼 + 腮红：**剪影完全相同**，唯一区别是 `BROS[pi]` 的调色——「兄弟」的长幼、性格全靠颜色脑补，缩小后根本分不清；
2. 身体是两层纯色平涂（`c.body` + `c.belly`），没有渐变、没有绒毛质感、没有 rim light；
3. 嘴部三态（吹泡泡 / 攒气 / 常态，954–969 行）逻辑很好但画得极简：吹泡就是一个白圆，攒气就是一个椭圆；
4. 形变三件套（落地压扁 / 被吹扁 / 掉出打转，909–917 行）是本款的好底子，**必须原样保住**；
5. `drawBubble` 泡泡、`drawCrate` 箱子、`drawSpring` 弹簧、`drawGoo` 黏液、`drawUpdraft` 上升气流、`drawWarp` 传送门逐个自查：预期平涂几何为主，把每个的结论记进开工 commit。

## 四、极高质量改进方案（绘制规格）

| 项 | 规格 |
| --- | --- |
| **哥哥「噗噗」重绘** | 剪影：头顶一撮翘起的呆毛（三段贝塞尔）+ 背带裤（两条肩带 + 前袋方块）+ 圆耳朵一对；材质：身体三停径向渐变（顶光 +22%）+ 肚皮浅色域 + 1.5px 描边；表情比弟弟稳重（眼睛稍小、眉毛平）。 |
| **弟弟「泡泡」重绘** | 剪影：头戴圆边小帽（帽檐 + 顶球）+ 围兜（半圆 + 波浪边）+ 尾巴小揪揪；材质同规格但主色更浅、腮红更大、眼睛更圆——「幼」感从形状来不是只从颜色来。 |
| **可区分性验证** | 16px 灰度自测：呆毛 vs 帽子、背带裤 vs 围兜、耳朵 vs 揪揪三通道可分辨，结论写进回复。 |
| **嘴部与吹气** | 吹泡泡的白圆升级为「腮帮鼓起 + 泡泡从嘴边长大」两层（沿用 `blowCd` 时序）；`drawPuffRing` 攒气环加彩虹渐变描边与内圈星尘 3 颗（提示功能不变，reduced 只描边）。 |
| **泡泡与场景** | 泡泡加薄膜质感：径向渐变 + 顶部月牙高光 + 底部 1px 彩虹缘（细到不喧宾）；箱子画木纹 + 角铁；弹簧画螺旋圈数随压缩变密（读既有压缩量）；黏液加流挂圆珠与光泽；上升气流画成半透明羽毛旋涡；传送门双色旋涡互为反色。 |
| **关卡氛围与布局** | 背景按关卡序号轮换三套淡色天空（晨 / 昼 / 暮），加两层软云视差；HUD 兄弟头像徽章 + 泡泡计数卡片化；胜利时兄弟击掌动画（两帧，reduced 静止合影）。 |

- 渐变 / 描边 / 落影统一走 `src/art/kit/`；光源统一左上 45°。
- `prefers-reduced-motion`：既有约定是形变三件套全关——新加的呆毛摆动、云视差、星尘也全部并入该开关。

### 四·补二：兄弟工序单（共用骨架 `broBody(params)`、两套参数）

1. 落影椭圆（0.8×`PLAYER_W`、0.2 高）；
2. 身体椭圆三停渐变 + 1.5px 描边（判定盒 `PLAYER_W×PLAYER_H` 不动）；
3. 肚皮浅色域（0.6 身宽椭圆）；
4. 识别件一：哥哥翘呆毛（三段贝塞尔）/ 弟弟圆边小帽（帽檐 + 顶球）；
5. 识别件二：哥哥背带裤（两肩带 + 前袋）/ 弟弟围兜（半圆波浪边）；
6. 识别件三：哥哥圆耳朵一对 / 弟弟后脑揪揪；
7. 表情参数化：哥哥眼稍小眉平 / 弟弟眼圆腮红大；
8. 嘴部三态沿用逻辑：吹泡改「腮帮鼓起 + 泡泡从嘴边长大」两层（时序读 `blowCd` 不改）。
