## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **手感三件套** | 出手前摇（≤ 80ms）、命中顿感（4–6 帧）、准星轻微散布随连发增大并随停手回收——三条都做成常量 + 单测。 |
| **靶子体系** | 补齐：分裂靶（打中变两个小的）、护盾靶（要打两次）、彩虹靶（限时高分）、**不许打的花朵靶**（打中扣分，教克制）。 |
| **连击与节奏** | 连续命中给递增倍率，失手清零；倍率上限封顶（避免一局定胜负）。 |
| **双人同屏** | 朵朵 / 星星各一套准星与颜色，键盘 + 触屏都要能同时操作；分数分列显示。 |
| **无尽「打不完的靶场」** | 靶速与密度随时间上升，出现频率曲线可复现；成绩 `save.recordEndlessBest("shoot-range", score)`。 |

## 五、模式矩阵

四种模式全保留（玩不了的要么修好、要么从 `modes` 里删）；闯关 **前 99 关数据不改**。

## 六、2.5D / 3D 决策

**保持 2D**，但允许「远近两排靶」的伪纵深（远排小且分值高）。**不做真 3D**。

## 七、视觉 · 建模 · 手感

- 命中：靶子变成星星炸开成彩纸；未命中：轻微「噗」的落空提示，不批评。
- 连击倍率用数字 + 光环双通道显示。
- `prefers-reduced-motion`：关屏震与散布抖动，保留数值。

## 八、手机 360px

- 触屏瞄准要有「按下预览 + 抬起发射」的可选模式（默认开），避免手指遮挡；准星始终画在手指上方 24px。
- 分数 / 连击 / 剩余弹一行显示，字号 ≥ 14px。
