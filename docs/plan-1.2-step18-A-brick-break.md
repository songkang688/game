## 四、1.2 玩法升级

| 项 | 规格 |
| --- | --- |
| **反弹模型** | 按「接触点相对板心的偏移」决定出射角，角度上下限 20°–160°（避免水平死球）；连续 8 秒未击砖则每秒微调 2° 并给提示。写纯函数 + 单测。 |
| **连续碰撞检测** | 用「上一帧位置 → 这一帧位置」的线段与砖块 AABB 求交，杜绝穿砖（高速球断言）。 |
| **砖块体系** | 普通 / 二层 / 三层 / 钢砖（不可破，需道具）/ 爆米花砖（连带周围）/ 道具砖；颜色 + 图案双通道区分。 |
| **道具平衡** | 加宽板、三球、穿透球、慢速、磁力板（接住可再发）；每种有时限，**不许出现永久强化**；负面道具最多「板变窄」且时间短。 |
| **无尽「砖塔」** | 砖墙不断下移，打掉一行加分，触底结束；成绩 `save.recordEndlessBest("brick-break", n)`。 |

## 六、2.5D / 3D 决策

**保持 2D**。反弹角度是核心可读性。

## 七、视觉 · 建模 · 手感

- 击砖有 3–5 帧顿感 + 碎片粒子；连击有音高递增（用 `api.play("pop")` 的节奏变化表达）。
- 球有短拖尾，速度越快尾越长（帮孩子预判）。
- 失球是「球滚出去，捡回来再来」，**无失败羞辱文案**。
- `prefers-reduced-motion`：关屏震，粒子减半。

## 八、手机 360px

- 拖板热区在屏幕下半整宽，板子跟随手指但**不被手指遮挡**（手指与板心可有偏移）。
- 关卡目标 / 剩余球一行显示，字号 ≥ 14px。
