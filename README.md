# 🍐 鸭梨康康 👓 · 1.2-kk

给小学生的原创小游戏合集。低年级可以从第 1 关慢慢玩；第 100–188 关和新玩法面向大约六年级。

- 🎨 粉彩萌系界面、大圆角、大按钮，全中文
- 🗺️ **76 款**游戏：闯关 / 休闲 / 对战 / 学习 / 动手
- 🚩 战役关卡从 99 关扩到 **188 关**（老存档自动补齐，进度不丢）
- 👫 双人同屏、人机三档、无尽、2.5D 跑酷
- 🏠 首页可按玩法筛选、搜索、收藏；小屋里能换人物 / 宠物 / 装备
- 🚫 无广告、无内购、无联网账号
- 💾 星星和进度只保存在本机（localStorage），不上传任何数据
- 🎵 音效全部由 Web Audio 现场合成，不依赖外部音源
- 📦 一套代码，四种玩法：网页 / 手机 PWA / 电脑安装包 / 安卓 APK

> 所有游戏均为**原创同类型玩法**，不使用任何商业 IP、商标或角色。两位小主角是 **鸭梨**（女生 Q
> 头像，黑发珍珠耳钉、白蕾丝高领配藏青针织衫）和 **康康**（男生，棕色蓬松刘海、银色圆框眼镜、
> 米白羽绒服）。评分用的「三星 / 星星余额」跟角色无关，仍叫星星。

## 🗺️ 188 关战役

1.0 的 99 关全部保留在前面，一个字没改。1.1 在末尾追加新章节到 **188 关**：

- **章节选关地图**：主题章节一格格点亮，窄屏也能翻页。
- **三星评级**：按表现给 1–3 颗星，随时回头重玩。
- **失败只重试本关**：输了不清进度、不回到开头。
- **家长跳关**：家长门过高权限算术后，可以跳过卡住的关（授权只存在内存里，5 分钟失效）。
- **📖 攻略**：进游戏后可打开侧栏，只讲方法不给现成答案。
- **存档 key 不变**：仍是 `yiduo-yixing.l99.<id>`。老玩家 99 长的星级数组读出来后面补 0，进度不丢。

对战三款（梨康擂台、梨康双人冲刺、鸭梨康康象棋）没有闯关地图，主打双人 / 人机。

需要 Node.js ≥ 22（建议 22.14+）。

```bash
npm install        # 安装依赖

npm test           # 跑单元测试(vitest)
npm run build      # 类型检查 + 构建到 dist/
npm run preview    # 本地预览构建产物
```

当前版本号 **1.2.0-kk**（`package.json`），对外叫 **1.2-kk**。开发线在分支 `1.2-kk`。

## 📱 手机上安装（PWA）——最简单，推荐

1. 把 `dist/` 部署到任意支持 HTTPS 的静态服务器（或局域网内 `npm run preview`）。
2. 手机浏览器打开地址：
   - **iPhone（Safari）**：分享按钮 → 「添加到主屏幕」。
   - **安卓（Chrome/Edge）**：菜单 → 「安装应用 / 添加到主屏幕」。
3. 之后从主屏幕图标打开，全屏运行、支持离线（Service Worker 预缓存）。

## 💻 电脑安装包（Electron）

### ⬇️ 从 GitHub Release 下载（不用装开发环境，推荐给普通用户）

每个正式版本的安装包都由 GitHub Actions 自动打好，挂在
**[Releases 页面](https://github.com/songkang688/game/releases/latest)** 上，下载对应的文件即可：

| 你的设备 | 下载这个 | 怎么用 |
| ---- | ---- | ---- |
| Windows 10/11 | `yiduo-yixing-<版本>-win-setup.exe` | **推荐**。双击安装，开始菜单里会有图标 |
| Windows 10/11（免安装） | `yiduo-yixing-<版本>-win-portable.exe` | 双击直接玩，可以放 U 盘里带走 |
| Mac（M1/M2/M3… Apple 芯片） | `yiduo-yixing-<版本>-mac-arm64.dmg` | 双击打开，把图标拖进「应用程序」 |
| Mac（Intel 芯片） | `yiduo-yixing-<版本>-mac-x64.dmg` | 同上 |
| Mac（不想用 dmg） | `yiduo-yixing-<版本>-mac-<架构>.zip` | 解压出来就是 App，拖进「应用程序」 |
| Linux x64 | `yiduo-yixing-<版本>-linux-x86_64.AppImage` | `chmod +x` 后双击运行 |
| 安卓手机 / 平板 | `yiduo-yixing-<版本>-android-debug.apk` | 传到手机点开安装（需允许「安装未知来源应用」） |

第一次打开的提示：

- **Mac 用户注意**：这些包没有花钱买苹果开发者签名，直接双击会提示「无法验证开发者」。
  请 **右键点图标 → 选「打开」→ 弹窗里再点一次「打开」**，之后就能正常双击了。
- **Windows**：SmartScreen 可能提示「不常见的应用」，点「更多信息 → 仍要运行」即可。
- **安卓**：是 debug 签名的 APK，家里自己装够用。

> 维护者怎么发版（打 tag 触发出包）见 [`docs/RELEASE.md`](docs/RELEASE.md)。

| Linux | `npm run dist` 或 `npm run dist:linux` | `release/yiduo-yixing-<版本>-linux-x86_64.AppImage` |
| Windows 便携版 | `npm run dist:win` | `release/yiduo-yixing-<版本>-win-portable.exe` |
| Windows 安装器（NSIS） | `npm run dist:win:nsis` | `release/yiduo-yixing-<版本>-win-setup.exe` |
| macOS（需在 Mac 上执行） | `npm run dist:mac` | `release/yiduo-yixing-<版本>-mac-<架构>.dmg` / `.zip` |

说明：

- AppImage 下载后 `chmod +x` 即可双击运行。
- Windows 便携版在 Linux 上也能交叉打包；**NSIS 安装器**在 Linux 上打包需要安装 wine，建议直接在 Windows 机器上执行 `npm run dist:win:nsis`。
- 安装包体积约 100–120 MB（内含 Chromium），因此 **不要把 release/ 提交进 git**（已在 `.gitignore` 中忽略）。
- 开发时想直接跑桌面窗口：`npm run electron:dev`。

## 🤖 安卓打包（Capacitor）

`android/` 工程已生成并提交，打 debug APK 的步骤：

1. 安装 Android Studio（或命令行 SDK），确保设置了 `ANDROID_HOME`（或 `ANDROID_SDK_ROOT`），并装好 JDK 17+。
2. 一条命令出包：

```bash
npm run android:apk
```

脚本会依次：构建 Web 产物 → `cap sync android` → `gradlew assembleDebug`。

3. 产物路径：`android/app/build/outputs/apk/debug/app-debug.apk`，传到手机安装即可（需允许安装未知来源应用）。

也可以 `npx cap open android` 用 Android Studio 打开工程后点运行。
正式签名发布请参考 [Capacitor 官方文档](https://capacitorjs.com/docs/android)。

> 注：Capacitor CLI 读取 `capacitor.config.ts` 需要 Node 22+ 的
> `--experimental-strip-types`，仓库里的脚本已自动带上，无需手动设置。

## 🧩 给游戏开发者：游戏模块约定

每个小游戏放在 `src/games/<游戏id>/`：

- `meta.ts`：纯数据（标题、分类、`modes`、`levels`），首页 eager 收集
- `index.ts`：顶部 `export { meta } from "./meta"`，导出 `mount`，进入游戏才懒加载

平台用 `import.meta.glob` 自动收集，**合并进仓库即自动出现在首页**，无需改壳代码。

```ts
import type { GameAPI, GameMeta } from "../../engine";

export const meta: GameMeta = {
  id: "my-game",
  title: "我的小游戏",
  emoji: "🐱",
  category: "casual",     // action 闯关 | casual 休闲 | party 对战 | edu 学习 | create 动手
  color: "#ffd6e7",
  blurb: "一句话介绍",
  modes: ["campaign", "endless"],
  levels: 188
};

export function mount(api: GameAPI): { destroy: () => void } {
  // api.root / api.play / api.addStars / api.getStars / api.onWin / api.onLose
  const el = document.createElement("div");
  api.root.appendChild(el);
  return { destroy() { el.remove(); } };
}
```

引擎还提供可选工具：`createLoop`、`attachCanvas`，从 `../../engine` 导入。
