## 一、现状审查（1.1 收尾时的事实）

| 问题 | 结论 |
| --- | --- |
| 现有题型 | 5 类基础（`vowel` 认韵母 / `initial` 认声母 / `match` 形近找相同 / `tone` 认调号 / `syllable` 看图选音节）+ 1.1 追加 6 类高年级（`whole` 整体认读 / `duoyin` 多音字 / `context` 联系句子定音 / `neutral` 轻声 / `erhua` 儿化 / `sentence` 句子注音）。**缺**：标声调（调号该标在哪个字母上）、拼读组合（声母＋韵母＋调）、找出读音不同的一个、易混淆专项。 |
| 声调标注规则 | `logic.ts` 的 `applyTone` 结果基本正确，但规则是「先找 a/o/e，再特判 `iu`/`ui`，兜底 `search(/[iuü]/)` 取**第一个**」，是三条互相打补丁的分支，不是一条可讲清的规则；也没有单独的「调号落在第几个字母」纯函数可测。 |

| 朗读 | 走 `speech.ts` 的 `speechSynthesis`；`quiz99.ts` 里「🔈 再听一遍」按钮默认 `hidden`，`whenSpeechReady` 回调到了才显示，`speak()` 无中文语音包时返回 false 且零副作用。**降级链路已存在，本次只验证不改坏**；但 1.1 的 `pickAll.ts` 多选关**没有**朗读入口。 |
| `pickAll.ts` / `timed.ts` 占比 | 188 关里挑拣车厢（多选）22 关（只在第 100 关之后、章内序号 %4==3），占 11.7%；限时特快覆盖第 122–188 关共 67 关，占 35.6%。前 99 关两者都不出现。 |
| 易混淆专项 | **没有**。`LOOKALIKE_GROUPS` 只服务「找出和车头一样的」形近题，且是**看形**不是**辨音**；b/d/p/q、n/l、f/h、an/ang、in/ing、z/zh 没有成体系的专项训练。 |
| `guide.ts` 泄题 | **没有泄题**。10 条章节条目全是方法（口型、发音部位、调形比划、先读词再定音），不含任何一题的答案，也能通过 `src/ui/guide.ts` 的 `isAnswerLeak` 过滤。 |

## 二、1.2 要做的事

1. **拼音规则纯函数化（硬性）**：新建 `pinyin.ts`，把标调位置、`ü` 去点、`y/w` 隔音、三拼省写、整体认读音节表全部写成纯函数，逐条单测。`logic.ts` 的 `applyTone` / `stripTone` / `toneOf` 改为转调新模块，对外签名与结果不变。
2. **题型补齐到 8 类**：新增 `tonemark`（标声调）、`spell`（拼读组合）、`odd`（找出读音不同的一个）、`confuse`（易混淆专项），与已有的认声母 / 认韵母 / 整体认读 / 看图选音节凑齐规格要求的 8 类。
3. **专项训练章**：在第 99 关之后插入第 7 章「易混淆专项站」（16 关），专攻 b-d-p-q、n-l、f-h、an-ang、in-ing、z-zh 六组，**每组保证 ≥6 题**（8 个答题关按组分配，一关一组，一关 6–9 题）。
4. **拼读组合车厢**：新建 `spell.ts`，火车车厢式拖拽（声母 / 韵母 / 声调三节车厢拖进插槽，靠近即吸附），也支持纯点击；答对小火车前进并 `play("win")`，答错温和提示不打叉。
5. **错题回顾**：新建 `review.ts`，关卡结束若有错题，用**同类新题**加练一轮；错题类型计数存 `yiduo-yixing.pinyin-train.wrong.v1`。复习轮只加练不判负。
6. **朗读**：`pickAll.ts` / `spell.ts` 补上「自动朗读题干 + 🔈 再听一遍」，无中文语音包时按钮隐藏且照常做题（与 `quiz99.ts` 同一套降级判据）。

## 四、模式矩阵

- `campaign` 188 关保留，**前 99 关题型参数不改**（`levels188.test.ts` 的 fnv 指纹继续钉住）。
- **不做对战**：拼音是「读得准不准」，同屏抢答只会奖励手快的一方，把学习变成反应竞赛，一年级同学之间的识字量差距还会让输的一方持续挫败——与「失败只鼓励」冲突。
- **不做无尽**：题库是有限的教学序列（16 个整体认读音节、19 张多音字卡、6 组易混淆），无限刷只能靠重复出题，练到后面是记选项位置而不是记读音，教学收益为负。

## 五、2.5D / 3D 决策

**保持 2D**。拼音辨认靠的是字形与调号的清晰度，任何透视都会让 `ü` 的两点和三声的小勾变形；禁止 three.js 也在硬约束里。

## 六、视觉与手感

- 拼音字母统一无衬线字体栈，字号 ≥20px（`ü` 的两点在 360px 下可辨的下限按 18px 钉死并写测试）。
- 车厢拖拽有吸附（`nearestSlotIndex` 纯函数，吸附半径可测）。
- 答对小火车前进 + `play("win")`；答错只抖一下车厢并给一句鼓励，不打叉。
- `prefers-reduced-motion: reduce` 时关掉抖动与脉冲。

## 七、平台接线

- `meta.platform` 填 `"both"`，`blurb` 与「11 座车站 188 关 + 拼读车厢 + 错题回顾」的事实对齐。
- `quiz99` / `mountLevelGame` 的跳关（skip）链路原样走框架，不越界改公共文件。
- `level99.ts` / `quiz99.ts` 目前**没有**对外开放「直开第 N 关」的入口（`mountLevelGame` 只接受 `chapters` 与 `playLevel`，`initialLevel` 不在 `LevelGameOptions` 里）。按「不越界改公共文件」的红线，本步**不加**这个参数，只在本目录提供 `resolvePinyinLevel()` 纯函数把 `?level=N` 归一化到 0 基关号，等窗口 1 的平台侧开放入口时直接接上；折中写在回复里。

## 九、落地记录（与计划的出入）

- **「直开第 N 关」比计划做得多一点。** 计划里写「只留一个归一化纯函数，等平台开口子」。实际落地时发现不改公共文件也能接：`runtime.ts` 的 `openLevelOnMap()` 照着地图上已经渲染出来的 `button.l99-tab` / `button.l99-node`（`aria-label` 形如「第 N 关，…」）替玩家点一下，先切章再点格子。章节或格子锁着、或者没渲染出来就返回 `false` 安静停在地图上，绝不因为这一步把游戏卡住。`level99.ts` / `quiz99.ts` / `speech.ts` 一个字未动。
- **实际占比（收尾复算）**：188 关里挑拣车厢 20 关（10.6%）、拼读车厢 4 关（2.1%）、答题关 164 关；限时特快覆盖 54 关（28.7%）。前 99 关依旧既不限时也没有新机制。
- **通用心得并成 6 条**：平台 `copy.test.ts` 限定每本攻略 3–6 条通用心得，1.2 新增三条规则说明后超了，把两条讲声调的并成一条。
