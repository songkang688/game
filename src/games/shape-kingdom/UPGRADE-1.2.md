## 一、现状审查（1.1 收尾时的事实）

### 1. 十章题型与「多步」的真相

| # | 章节 | 关号 | 题型 | 推理步数 |
| --- | --- | --- | --- | --- |
| 1 | 形状城门 | 1–17 | `shape` 看图选名 / `findshape` 听名找图 | 1 |
| 2 | 彩虹染坊 | 18–34 | `color` / `findcolor` | 1 |
| 3 | 大小滑梯 | 35–51 | `size`（＋`shape`） | 1 |
| 4 | 数边小桥 | 52–67 | `sides`（＋`shape`） | 1 |
| 5 | 数数广场 | 68–83 | `countshape`（＋`sides`） | 1 |
| 6 | 国王大赛 | 84–99 | 前五章混合 | 1 |
| 7 | 周长面积镇 | 100–122 | `perimeter` / `area` | 名义 1–2，**无字段** |
| 8 | 对称旋转塔 | 123–144 | `symmetry` / `mirror` / `rotate` | 名义 1，**无字段** |
| 9 | 立体展开馆 | 145–166 | `solid` / `net`（＋`symmetry`） | 名义 1，**无字段** |
| 10 | 坐标方位岛 | 167–188 | `coord` / `path`（＋`area`/`solid`） | `path` 真走 2–3 步，其余 1 |

**结论：后 4 章唯一真正多步的只有方位题（`qPath` 里 `steps = t < 0.4 ? 2 : 3`）。**
缺角 L 形面积算是隐含两步（先整块再减缺口），但代码里既没有「推理步数」字段，
也没有任何一处按步数排布难度——所谓「多步推理」在 1.1 里是章节介绍里的说法，不是代码事实。

### 2. 面积 / 周长纯函数

`rectArea` / `rectPerimeter` / `triangleArea`（直角三角形，底×高÷2）/
`lShapeArea(w,h,cutW,cutH)` / `lShapePerimeter(w,h)` 五个。

- **覆盖**：长方形 ✅、直角三角形 ✅、缺一个角的 L 形 ✅。
- **不覆盖**：两块长方形拼起来的组合图形 ❌、从格子集合直接算面积周长 ❌。
- **单位**：全仓统一「厘米 / 平方厘米」，方格纸每格 1 厘米（`lFigSVG` 里写死了这句），
  没有「格」和 cm 混用的问题。✅
- **隐患**：`lShapePerimeter` 只吃 `w,h`，把「缺角不改变周长」硬编码进函数名里。
  这个结论只对**缺在角上**成立；缺在边中间（凹槽）时周长会多出 2×凹槽深度。
  函数签名没法表达这个前提，误用一定出错。

### 3. `SOLID_NETS`

1.1 的「展开图」根本不是图，是**八句话**（`cube: "6 个一样大的正方形"`…）。
既然没有图形数据，「这张展开图折不成」这种错题当然无从谈起——但**文字本身有一处真错**：

> `cube` = 「6 个一样大的正方形」，`cuboid` = 「6 个长方形，对面两两相同」。

正方形是长方形的特例，所以问「正方体的展开图是哪一个」时，`cuboid` 那句**也成立**，
而 `qNet` 挑干扰项时只排除「文字与答案相同」的，两句话不同，于是**同一道题能出现两个正确选项**。

### 4. `SYMMETRY_AXES` 与 `rotateCells`

- `rotateCellsCW` 的下标推导 `out[r][c] = in[size-1-c][r]` **正确**，转四次回原样，已有单测钉住。
- `mirrorCellsH` **正确**。
- `makePattern` 要求「4 个旋转 + 1 个镜像」共 5 个 key 互不相同，所以正常路径下
  `qMirror` / `qRotate` 的三个选项一定唯一。**但兜底图案是错的**：兜底摆的是 L 形三格骨牌
  `{(0,0),(0,1),(1,0)}`，它的顺时针 90° 恰好等于左右镜像，一旦走到兜底就会出现两个相同选项。
- `SYMMETRY_AXES` 的**数值**基本对（圆 ∞、正方形 4、长方形 2、菱形 2、爱心 1、等腰三角形 1），
  **但画出来的图形对不上**：`SHAPE_PATHS.pentagon` 的五个顶点是
  `50,8 90,38 75,88 25,88 10,38`，边长依次约 50 / 52.2 / 50 / 52.2 / 50——**不是正五边形**，
  只有左右一条对称轴，表里却写 5 条。星形同理没有精确坐标保证。
  也就是说「它有几条对称轴」这一题，**图和答案不一致**。

### 5. 坐标方位的说法

用的是**数对** `(3, 2)`，`formatPoint` 固定「先横后竖」，`coordSVG` 原点在左下角、
横轴向右、纵轴向上。与人教版五年级上册「数对（列，行）」一致 ✅。
不足：坐标格只标了数字，没标「列 / 行」两个字，孩子容易忘记先读哪个。

### 6. 全是选择题

是。188 关每一关都走 `runQuiz`，清一色三选一，**没有任何动手画 / 摆的环节**。

### 7. `guide.ts` 泄题

**没有**。10 条章节条目全是方法（数边再数角、周长是绕一圈、找能对折重合的线、
先折底面再折四周、走完倒着走回去核对），不含任何一题的选项，
也能通过 `src/games/copy.test.ts` 与 `ui/guide.ts` 的 `isAnswerLeak` 过滤。

## 二、1.2 要做的事

1. **几何正确性（硬性）** —— 新建 `geometry.ts`：
   - 从**格子集合**直接算面积与周长（`polyominoArea` / `polyominoPerimeter`），
     与 `rectArea` / `lShapeArea` / `lShapePerimeter` 交叉验算，公式与第一性原理必须对得上；
   - 补 `notchPerimeter`（凹槽在边中间的情形）与 `compositeArea`（两块矩形拼合）；
   - `countSymmetryAxes(顶点表)` 数值求对称轴条数，用它**反过来校验** `SYMMETRY_AXES`；
     对称题改用精确顶点表渲染（正五边形、正五角星、等腰三角形、非正方形的菱形与长方形）；
   - `eulerHolds(V,E,F)` 写成断言，逐个多面体过一遍 V−E+F=2。
2. **折叠校验器** —— 新建 `nets.ts`：
   - 正方体 / 长方体的展开图用**六连方格**表示，`foldsIntoCube` 做真正的三维折叠模拟
     （沿格子走一步就把局部坐标系绕棱转 90°，落到哪个面就占哪个面，六个面各占一次才算过）；
   - 三棱柱 / 四棱锥 / 三棱锥用**面 + 折痕树**表示，`foldsIntoSolid` 做组合校验
     （面的多边形种类计数相同、折痕图是生成树、每条折痕都落在立体真实的相邻面对上、
     折痕两侧棱长相等）；
   - 每张 net 都跑校验，**折不成的直接删掉换对的**；
   - 文字版 `SOLID_NETS` 保留（前 99 关不受影响，老用例照旧），
     但 `qNet` 里把「正方体 ↔ 长方体」两句互斥掉，堵死双正确答案。
3. **作图题（新题型）** —— 新建 `draw.ts`，三类动手题，判定全走纯函数：
   - `rect`：在点阵上拖两个点画长方形，判定按目标周长 / 面积；
   - `symfill`：给半边图案，沿对称轴把另一半补全，判定按**格子集合相等**；
   - `tiling`：把几块多联骨牌摆满目标轮廓，判定按**并集等于轮廓且互不重叠**。
   点阵吸附 12px、实时读数、拖动预览；关卡内错了同类再补一道。
4. **题型补齐到 12 类**：认形状 / 辨颜色 / 比大小 / 数边数 / 数图形个数 / 周长面积 /
   对称轴 / 旋转平移 / 立体展开 / 坐标方位 / **作图补全**（`draw.ts`）/ **分类归纳**（新 `classify`），
   外加一个真正看图的 **`netpick`**（三张展开图里挑能折成正方体的那张）。
5. **难度曲线**：`ShapeQ` 加**可选** `steps` 字段（1/2/3）。每章内前 1/3 单步、中 1/3 两步、
   后 1/3 三步，生成器按 steps 真的换题（例如面积：单步长方形 → 两步缺角 → 三步组合图形）。
   **只给第 100–188 关加**，前 99 关的题目对象一个键都不多，快照才钉得死。
6. **错题回顾** —— 新建 `review.ts`：关卡结束用同一知识点的**新题**复查，
   错题类型存 `yiduo-yixing.shape-kingdom.wrong.v1`，回顾轮只练不判负。
7. **多步提示** —— 新建 `hints.ts`：三级提示①考什么②公式③第一步结果，
   **任何一级都不含答案**（写成用例：答案里的数字不许在任何一级提示里单独出现）。
8. **文案与接线**：`meta.blurb` 已经在 1.1 收尾时改成了「十大王国区域 188 关」，
   **但 `meta.ts` 里那条「blurb 里的『99』是 1.0 遗留文案，归 B 改」的注释还在**，
   注释与代码互相打脸——本步把注释删掉、blurb 按 1.2 的事实重写（补上作图与错题回顾），
   `meta.platform` 按实测填。

## 四、模式矩阵

- `campaign` 188 关保留，**前 99 关题型参数不改**（`upgrade12.test.ts` 用 99 个逐关指纹钉死）。
- **不做对战**：几何推理的答题速度和空间想象力的个体差异极大，同屏抢答只会让空间感发育慢的
  一方持续被秒杀；而且面积、展开图这类题需要在脑子里折一折、拆一拆，被人抢答打断就没了。
- **不做无尽**：本款的教学序列是有限且有序的（先认形状，再量周长面积，再对称旋转，
  再立体展开，最后坐标方位）。无限刷只能重复随机参数，练到后面是记「选项排第几个」，
  教学收益为负。

## 五、2.5D / 3D 决策

立体图形改用**等距斜投影**（伪 2.5D）绘制：顶面 / 左面 / 右面三种明度，棱线加深，
让孩子看清「哪几个面看得见、哪几个面被挡住」。旋转展示用**逐帧预渲染的斜投影序列**，
`prefers-reduced-motion: reduce` 时直接给最终姿态。
**不做真 3D、不引入任何 3D 库**（无 three.js，无 WebGL，无 canvas 3D）。

## 六、视觉 · 手感 · 360px

- 图形高对比描边 ≥ 2px ＋ 填充，**不只靠颜色区分**：新章节的图形按形状套不同 SVG `pattern`
  纹理（斜线 / 网格 / 点阵 / 实心），色觉障碍也能分辨。
  （前 99 关的 `shapeSVG` 因快照契约不动，这条只在 1.2 新增的渲染器上落地，理由写进回复。）
- 点阵作图吸附半径 12px，拖动中实时显示当前周长 / 面积读数与轮廓预览。
- 答对：城堡长高一层 ＋ `api.play("win")`；答错只温和提示，不打叉。
- 360px：作图区 ≥ 280×280px，点的热区 ≥ 44px（视觉半径可以小），
  立体图与选项分行排，选项按钮 ≥ 44px。
