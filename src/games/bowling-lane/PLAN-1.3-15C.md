## 一、现状审美评测(逐行自查结论)

打开 `src/games/bowling-lane/index.ts`,绘制入口 `render` / `band` / `rail` 与 `laneProject`:

1. **透视骨架是好的**:`laneProject` 近大远小、`band`(687–704 行)10 段折线采样会聚形,
   全部保留。但球道面就是一块 `#f7e6c8` 平涂梯形(740 行):没有木板缝、油区只是一层
   半透明蓝(746 行)、瓶台 `#e0c79a` 平涂(748 行)没有灯箱 —— 有骨没有肉;
2. **球瓶 = 白椭圆 + 粉描边**(789–799 行):没有「细颈宽肩」剪影、没有红颈环、没有高光;

3. **球 = 纯色圆 + 3 个白点公转**(810–827 行):白点相位 `spun = b.y / 3` 是「球在转」的
   功能表达(**保住,换成指孔**),但球体没有渐变、没有指孔、没有地板反射;

   是 1.2 留下的好底子,**参数原样常量化保留**;

   几何(贴出手线一条横带)是对的,但颜色贴脸球道色几乎看不见;升级只加深一档,几何不动;
7. **教学线自查(753–756 行)**:口袋双色虚线 `[7,6]`、浓淡走 `guideAt`,是清晰的功能

- 新增 `visual13.ts`:配色板(4.3 表逐 token 落死)、时序表、瓶剪影比例
  (肩 0.42h@0.62h / 颈 0.16h@0.82h / 底 0.3h / 双红颈环 0.78h、0.84h)、
  倒瓶旋转(250ms easeInQuad + 弹跳一次,方向沿受击矢量,reduced 直躺)、
  指孔公转(沿用旧白点相位 `y/3`)、霓虹呼吸(2400ms sin)、全中灯箱闪(3×160ms);

  相邻木板 `blWoodA/blWoodB` 双色、沟槽内壁立面(深 22%)、油区镜面高光带 +
  球经过的倒影拉丝(200ms 渐隐,reduced 不生成)、尽头瓶台灯箱立面(暖光渐变 +
  顶部小星招牌);
