## 一、现状审查(规格第三节,逐条)

| # | 问题 | 现状(1.1 收尾这一版) |
| --- | --- | --- |
| 1 | `physics.ts` 的抛物线是按 delta time 积分吗?蓄力时长 → 初速的曲线是什么? | **不是积分,是解析式**:`positionAt` 直接算 `x=x₀+vx·t+½·wind·t²`、`y=y₀+vy·t−½·g·t²`,`GRAVITY=22`,**没有空气阻力**;风被当成恒定水平加速度。蓄力→初速是 `throwSpeed(power)=10+28·(power/100)` 的**线性**映射,而 `power` 本身来自 `chargeAt(t)`:1.6 秒一个来回的**三角波**(0→100→0),所以真正的输入是「按住多久松手」踩在三角波的哪一格,不是「按住多久 = 多大力」。 |
| 2 | 有没有预测落点圈?瞄准是自由角度还是八方向? | **没有落点圈**。有一条 `drawAim` 的瞄准虚线,把整条轨迹都画出来了——比落点圈还多给,但没有「越远越不准」的表达。瞄准是**准自由角度**:10°–85°,`ANGLE_STEP=3` 一档一档调,不是八方向。 |
| 3 | 有没有「搓雪球」这类节奏机制? | **没有**。闯关是「这一关发你 N 个雪球」,对战与无尽直接 `balls:-1` 无限扔。没有制作时间、没有手持上限、地面积雪不参与玩法。 |
| 4 | 掩体系统:可躲藏、可打碎的雪墙有没有? | **半个**。有两种掩体(`ice` 冰砖 / `snow` 自己堆的雪墙),都能被砸碎(hp 2–4),`buildWall` 花一回合堆一堵。但**没有「躲」的语义**:人站在哪儿和掩体没关系,掩体只是挡飞行中的雪球;也没有木箱、没有雪坡,更没有蹲下半隐藏。 |
| 5 | 四种模式各自的胜负条件?无尽是什么? | `campaign`:清光全部靶子算赢;雪怪走到 `GUARD_X=12` 或雪球扔光还有靶子算输(188 关,`levels.ts` 确定性生成)。`versus`(界面上的「双人对战」)与 `ai`(「人机对战」三档):先把对面三盏雪灯笼砸化的赢,60 回合用完按剩余灯笼数判。`endless`:雪怪一波波来,雪球无限,雪怪走到雪堡结束,`recordEndlessBest` 记波次。四个入口都真的能进,`meta.modes` 没有虚报。 |
| 6 | 双人同屏时两人的准星互不干扰吗? | **互不干扰,但也从来不同时存在**。`angles[]` / `charge[]` 按座位分开,`KEY_MAP` 两套键位零冲突(`keyConflicts()` 返回空),`canAct(seat)` 还要求「轮到你」——因为是**回合制**,同一时刻只有一个人能瞄。规格要的「躲—搓—投」节奏在回合制下根本不存在。 |

一句话:1.1 的雪球大作战是一款**做得挺扎实的回合制炮击游戏**,缺的正好是规格第四节的全部——蓄力手感、落点不确定性、雪球经济、掩体的「躲」、被砸中的实时后果。

## 二、1.2 要做成什么

把这一款从「回合制炮击」升级成**实时的「躲—搓—投」**:

| 项 | 做法 |
| --- | --- |
| 蓄力与落点 | 新 `throw12.ts`:重力 / 空气阻力常量化,定步长 `1/120` 秒**积分**(不再解析式),蓄力 0–1.2 秒经一条单调曲线映射到初速;`landingCircle()` 给出落点圈的**圆心 / 半径 / 模糊度**,越远半径越大越模糊。 |
| 雪球经济 | 新 `economy.ts`:手里最多 3 颗,蹲下搓 0.6 秒得 1 颗,松开 / 被砸中就**清空进度**;地面按格记「积雪厚度」,搓一颗挖掉一层,薄了搓得更慢、挖光了得换地方——这就是「阵地选择」。雪球落地会补回一点点雪。 |
| 掩体 | 新 `covers12.ts`:雪墙(3 下砸碎)、木箱(砸不碎但会被推着走)、雪坡(蹲下时半隐藏,对手的雪球有一半会滑过去)。全是纯函数。 |
| 命中反馈 | 新 `snowman.ts`:被砸中 = 变雪人 1.5 秒不能动(**不掉血、不淘汰**),连中三次进「暖手休息」5 秒再回场、计数清零。已经是雪人的时候再被砸不叠加。 |
| 无尽「雪季」 | `arena.ts` 的 `seasonWave(wave)`:一波波雪人对手,越来越准、越来越多;结束记 `save.recordEndlessBest("snow-fight", wave)`。 |
| 伪纵深 | 保持 2D:掩体与靶子分「近排 / 远排」两排,远排画得小、抬得高,**判定半径按 0.7 收紧**并在 HUD 写明——不做真 3D。 |

## 四、测试(新增 ≥ 18 个用例,目标 40 上下)

- `throw12.test.ts`:定步长可复现、蓄力→初速单调且封顶、空气阻力真的让射程变短、落点预测与实际落地的误差范围、落点圈越远越大越模糊。
- `economy.test.ts`:手上限 3、0.6 秒一颗、搓一半被打断清零、薄雪变慢、同一处挖光要换阵地、雪会慢慢回来。
- `covers12.test.ts`:雪墙三下碎、木箱砸不碎但被推走且推不出界、雪坡只有蹲下才半隐藏、远排判定更严。
- `snowman.test.ts`:1.5 秒不能动、连中三次进 5 秒暖手、暖手完计数清零、当雪人时再被砸不叠加。
- `arena.test.ts`:同种子同输入结果一致、campaign 抽样关实时也打得完、雪怪越线是「结束」不是「受伤」、无尽波次越来越准、双人两套输入互不串、AI 三档强弱有序。
- `runtime12.test.ts`(DOM 桩):蓄力松手真的飞出雪球、落点圈松手前就在、蹲下搓雪 HUD 变化、`?level=` / `initialLevel` / `openCampaignLevel` 直达、Skip 走 `requestSkip`、`destroy` 之后 rAF / window 监听 / 两套键位全部归零。

## 五、分级红线

无伤害、无血、无死亡:靶子化成一摊雪,人只是**变雪人**,连中三次去**暖手**。失败文案只鼓励(「雪怪走到雪堡跟前啦,下次先拦最靠前的那个」),不出现输 / 死 / 血 / 伤 / 疼。无商标、无真人形象。
