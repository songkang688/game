# 第一款:`bumper-cars`

## 一、现状审查(规格第三节,逐条)

| # | 问题 | 现状(1.1 这一版) |
| --- | --- | --- |
| 1 | 撞击是弹性碰撞还是简单反向?质量差体现了吗? | **已经是冲量法弹性碰撞**:`resolveCollision(a,b,e)` 沿连心线解冲量、按质量倒数分配,`CAR_BOUNCE=0.75`、冲刺时 `DASH_BOUNCE=1.15`。质量差**体现了**(重车 `mass=1.9`,`bodyOf` 用 `inv=1/mass`)。缺的是:恢复系数没有边界约束(1.15 已经越过规格要的 0.6–0.8)、没有动量守恒单测。 |
| 2 | 出界 / 击倒判定?会「一撞出局」吗? | 中心越过边缘 `FALL_MARGIN=CAR_R*0.55≈2.3` 就 `dropCar` 立刻判掉,生命减一。`hearts` 多的时候不会退场,但**闯关外的对战 `hearts=1`,确实是一撞出局**。 |
| 3 | 转向手感:坦克式还是有转弯半径?有漂移吗? | **全向推力**(摇杆方向直接给加速度),`face` 只跟着输入转,没有转弯半径也没有漂移。挨重撞会 `skid` 420ms 把油门压到三成,算半个「失控」,但**车头不会自己转**。 |
| 4 | AI 会不会贴墙转圈? | 不会。`chooseCarAction` 把「追人」和「往场心掰」按 `danger` 加权混合,`worldEdge` 一近就压回场内;没轮到出战的走 `patrolIntent` 沿中圈兜。 |
| 5 | 四种模式都能玩到结算吗? | 能。`smoke.test.ts` 已经把闯关 / 双人 / 人机 / 无尽四条路径都无头跑完。 |
| 6 | 触屏是摇杆还是左右转 + 油门? | **虚拟摇杆**(`makeStick`)+ 冲刺 / 刹车两个键,热区 44px。 |

一句话:物理骨架是好的,缺的是规格第四节点名的五件——恢复系数的边界与守恒断言、0.3 秒失控旋转、
蓄力冲撞、三种场地机关、两段式淘汰,外加 AI 从三档扩到四档。

## 二、1.2 要做成什么

| 项 | 做法 |
| --- | --- |
| **撞击物理** | 恢复系数收进 `E_MIN=0.6 / E_MAX=0.8` 并由 `clampRestitution()` 统一夹取(冲刺撞人取 `E_MAX`,不再用 1.15 这种「造能量」的值);`resolveCollision` 保持冲量法,补动量守恒 / 恢复系数边界 / 质量比分配三组单测。 |
| **失控旋转** | 新增 `SPIN_MS=300`:挨到 `SKID_MIN` 以上的一撞就进 0.3 秒失控旋转,`spinFaceAt()` 是纯函数(角速度按冲击强度定,`SPIN_TURNS_MIN/MAX`),这 0.3 秒里油门打折、车头自己转。 |
| **蓄力冲撞** | `charge` 从 `Intent` 进来:按住 `CHARGE_MS=800` 蓄满,松手先有 `CHARGE_WINDUP_MS=180` 的前摇(车明显减速,给对手躲避窗口),再放出 `chargeKick(ratio)` 的强撞,冷却 `CHARGE_CD_MS=2600`。原来的 `dash` 保留成「轻冲刺」。 |
| **场地机关** | 三种纯函数机关:`Spring`(护栏,沿用 `SPRING_BOUNCE`,补 `springBounce()` 纯函数)、`Spinner` 旋转盘(`spinnerEffect()` 改朝向 + 给切向推力)、`Slick` 油渍(`slickKeep()` 把这一格的每秒保留比例抬上去 = 摩擦变小)。各自独立单测。 |
| **淘汰规则** | 两段式:越过边缘先进 `TEETER_MS=2000` 的「打转」,这两秒里往场内打方向能自己开回来;**期间再被撞一下(冲击 ≥ `BUMP_MIN`)立刻出局**,两秒到了还在界外也出局。无尽模式复活上限常量化 `ENDLESS_REVIVES=3`。 |
| **AI 四档** | `AiLevel` 扩到 `1|2|3|4`:1 瞎撞、2 会追、3 会预判走位(按对手速度取提前量)、4 会卡边角逼出界(挑最近的悬崖侧绕位 + 攒蓄力 + 专挑打转中的对手)。固定 seed 胜率断言。 |

2.5D / 3D 决策:**保持 2D 俯视**,只给车身加一点斜投影厚度与撞击形变,不做真 3D(不引入任何 3D 库)。

# 第二款:`bowling-lane`

## 五、现状审查(规格第十二节,逐条)

| # | 问题 | 现状(1.1 这一版) |
| --- | --- | --- |
| 1 | 三段式怎么输入?能反悔吗? | 三条**来回跑的指针**(`sweep` 三角波,1500/1300/1100ms),按确认键停一段。`stepBack()` 能退回上一段,**已经可以反悔**,但只能退一段、也没有 UI 明示。 |
| 2 | 连锁倒瓶是真物理还是查表? | **真物理**:`stepLane` 里球撞瓶、瓶撞瓶都走 `resolveHit` 冲量法,瓶被推离原位超过 `topple` 才算倒。瓶间距 `PIN_GAP=12` / 排距 `ROW_GAP=10.4` / 半径 `PIN_R=2.4` 都是常量,但**排距不是正三角形该有的值**(正三角阵应当是 `PIN_GAP*√3/2 ≈ 10.39`,凑得很近但没写明关系),也没有「正面口袋球能推倒 10 瓶」的断言。 |
| 3 | 旋转怎么影响球路? | `hookAccel(spin, oil)` 给一个恒定侧向加速度,油越厚越拐不动。有手感,但没有「侧旋进袋位」的说法与教学。 |
| 4 | 记分对不对? | **对**。`scoreGame` 全中加后两球、补中加后一球、第十格三投都写了,`running` 还会在未结算处断开。缺的是**把六种边界钉死的单测**。 |
| 5 | 188 关的差异是什么? | 只有「特殊瓶种类 + 数量 + 油量 + 格数 + 目标分」,八章其实是**同一个模板换数字**。 |
| 6 | `twoPlayer` 与 `versus` 的区别?无尽怎么算? | 同一个 `createDesk`,区别只在座位 1 是真人还是电脑。无尽是「一格一格打,某格没够到目标分就结束」。 |
| 7 | 触屏怎么出球?360px 看得全吗? | 点击画布 = 停指针,三次点击出一球;球道**横着画**(球从左出手、瓶阵在右),360px 下看得全但没有纵深感。 |

## 六、1.2 要做成什么

| 项 | 做法 |
| --- | --- |
| **记分正确性** | `scoring.ts` 补 `PERFECT_GAME` / `ALL_SPARES` / `GUTTER_GAME` 三组标准牌面与 `bonusAfter()`,单测钉死:300 满分、全场补中+尾球全中=155、第十格三投、洗沟局 0 分、连续两次全中的进位、空格。 |
| **连锁倒瓶** | 排距改成由 `PIN_GAP` 推出的正三角形常量 `ROW_GAP = PIN_GAP*√3/2`,新增 `PIN_LAYOUT` 汇总常量;单测断言正面口袋球真能连锁推倒 10 瓶、瓶阵是标准三角阵、动量守恒。 |
| **三段出球** | `shotPlan.ts`(新):三段状态机写成纯函数(`advanceStage` / `undoStage` / `resetPlan`),**每段确认前都能撤销、能一路退回第一段**;`traceShot()` 给出可回放的采样轨迹,单测断言同参数同轨迹。UI 加「↩ 重来」键与三段面包屑。 |
| **口袋位教学** | `pocketAimFor(standing)` 给方向不给必中值;`aimGuideAlpha(chapter)` 前两章常驻、越往后越淡到第 7 章归零;球道画凹槽教学线(`gutterGuide`)。 |
| **关卡差异** | 八章各自一个 `LaneVariant`:标准阵 / 3-7 分瓶 / 移动瓶 / 有护栏 / 无护栏 / 油路弯曲 / 限球数 / 连续全中挑战。`BowlLevel` 新增 `variant` `rackMask` `bumpers` `sway` `ballLimit` `strikeGoal` 字段,单测断言八章配置**确有结构性差异**。 |
| **AI 三档** | 高斯噪声(Box–Muller,种子确定)替掉均匀抖动,`AI_SIGMA` 按档定方差:1 档常洗沟、2 档稳定补中、3 档常全中;固定 seed 胜率断言。 |
| **无尽** | `endlessTier(frame) = floor((frame-1)/10)`,**每十格**抬一次难度:球道变窄(`gutter` 变宽)、分瓶更刁、油路更强;单测断言三条曲线单调不降。成绩仍走 `save.recordEndlessBest("bowling-lane", n)`。 |
| **伪 2.5D 透视** | `view25.ts`(新):`project()` / `unproject()` 一对互逆的纯函数,球道画成近大远小的梯形、球随距离缩放。**碰撞判定仍在 2D 俯视坐标系里算**,透视只在渲染层做,不引入 3D 库。 |
