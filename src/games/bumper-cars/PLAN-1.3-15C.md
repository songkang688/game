## 一、现状审美评测(逐行自查结论)

打开 `src/games/bumper-cars/index.ts`,绘制入口 `render` / `drawSprings` / `drawCliffs` / `emojiAt`:

1. **车就是一个 emoji**:主体 = `emojiAt(car.emoji, …)`(约 795 行),复活预告 = 28% 透明度
   的同一个 emoji(746–750 行)。阵营辨识、大小、字形全押在系统 emoji 字库上,不同机器
   长得不一样;
2. **道具全是「圆 + emoji」**:油渍 = 紫色平涂圆 + 💧(689–702 行);旋转盘 = 平涂圆 +
   4 根线(705–723 行);滚桶 = 平涂圆 + 内圈描边 + 🛢️(726–737 行);
3. **场地零厚度**:`traceField` 平涂两层(场外 `#efe8f6` 雾底、已化圈 `#ffd9e7`、地面
   章节色一块),没有围栏立面、没有灯串、没有地板反光,「悬崖」只是一条虚线;
4. **蓄力环 / 冲刺残影是 debug 图形**:蓄力环(761–770 行)纯色圆弧,起点 -π/2、
   `ratio * 2π` 的进度映射是对的(**这个映射原样保住**);残影(752–759 行)纯色圆;
5. **`drawSprings` 自查(573–603 行)**:弹簧护栏 = 单色 `#f5a7c6` 圆头线;round 场地按
   `arc.from/to` 画弧、rect 场地按边画直线。**几何采样是对的**,问题是没有厚度、没有支柱,
   读不出「这是一圈能弹回来的护栏」。升级 = 沿同一几何画两遍(立面 `bcRailSide` 下移 +
   顶面 `bcRail`)再点支柱,几何一行不动;
6. **`drawCliffs` 自查(605–638 行)**:悬崖 = `#c9bde0` 虚线 `[2.2,2.2]`;round 72 段逐段
   跳过弹簧弧、rect 逐边跳过弹簧边。**跳段逻辑是对的**,问题是一条虚线讲不出「掉下去就
   出局」的空间关系。升级 = 融冰断面立面(`traceField(inset)` 下移一小截铺 `bcIceEdge`
   浅蓝 + 裂纹),虚线保留但退居引导层;
7. teeter 倒计时圈(796–806 行)是功能表达,保留;🧹 / 💫 两个点缀 emoji 一并替换成自绘。

## 二、改造方案

- 新增 `visual13.ts`:配色板(3.3 表逐 token 落死)、时序表、纯函数相位
  (squash / 流光 / 灯串 / 降落伞)、车三层 / 道具 / 星星矢量绘制函数;
- 车三层自绘:防撞橡胶圈(深环 + 高光弧)→ 车壳(阵营色三停径向渐变,左上受光)→
  座舱司机(朵朵花发卡 / 星星呆毛 + 扶方向盘的手)+ 车尾集电杆(斜线 + 小旗,
  转向摆动、满蓄竖旗);半径仍是 `car.r`;
- 场地 2.5D:围栏立面双层 + 支柱、四角灯柱 + 灯串(900ms 交替,reduced 常亮)、
  融冰断面 + 裂纹、地板反射斑两块;
- 道具自绘:彩虹肥皂渍(薄膜渐变 + 泡泡两颗)/ 木纹滚筒(横纹 + 端面年轮)/
  唱片机转盘(同心纹 + 中心星标)/ 加速带流光箭头;
- 撞击 squash:压扁 12%、80ms easeOutBack 回弹,只动绘制矩阵,`car.x/y/r` 不碰;
  reduced 关闭、只出星花 1 帧;
- 出局降落伞:时序只读 `RESPAWN_MS`,reduced 直接淡出淡入;
- 图层序:地板+反射斑 → 融冰断面 → 道具 → 车+集电杆 → 星花/彩纸 → 围栏与灯柱 → HUD;
- kit:只 import 既有 `palette` / `volume` / `outline` / `sparkle`;新增 `mirror.ts`
  (地板反光斑 / 倒影)归本档所有;
- 测试只增不减,新增 ≥ 8 条视觉用例;`upgrade12.test.ts` / `ai.test.ts` 等一字不改。
