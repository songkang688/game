## 一、现状审查(规格第三节六问,先给结论)

1. **移动是格子对齐还是自由角度?炮口与移动是否解耦?**
   坐标是连续浮点(`Tank.x/y`),但方向只有上右下左四个轴向(`Dir` 0..3),
   横走时 `moveTank` 会把 y 往车道中线拉(`lane = floor(y)+0.5`),所以是「轴向自由滑动 + 车道吸附」,
   不是整格步进,也没有任意角度。**炮口与移动完全耦合**:`moveTank` 第一行就是 `t.dir = dir`,
   没有单独的炮塔朝向,想只转炮口不挪车做不到。

2. **弹是直线还是可反弹?反弹次数是常量吗?**
   只有直线。`advanceBullet` 每步按 `DX[b.dir] / DY[b.dir]` 推进,撞砖 / 钢 / 堡垒 / 出界一律消失,
   **没有反弹**,自然也没有反弹次数常量;`Bullet` 结构里连速度向量都没有,只有 `dir + speed`。

3. **地图元素有几种?可破坏粒度?**
   五种 tile:`.` 空地、`#` 砖、`S` 钢、`~` 水、`*` 草,外加 `B` 堡垒(`1/2/e` 是出生点标记)。
   **没有冰**。砖的破坏是**整块**:`brickHp = 2`,挨两发整格变空地,没有四分之一格粒度。
   钢是绝对打不动的(没有强化弹这一说)。

4. **基地 / 老巢保护规则?失守判定清晰吗?**
   规则清晰:堡垒在底边正中,开局有一层 `baseShield` 星星护罩替它挡第一发;
   护墙 `scanFort` 记下开局的砖,`fortGaps` 报缺口,玩家按 G / K 用备用砖补回去。
   敌方炮弹打到 `B` 且护罩已碎 → `status="lose"`,`reason="星星堡垒被砸中啦"`。判定单点、可测,没问题。

5. **`coop` 与 `versus` 真能两人同屏打到结算吗?**
   能。`coop` 是选关地图上的「双人合作」开关,`players=2` 时 1 号位出场,两套键位(WASD+F/G、方向键+L/K),
   `sim.test.ts` 已经跑通 188 关双人;`versus` 有独立入口、左右对称地图、先弹飞对方 3 次或时间到判胜,
   `mountVersus` 有结算浮层。**缺的是「可选 AI」**:对战只能两个人玩,一个人来了没有陪练。

6. **AI 会不会卡在墙角?有没有寻路?**
   有寻路,但不是 A\*:`distanceField` 是一张带权 Dijkstra 距离场(砖按 `brickCost` 计价),
   `stepDownField` 顺着往下走。卡墙角靠两个补丁兜:撞不动就 `stuck += dt` 并把重算间隔压到 0.05 秒,
   `stuck > 0.7` 秒才允许拆挡路的砖。实测不会长时间卡死,但**没有强度分档**——
   四种车只有速度 / 装甲 / 冷却和「偷家倾向」的差别,行为模板是同一套,也没有固定 seed 的胜率断言。

## 三、边界

- 分级红线:**铁皮玩具坦克**,发射的是弹力球 / 彩纸弹。没有战争写实、没有碾压、没有爆炸伤人、没有死亡。
  被击中 = 零件散一地,3 秒后修好回场。失败文案只给方法,不评价人。不出现任何同类经典商业作品名。
- 保持 2D 俯视,只允许坦克有一点点斜投影厚度。
- 音效只走 `api.play`;不自建 `AudioContext`,不用 `setInterval`。
- 188 关战役地图由 `levels.ts` 的确定性生成器产出,本次**不动生成器**,
  所以前 99 关(以及后 89 关)的地图快照与既有 `levels.test.ts` 全部保持原样。
