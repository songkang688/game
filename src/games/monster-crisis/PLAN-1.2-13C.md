## 二、现状审查（规格第三节六问）

1. **角色操作是自动出手还是手动？三个手感参数在哪？**
   手动：键盘 `F` / `L`、方向盘上的 🎨 键、以及「手指按住画面」时每次冷却结束自动补一发。
   参数全是 `logic.ts` 顶上的裸常量 —— `HERO_BASE_DAMAGE = 3`、`HERO_BASE_RELOAD = 0.55`、
   `HERO_BASE_SPEED = 3.4`、`HERO_BULLET_SPEED = 9`，只有 `heroDamage/heroReload/heroSpeed`
   三个函数按「主角线」科技等级线性缩放。**「范围」这个参数根本不存在**：颜料弹沿着自己那条道一直飞到
   出屏为止，射程无限、方向唯一，所以手感只有「快慢」没有「远近」和「宽窄」。

2. **升级系统是关内三选一还是关外养成？会不会一条路线碾压？**
   关内，但不是三选一，是**三条科技线的常驻商店**（颜料线 / 炮台线 / 主角线，各 5 级，随时能买）。
   会碾压：颜料线是利滚利（`paintInterval` 与 `jarInterval` 同时变快、上限还涨），
   连本仓自己的无头模拟器 `sim.ts` 的固定策略都写死 `order: ["paint", "tower", "hero"]`，
   主角线排在最后 —— 等于官方策略自己承认「先点颜料」永远不亏。没有随机、没有取舍、没有 build 感。

3. **四种模式各自的胜负条件？`coop` 与 `versus` 真能玩到结算吗？**
   - `campaign`：清完本关全部波次即胜；家门口 3 罐颜料被搬光即负，星级按剩几罐算。
   - `endless`：无胜利条件，颜料被搬光为止，成绩是「清掉的波数」。
   - `coop`：两人共守，清满 `COOP_TARGET_WAVES = 10` 波即胜，颜料搬光即负。
   - `versus`：守家方撑满 `VERSUS_SECONDS = 100` 秒即胜，指挥官把 4 罐颜料抢光即胜。
   四种**引擎层面都能走到 `finish()`**，`coop`/`versus` 也真有结算浮层；1.1 的冒烟脚本只验证了
   「能打开 + 能退回」，没有把 coop/versus 打到结算，所以「能结算」这件事此前没有回归保护。

4. **波次生成是否可复现？无尽是不是只加血量？**
   可复现：`buildLevel` 用 `mulberry32(levelIdx * 7919 + 1013)`，同一关每次出怪表逐条一致；
   无尽 `buildEndlessWave(wave)` 也是按波号播种。无尽**不只是加血**：`endlessRoster` 每两波放一种新怪、
   `endlessBudget` 线性涨预算、每 8 波来一只大怪、血量按 `endlessLevelIndex` 折算等效关号变厚。
   但**没有小 boss 节奏、没有换场景**，界面从第 1 波到第 50 波长得一模一样。

5. **敌人数量上限与对象池：怪多的时候会不会掉帧？**
   **完全没有对象池，也没有任何上限**：`monsters/shots/puffs` 三个数组一律 `push` + `splice`，
   每只怪、每发弹、每团烟都是新对象，果冻怪分裂还会在遍历里再 `push`。
   `stepShots` 是「每发子弹 × 每只怪」的双重循环，`stepMonsters` 里每只怪又要遍历一次整张塔表。
   波次预算涨到后期（无尽 30 波往上）同屏几十只怪时，GC 抖动与 O(n·m) 一起上，低端机必掉帧。

6. **手机上走位是摇杆还是点触移动？**
   两套并行，但都不是摇杆：① 手指按在画布上「牵着走」（按住不放还会连发）；
   ② 画布下面一排 3×3 的方向键。方向键在 ≤420px 的媒体查询里被压到 `min-width:40px;min-height:36px`，
   **热区低于 44px**；`.mc-tip` 压到 10px、`.mc-item` 压到 11px，**字号低于 14px**。
   摇杆不在左下、技能钮不在右下，而是挤在画布下方一整行，占掉了本来就不够的竖屏高度。

## 三、1.2 要做成什么样（与 A / B 的分工）

第 13 步三款互不抄：A `garden-guard` 是格子塔防，B `sprout-defense` 是横排通道 + 种植阵列。
**本款 C 是「玩家角色亲自上场的动作防守」——走位 + 出手 + 关内成长，不布塔、不种苗。**
所以 1.2 把战场从「五条横道 + 摆建筑」改成**俯视竞技场**：家在正中间，小怪物从四面八方围上来，
朵朵在场上自由跑位、手动出手，每 3 波从三张成长卡里挑一张。`meta.blurb` 里 1.1 那句
「摆路障、架炮台」到时候必须跟着改，不能留着骗人。
