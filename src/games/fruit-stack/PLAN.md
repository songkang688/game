## 一、这一款是什么

连续坐标下的**圆形物理堆叠 + 同级相碰合成**。不是网格合成，也不是叠高塔：
落点由重力、弹性、摩擦和已有果堆的形状决定，同一等级的两颗果子碰在一起就升一级。

- 不碰 `fruit-catch`（接水果）、`fruit-slice`（切水果）、`dot-maze`、`pool-stars`。
- 不引入任何物理引擎依赖，圆-圆冲量与圆-墙反射全部自写。

得分 `scoreFor(level, chain) = BASE[level] * (1 + 0.5 * (chain - 1))`，向下取整；
`chain` 是这一次连锁的第几节（第一节是 1）。

最高级规则：两颗「团圆瓜」相碰按常量 `TOP_RULE = "clear"` 处理——**两颗一起变成星星散开并加 `TOP_CLEAR_SCORE = 200` 分**，
这样牌面不会被三颗以上的团圆瓜彻底堵死。单测锁死这条规则。

## 三、物理参数表（固定 dt 子步进）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `SUB_DT` | 1/120 s | 固定子步长；一帧按累计时间跑 1–4 个子步，超出部分丢弃 |
| `MAX_SUBSTEPS` | 4 | 一帧最多 4 个子步，切后台回来不会一次算爆 |
| `GRAVITY` | 1500 px/s² | 向下 |
| `RESTITUTION` | 0.16 | 圆-圆与圆-墙共用；「弹力果」章节抬到 0.42 |
| `DAMPING` | 0.88 /s | 每秒保留的速度比例，按子步换算成 `pow(0.88, dt)` |
| `FRICTION` | 0.28 | 圆-圆切向库仑摩擦系数 |
| `WALL_FRICTION` | 0.22 | 圆-墙切向摩擦 |
| `CORRECTION` | 0.8 | 位置纠正比例（只推位置，不加速度，所以不会造能量） |
| `SLOP` | 0.05 px | 允许的微小穿透，避免抖动 |
| `SETTLE_SPEED` | 14 px/s | 低于它才开始累计静止时间 |
| `SETTLE_MS` | 380 ms | 连续低速这么久算 settled |
| `GRACE_MS` | 900 ms | 刚落下的宽限期，期内不参与越线判定 |
| `MERGE_SLOP` | 1.5 px | 圆心距 ≤ ra+rb+slop 视为相碰 |
| `PULL_MS` / `POP_MS` | 130 / 80 | 吸合 + 弹出，合成总时长 210 ms；`prefers-reduced-motion` 下缩到 55 / 35 |
| `BOX_W` × `BOX_H` | 300 × 430 | 基准容器；「窄瓶」章节压到 226 |
| `LINE_Y` | 96 | 警戒线；「警戒线」章节降到 76 |
| `WARN_MS` | 900 ms | 快越线时警戒线先闪这么久 |

**不会爆能量的理由**（写成断言）：

1. 积分只做 `v += g*dt`、`x += v*dt`，没有任何显式的位置修正回灌速度；
2. 重叠分离只改位置不改速度，所以它对动能的贡献恒为 0；
3. 圆-圆冲量按 `j = -(1+e) * vRelN / (1/ma + 1/mb)`，`e ≤ 1`，法向相对速度只会被反向缩小；
4. 切向摩擦冲量同时被库仑上限 `μ|j|` 和「刚好抹平切向相对速度」的值夹住，绝不会反向加速；
5. 墙面反射同样是 `v = -e * v`，`e ≤ 1`；
6. 阻尼每子步乘一个 `≤ 1` 的系数。

综合起来：关掉重力时，**总动能对子步单调不增**。`physics.test.ts` 连续跑 100 个子步逐步断言。
