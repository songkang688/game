## 现状审美评测(第三节逐函数结论)

| 函数 | 现状结论 |
| --- | --- |
| `drawHero` | 两位主角**同一个圆**:纯色平涂 `ICE_BODY` / `FIRE_BODY` + 描边 + 两点眼 + 笑弧;唯一区别 = 换色 + 头顶小尖(冰三角、火一撇)。剪影完全一样,16px 灰度下不可分 —— 主管点名的「草稿圆」反面教材。当前控制角色的虚线圈(功能件)要保住。 |
| 借位小云朵 | 三个白圆 + 两点眼,能用但偏硬,可以更软(加腮红与眯眯眼,不改云朵判定与时序)。 |
| `drawParallax` | 三层远景就是三排白色半透明圆(`#ffffff5c` / `#ffffff44` / wallTop),号称「森林」一棵树都没有。视差比例 0.18/0.34/0.55 本身是对的,保留。 |
| `drawTile` | 地板纯色 + 1px 网格线;墙是双色圆角块,尚可但无立体感。 |
| `drawGem` | 单色菱形平涂 + 描边,无切面、无高光。 |
| `drawIcePool` | 圆角池 + 三道波纹 + 雪花,形状语言(圆角 vs 尖角)是对的,但纯平涂,无镜面反光、无池沿霜花。 |
| `drawLavaPool` | 16 齿尖角星 + 两粒深色点,无流动高光、无气泡、无池沿描边层次。 |
| `drawSlime` | 圆角方 + 两粒点,平涂。 |
| `drawGate` | 关门 = 圆角块 + 三竖线,开门 = 虚线框;无石框立面、无开门反馈。 |
| `drawKit` / `drawLinks` | 功能件(按钮圈、传送门、升降台、木箱、光路虚线),逻辑一律不动,只在质感上顺手描边。 |
| `drawCheckpoints` | 竖光带 + 🚩 emoji fillText;改为程序化飘动小旗(900ms sin,reduced 静止),HUD 的「🚩 n/m」文案不动。 |
| `drawArrows` | 功能件,保留;只加白色衬边提升可读性。 |

## 动工顺序(每条一个 commit)

1. `feat(ice-fire-forest-visual)`: 配色板(四·补一)与图层序、动效时序表(四·补三)常量块 —— `visual13.ts`;
2. `feat(ice-fire-forest-visual)`: 双角色剪影重绘(`heroSilhouette` 两套参数:凛凛水滴形 + 雪晶发饰 + 围巾,焰焰火苗形 + 火簇发型 + 腰带);
3. `feat(ice-fire-forest-visual)`: 森林三层视差替换白圆(远层树冠 / 中层树干蘑菇 / 近层草藤),冰火半场色温过渡;
4. `feat(ice-fire-forest-visual)`: 两池 / 机关 / 宝石质感(岩浆高光条与气泡、冰池镜面带与霜花、石框立面与开门尘土、宝石切面与旋转闪点);
5. `feat(ice-fire-forest-visual)`: 特效 / HUD(集合点旗帜、箭头衬边、HUD 双人头像卡片)+ reduced 接线 + destroy 清理;
6. `test(ice-fire-forest-visual)`: ≥ 12 个视觉用例。

## 红线自查

- 渐变 / 描边 / 落影统一走 `src/art/kit/`(palette / volume / outline 只 import 不改);
- 光源统一左上 45°;冰阴影冷蓝 `rgba(110,150,200,.16)`、火阴影暖褐 `rgba(160,110,80,.16)`;
- `prefers-reduced-motion`:火苗跳动、围巾摆动、气泡、闪点、尘土、旗帜全停,静态渐变与 rim light 保留;
- 与《森林冰火人》原版拉开差异:不用「头顶水滴 / 火焰」的经典头形,凛凛是水滴**身形** + 六角雪晶发饰,焰焰是火苗**身形** + 三簇小火苗发型,配色回到本库粉彩;
- 无坠落受伤表达:进池仍是「变小云朵换个地方接着玩」。
