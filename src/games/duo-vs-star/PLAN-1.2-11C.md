# 11-C · `duo-vs-star`「朵朵大战星星」1.2 升级计划

对着 `docs/plan-1.2-step11-C-duo-vs-star.md` 写，只动 `src/games/duo-vs-star/**`。
本款 1.1 已经很厚（12 位角色 / 10 张场地 / 14 种道具 / 188 关 / 五模式全在），
1.2 的活是**平衡与打磨**，不加新系统。

## 一、现状审查结论（动代码前先看过一遍）

| 问 | 现状 |
| --- | --- |
| 角色平衡 | `roster.ts` 体重 72–132、速度 0.82–1.24、力度 0.80–1.24，**四条数值线各走各的，没有交叉验证过胜率**；轻角色（啾啾 72 / 云云 78）撞飞距离吃 `WEIGHT_REF / w` 的除法，理论上会被拉开 |
| 击退公式 | `launchSpeed` 已有 `MAX_LAUNCH` 封顶，但**没有「元气 → 击退距离」的可读分档**，也**没有低元气的挣扎窗口**——被打到高击退值时只能干看着 |
| 道具 | `spawnItem` 的落点是 `zone.min + 30 + rand * (宽 - 60)`，**纯随机、不镜像**，连着几次偏一边就是白送；软软锤子拿到即 ×1.9 力度，**没有任何前摇**，是唯一能直接终结对局的道具 |
| 五模式 | 都能跑到结算；但 `coop` 只是 2v2 各打各的，**没有任何非要两个人才做得到的动作** |
| AI 档位 | 三档差距靠 `think / mistake / ledgeCare / passive`，能量化；后段战役靠 `powerBonus` 一路加数值堆难度 |
| 键位 / 触屏 | `keys.ts` 两张表零交集，同屏不抢键；触屏只有 ◀ ▲ ▶ ✋ 💥 五个键，**没有 ▼**，也没有配合键 |

## 二、要做的事

1. **平衡表**：新增 `balance.ts`，用 `knockback.ts` 的真实公式跑确定性循环赛
   （12 人两两对阵，每对 ≥ 20 局，固定 seed），胜率矩阵写死进测试；
   **任何角色总胜率必须落在 40%–60%**，超出就回头调 `roster.ts` 的数值。
2. **击退曲线**：抽 `knockbackDistance()` 纯函数 + `KNOCKBACK_TABLE` 分档表（元气 100 → 0），
   距离封顶，杜绝「一击必出界」；低元气时给 `STRUGGLE_WINDOW = 0.4` 秒挣扎窗口。
3. **道具公平**：落点改成**左右轮流、镜像对称**（`itemSpawnX` 纯函数）；
   软软锤子改成**要蓄力 `HAMMER_CHARGE` 秒才生效**，捡到不再是立刻定胜负。
4. **合作模式**：新增 `coop.ts`——**顶举**（队友踩在头顶时按上，把他送上去）与
   **接应**（按下 + 副动作，把飞出去的队友拉回场地）；配 3 关「合作特训」，
   过关条件只认配合动作次数，**一个人怎么按都过不了**。
5. **战役 188**：不动关卡数据结构，把后段的数值堆叠压平，改成三种新行为
   （`flank` 会绕后 / `greedy` 会抢道具 / `patient` 会等你出招）。
6. **打磨**：元气条颜色 + 数值双通道；命中顿帧 ≤ 6 帧、弱化动效下为 0；
   出界演出改成小星星飞走；触屏补 ▼ 与 🤝，360px 下 HUD 折两行、长名字缩写。
7. `meta.platform` 按实测填 `"both"`，`blurb` 与事实对齐。
