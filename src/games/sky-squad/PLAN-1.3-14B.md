# 1.3 第 14 步 · B 档 —— sky-squad「飞机小队」视觉升级计划

工作分支 `game-1.3-window5`,基线 `origin/game-1.3`。只改视觉表现:
一行玩法逻辑、一个判定数值、一条关卡数据都不动。禁止 three.js、禁止位图大文件,
全部程序化绘制。独占范围:`src/games/sky-squad/**` 与新增的 `src/art/kit/*` 文件。

## 一、现状审美评测(逐函数结论)

打开 `src/games/sky-squad/index.ts` 逐行读完绘制层,确认的问题:

1. **`drawPlane`(1409 行起)**:主机 = 两个纯色椭圆机翼 + 一个 `roundRect` 机身 +
   白椭圆驾驶舱 + 一个色点。通体没有一处渐变、描边或高光;粉 / 蓝两架只换
   `fillStyle`,灰度下剪影完全相同,像两粒药丸。
2. **僚机(1467–1478 行)**:16×24 的圆角矩形加一个 2.4px 圆点,连机翼都没有,
   和主机没有任何「同一支编队」的视觉血缘 ——「小队」的僚机比主机还敷衍。
3. **`drawFoe`(1481 行起)**:四种敌机 = 三角形(scout)/ 圆加两圆(puff)/
   菱形(kite)/ 圆角矩形(tanker)纯色几何 + 两颗定位眼。剪影之间只差一个
   多边形,没有任何「飞行器」特征:机翼、尾翼、吊篮、骨架全无。
4. **尾焰(1431–1437 行)**:单个三角形 `rgba(255,214,120,.85)` 正弦抖动
   (`Math.sin(clock*24)*4`,基长 12),没有内焰 / 外焰层次。
5. **画面没有纵深**:云只有两层椭圆(16 / 30 px/s),没有三档视差、没有飞机在
   云上的投影;天空是「白 → tint」两停渐变,没有大气层次。
6. **`drawBoss`(1529–1591 行)逐行读完的问题**:
   - 主体是**一个纯色椭圆**加白肚皮和两颗眼,没有底盘 / 主体 / 炮台的分层,
     没有渐变,54 半径的大家伙看上去和放大的 puff 敌机没区别;
   - 蓄力提示只是描边从白换成金色(1545 行)加整体缩放,没有「红晕渐亮」这种
     越来越紧张的连续信号,`cueLeft` 的时间信息只靠下面那根倒计时条;
   - 受击反馈是 `Math.sin(clock*60)*3` 的整体平移抖动,无闪白 / 无层次;
   - 元气条是两个圆角矩形叠一起,无壳、无描边,刻度线直接压在条上;
   - `fillText` 画 emoji 在机身正中,和「炮台剪影」的规格差距很大。
7. **弹幕**:敌弹无拖尾(一帧一个位置,高速弹有「跳格」感);我方弹是纯色
   三角 / 圆角条,无星星头、无光带尾。
8. **HUD**:`.sks-chip` 是纯白 999px 胶囊,无卡片层次、无描边。

## 二、改造方案(对齐 step 规格)

- **常量块**:新增纯视觉模块 `src/games/sky-squad/art.ts`,落 `SKS_PALETTE`
  (四·补一的 9 个 token)、三档视差 0.2/0.5/0.9、图层序 ①–⑨、翼灯 800ms、
  侧倾 120ms/0.82、投影 0.12 与 0.8–1.15、内焰 0.6、拖尾 3 帧、烟圈 360ms。
  无魔法数散落。
- **共享套件**:`src/art/kit/` 远端尚未有人落文件,本步新增并自带单测:
  `palette.ts`(`shade`)、`volume.ts`(`ballGradient`/`softShadow`)、
  `outline.ts`(统一 1.5–2px 深 20% 描边)、`parallax.ts`(云层滚动器)。
- **2.5D 天空**:三层云海视差(高空薄云 0.2×、中层棉花云 0.5× 带底影、
  低层大朵云 0.9× 边缘受光,透明度 ≤ 0.5),飞机在中层云上投 0.12 椭圆影,
  随 y 在 0.8–1.15 之间缩放。
- **主机七道工序**:云上投影 → `planePath(scale)` 后掠机翼(贝塞尔前缘)→
  机身三停渐变 + 1.5px 描边 → 舱盖斜高光 → 翼尖红绿灯 800ms → 双层尾焰
  (外焰沿用 1.2 抖动参数、内焰 0.6×)→ 水平侧倾 `scaleX` 0.82 只包在
  save/restore 内。粉 / 蓝翼形与尾翼双通道区分。
- **僚机**:`planePath(0.55)` 缩小剪影复用 + 半透明牵引光索连到主机。
- **敌机**:纸飞机 / 气球飞艇 / 风筝 / 运输艇四种新剪影,几何全部落在原
  `info.r` 判定半径内,受光面 + 1.5px 描边。
- **BOSS**:底盘暗色 → 主体三停渐变 → 顶部炮台小剪影;`cueLeft` 映射外圈
  红晕渐亮;元气条加圆角壳与分段刻度。
- **弹幕**:敌弹 3 帧拖尾渐隐;我方弹星星头 + 光带尾。
- **HUD**:chips 卡片化(圆角 12px、白 72% 底、1.5px 描边)。
- **reduced**:视差 0、侧倾关、翼灯常亮、装饰粒子 0;拖尾与蓄力红晕保留
  (功能可读性)。`destroy` 清干净滚动器与粒子。
