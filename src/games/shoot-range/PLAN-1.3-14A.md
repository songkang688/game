## 一、现状审美评测（逐函数）

### `drawField`（index.ts 1310–1457 行）

现在画了：天空两停线性渐变（`SKY_TOP` → 章节 tint）、4 个 45% 白的半圆「小山」、
y=236 一条 35% 白的细带充当「远排台子」、y=520 起两块纯色绿矩形当草地、
木板障碍（平涂 `#D9B892` 圆角矩形）、倒下的靶、远排靶 → 近排靶、彩纸方块粒子、
飘分、弹道、发射台、准星、装填条。

缺什么：没有一点嘉年华的「剧场感」——没有帐篷天幕、没有彩旗、没有木质横梁与柜台；
「远」只有一条白带 + 白雾圈，纵深基本靠猜；图层是随手插的，没有归层约定；
全场没有统一光源与落影。

### `drawTarget`（index.ts 988–1246 行）

- `bull`：4 圈平涂同心圆（`#FFFFFF/#FFC9DC/#FFFFFF/#F4859F`）+ 中心点 + 一根
  `#C9A98F` 平涂矩形当杆——没有靶框、没有支架、没有受光面，典型「草稿圆」。
- 远排（992–998 行）：只垫一圈 45% 白雾 + 半径缩小，没有地平线、没有落影。
- 离场（999–1001 行）：只有 `globalAlpha` 正弦闪烁，没有任何离场动画。
- `balloon`：平涂椭圆 + 一枚白斑 + 细线绳，无体积渐变。
- `ufo`：两个平涂椭圆 + 5 个圆点灯，无高光、无金属感、无落影。
- `robot`：平涂圆角矩形 + 天线 + 两点一线的脸，无接缝、无光影。
- `number`：平涂圆角方块 + 数字，无边框层次。
- `split`：85% 透明蓝圆 + 两个白描边小圆——「会分裂」的剪影不成立，缩小后像普通泡泡。
- `shield`：平涂粉圆 + 一圈紫描边（整圈/断续两态）——「盾罩」没有体积，裂纹只是断弧。
- `rainbow`：6 条描边半圆带 + 剩余时间弧——静态，没有扇形七彩环、没有自转。
- `flower`：5 片平涂椭圆花瓣 + 笑脸 + 茎——可爱但全平涂，无受光面与叶子。
- `friend`：平涂圆脸 + 旗子，可读但同样是纯色几何拼贴。

### `drawCrosshair`（index.ts 1249–1288 行）

现在画了：连击光环（单圈描边）、准星圆圈、6 片绕圈自转的小花瓣、中心点、双人名字。
缺什么：两个人准星同形只换色（朵朵/星星剪影不分）、没有呼吸外圈、
散布只映射到圆半径而没有「爪张开」的形体语言、金环只有单通道单圈。

### `drawLauncher`（index.ts 1291–1308 行）

现在画了：粉色平涂圆角矩形 + ink 描边 + `fillText("★")` 一个字形星。
缺什么：无木质纹理、无体积、星星是文本字形不是自绘矢量。
