# 13-B `sprout-defense`「绿芽保卫战」1.2 升级计划

对应规格:`docs/plan-1.2-step13-B-sprout-defense.md`(第 13 步 B 档)。
本窗口(window3)工作基线是 `origin/game-1.2-window3`,只往这条线推。

三连分工:A `garden-guard` 是格子布塔的经典塔防,C `monster-crisis` 是角色主动战斗,
**本款是「横排通道 + 阳光/露水双资源 + 种植阵列」的防守**。三份互不抄、不共用文件。

## 一、现状审查(规格第三节六问)

1. **几条通道、几种绿芽、资源曲线**
   `LANES = 4` 条横排通道、`PLANT_COLS = 8` 列种植位;绿芽 9 种
   (闪光芽 / 泡泡芽 / 果果墩 / 星星芽 / 冰冰花 / 爆爆果 / 荷叶垫 / 望望草 / 月月菇)。
   资源**只有露珠一种**,没有阳光:被动每 `3.5s × 场景倍率`(白天 3.5s、星夜 6.48s、
   沙滩 2.98s)出 1 滴,黑夜再 ×1.45;闪光芽 4.5s 出 1 滴,月月菇仅月光时段 3.0s 出 1 滴;
   清掉一只虫 +1。消耗 1~4 滴,新章有露珠罐上限(`dewCap` + 每株产露植物 +3)。
2. **有没有「万能绿芽」**
   有,而且是硬伤:冰冰花与星星芽同价 3 滴,`SHOOT_CD` 是全局常量 1.3s 所以射速一样,
   两者都打得到飞的,冰冰花还白送减速 —— **冰冰花严格支配星星芽**;
   星星芽又只比泡泡芽贵 1 滴却多了对空,露珠一宽裕就没人再种泡泡芽。
3. **敌人是不是只有直线推进**
   基本是。只有钻钻虫会跳过遇到的第一棵植物、地地虫钻在土里(要望望草照)、
   飘飘虫/扑扑蛾会飞。**没有「挖地绕到后排出土」,带甲只是数值不是「破盾」机制,
   而且所有虫都是直接出现在最右边,零预警。**
4. **188 关后段是加数值还是加机制**
   以机制为主:`bugHp` 在第 100 关回落再缓爬,新章靠昼夜循环 / 地下虫 / 露珠上限 /
   分裂虫撑难度。但**关卡类型只有一种**(波次防守),章内差异仍靠波数与数值。
5. **铲子与误触保护**
   有铲子(`shovelRefund` 退半价),**没有任何误触保护**:选中铲子点一下就铲掉。
6. **手机两步操作顺不顺**
   有「先点卡再点格子」的提示条和绿色 ➕ 高亮,方向是对的;但 360px 上
   卡片宽 `(w-100)/10 ≈ 26px`,远小于 44px 热区,卡片也没有冷却圈;
   通道高 `min(w/9.6, (h-64)/4) = 37.5px < 40px`,同样不达标。

## 二、1.2 施工清单

### 1. 阳光 / 露水双资源(本款与 A、C 的分界线)

- 💧 露珠:沿用被动 + 闪光芽 + 月月菇 + 清虫掉落。
- ☀️ 阳光:**新增**,只有产资源类的「暖暖花」会开(亮场景/白天快、黑夜慢),
  高阶绿芽(蓬蓬花、弹弹网)要花阳光。前 99 关不解锁任何吃阳光的绿芽,**老关一点不受影响**。
- 两种流派:纯露珠速攻 vs 先铺暖暖花再上溅射/防跳的稳扎稳打,靠模拟器双策略验证。

### 2. 绿芽体系:12 种,四类 + 辅助

| 类 | 绿芽 | 露珠 | 阳光 | 冷却 | 定位 |
| --- | --- | --- | --- | --- | --- |
| 产资源 | 闪光芽 / 月月菇 / **暖暖花**(新) | 1 / 2 / 3 | 0 | 3 / 3 / 6s | 露珠、夜露、阳光 |
| 直射 | 泡泡芽 / 星星芽 / 冰冰花 | 2 / 3 / 3 | 0 | 2.5 / 3.5 / 4s | 便宜对地 / 快速对空 / 慢速减速 |
| 溅射 | **蓬蓬花**(新) / 爆爆果 | 2 / 4 | 2 / 0 | 5 / 9s | 持续小范围 / 一次性大范围 |
| 阻挡 | 果果墩 / **弹弹网**(新) | 2 / 2 | 0 / 1 | 4 / 5s | 厚墙 / 会跳的跳不过、挖地的钻不过 |
| 辅助 | 荷叶垫 / 望望草 | 1 / 2 | 0 | 1.5 / 4s | 水路铺垫 / 照亮整道 |

- 每种绿芽单独的射速(`SHOOT_CD_BY_KIND`)与冷却,解掉「冰冰花支配星星芽」。
- 攻略里给一张对照表;测试用能力矩阵断言**没有任何一种绿芽在所有维度上压过别人**,
  并用「只准种一种绿芽」的模拟跑一遍中段关卡,一种都赢不了。

### 3. 敌人四类机制 + 预警

| 机制 | 虫 | 玩法 | 预警 |
| --- | --- | --- | --- |
| 带盾 | 壳壳虫 / 桶桶虫 | 先打碎盾才掉血 | 出场前 3 秒该道亮盾牌角标 |
| 跳跃 | 钻钻虫 | 跳过第一排阻挡;**弹弹网跳不过** | 弹簧角标 |
| 挖地 | **哧溜虫**(新) | 进场就钻地,3.5s 后从第 2 列出土绕过前排;有弹弹网就只能在网前出土 | 出土点提前冒土花,整段钻地都看得见 |
| 飞行 | 飘飘虫 / 扑扑蛾 | 只有对空绿芽打得到 | 翅膀角标 + 高空影子 |

预警统一走 `buildWarnings(schedule)`,提前 `WARN_LEAD = 3s`,测试断言**每一只带机制的虫
都有预警**,不许突然袭击。

### 4. 三种特殊关,每种 ≥6 关

188 关总数不变(**不加关也不删关**),从新四章的虫潮关里挑出 24 关改成特殊关:

- **解谜关**`puzzle`:没有露珠收入,只给一份固定苗库存,考位置不考手速。
- **传送关**`conveyor`:传送带每隔几秒送一株苗进队列(最多 5 张),不花资源,来什么用什么。
- **速攻关**`blitz`:波次间隔压缩,必须在限时内清完全场。

每种 8 关(4 章 × 2),全部落在第 100 关之后。

### 5. 无尽「守到天亮」

波次无限,`endlessWave(n)` 逐波加量加种类,天色从深夜一点点泛白,第 20 波日出后继续加场;
撑过几波就 `save.recordEndlessBest("sprout-defense", wave)`。

### 6. 手感 / 视觉 / 手机

- 保持 2D 横排俯视;种植时格子高亮 + 半透明预览苗,不可种给原因(冷却 / 资源不足 / 已有)。
- 清虫是「打个喷嚏跑回家」,无血无伤无死亡;最后一只有小庆祝;波间 3 秒布置时间与提示。
- `prefers-reduced-motion` 关抖动。
- 卡片条横滑一行,卡片 ≥ 44px 且带冷却圈;顶部一行资源与波次字号 ≥ 14px;
  通道高保底 40px(格子改成宽高分离,窄屏也不挤)。
- 铲子二次确认(2.5 秒窗口),防误铲。

### 7. 平台接线与红线

- `openCampaignLevel(n)`、`api.initialLevel` / `?level=`、Skip 走 `requestSkip`(本关 0 星并解锁下一关)。
- `meta.modes` 补 `"endless"`;对战不做 —— 本款是单人布阵防守,一块屏上两个人各守四条道
  会把 8 条道压到手机上每条不足 30px,判定与可读性都保不住,**故不做对战**。
- 只改 `src/games/sprout-defense/**`;CSS 类名一律 `spd-` 前缀、局部 `<style>`,不碰 `src/styles.css`。
- `destroy` 清 rAF / 监听 / 朗读 / 局内状态。

### 8. 测试(新增 ≥ 20 个用例)

绿芽数据表与四类齐备、无支配苗(能力矩阵 + 单苗模拟)、四类敌人机制与预警、
三种特殊关规则各自成立、资源曲线 20 秒内能开种、两种流派都能赢、
188 关抽样可解(含 100 / 145 / 188)、无尽递增、`destroy` 归零。
